# Лекция: RASP и FreeRASP — защита мобильных приложений на уровне runtime

## Введение

В современном мире мобильной разработки обеспечение безопасности приложений становится критически важным. С ростом числа атак, направленных на взлом мобильных приложений, важно внедрять меры защиты на всех уровнях — от разработки до эксплуатации.

Одним из подходов к повышению безопасности является **Runtime Application Self-Protection (RASP)**. Это технология, которая позволяет приложению защищать себя в режиме выполнения, обнаруживая и предотвращая попытки взлома, атаки на уязвимости, а также подозрительные действия в реальном времени.

Эта лекция посвящена RASP и FreeRASP — свободной реализации технологии, применяемой в мобильных приложениях Flutter. Мы рассмотрим:

1. Что такое RASP и FreeRASP
2. Как интегрировать FreeRASP в Flutter-проект
3. Как определять угрозы с помощью RASP

---

## 1. Что такое RASP и FreeRASP

### 1.1. Введение в RASP (Runtime Application Self-Protection)

**RASP (Runtime Application Self-Protection)** — это подход к обеспечению безопасности, который интегрирует защитные механизмы прямо в саму среду выполнения приложения. В отличие от классических систем защиты (например, WAF или SIEM), RASP работает на уровне выполнения, то есть **в момент работы приложения**, а не только на уровне входящих данных или сетевого трафика.

RASP позволяет:

- Обнаруживать попытки взлома, в том числе через дампы памяти, динамическое изменение кода (DEX/bytecode), обход авторизации.
- Предотвращать атаки, такие как:
  - Реверс-инжиниринг
  - Декомпиляция
  - Прямой доступ к API
  - Манипуляции с данными
  - Подделка сертификатов
  - Использование Root-инструментов

### 1.2. FreeRASP — открытая реализация RASP

**FreeRASP** — это бесплатная, открытая реализация технологии RASP, разработанная специально для мобильных приложений. Он позволяет внедрить в приложение механизмы защиты от распространённых атак и обнаружения подозрительных действий без необходимости покупать платные решения.

FreeRASP работает на уровне:

- **Детекции Root-доступа**
- **Обнаружения прокси/антивирусов**
- **Мониторинга поведения приложения**
- **Защиты от динамического кодирования (JIT/Reflection)**
- **Использования инструментов отладки**

## 2. Интеграция FreeRASP в Flutter

FreeRASP не является стандартной библиотекой, и для его использования в Flutter необходимо:

1. Использовать специализированные **Flutter-плагины** или
2. Внедрить нативные компоненты (Android/iOS) через методы взаимодействия с Dart.

### 2.1. Подключение FreeRASP через Flutter плагин

Существует несколько способов подключить FreeRASP в Flutter:

#### Способ 1: Использование готового пакета (например, `flutter_rasp`)

> **Примечание**: На момент написания этой лекции таких пакетов нет в официальном репозитории pub.dev. Однако можно использовать нативные библиотеки и реализовать интеграцию через `MethodChannel`.

Пример структуры интеграции:

```dart
import 'package:flutter/services.dart';

class RaspService {
  static const MethodChannel _channel = MethodChannel('com.example.rasp');

  static Future<bool> isRootDetected() async {
    try {
      final bool result = await _channel.invokeMethod('isRootDetected');
      return result;
    } on PlatformException {
      return false;
    }
  }

  static Future<void> startMonitoring() async {
    await _channel.invokeMethod('startMonitoring');
  }
}
```

#### Способ 2: Нативная реализация через Android/iOS

1. **Android (Kotlin)**:

```kotlin
class RaspManager {

```

2. **iOS (Swift)**:

## 3. Определение угроз

RASP-система позволяет определять и реагировать на угрозы в режиме реального времени. Ниже приведены примеры типов угроз, которые можно обнаружить с помощью FreeRASP или аналогичных решений.

### 3.1. Обнаружение Root-доступа

**Описание**: Когда устройство имеет root-доступ, злоумышленник может получить полный контроль над системой, включая возможность обхода безопасности приложений.

**Реализация (Android)**:

```kotlin
fun isDeviceRooted(): Boolean {
    val buildTags = android.os.Build.TAGS
    if (buildTags != null && buildTags.contains("test-keys")) {
        return true
    }

    val paths = arrayOf(
        "/system/app/Superuser.apk",
        "/sbin/su",
        "/system/bin/su",
        "/system/xbin/su",
        "/data/local/xbin/su",
        "/data/local/bin/su",
        "/system/sd/xbin/su",
        "/system/bin/failsafe/su"
    )

    for (path in paths) {
        if (File(path).exists()) return true
    }

    return false
}
```

### 3.2. Обнаружение использования дебаггеров

**Описание**: Приложение может проверять, запущен ли оно под отладчиком.

**Пример реализации (Android)**:

```kotlin
fun isBeingDebugged(): Boolean {
    return Debug.isDebuggerConnected() || Debug.waitingForDebugger()
}
```

### 3.3. Проверка на использование прокси

**Описание**: Если приложение выполняется через прокси, это может указывать на попытку перехвата трафика.

```dart
// Dart-код (проверка через нативный вызов)
Future<bool> isUsingProxy() async {
  try {
    final bool result = await _channel.invokeMethod('isUsingProxy');
    return result;
  } on PlatformException {
    return false;
  }
}
```

### 3.4. Защита от подделки сертификатов

**Описание**: Используя проверку подписи приложения, можно обнаружить его модификацию.

```dart
// Android: Проверка подписи приложения
fun isAppSignatureValid(context: Context): Boolean {
    val packageInfo = context.packageManager.getPackageInfo(
        context.packageName,
        PackageManager.GET_SIGNATURES
    )
    val signatures = packageInfo.signatures

    // Сравниваем с известным сертификатом
    return checkSignature(signatures)
}
```

## 4. Примеры использования FreeRASP в Flutter-приложении

Допустим, у нас есть простое приложение Flutter с функцией авторизации. Мы хотим защитить его от Root-доступа и подозрительных действий.

### Код примера:

```dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'RASP Demo',
      home: HomeScreen(),
    );
  }
}

class HomeScreen extends StatefulWidget {
  @override
  _HomeScreenState createState() => _HomeScreenState();
}

class _HomeScreenState extends State<HomeScreen> {
  bool isRooted = false;

  @override
  void initState() {
    super.initState();
    checkForRoot();
  }

  Future<void> checkForRoot() async {
    final detected = await RaspService.isRootDetected();
    setState(() {
      isRooted = detected;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("RASP Demo")),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(isRooted ? "Устройство Root-доступно!" : "Безопасное устройство"),
            SizedBox(height: 20),
            ElevatedButton(
              onPressed: () {
                // Проверка на Root при нажатии
                checkForRoot();
              },
              child: Text("Проверить"),
            ),
          ],
        ),
      ),
    );
  }
}
```
