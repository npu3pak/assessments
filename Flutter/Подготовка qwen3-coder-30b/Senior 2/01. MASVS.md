# Лекция: MASVS — Методология безопасности для мобильных приложений

---

## Введение: Что такое MASVS?

**MASVS (Mobile Application Security Verification Standard)** — это международная методология, разработанная OWASP (Open Web Application Security Project), которая описывает набор требований к безопасности мобильных приложений. Цель MASVS — помочь разработчикам, тестировщикам и аудиторам определить уровень безопасности мобильного приложения и проверить его соответствие стандартам.

MASVS состоит из 9 категорий (контрольных точек), каждая из которых охватывает определённые аспекты безопасности:

1. **Storage**
2. **Crypto**
3. **Auth**
4. **Network**
5. **Platform**
6. **Code**
7. **Resilience**
8. **Privacy**
9. **Logging**

В этой лекции мы подробно рассмотрим каждую из этих категорий с акцентом на практическое применение в Flutter/Dart.

---

## 1. Storage (Хранение данных)

**Описание:**  
Эта категория касается безопасного хранения конфиденциальных данных внутри приложения, таких как токены, пароли, персональные данные и другие чувствительные сведения.

### Основные принципы:

- Данные не должны сохраняться в открытом виде.
- Используйте шифрование для хранения данных.
- Избегайте хранения чувствительных данных в `SharedPreferences`, `SQLite`, или файлах на диске без шифрования.
- При использовании хранилищ на уровне платформы (например, Keychain на iOS или Keystore на Android) используйте их правильно.

### Примеры:

#### Хранение токена в Flutter с помощью `flutter_secure_storage`:

```dart
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

final storage = FlutterSecureStorage();

// Сохраняем токен
await storage.write(key: "auth_token", value: token);

// Читаем токен
String? token = await storage.read(key: "auth_token");
```

#### Пример: Хранение пароля (небезопасно — не делайте так):

```dart
SharedPreferences prefs = await SharedPreferences.getInstance();
prefs.setString("password", userPassword); // Небезопасно!
```

> ✅ Рекомендуется использовать `flutter_secure_storage` или другие специализированные библиотеки для хранения данных.

## 2. Crypto (Криптография)

**Описание:**  
Категория касается применения криптографических стандартов в мобильном приложении — шифрование данных, использование сильных алгоритмов, управление ключами и т.д.

### Основные требования:

- Используйте только проверенные и современные криптографические алгоритмы (например, AES-256).
- Избегайте использования слабых хэш-функций (MD5, SHA1).
- Не реализуйте собственные криптографические алгоритмы.
- Используйте ключи и сертификаты с правильной длиной и надёжностью.

### Пример: Шифрование данных в Flutter

```dart
import 'package:cryptography/cryptography.dart';

final secretKey = await SecretKey.fromSecureRandom(32); // 256-bit key

final plainText = utf8.encode("Secret message");
final cipher = AesGcm.with256bits();
final encrypted = await cipher.encrypt(
  plainText,
  secret: secretKey,
);

print("Зашифрованные данные: ${base64Encode(encrypted.bytes)}");
```

## 3. Auth (Аутентификация)

**Описание:**  
Проверка идентичности пользователя в приложении. Включает проверку подлинности, управление сессиями и защиту от подделки.

### Основные принципы:

- Используйте надёжные методы аутентификации (OAuth2, OpenID Connect).
- Не храните пароли в открытом виде.
- Используйте токены JWT или другие безопасные механизмы сессии.
- Реализуйте многократную проверку при неудачной попытке входа (rate limiting).

### Пример: Аутентификация с использованием JWT

```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

Future<String?> login(String email, String password) async {
  final response = await http.post(
    Uri.parse('https://yourapi.com/login'),
    body: {
      'email': email,
      'password': password,
    },
  );

  if (response.statusCode == 200) {
    final data = jsonDecode(response.body);
    return data['token'];
  }
  return null;
}
```

### Пример: Сохранение токена в secure storage

```dart
String? token = await login('user@example.com', 'password');
if (token != null) {
  await storage.write(key: "jwt_token", value: token);
}
```

## 4. Network (Сеть)

**Описание:**  
Проверяет безопасность сетевых соединений, передачу данных и защиту от MITM (Man-in-the-Middle) атак.

### Основные требования:

- Используйте HTTPS для всех запросов.
- Проверяйте SSL/TLS сертификаты.
- Не отправляйте конфиденциальные данные через HTTP.
- Реализуйте защиту от перехвата данных (например, с помощью SSL pinning).

### Пример: SSL Pinning в Flutter

```dart
import 'package:http/http.dart' as http;

class MyHttpClient {
  static final HttpClient client = HttpClient()
    ..badCertificateCallback =
        (X509Certificate cert, String host, int port) {
      // Здесь можно реализовать проверку сертификата
      return true; // Позволяет подключение, если сертификат совпадает
    };
}
```

## 5. Platform (Платформа)

**Описание:**  
Проверяет безопасность взаимодействия с нативной платформой (Android / iOS), включая использование API, обработку ошибок и защиту от инъекций.

### Основные принципы:

- Не используйте `exec()` или другие команды, которые могут быть использованы для выполнения кода.
- Используйте безопасные методы взаимодействия с системой (например, через `MethodChannel`).
- Проверяйте входные данные на предмет инъекций и недопустимых значений.

### Пример: Безопасное использование MethodChannel

```dart
import 'package:flutter/services.dart';

Future<String> getDeviceInfo() async {
  const platform = MethodChannel('com.example.device_info');
  try {
    String deviceInfo = await platform.invokeMethod('getDeviceInfo');
    return deviceInfo;
  } on PlatformException {
    return "Failed to get device info.";
  }
}
```

## 6. Code (Код)

**Описание:**  
Отвечает за безопасность исходного кода приложения, включая защиту от reverse engineering и эксплуатации уязвимостей.

### Основные принципы:

- Избегайте использования уязвимых библиотек.
- Не вставляйте конфиденциальные данные напрямую в код (например, API ключи).
- Используйте обфускацию и другие техники защиты.
- Проверяйте код на предмет подозрительных действий.

### Пример: Использование `.env` файлов

```yaml
# pubspec.yaml
dependencies:
  flutter_dotenv: ^5.0.2
```

```dart
import 'package:flutter_dotenv/flutter_dotenv.dart';

final apiEndpoint = dotenv.get('API_ENDPOINT');
```

## 7. Resilience (Устойчивость)

**Описание:**  
Проверяет, насколько приложение устойчиво к сбоям и атакам, включая защиту от обработки ошибок, восстановление после сбоев.

### Основные принципы:

- Обрабатывайте ошибки корректно.
- Не раскрывайте внутренние детали приложений.
- Реализуйте механизм восстановления после сбоев.
- Используйте retry логику для сетевых вызовов.

### Пример: Обработка ошибок

```dart
Future<void> fetchUserData() async {
  try {
    final response = await http.get(Uri.parse('https://api.example.com/user'));
    if (response.statusCode == 200) {
      // Успешный ответ
    } else {
      throw Exception("Ошибка получения данных");
    }
  } catch (e) {
    print("Ошибка: $e"); // Логирование без деталей для пользователя
  }
}
```

## 8. Privacy (Приватность)

**Описание:**  
Касается защиты конфиденциальных данных пользователя, включая сбор, использование и обработку персональной информации.

### Основные принципы:

- Соблюдайте GDPR, CCPA и другие законы о защите данных.
- Не собирайте данные без согласия пользователя.
- Используйте прозрачную политику конфиденциальности.
- Реализуйте механизмы удаления данных.

### Пример: Запрос на согласие

```dart
// В Flutter можно использовать flutter_appauth или аналоги для запроса разрешений
Future<void> requestPermission() async {
  // Используем Permission package
  final status = await Permission.location.request();
  if (status.isGranted) {
    print("Разрешение получено");
  }
}
```

## 9. Logging (Логирование)

**Описание:**  
Обеспечивает безопасное ведение логов, предотвращая утечку данных и логирование конфиденциальной информации.

### Основные принципы:

- Не записывайте чувствительные данные (пароли, токены) в логи.
- Используйте безопасные механизмы ведения журналов.
- Не храните логи на устройстве без шифрования.

### Пример: Безопасное логирование

```dart
import 'package:logger/logger.dart';

final logger = Logger(
  printer: PrettyPrinter(
    methodCount: 0,
    errorMethodCount: 8,
    lineLength: 120,
  ),
);

void safeLog(String message) {
  // Логируем только безопасные данные
  logger.i("App event: $message");
}
```
