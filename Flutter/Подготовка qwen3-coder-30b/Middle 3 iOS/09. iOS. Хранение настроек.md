# Лекция: Хранение настроек в iOS для Flutter-разработчика (Middle 3)

---

## Введение

В мобильной разработке, особенно при создании приложений под iOS и Android, одной из важнейших задач является хранение пользовательских настроек и данных. Это может быть тема оформления, язык интерфейса, включенные/выключенные функции, логины, пароли и т.д.

В рамках этой лекции мы рассмотрим два основных способа хранения данных на iOS: **UserDefaults** и **Keychain**, а также расскажем, как их использовать в Flutter-приложениях через Dart-пакеты.

---

## 1. UserDefaults

### Что такое UserDefaults?

`UserDefaults` — это простой механизм хранения небольших данных на устройстве пользователя, который является частью фреймворка **Foundation** в iOS. Он работает как хранилище пар "ключ-значение" и сохраняет данные локально на устройстве.

### Основные особенности:

- Хранит простые типы данных: `String`, `Int`, `Double`, `Bool`, `Data`, `Array`, `Dictionary`.
- Данные автоматически синхронизируются между сессиями приложения.
- Не предназначен для хранения конфиденциальной информации (например, паролей).
- Хранит данные в формате plist (plist = Property List — XML-подобный формат).

### Использование в iOS (Swift):

В Swift можно использовать `UserDefaults` следующим образом:

```swift
// Сохранение значения
UserDefaults.standard.set("John", forKey: "username")
UserDefaults.standard.set(25, forKey: "age")
UserDefaults.standard.set(true, forKey: "isPremium")

// Получение значения
let username = UserDefaults.standard.string(forKey: "username")
let age = UserDefaults.standard.integer(forKey: "age")
let isPremium = UserDefaults.standard.bool(forKey: "isPremium")
```

### Использование в Flutter

В Flutter `UserDefaults` не доступен напрямую, но можно использовать пакет [shared_preferences](https://pub.dev/packages/shared_preferences), который использует `UserDefaults` на iOS и `SharedPreferences` на Android.

#### Установка:

```yaml
dependencies:
  shared_preferences: ^2.2.2
```

#### Пример использования:

```dart
import 'package:shared_preferences/shared_preferences.dart';

class SettingsService {
  static const String _usernameKey = 'username';
  static const String _ageKey = 'age';
  static const String _isPremiumKey = 'isPremium';

  // Сохранение настроек
  static Future<void> saveSettings(String username, int age, bool isPremium) async {
    final prefs = await SharedPreferences.getInstance();
    prefs.setString(_usernameKey, username);
    prefs.setInt(_ageKey, age);
    prefs.setBool(_isPremiumKey, isPremium);
  }

  // Получение настроек
  static Future<Map<String, dynamic>> getSettings() async {
    final prefs = await SharedPreferences.getInstance();
    return {
      'username': prefs.getString(_usernameKey),
      'age': prefs.getInt(_ageKey),
      'isPremium': prefs.getBool(_isPremiumKey),
    };
  }
}
```

### Когда использовать UserDefaults?

- Хранение настроек пользователя (например, тема, язык).
- Хранение предпочтений (включено/выключено уведомления).
- Простые данные, которые не требуют безопасности.

## 2. Keychain

### Что такое Keychain?

Keychain — это механизм шифрованного хранения данных в iOS, который обеспечивает высокий уровень безопасности. Он используется для хранения конфиденциальной информации, такой как пароли, токены, ключи.

### Особенности Keychain:

- Данные шифруются и хранятся в защищенном хранилище.
- Доступ к данным возможен только при наличии правильного сертификата или привязки к устройству.
- Поддерживает хранение бинарных данных, строк, токенов.

### Использование в iOS (Swift):

```swift
import Security

// Сохранение в Keychain
let query: [String: Any] = [
    kSecClass as String: kSecClassGenericPassword,
    kSecAttrAccount as String: "username",
    kSecValueData as String: "password".data(using: .utf8)!,
]

SecItemAdd(query as CFDictionary, nil)

// Получение из Keychain
let queryGet: [String: Any] = [
    kSecClass as String: kSecClassGenericPassword,
    kSecAttrAccount as String: "username",
    kSecReturnData as String: true,
]

var result: AnyObject?
SecItemCopyMatching(queryGet as CFDictionary, &result)

if let data = result as? Data {
    let password = String(data: data, encoding: .utf8)
    print(password) // Выводит пароль
}
```

### Использование в Flutter

Для работы с Keychain в Flutter можно использовать пакет [keychain](https://pub.dev/packages/keychain), который предоставляет удобный интерфейс для работы с системным Keychain.

#### Установка:

```yaml
dependencies:
  keychain: ^3.0.1
```

#### Пример использования:

```dart
import 'package:keychain/keychain.dart';

class SecureStorageService {
  static Future<void> saveToken(String token) async {
    await Keychain.set(key: 'auth_token', value: token);
  }

  static Future<String?> getToken() async {
    return await Keychain.get(key: 'auth_token');
  }

  static Future<void> deleteToken() async {
    await Keychain.delete(key: 'auth_token');
  }
}
```

### Когда использовать Keychain?

- Хранение токенов авторизации (например, JWT).
- Хранение паролей.
- Конфиденциальные данные, которые не должны быть доступны в открытом виде.

## Сравнение UserDefaults и Keychain

| Характеристика         | UserDefaults                          | Keychain                              |
|------------------------|---------------------------------------|----------------------------------------|
| Тип данных             | Простые типы (String, int, bool)      | Любые данные (включая бинарные)        |
| Безопасность           | Низкая                                | Высокая                                |
| Шифрование             | Нет                                   | Да                                     |
| Использование          | Настройки, предпочтения               | Пароли, токены                         |
| Скорость доступа       | Быстрее                               | Медленнее                              |
| Поддержка на Android   | Да (через SharedPreferences)          | Нет                                    |
