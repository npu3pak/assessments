# Лекция: iOS Swift UI для Flutter-разработчика

## Введение

Добро пожаловать в лекцию по **SwiftUI** — современной фреймворку Apple для создания пользовательских интерфейсов. Если вы разрабатываете приложения на Flutter, то, возможно, вы уже знакомы с концепцией реактивного программирования и построения UI через декларативный подход.

SwiftUI использует **декларативный стиль написания кода**, где вы описываете, как должен выглядеть интерфейс, а не как его рисовать. Это сильно напоминает Flutter-подход с использованием Widget-дерева и состояния.

В этой лекции мы рассмотрим основные элементы SwiftUI и научимся строить полноценные приложения, аналогичные тем, что вы делали в Flutter — от простых View до сложных навигационных структур с анимациями и взаимодействием с UIKit.

## 1. Создание и комбинирование View

В SwiftUI каждая часть интерфейса — это **View**, и она строится через декларативный код. Каждый View описывает структуру, стиль и поведение элемента.

### Пример базовой View:

```swift
struct ContentView: View {
    var body: some View {
        Text("Hello, World!")
            .font(.largeTitle)
            .foregroundColor(.blue)
    }
}
```

- `Text` — это базовый элемент интерфейса.
- `.font(.largeTitle)` — устанавливает размер шрифта.
- `.foregroundColor(.blue)` — цвет текста.

### Комбинирование View:

```swift
struct ContentView: View {
    var body: some View {
        VStack(spacing: 20) {
            Text("Заголовок")
                .font(.title)
            
            Text("Подзаголовок")
                .font(.subheadline)
                .foregroundColor(.secondary)
            
            Button("Нажми меня") {
                print("Кнопка нажата!")
            }
        }
    }
}
```

- `VStack` — вертикальный контейнер, где элементы размещаются друг под другом.
- `HStack` — горизонтальный контейнер.
- `ZStack` — слои (наложение View друг на друга).

### Вложенные структуры:

```swift
struct ContentView: View {
    var body: some View {
        VStack {
            HeaderView()
            ContentViewBody()
            FooterView()
        }
    }
}

struct HeaderView: View {
    var body: some View {
        Text("Заголовок")
            .font(.headline)
    }
}

struct ContentViewBody: View {
    var body: some View {
        Text("Тело контента")
            .font(.body)
    }
}

struct FooterView: View {
    var body: some View {
        Text("Футер")
            .font(.caption)
    }
}
```

## 2. Создание превью

SwiftUI позволяет создавать **превью** прямо в коде — это удобно для быстрого тестирования интерфейса.

```swift
struct ContentView_Previews: PreviewProvider {
    static var previews: some View {
        ContentView()
    }
}
```

Вы можете создавать несколько превью с разными состояниями:

```swift
struct ContentView_Previews: PreviewProvider {
    static var previews: some View {
        Group {
            ContentView()
                .previewDisplayName("Стандартный вид")
            
            ContentView()
                .preferredColorScheme(.dark)
                .previewDisplayName("Темная тема")
        }
    }
}
```

### Превью с параметрами:

```swift
struct MyView_Previews: PreviewProvider {
    static var previews: some View {
        MyView(title: "Заголовок", isOn: true)
            .previewDisplayName("С включенным переключателем")
    }
}

struct MyView: View {
    let title: String
    let isOn: Bool
    
    var body: some View {
        VStack {
            Text(title)
            Toggle("Переключатель", isOn: .constant(isOn))
        }
    }
}
```

## 3. Построение списков

SwiftUI предоставляет мощные инструменты для создания списков с помощью `List` или `ForEach`.

### Простой список:

```swift
struct ContentView: View {
    let items = ["Item 1", "Item 2", "Item 3"]
    
    var body: some View {
        List(items, id: \.self) { item in
            Text(item)
        }
    }
}
```

### Список с иконками и кастомными элементами:

```swift
struct ContentView: View {
    let items = [
        Item(name: "Андрей", age: 25),
        Item(name: "Мария", age: 30)
    ]
    
    var body: some View {
        List(items, id: \.name) { item in
            HStack {
                Image(systemName: "person.circle")
                    .font(.title2)
                
                VStack(alignment: .leading) {
                    Text(item.name)
                        .font(.headline)
                    Text("Возраст: \(item.age)")
                        .font(.subheadline)
                        .foregroundColor(.secondary)
                }
            }
        }
    }
}

struct Item: Identifiable {
    let id = UUID()
    let name: String
    let age: Int
}
```

## 4. Навигация

SwiftUI использует `NavigationStack`, `NavigationView` и `NavigationLink` для построения навигации.

### Простая навигация:

```swift
struct ContentView: View {
    var body: some View {
        NavigationStack {
            List {
                NavigationLink("Перейти к деталям") {
                    DetailView()
                }
            }
            .navigationTitle("Главная")
        }
    }
}

struct DetailView: View {
    var body: some View {
        Text("Это детальная страница")
            .navigationTitle("Детали")
    }
}
```

### С переходом с данными:

```swift
struct ContentView: View {
    let items = ["Item 1", "Item 2", "Item 3"]
    
    var body: some View {
        NavigationStack {
            List(items, id: \.self) { item in
                NavigationLink(destination: DetailView(item: item)) {
                    Text(item)
                }
            }
            .navigationTitle("Список")
        }
    }
}

struct DetailView: View {
    let item: String
    
    var body: some View {
        Text("Вы выбрали: \(item)")
            .padding()
            .navigationTitle(item)
    }
}
```

## 5. Анимация

SwiftUI предоставляет встроенные средства для анимации через `Animation`, `withAnimation` и `@State`.

### Простая анимация:

```swift
struct ContentView: View {
    @State private var isTapped = false
    
    var body: some View {
        Button("Нажми меня") {
            withAnimation(.easeInOut(duration: 0.5)) {
                isTapped.toggle()
            }
        }
        .scaleEffect(isTapped ? 1.2 : 1.0)
        .foregroundColor(.blue)
    }
}
```

### Анимация с использованием `GeometryReader`:

```swift
struct AnimatedView: View {
    @State private var offset = CGSize.zero
    
    var body: some View {
        Button("Анимация") {
            withAnimation(.easeInOut(duration: 0.5)) {
                offset = CGSize(width: 100, height: 100)
            }
        }
        .padding()
        .background(Color.blue)
        .offset(offset)
    }
}
```

## 6. Ввод текста

Для ввода текста используется `TextField` и `TextEditor`.

### Однострочный ввод:

```swift
struct ContentView: View {
    @State private var text = ""
    
    var body: some View {
        VStack {
            TextField("Введите текст", text: $text)
                .textFieldStyle(RoundedBorderTextFieldStyle())
            
            Text("Вы ввели: \(text)")
        }
    }
}
```

### Многострочный ввод:

```swift
struct ContentView: View {
    @State private var text = ""
    
    var body: some View {
        VStack {
            TextEditor(text: $text)
                .frame(height: 150)
                .border(Color.gray, width: 1)
            
            Text("Вы ввели: \(text)")
        }
    }
}
```

## 7. Взаимодействие с UIKit

SwiftUI позволяет использовать UIKit-компоненты через `UIViewRepresentable`.

### Пример:

```swift
struct MyUIKitView: UIViewRepresentable {
    func makeUIView(context: Context) -> UIView {
        let uiView = UIView()
        uiView.backgroundColor = .red
        return uiView
    }
    
    func updateUIView(_ uiView: UIView, context: Context) {}
}

struct ContentView: View {
    var body: some View {
        MyUIKitView()
            .frame(width: 200, height: 200)
    }
}
```

Также можно использовать `UIViewControllerRepresentable` для более сложных компонентов.

## Практическое задание

Создайте приложение с навигацией, в котором:

1. Главный экран отображает список пользователей.
2. При выборе пользователя открывается детальная страница с его информацией.
3. На детальной странице есть поле для ввода текста и кнопка "сохранить".

5. Используйте превью для разных состояний.
