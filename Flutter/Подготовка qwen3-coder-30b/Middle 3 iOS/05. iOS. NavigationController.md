# Лекция: iOS NavigationController

## Введение

NavigationController — это один из ключевых компонентов iOS-разработки, обеспечивающий навигацию между экранами приложения. Он представляет собой стек (stack) контроллеров, который позволяет пользователю перемещаться вперед и назад по иерархии экранов.

В этой лекции мы рассмотрим принцип работы NavigationController, его внутреннюю архитектуру, возможности управления переходами и передачи данных между экранами. Мы также поговорим о том, как использовать Segues для создания навигации в приложениях на Swift.

---

## 1. Навигация с помощью NavigationController. Принцип стека

### Что такое NavigationController?

NavigationController — это контроллер навигации, который управляет стеком экранов (view controllers). Каждый элемент стека представляет собой представление, которое отображается на экране. Когда пользователь переходит к новому экрану, он добавляется в вершину стека, а когда возвращается назад — удаляется из стека.

### Принцип работы стека

Стек в NavigationController работает по принципу **LIFO** (Last In, First Out). То есть:

- Когда вы переходите на новый экран, он помещается **на вершину стека**.
- При возвращении назад — **удаляется с вершины стека**.
- Стек может содержать несколько контроллеров, и текущий отображаемый контроллер находится на его вершине.

### Как работает навигация

Для перехода между экранами используется метод `pushViewController(_:, animated:)`, который добавляет новый контроллер в стек.

Пример:

```swift
let secondViewController = SecondViewController()
navigationController?.pushViewController(secondViewController, animated: true)
```

В этом примере мы создаем экземпляр второго контроллера и добавляем его в стек навигации. Параметр `animated` указывает, нужно ли анимировать переход.

### Управление стеком

Также можно управлять стеком напрямую:

- `popViewController(animated:)` — возвращает к предыдущему экрану.
- `setViewControllers(_:animated:)` — заменяет весь стек контроллеров.
- `popToRootViewController(animated:)` — возвращает к первому экрану.

Пример:

```swift
navigationController?.popViewController(animated: true)
```

### Структура навигации

NavigationController обычно используется вместе с NavigationBar, которая отображает заголовок текущего экрана и кнопки управления (например, "назад", "меню"). Эта панель находится в верхней части экрана.

## 2. Внешний вид и поведение NavigationController при анимации

### Анимация переходов

Все переходы между экранами в NavigationController можно анимировать с помощью параметра `animated`:

```swift
navigationController?.pushViewController(secondViewController, animated: true)
```

Если `animated = false`, переход происходит мгновенно без анимации.

### Стиль NavigationBar

NavigationController позволяет настраивать внешний вид NavigationBar через свойства:

- `navigationBar.prefersLargeTitles` — включает большие заголовки.
- `navigationBar.backgroundColor` — цвет фона.
- `navigationBar.tintColor` — цвет элементов навигационной панели.

Пример:

```swift
navigationController?.navigationBar.prefersLargeTitles = true
navigationController?.navigationBar.backgroundColor = UIColor.systemBlue
```

### Анимации при изменении стека

Когда вы добавляете или удаляете контроллер из стека, NavigationController автоматически анимирует изменения. Это включает:

- Сдвиг экранов слева направо при переходе вперед.
- Сдвиг справа налево при возврате.

Анимация может быть настроена через параметр `animated` или даже изменена с помощью кастомных переходов, если вы реализуете собственные `UIViewControllerAnimatedTransitioning`.

## 3. Стандартные transitions, доступные в NavigationController

NavigationController предоставляет стандартные типы анимаций переходов:

### Типы переходов

- **Push/Pop** — стандартный переход влево/вправо.
- **Modal** — модальное окно (не используется напрямую с NavigationController, но может использоваться внутри).
- **Custom transitions** — кастомные анимации (требуют реализации `UIViewControllerAnimatedTransitioning`).

### Стандартные переходы

Все стандартные переходы в NavigationController основаны на анимации слайдов:

- При `pushViewController` экран сдвигается влево.
- При `popViewController` экран сдвигается вправо.

Вы можете изменить тип перехода, используя `transitioningDelegate`, если реализуете кастомную анимацию.

### Пример кастомной анимации

```swift
class CustomTransition: NSObject, UIViewControllerAnimatedTransitioning {
    func transitionDuration(using transitionContext: UIViewControllerContextTransitioning?) -> TimeInterval {
        return 0.5
    }

    func animateTransition(using transitionContext: UIViewControllerContextTransitioning) {
        // Ваша реализация анимации
    }
}
```

## 4. Segues и передача данных при их использовании

### Что такое Segue?

Segue — это способ связать два экрана в Storyboard, позволяющий автоматически выполнить переход между ними. В iOS используется для переходов через NavigationController или модальные окна.

### Типы Segue

- **Show** — стандартный переход (push) в NavigationController.
- **Present Modally** — модальное отображение экрана.
- **Show Detail** — используется в Split View Controller.

### Использование Segue с NavigationController

Чтобы использовать Segue для перехода через NavigationController:

1. Создайте связь между двумя контроллерами в Storyboard.
2. Выберите тип `Show` (Push).
3. При переходе будет автоматически вызван `pushViewController`.

### Передача данных через Segue

Для передачи данных между экранами используется метод `prepare(for:sender:)`:

```swift
override func prepare(for segue: UIStoryboardSegue, sender: Any?) {
    if let secondVC = segue.destination as? SecondViewController {
        secondVC.data = "Hello World"
    }
}
```

В этом примере мы передаем строку в контроллер второго экрана. Передаваемые данные могут быть любыми — строками, объектами, массивами и т.д.

### Пример передачи данных

```swift
class FirstViewController: UIViewController {
    
    @IBAction func buttonTapped(_ sender: UIButton) {
        performSegue(withIdentifier: "goToSecond", sender: self)
    }
    
    override func prepare(for segue: UIStoryboardSegue, sender: Any?) {
        if let secondVC = segue.destination as? SecondViewController {
            secondVC.user = User(name: "John", age: 30)
        }
    }
}
```
