# Лекция: REST-клиент в iOS разработке

## Введение

В современной мобильной разработке работа с REST API — один из ключевых навыков. REST (Representational State Transfer) — это архитектурный стиль взаимодействия между клиентом и сервером, основанный на HTTP-запросах. В iOS разработке для работы с REST API мы используем встроенные инструменты, такие как **URLSession**, или сторонние библиотеки, например **Alamofire**.

В рамках этой лекции мы рассмотрим:
1. Как работать с JSON в Swift и Dart (в контексте Flutter).
2. Как отправлять HTTP-запросы с помощью URLSession.
3. Как строить REST-клиенты в iOS и Flutter.

## 1. Работа с JSON с помощью Codable

### Что такое Codable?

`Codable` — это протокол, объединяющий `Encodable` и `Decodable`. Он позволяет автоматически сериализовать и десериализовать данные из/в формат JSON.

Для использования `Codable` необходимо:
1. Создать структуру или класс.
2. Убедиться, что все поля в структуре реализуют `Codable`.
3. Использовать `JSONDecoder` для десериализации и `JSONEncoder` для сериализации.

### Пример на Swift

```swift
struct User: Codable {
    let id: Int
    let name: String
    let email: String
}

// Десериализация JSON в объект
let jsonString = """
{
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
}
"""

if let data = jsonString.data(using: .utf8) {
    do {
        let user = try JSONDecoder().decode(User.self, from: data)
        print(user.name) // John Doe
    } catch {
        print("Ошибка десериализации: $error)")
    }
}
```

### Пример на Dart (Flutter)

В Flutter для работы с JSON используется `json_serializable` или просто `json.decode()` и `json.encode()`.

```dart
import 'dart:convert';

class User {
  final int id;
  final String name;
  final String email;

  User({required this.id, required this.name, required this.email});

  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      id: json['id'],
      name: json['name'],
      email: json['email'],
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'name': name,
      'email': email,
    };
  }
}

void main() {
  String jsonString = '''
  {
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
  }
  ''';

  Map<String, dynamic> jsonMap = jsonDecode(jsonString);
  User user = User.fromJson(jsonMap);
  print(user.name); // John Doe
}
```

## 2. Отправка запросов с помощью URLSession

### Что такое URLSession?

`URLSession` — это встроенный фреймворк iOS для работы с сетью. Он предоставляет асинхронную поддержку HTTP-запросов и позволяет обрабатывать данные, ошибки, загрузку и отмену запросов.

### Основные компоненты URLSession:

1. **URLSessionTask** — основной объект для выполнения запроса.
2. **URLSessionDataTask** — используется для GET/POST запросов.
3. **URLSessionDownloadTask** — для загрузки файлов.
4. **URLSessionUploadTask** — для отправки данных.

### Пример: GET-запрос с URLSession

```swift
let url = URL(string: "https://jsonplaceholder.typicode.com/users/1")!

let task = URLSession.shared.dataTask(with: url) { data, response, error in
    if let error = error {
        print("Ошибка: $error)")
        return
    }

    guard let data = data else {
        print("Нет данных")
        return
    }

    do {
        let user = try JSONDecoder().decode(User.self, from: data)
        print(user.name)
    } catch {
        print("Ошибка десериализации: $error)")
    }
}

task.resume()
```

### Пример: POST-запрос с URLSession

```swift
let url = URL(string: "https://jsonplaceholder.typicode.com/users")!
var request = URLRequest(url: url)
request.httpMethod = "POST"
request.setValue("application/json", forHTTPHeaderField: "Content-Type")

let body = [
    "name": "John Doe",
    "email": "john@example.com"
]

do {
    request.httpBody = try JSONSerialization.data(withJSONObject: body)
} catch {
    print("Ошибка сериализации: $error)")
}

let task = URLSession.shared.dataTask(with: request) { data, response, error in
    if let error = error {
        print("Ошибка: $error)")
        return
    }

    if let httpResponse = response as? HTTPURLResponse {
        print("Статус: $httpResponse.statusCode)")
    }
}

task.resume()
```

## 3. Отправка запросов с помощью Alamofire (iOS)

### Что такое Alamofire?

Alamofire — популярная библиотека для работы с сетью в Swift. Она упрощает отправку HTTP-запросов, предоставляет удобный синтаксис и поддерживает автоматическую сериализацию JSON.

### Установка Alamofire

Добавьте в `Podfile`:

```ruby
pod 'Alamofire'
```

Затем выполните:

```bash
pod install
```

### Пример запроса с Alamofire

```swift
import Alamofire

AF.request("https://jsonplaceholder.typicode.com/users/1")
    .validate()
    .responseJSON { response in
        switch response.result {
        case .success(let data):
            print(data)
        case .failure(let error):
            print("Ошибка: $error)")
        }
    }

// С использованием Codable

AF.request("https://jsonplaceholder.typicode.com/users/1")
    .validate()
    .responseDecodable(of: User.self) { response in
        switch response.result {
        case .success(let user):
            print(user.name)
        case .failure(let error):
            print("Ошибка: $error)")
        }
    }
```

## 4. REST-клиент в Flutter

### Какие библиотеки использовать?

В Flutter для работы с сетью используются:
- `http` — базовая библиотека для HTTP-запросов.
- `dio` — более продвинутая альтернатива с поддержкой интерцепторов, логирования и т.д.

### Пример с http

```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

Future<User> fetchUser(int id) async {
  final response = await http.get(
    Uri.parse('https://jsonplaceholder.typicode.com/users/$id'),
  );

  if (response.statusCode == 200) {
    final json = jsonDecode(response.body);
    return User.fromJson(json);
  } else {
    throw Exception('Не удалось загрузить пользователя');
  }
}
```

### Пример с dio

```dart
import 'package:dio/dio.dart';

final dio = Dio();

Future<User> fetchUser(int id) async {
  final response = await dio.get('https://jsonplaceholder.typicode.com/users/$id');

  return User.fromJson(response.data);
}
```
