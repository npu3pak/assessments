# Лекция: iOS. Ресурсы

## Введение

В мобильной разработке, особенно в Flutter-проектах, работа с ресурсами играет ключевую роль. Ресурсы включают изображения, цвета, шрифты, звуки и другие данные, которые используются приложением. В рамках данной лекции мы сосредоточимся на **растровой графики**, **векторной графике** и **цветах**, как основных компонентах ресурсов в iOS-приложениях.

Flutter позволяет легко работать с ресурсами, независимо от того, на какой платформе запускается приложение (iOS или Android). Однако важно понимать особенности работы с ресурсами именно под iOS, поскольку это может повлиять на производительность и внешний вид приложения.

---

## 1. Растровая графика в ресурсах

Растровая графика — это изображение, состоящее из пикселей. Каждый пиксель имеет определённый цвет и положение. В Flutter растровые изображения обычно используются в форматах PNG, JPG и GIF.

### 1.1 Форматы растровых изображений

- **PNG** — без потерь, поддерживает прозрачность.
- **JPG** — сжатие с потерями, не поддерживает прозрачность.
- **GIF** — анимированные изображения.

### 1.2 Использование растровых изображений в Flutter

В Flutter растровые изображения размещаются в папке `assets/images`. Чтобы использовать изображение в коде, нужно:

```dart
Image.asset('assets/images/logo.png')
```

Также важно настроить файл `pubspec.yaml`, чтобы Flutter знал, какие ресурсы нужно включать:

```yaml
flutter:
  assets:
    - assets/images/
    - assets/icons/
```

### 1.3 Особенности работы с растровыми изображениями на iOS

iOS требует определённых размеров и разрешений для корректной работы с изображениями:

- **@1x** — стандартное разрешение.
- **@2x** — двойное разрешение (для Retina экранов).
- **@3x** — тройное разрешение.

Пример структуры ресурсов в Flutter проекте:

```
assets/
  images/
    logo.png
    logo@2x.png
    logo@3x.png
```

Flutter автоматически выбирает правильный файл в зависимости от устройства. Это называется **device pixel ratio** (DPR).

### 1.4 Пример использования растрового изображения

```dart
class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Center(
      child: Image.asset('assets/images/logo.png', width: 100, height: 100),
    );
  }
}
```

Также можно использовать `Image.network` для загрузки изображений по URL.

## 2. Векторная графика в ресурсах

Векторная графика — это изображение, представленное в виде математических формул и кривых. Основное преимущество — масштабируемость без потери качества.

### 2.1 Форматы векторных изображений

- **SVG** — стандартный формат векторной графики.
- **PDF** — также может быть использован как векторный ресурс.

### 2.2 Поддержка SVG в Flutter

Flutter не поддерживает SVG напрямую, но существует библиотека `flutter_svg`, которая позволяет отображать SVG изображения:

```yaml
dependencies:
  flutter_svg: ^2.0.7
```

Пример использования:

```dart
import 'package:flutter_svg/flutter_svg.dart';

class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Center(
      child: SvgPicture.asset('assets/icons/icon.svg'),
    );
  }
}
```

### 2.3 Особенности векторной графики на iOS

iOS нативно поддерживает векторные изображения в формате **SF Symbols** — встроенные наборы иконок от Apple.

В Flutter можно использовать SF Symbols через пакет `sf_symbols` или напрямую через `Image.asset`, если добавить их в ресурсы.

### 2.4 Пример работы с SF Symbols

```dart
class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Center(
      child: Image.asset('assets/icons/sf_symbol.png', width: 50, height: 50),
    );
  }
}
```

### 2.5 Преимущества и недостатки векторной графики

**Преимущества:**
- Масштабируемость.
- Небольшой размер файла.
- Подходит для иконок, логотипов.

**Недостатки:**
- Не все форматы поддерживаются нативно (например, SVG).
- Сложнее редактировать вручную.

## 3. Цвета в ресурсах

Цвета — это не просто значения, а важный элемент дизайна и UX. В Flutter цвета могут быть заданы напрямую или из ресурсов.

### 3.1 Прямое использование цветов

```dart
Container(color: Colors.blue)
```

### 3.2 Создание цветовых палитр

Можно создать отдельный файл `colors.dart`:

```dart
class AppColors {
  static const primary = Color(0xFF6200EE);
  static const secondary = Color(0xFF03DAC5);
  static const background = Color(0xFFF5F5F5);
}
```

И использовать его в проекте:

```dart
Container(color: AppColors.primary)
```

### 3.3 Работа с темами (Themes)

В Flutter можно создавать разные темы — светлую и тёмную, например:

```dart
ThemeData lightTheme = ThemeData(
  primaryColor: Colors.blue,
  scaffoldBackgroundColor: Colors.white,
);

ThemeData darkTheme = ThemeData(
  primaryColor: Colors.grey[800],
  scaffoldBackgroundColor: Colors.black,
);
```

### 3.4 Использование цветов в ресурсах

Можно хранить цвета в файлах `colors.dart` или даже в отдельных JSON-файлах, если используется динамическая темизация.

```dart
{
  "primary": "#6200EE",
  "secondary": "#03DAC5"
}
```

Затем парсить их с помощью `json.decode()` и преобразовывать в `Color`.

## Практическое задание

1. Создайте Flutter проект.
2. Добавьте растровые изображения (PNG) в папку `assets/images/`.
3. Настройте `pubspec.yaml` для загрузки изображений.
4. Используйте `Image.asset()` для отображения одного изображения на экране.
5. Добавьте SVG-иконку с помощью `flutter_svg`.
6. Создайте файл `colors.dart`, где определите цвета для темной и светлой темы.
7. Примените тему к приложению и проверьте, как она отображается.
