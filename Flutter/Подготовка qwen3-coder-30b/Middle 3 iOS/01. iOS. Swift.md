## 1. Отличия `class` и `struct`

В Swift есть два способа определения типов: через `class` и `struct`. Они похожи, но имеют ключевые различия.

### 📌 Class (Класс)
- Это **ссылочный тип**.
- Экземпляры классов разделяют одну и ту же ссылку в памяти.
- Поддерживает наследование, протоколы, делегирование.
- Пример:

```swift
class Person {
    var name: String
    init(name: String) {
        self.name = name
    }
}

let person1 = Person(name: "Alex")
let person2 = person1 // person2 ссылается на тот же объект в памяти

person2.name = "John"
print(person1.name) // Вывод: John
```

### 📌 Struct (Структура)
- Это **значимый тип**.
- Каждый экземпляр структуры — это независимая копия данных.
- Не поддерживают наследование.
- Пример:

```swift
struct Person {
    var name: String
}

var person1 = Person(name: "Alex")
var person2 = person1 // Это копия

person2.name = "John"
print(person1.name) // Вывод: Alex (не изменилось)
```

> ⚠️ **Важно**: если вы работаете с `struct`, изменения в копии не влияют на оригинал.

## 2. Nullable-типы и проверка на null (`Optional`)

Swift имеет концепцию `Optional`, которая позволяет переменным содержать либо значение, либо `nil`.

### 📌 Определение Optional

```swift
var name: String? = "Alex"
var age: Int? = nil
```

- Если тип не указан как `Optional`, он **не может быть nil**.
- Для доступа к значению нужно использовать безопасный способ.

### 📌 Проверка на nil

#### 1. Использование `if let`
```swift
if let unwrappedName = name {
    print("Имя: \(unwrappedName)")
} else {
    print("Имя не задано")
}
```

#### 2. Использование `guard let`
```swift
func greetUser(name: String?) {
    guard let userName = name else {
        print("Имя не передано")
        return
    }
    print("Привет, \(userName)!")
}
```

> 📌 `guard` — это удобная конструкция для раннего выхода из функции при отсутствии значения.

#### 3. Использование `!` (Force unwrap)
```swift
let name = "Alex"
let unwrappedName: String = name! // Только если вы уверены, что не nil
```
> ⚠️ **Осторожно**: Force unwrap может вызвать crash, если значение равно `nil`.

## 3. Конструкции `guard` и `if let`

### 📌 if let

Используется для безопасного извлечения значения из `Optional`:

```swift
let userAge: Int? = 25

if let age = userAge {
    print("Возраст: \(age)")
} else {
    print("Возраст не указан")
}
```

### 📌 guard let

Используется для раннего возврата из функции, если `Optional` не содержит значения:

```swift
func processUser(name: String?, age: Int?) {
    guard let userName = name else {
        print("Имя не передано")
        return
    }
    
    guard let userAge = age else {
        print("Возраст не передан")
        return
    }
    
    print("Пользователь \(userName), возраст \(userAge)")
}
```

> 📌 `guard` — это более читаемый способ обработки `Optional`, особенно в функциях.

## 4. Сильные и слабые ссылки (`strong` и `weak`)

В Swift для управления циклическими ссылками используются **сильные** и **слабые** ссылки.

### 📌 Strong (сильная ссылка)
- По умолчанию все ссылки — сильные.
- Объект не будет удалён из памяти, пока существует хотя бы одна сильная ссылка.

### 📌 Weak (слабая ссылка)
- Используется для разрыва циклической зависимости между объектами.
- Если объект освобождается, слабая ссылка становится `nil`.

### 🧠 Пример с циклической зависимостью:

```swift
class Parent {
    var child: Child? // strong reference
    
    deinit {
        print("Parent уничтожен")
    }
}

class Child {
    weak var parent: Parent? // weak reference
    
    deinit {
        print("Child уничтожен")
    }
}
```

Если `parent` и `child` ссылаются друг на друга, без `weak`, они будут жить вечно (memory leak).

## 5. Замыкания (`Closures`)

Замыкание — это блок кода, который можно передавать как аргумент или хранить в переменной.

### 📌 Простой пример замыкания:

```swift
let greet = { print("Hello!") }
greet() // Вывод: Hello!
```

### 📌 Замыкание с параметрами и возвратом:

```swift
let multiply = { (a: Int, b: Int) -> Int in
    return a * b
}
print(multiply(3, 4)) // Вывод: 12
```

### 📌 Использование замыканий в функциях:

```swift
func performOperation(_ operation: (Int, Int) -> Int, x: Int, y: Int) -> Int {
    return operation(x, y)
}

let result = performOperation({ a, b in a + b }, x: 5, y: 3)
print(result) // Вывод: 8
```

> 🧠 Замыкания часто используются в UIKit и Flutter (например, при работе с `Future`, `Stream`, `Callback`).
