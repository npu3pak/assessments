# Лекция: iOS. Многопоточность async/await

В этой лекции мы рассмотрим тему **асинхронного программирования** в контексте разработки приложений под iOS, используя язык **Dart** и фреймворк **Flutter**, который предоставляет мощные инструменты для работы с асинхронными задачами.

## Введение

Многопоточность — это способность выполнять несколько операций одновременно. В мире мобильной разработки особенно важно правильно управлять асинхронными задачами, чтобы избежать блокировки интерфейса пользователя и обеспечить высокую производительность.

**Dart** поддерживает асинхронное программирование через ключевые слова `async`, `await`, а также предоставляет удобные механизмы для работы с `Future` и `Stream`.

---

## 1. Tasks, приоритет, detached

### Что такое Task?

**Task** (задача) — это выполнение какого-либо кода в фоне, которое может быть выполнено параллельно или последовательно с основным потоком.

В Dart задачи реализуются через `Future`, которые являются обещаниями выполнения асинхронной операции. `Future` может быть:
- **Завершённой** (completed)
- **Выполняемой** (pending)
- **Отменённой** (cancelled)

### Приоритет задач

В Dart нет прямого понятия "приоритета" для `Future`. Однако можно использовать различные подходы:
- Использование `Future.delayed()` — для запланированного выполнения
- Использование `compute()` — для параллельной обработки данных (доступен только в Flutter)
- Для управления приоритетом задач в более сложных сценариях можно использовать библиотеки, например, `flutter_scheduler`

Пример:
```dart
Future<void> main() async {
  // Задача 1
  Future.delayed(Duration(seconds: 2), () {
    print("Задача 1 выполнена");
  });

  // Задача 2
  Future.delayed(Duration(seconds: 1), () {
    print("Задача 2 выполнена");
  });

  await Future.delayed(Duration(seconds: 3));
}
```

В этом примере обе задачи запускаются асинхронно, но в порядке задержки.

### Detached Tasks

**Detached tasks** — это задачи, которые не связаны с контекстом вызова и могут выполняться независимо. В Dart таких понятий нет напрямую, но можно использовать `compute()` для выполнения задач в отдельном потоке.

Пример:
```dart
import 'package:flutter/foundation.dart';

int computeSum(List<int> numbers) {
  return numbers.reduce((a, b) => a + b);
}

Future<void> main() async {
  final data = List.generate(1000000, (i) => i);

  // Выполняется в отдельном потоке
  final result = await compute(computeSum, data);
  print("Сумма: $result");
}
```

## 2. Конструкция async/await

### Что такое async/await?

`async` и `await` — это синтаксические конструкции для работы с асинхронными операциями в Dart.

- `async` указывает, что функция будет выполнять асинхронные операции.
- `await` ожидает завершения `Future` перед продолжением выполнения кода.

### Пример:

```dart
Future<String> fetchData() async {
  await Future.delayed(Duration(seconds: 2));
  return "Данные получены";
}

void main() async {
  print("Начинаем загрузку...");
  final data = await fetchData();
  print(data); // Вывод: "Данные получены" через 2 секунды
}
```

### Особенности:

- `await` может использоваться только внутри функций, помеченных как `async`.
- `async` функция всегда возвращает `Future`.

### Важно:
Если вы вызываете `await` без `async`, компилятор выдаст ошибку. Пример ошибки:

```dart
void main() {
  var data = await fetchData(); // ОШИБКА!
}
```

## 3. Вызов асинхронного кода из синхронного метода

В Dart нельзя напрямую вызвать `await` в синхронной функции, но можно обернуть вызов в `Future`.

### Пример:

```dart
void main() {
  fetchData().then((data) {
    print(data);
  });
}

Future<String> fetchData() async {
  await Future.delayed(Duration(seconds: 2));
  return "Данные получены";
}
```

Если же вы хотите использовать `await` в синхронном контексте, вы можете обернуть его в `async`:

```dart
void syncFunction() {
  // Нельзя использовать await здесь напрямую
  fetchData().then((data) {
    print(data);
  });
}
```

Альтернатива — использовать `Future` с цепочкой вызовов (`then`, `catchError`, и т.д.).

## 4. Параллельное выполнение нескольких асинхронных функций

Чтобы выполнять несколько асинхронных задач параллельно, можно использовать `Future.wait()` или `Future.forEach`.

### Пример:

```dart
Future<String> fetchUser(int id) async {
  await Future.delayed(Duration(seconds: 1));
  return "Пользователь $id";
}

Future<void> main() async {
  final futures = [
    fetchUser(1),
    fetchUser(2),
    fetchUser(3)
  ];

  // Все задачи выполняются параллельно
  final results = await Future.wait(futures);
  print(results); // Вывод: ["Пользователь 1", "Пользователь 2", "Пользователь 3"]
}
```

### Альтернатива с `Future.forEach`:

```dart
Future<void> main() async {
  final ids = [1, 2, 3];
  await Future.forEach(ids, (id) async {
    final user = await fetchUser(id);
    print(user);
  });
}
```

## 5. Асинхронные свойства

В Dart **свойства не могут быть асинхронными напрямую**, но можно использовать `Future` как значение свойства.

Пример:

```dart
class ApiService {
  Future<String> _data = Future.value("default");

  Future<String> get data async {
    return await _data;
  }

  set data(Future<String> value) {
    _data = value;
  }
}

void main() async {
  final api = ApiService();
  print(await api.data); // Вывод: default
}
```

Можно также использовать `late` и `FutureBuilder` в Flutter для асинхронных данных.

## 6. Отмена асинхронных задач

В Dart нет встроенного механизма отмены `Future`, но можно использовать `Completer` и `cancel()`.

### Пример:

```dart
Future<String> fetchDataWithCancel() {
  final completer = Completer<String>();

  Future.delayed(Duration(seconds: 5), () {
    if (!completer.isCompleted) {
      completer.complete("Данные получены");
    }
  });

  return completer.future;
}

void main() async {
  final future = fetchDataWithCancel();
  try {
    final result = await future.timeout(Duration(seconds: 2));
    print(result);
  } catch (e) {
    print("Запрос отменён или превышен таймаут");
  }
}
```

Также можно использовать `Future.cancel()` в специальных случаях.

## 7. Обработка ошибок

В Dart ошибки в асинхронных задачах обрабатываются через `try/catch` или методы `catchError`.

### Пример:

```dart
Future<String> fetchDataWithError() async {
  await Future.delayed(Duration(seconds: 1));
  throw Exception("Ошибка при получении данных");
}

void main() async {
  try {
    final data = await fetchDataWithError();
    print(data);
  } on Exception catch (e) {
    print("Произошла ошибка: $e");
  }
}
```

### Альтернатива через `then` и `catchError`:

```dart
void main() {
  fetchDataWithError()
    .then((data) => print(data))
    .catchError((error) => print("Ошибка: $error"));
}
```
