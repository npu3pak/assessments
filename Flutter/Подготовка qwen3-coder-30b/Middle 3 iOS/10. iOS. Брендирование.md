# Лекция: iOS. Брендирование приложения в Flutter

## Введение

В мире мобильной разработки **брендинг** — это не просто красивая обложка или логотип. Это ощущение, которое получает пользователь при взаимодействии с вашим приложением. Особенно важно правильно реализовать брендирование на iOS, где пользователи ожидают высокого уровня качества и стиля.

В данной лекции мы рассмотрим ключевые аспекты **брендирования приложений на iOS**, используя Flutter и Dart. Мы расскажем о:

1. Базовой настройке темы с помощью `Appearance`.
2. Кастомизации названия приложения.
3. Настройке значка (App Icon).
4. Кастомизации экрана запуска (Splash Screen).

Эта информация поможет вам создавать профессиональные, хорошо оформленные и визуально согласованные мобильные приложения.

## 1. Базовая настройка темы приложения с помощью Appearance

В iOS существует возможность глобальной установки темы через систему `UIAppearance`. Хотя Flutter — кроссплатформенная технология, она позволяет использовать и нативные возможности iOS через `PlatformView` или через специальные пакеты (например, `flutter_native_splash`, `flutter_app_icon`). Однако в рамках чистого Flutter-приложения, чтобы настроить тему (например, стиль кнопок, панелей и т.п.), нужно использовать **Material Design** с определёнными правилами.

### 1.1 Что такое Appearance?

`Appearance` — это механизм iOS, позволяющий управлять внешним видом элементов интерфейса на уровне приложения или конкретного контроллера. Он применяется для изменения стиля UI-компонентов без переписывания кода.

### 1.2 Пример: Установка темы через MaterialApp

В Flutter вы можете использовать `MaterialApp` для установки глобальной темы. Вот как это делается:

```dart
void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'My App',
      theme: ThemeData(
        primarySwatch: Colors.blue,
        brightness: Brightness.light, // Темная или светлая тема
        fontFamily: 'Roboto', // Шрифт
        appBarTheme: AppBarTheme(
          backgroundColor: Colors.blue,
          foregroundColor: Colors.white,
        ),
        elevatedButtonTheme: ElevatedButtonThemeData(
          style: ElevatedButton.styleFrom(
            backgroundColor: Colors.blue, // Цвет кнопки
            foregroundColor: Colors.white,
          ),
        ),
      ),
      home: HomeScreen(),
    );
  }
}
```

В этом примере мы задаём тему светлую (`brightness: Brightness.light`) с синим основным цветом, устанавливаем стиль `AppBar`, а также кастомизируем кнопки.

> ⚠️ Важно: `MaterialApp` не предоставляет прямого доступа к нативному `UIAppearance`, но вы можете использовать пакеты, такие как [flutter_appappearance](https://pub.dev/packages/flutter_appappearance), для более тонкой настройки темы.

### 1.3 Настройка темной темы

Если вы хотите поддерживать и темную тему, это можно сделать через `ThemeData`:

```dart
theme: ThemeData(
  brightness: Brightness.dark,
  primarySwatch: Colors.blue,
  appBarTheme: AppBarTheme(
    backgroundColor: Colors.grey[900],
    foregroundColor: Colors.white,
  ),
),
```

## 2. Кастомизация названия приложения

В iOS название приложения отображается в заголовке экрана, в менеджере приложений, а также в системном интерфейсе.

### 2.1 Название в Flutter (title)

В Flutter вы можете задать название приложения в `MaterialApp`:

```dart
MaterialApp(
  title: 'Моё Приложение',
  ...
)
```

Но это не всегда отображается в системе, особенно если вы используете нативные компоненты или пакеты.

### 2.2 Официальное название в Info.plist

Чтобы имя отображалось корректно в iOS (например, на экране запуска, в списке приложений), вам нужно изменить файл `Info.plist`:

1. Перейдите в папку `ios/Runner/`.
2. Откройте файл `Info.plist`.
3. Найдите строку `<key>CFBundleDisplayName</key>` и установите нужное значение:

```xml
<key>CFBundleDisplayName</key>
<string>Моё Приложение</string>
```

Это имя будет отображаться в системе и в менеджере приложений.

## 3. Кастомизация значика приложения

Значок (App Icon) — один из самых важных элементов брендинга, поскольку он первым бросается в глаза пользователю.

### 3.1 Подготовка иконки

iOS требует несколько размеров иконок:

- `20x20` (iPhone Settings)
- `29x29` (iPhone Spotlight)
- `40x40` (iPhone Notifications)
- `60x60` (iPhone Home Screen)
- `76x76` (iPad App Store)
- `83.5x83.5` (iPad Pro)

Формат: PNG без прозрачности.

### 3.2 Установка значков в Flutter

1. Скопируйте подготовленные иконки в папку `ios/Runner/Assets.xcassets/AppIcon.appiconset`.
2. Замените файл `Contents.json` на вашу версию, указав размеры.

Пример `Contents.json`:

```json
{
  "images": [
    {
      "size": "20x20",
      "idiom": "iphone",
      "filename": "icon-20@2x.png",
      "scale": "2x"
    },
    {
      "size": "20x20",
      "idiom": "iphone",
      "filename": "icon-20@3x.png",
      "scale": "3x"
    }
  ],
  "info": {
    "version": 1,
    "author": "xcode"
  }
}
```

> ⚠️ Важно: Используйте пакет `flutter_launcher_icons` для автоматической генерации иконок из одного изображения:

```yaml
dev_dependencies:
  flutter_launcher_icons: ^0.13.1

# В pubspec.yaml
flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/icon.png"
```

Запустите:

```bash
flutter pub get
flutter pub run flutter_launcher_icons:main
```

## 4. Кастомизация экрана запуска (Splash Screen)

iOS не позволяет установить полноценный splash screen как в Android, но можно использовать **LaunchScreen.storyboard** для создания эффекта запуска.

### 4.1 Что такое LaunchScreen

LaunchScreen — это статический экран, который отображается сразу после запуска приложения до тех пор, пока Flutter не загрузится полностью. Он создаётся в Xcode.

### 4.2 Создание LaunchScreen в Xcode

1. Откройте проект в Xcode: `ios/Runner.xcworkspace`.
2. Перейдите в папку `Runner` → `LaunchScreen.storyboard`.
3. Добавьте изображение (например, логотип) и настройте его положение.
4. Убедитесь, что он отображается в режиме `Scale to Fill` или `Aspect Fit`.

### 4.3 Стилизация через Flutter

Если вы хотите сделать Splash Screen в Flutter (на самом деле, это не стандартный способ), используйте пакет [flutter_native_splash](https://pub.dev/packages/flutter_native_splash):

```yaml
dev_dependencies:
  flutter_native_splash: ^2.3.0

# В pubspec.yaml
flutter_native_splash:
  color: "#42a5f5"
  image: assets/splash.png
  android_gravity: center
  ios_content_mode: scaleAspectFit
```

Затем выполните:

```bash
flutter pub get
flutter pub run flutter_native_splash:create
```
