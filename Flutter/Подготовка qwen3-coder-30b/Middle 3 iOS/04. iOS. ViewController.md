### Лекция: iOS ViewController

#### Введение  
В рамках этой лекции мы рассмотрим один из ключевых компонентов архитектуры приложений под iOS — **UIViewController**. Несмотря на то, что Flutter не использует MVC (Model-View-Controller) напрямую, знание работы ViewController важно для понимания логики взаимодействия между экранами и управлением жизненным циклом в мобильной разработке, особенно если вы работаете с iOS или используете Flutter с нативными компонентами.

---

## 1. Создание и запуск ViewController

### Что такое UIViewController?

**UIViewController** — это класс, который управляет отображением и взаимодействием с пользователем на одном экране (view). Он представляет собой контроллер между моделью данных и интерфейсом пользователя.

Вот основные обязанности `UIViewController`:

- Управление жизненным циклом экрана
- Обработка событий от UI-компонентов
- Управление переходами между экранами
- Поддержка анимаций
- Взаимодействие с другими контроллерами через `navigation stack`, `tab bar`, и т.п.

---

### Как создать ViewController?

Создание `UIViewController` может происходить двумя способами:

#### 1. Программное создание:
```swift
class MyViewController: UIViewController {
    override func viewDidLoad() {
        super.viewDidLoad()
        view.backgroundColor = UIColor.white
        title = "Мой экран"
    }
}
```

Здесь мы наследуемся от `UIViewController` и переопределяем метод `viewDidLoad`, который вызывается после того, как view загружена в память.

#### 2. Через Storyboard:
1. Открываем файл `Main.storyboard`
2. Добавляем новый UIViewController через панель инструментов
3. Привязываем его к классу `MyViewController` в Identity Inspector

Для запуска ViewController нужно установить его как начальный контроллер в `SceneDelegate` или `AppDelegate`.

Пример установки начального контроллера в `SceneDelegate.swift`:
```swift
func scene(_ scene: UIScene, willConnectTo session: UISceneSession, options connectionOptions: UIScene.ConnectionOptions) {
    guard let windowScene = (scene as? UIWindowScene) else { return }
    
    window = UIWindow(windowScene: windowScene)
    let storyboard = UIStoryboard(name: "Main", bundle: nil)
    let initialViewController = storyboard.instantiateInitialViewController()
    window?.rootViewController = initialViewController
    window?.makeKeyAndVisible()
}
```

> 🔍 *Примечание:* В современных проектах используются SceneDelegate, а не AppDelegate напрямую. Если вы используете старые проекты — проверьте, где именно инициализируется `UIWindow`.

## 2. Жизненный цикл ViewController

Жизненный цикл `UIViewController` определяет этапы жизни контроллера от создания до удаления. Понимание этих этапов позволяет правильно управлять ресурсами, начинать/останавливать таймеры, обновлять UI и т.п.

### Основные методы жизненного цикла:

| Метод | Описание |
|-------|----------|
| `init` | Конструктор контроллера |
| `loadView()` | Создаёт view (если не задан через Storyboard) |
| `viewDidLoad()` | View загружена, можно настраивать UI |
| `viewWillAppear(_:)` | Перед показом view |
| `viewDidAppear(_:)` | После показа view |
| `viewWillDisappear(_:)` | Перед скрытием view |
| `viewDidDisappear(_:)` | После скрытия view |
| `deinit` | Освобождение ресурсов перед удалением |

### Пример реализации:

```swift
class MyViewController: UIViewController {
    
    override func viewDidLoad() {
        super.viewDidLoad()
        print("View loaded")
    }
    
    override func viewWillAppear(_ animated: Bool) {
        super.viewWillAppear(animated)
        print("View will appear")
    }
    
    override func viewDidAppear(_ animated: Bool) {
        super.viewDidAppear(animated)
        print("View did appear")
    }
    
    override func viewWillDisappear(_ animated: Bool) {
        super.viewWillDisappear(animated)
        print("View will disappear")
    }
    
    override func viewDidDisappear(_ animated: Bool) {
        super.viewDidDisappear(animated)
        print("View did disappear")
    }
    
    deinit {
        print("ViewController deallocated")
    }
}
```

> ⚠️ Важно: `viewDidLoad` вызывается один раз при первом доступе к `view`, а все остальные методы могут вызываться многократно при переходах между экранами.

## 3. Верстка в Storyboard. Привязка UI компонентов Storyboard к ViewController

Storyboard — это визуальный редактор, позволяющий создавать интерфейс приложения без написания кода. Он представляет собой графическое представление структуры экранов и связей между ними.

### Основные элементы:

- **ViewController** — основной экран
- **View** — контейнер для UI-компонентов
- **UI Components (UILabel, UIButton, UITextField и т.д.)**
- **Constraints (ограничения)** — обеспечивают адаптивность

### Привязка компонентов к коду:

Чтобы использовать UI-элементы в коде, необходимо создать **IBOutlet** — ссылку на элемент из Storyboard.

#### Пример:
```swift
class MyViewController: UIViewController {
    
    @IBOutlet weak var nameLabel: UILabel!
    @IBOutlet weak var button: UIButton!
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        nameLabel.text = "Привет мир"
        button.setTitle("Нажми меня", for: .normal)
    }
}
```

Чтобы связать компонент с кодом:

1. Выберите нужный UI-компонент в Storyboard
2. Перейдите в правую панель (Assistant Editor)
3. Нажмите на `+` рядом с `Connections` и выберите нужное свойство (`Outlet`, `Action`)
4. Добавьте переменную/функцию

> 💡 *Подсказка:* Обратите внимание на `weak` — это предотвращает циклические ссылки между view и контроллером.

## 4. UITableViewController. Показ секций и ячеек, верстка ячеек в Storyboard, оптимизация потребления ресурсов при создании ячеек

**UITableViewController** — специализированный класс `UIViewController`, предназначенный для отображения списка элементов (UITableView). Он уже содержит в себе `UITableView` внутри себя.

### Основные особенности:

- Использует **data source pattern**
- Поддерживает **sectioned lists** (разделы)
- Автоматически обрабатывает **cell reuse**
- Легко подключается к Storyboard

---

### Базовая реализация UITableViewController

#### Простой список без разделов:

```swift
class ListViewController: UITableViewController {
    
    let items = ["Item 1", "Item 2", "Item 3"]
    
    override func viewDidLoad() {
        super.viewDidLoad()
        title = "Список"
    }
    
    // Количество строк в таблице
    override func tableView(_ tableView: UITableView, numberOfRowsInSection section: Int) -> Int {
        return items.count
    }
    
    // Настройка ячейки
    override func tableView(_ tableView: UITableView, cellForRowAt indexPath: IndexPath) -> UITableViewCell {
        let cell = tableView.dequeueReusableCell(withIdentifier: "Cell", for: indexPath)
        cell.textLabel?.text = items[indexPath.row]
        return cell
    }
}
```

---

### Секции (Sectioned Lists)

Для работы с секциями нужно реализовать:

```swift
override func numberOfSections(in tableView: UITableView) -> Int {
    return sections.count
}

override func tableView(_ tableView: UITableView, numberOfRowsInSection section: Int) -> Int {
    return sections[section].items.count
}

override func tableView(_ tableView: UITableView, titleForHeaderInSection section: Int) -> String? {
    return sections[section].title
}
```

---

### Верстка ячеек в Storyboard

#### Создание кастомной ячейки:

1. В Storyboard добавьте `UITableViewCell`
2. Установите custom class для ячейки (например, `CustomTableViewCell`)
3. Добавьте IBOutlets и IBActions
4. В коде используйте `dequeueReusableCell(withIdentifier:for:)`

Пример кастомной ячейки:

```swift
class CustomTableViewCell: UITableViewCell {
    @IBOutlet weak var titleLabel: UILabel!
    @IBOutlet weak var subtitleLabel: UILabel!
    
    func configure(with item: Item) {
        titleLabel.text = item.title
        subtitleLabel.text = item.subtitle
    }
}
```

---

### Оптимизация потребления ресурсов при создании ячеек

#### Использование reuse identifier:

```swift
override func tableView(_ tableView: UITableView, cellForRowAt indexPath: IndexPath) -> UITableViewCell {
    let cell = tableView.dequeueReusableCell(withIdentifier: "CustomCell", for: indexPath) as! CustomTableViewCell
    
    let item = items[indexPath.row]
    cell.configure(with: item)
    
    return cell
}
```

Это позволяет повторно использовать ячейки, что значительно экономит память и ускоряет отрисовку.

## Практическое задание

Создайте приложение в Xcode с использованием Storyboard:

1. Добавьте **UITableViewController**
2. Реализуйте список с разделами (например, "Домашние животные", "Птицы", "Рыбы")
3. Каждый раздел должен содержать не менее 5 элементов
4. Сделайте кастомную ячейку с иконкой и текстом
5. При нажатии на ячейку открывайте новый экран (`DetailViewController`) с информацией о выбранном элементе

> 🧠 *Совет:* Используйте `prepare(for:sender:)` для передачи данных между контроллерами.
