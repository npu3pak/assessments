# Лекция: NoSQL базы данных и работа с Hive в Flutter

---

## 1. NoSQL. Область применения и возможности.

### Что такое NoSQL?

**NoSQL (Not Only SQL)** — это термин, обозначающий подход к хранению и управлению данными, который не использует традиционные реляционные модели. В отличие от SQL-баз данных (например, MySQL, PostgreSQL), NoSQL базы данных не требуют фиксированной схемы таблиц, имеют гибкую структуру и часто обеспечивают высокую производительность при масштабировании.

### Основные типы NoSQL баз:

1. **Документо-ориентированные** — хранят данные в формате JSON или BSON, например MongoDB.
2. **Ключ-значение** — используют пары ключ-значение, например Redis, DynamoDB.
3. **Графовые** — хранят данные в виде узлов и связей (например, Neo4j).
4. **Колоночные** — эффективны для агрегационных запросов, например Cassandra.

### Области применения NoSQL:

- **Системы с высокой нагрузкой**, где важно быстрое чтение/запись.
- **Масштабирование горизонтально** (разделение данных по серверам).
- **Гибкие структуры данных**, когда данные меняются часто.
- **Работа с большими объемами неструктурированных данных** (например, логи, медиафайлы).

### Преимущества NoSQL:

- **Гибкость структуры данных** — нет необходимости в фиксированной схеме.
- **Высокая производительность** — особенно при большом количестве параллельных запросов.
- **Масштабируемость** — легко распределить данные по нескольким серверам.
- **Поддержка нестандартных форматов данных**, таких как JSON, XML и т. д.

### Недостатки NoSQL:

- **Отсутствие JOIN'ов** — сложно строить сложные связи между данными.
- **Нет строгой согласованности** — могут возникать проблемы с консистентностью данных (ACID vs BASE).
- **Ограниченная поддержка сложных запросов**, таких как агрегации и транзакции.

### В Flutter:

В Flutter, особенно при разработке офлайн-приложений или при необходимости хранить данные локально, **NoSQL подход** особенно полезен. Для этого используются **локальные NoSQL-хранилища**, такие как **Hive** — популярная и простая библиотека для хранения данных на устройстве пользователя.

## 2. Hive. Описание возможностей

### Что такое Hive?

**Hive** — это легковесная и быстрая NoSQL база данных для Dart/Flutter. Она позволяет хранить данные локально на устройстве пользователя, без подключения к интернету или серверу.

### Основные возможности Hive:

1. **Быстрый доступ к данным** — использует прямой доступ к памяти.
2. **Поддержка разных типов данных** — примитивы (int, double, bool), строки, списки, карты и объекты.
3. **Простота использования** — не требует сложной настройки или подключения к серверу.
4. **Работа с транзакциями** — поддержка атомарности операций.
5. **Поддержка индексов и запросов** — можно делать фильтрацию и сортировку.
6. **Легковесная архитектура** — не требует больших ресурсов.

### Когда использовать Hive?

- Для хранения настроек пользователя.
- Для кэширования данных (например, загруженные данные из API).
- Для офлайн-приложений.
- Для хранения временных данных, которые не требуют сложных отношений между сущностями.

### Как подключить Hive?

1. Добавьте в `pubspec.yaml`:

```yaml
dependencies:
  hive: ^2.2.3
  hive_flutter: ^1.1.0
```

2. Запустите:

```bash
flutter pub get
```

3. Инициализация Hive:

```dart
import 'package:flutter/material.dart';
import 'package:hive_flutter/hive_flutter.dart';

void main() async {
  await Hive.initFlutter();
  runApp(MyApp());
}
```

## 3. Hive. Работа с примитивными типами

### Хранение примитивных типов

Hive поддерживает следующие примитивные типы:

- `String`
- `int`
- `double`
- `bool`
- `DateTime`

Пример:

```dart
import 'package:hive_flutter/hive_flutter.dart';

void main() async {
  await Hive.initFlutter();
  final box = await Hive.openBox('myBox');

  // Запись примитивных типов
  box.put('name', 'Alice');
  box.put('age', 25);
  box.put('isStudent', true);
  box.put('height', 165.5);

  // Чтение
  String name = box.get('name');
  int age = box.get('age');
  bool isStudent = box.get('isStudent');
  double height = box.get('height');

  print('$name, $age, $isStudent, $height');
}
```

### Особенности работы с примитивами:

- Hive работает с `Box`, который представляет собой хранилище пар ключ-значение.
- Все данные сохраняются в формате бинарных данных, что делает их очень быстрыми.
- Ключи должны быть уникальными и типизированными (обычно `String` или `int`).

## 4. Hive. Работа с объектами

### Сериализация объектов в Hive

Для хранения объектов нужно использовать **Hive Object Oriented** (Hive OOP) подход.

1. Создайте класс, который будет сериализуемым:

```dart
import 'package:hive_flutter/hive_flutter.dart';

part 'user.g.dart'; // Файл генерации

@HiveType(typeId: 0)
class User extends HiveObject {
  @HiveField(0)
  String name;

  @HiveField(1)
  int age;

  @HiveField(2)
  bool isActive;

  User(this.name, this.age, this.isActive);
}
```

2. Запустите генерацию:

```bash
flutter pub run build_runner build
```

3. Используйте объекты в коде:

```dart
void main() async {
  await Hive.initFlutter();
  Hive.registerAdapter(UserAdapter()); // Регистрация адаптера
  final box = await Hive.openBox<User>('users');

  // Создание объекта
  final user = User('Bob', 30, true);

  // Сохранение
  box.add(user); // добавить в конец

  // Получение
  User retrievedUser = box.getAt(0);
  print(retrievedUser.name); // Bob
}
```

### Особенности:

- `@HiveType(typeId: 0)` — указывает уникальный тип для сериализации.
- `@HiveField(0)` — поле, которое будет сохранено.
- Для работы с объектами нужна генерация кода (`build_runner`).

## 5. Hive. Транзакции

### Что такое транзакция?

Транзакция в Hive — это группа операций, которые выполняются **всё или ничего** (атомарность). Если одна из операций не удалась, все изменения откатываются.

### Пример использования:

```dart
final box = await Hive.openBox('myBox');

// Начинаем транзакцию
box.transaction(() {
  box.put('key1', 'value1');
  box.put('key2', 'value2');
  // Если произойдет ошибка — все изменения откатятся
});
```

### Зачем нужны транзакции?

- Для обеспечения согласованности данных.
- Когда нужно выполнить несколько операций, и если одна из них не удалась — все остальные не должны быть применены.
