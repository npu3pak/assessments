# Лекция 02: Работа с файлами

## Введение

Работа с файлами — один из важнейших аспектов мобильной разработки, особенно в Flutter. Приложение может сохранять данные пользователя, кэшировать ресурсы, обмениваться информацией и т.д. Для эффективной работы с файловой системой необходимо понимать, где хранятся файлы, какие разрешения нужны, как управлять каталогами и файлами, а также как читать и записывать данные.

В этой лекции мы рассмотрим:

- Где можно хранить файлы в Android и iOS
- Какие разрешения требуются для работы с файлами
- Основные операции с файлами: создание, удаление, копирование, чтение, запись
- Использование библиотеки `path_provider` и `file_picker`
- Примеры на Dart и Flutter

## 1. Где можно хранить файлы в Android и iOS

### В Android:

В Android приложения имеют доступ к следующим каталогам:

#### a) **Internal Storage (внутреннее хранилище)**

- Доступно только вашему приложению.
- Путь: `/data/data/<package_name>/files/`
- Нет необходимости в разрешениях для чтения/записи.
- При удалении приложения данные удаляются.

#### b) **External Storage (внешнее хранилище)**

- Доступно другим приложениям и пользователю.
- Путь: `/storage/emulated/0/Android/data/<package_name>/files/`
- Для доступа к нему нужно запросить разрешение `WRITE_EXTERNAL_STORAGE` (до Android 10) или использовать Scoped Storage (с Android 10+).
- Файлы не удаляются при удалении приложения.

#### c) **Shared Preferences / Documents**

- Используется для хранения небольших данных.
- Нет прямого доступа к файловой системе, но можно использовать `path_provider`.

### В iOS:

iOS более ограничительный в плане файловой системы. Основные каталоги:

#### a) **Documents**

- Каталог для хранения пользовательских данных.
- Путь: `/var/mobile/Containers/Data/Application/<UUID>/Documents/`
- Данные синхронизируются через iCloud (если включено).
- Не требует разрешений.

#### b) **Library/Caches**

- Каталог для временных файлов и кэширования.
- Путь: `/var/mobile/Containers/Data/Application/<UUID>/Library/Caches/`
- Не синхронизируется, данные могут быть удалены системой.

#### c) **tmp (временная папка)**

- Используется для временных файлов.
- Не рекомендуется хранить важные данные.

> Важно: В iOS все пути к файлам должны быть получены через `path_provider`.

## 2. Разрешения в мобильных ОС

### Android

Для доступа к внешнему хранилищу (не включая внутреннюю папку приложения) необходимо:

1. Добавить разрешение в `AndroidManifest.xml`:
   ```xml
   <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"/>
   ```

2. Для Android 6.0 и выше — запросить разрешение во время выполнения (runtime permission):
   ```dart
   import 'package:permission_handler/permission_handler.dart';

   Future<void> requestStoragePermission() async {
     if (await Permission.storage.request().isGranted) {
       // Разрешение получено
     } else {
       // Пользователь отклонил запрос
     }
   }
   ```

### iOS

iOS не требует разрешений для доступа к внутреннему хранилищу. Однако, если вы используете `file_picker` или `path_provider`, разрешения не нужны.

> Но при работе с iCloud и другими облачными сервисами могут потребоваться дополнительные настройки в `Info.plist`.

## 3. Работа с каталогами и файлами

Для работы с файловой системой в Flutter мы будем использовать библиотеку `path_provider`:

```yaml
dependencies:
  path_provider: ^2.1.1
```

### Получение путей к каталогам

```dart
import 'package:path_provider/path_provider.dart';
import 'dart:io';

Future<String> get _localPath async {
  final directory = await getApplicationDocumentsDirectory();
  return directory.path;
}

Future<File> get _localFile async {
  final path = await _localPath;
  return File('$path/todo.txt');
}
```

Также можно использовать:

- `getApplicationDocumentsDirectory()` — для хранения пользовательских данных.
- `getTemporaryDirectory()` — для временных файлов.
- `getExternalStorageDirectory()` — для внешнего хранилища (Android).

## 4. Основные операции с файлами

### a) Создание файла

```dart
Future<File> createFile(String fileName, String content) async {
  final file = File('$path/$fileName');
  await file.writeAsString(content);
  return file;
}
```

### b) Чтение файла

```dart
Future<String> readFromFile() async {
  try {
    final file = await _localFile;
    final contents = await file.readAsString();
    return contents;
  } catch (e) {
    print("Ошибка чтения файла: $e");
    return '';
  }
}
```

### c) Удаление файла

```dart
Future<void> deleteFile() async {
  try {
    final file = await _localFile;
    if (await file.exists()) {
      await file.delete();
      print('Файл удален');
    }
  } catch (e) {
    print("Ошибка удаления файла: $e");
  }
}
```

### d) Копирование файла

```dart
Future<void> copyFile() async {
  final file = await _localFile;
  if (await file.exists()) {
    final newFile = File('${file.path}_copy');
    await file.copy(newFile.path);
    print('Файл скопирован');
  }
}
```

### e) Переименование файла

```dart
Future<void> renameFile() async {
  final file = await _localFile;
  if (await file.exists()) {
    final renamedFile = File('${file.path}_renamed');
    await file.rename(renamedFile.path);
    print('Файл переименован');
  }
}
```

### f) Получение метаданных файла

```dart
Future<void> getFileMetadata() async {
  final file = await _localFile;
  if (await file.exists()) {
    final stat = await file.stat();
    print('Размер: ${stat.size} байт');
    print('Дата создания: ${stat.modified}');
  }
}
```

### g) Получение списка файлов в каталоге

```dart
Future<List<File>> getFilesInDirectory() async {
  final directory = await getApplicationDocumentsDirectory();
  final files = directory.listSync(recursive: false)
      .where((file) => file is File)
      .map((file) => file as File)
      .toList();

  return files;
}
```

## 5. Как прочитать файл

Существует несколько способов чтения файлов:

### Строки

```dart
String content = await file.readAsString();
```

### Байты

```dart
Uint8List bytes = await file.readAsBytes();
```

### Построчно

```dart
final lines = await file.readAsLines();
for (var line in lines) {
  print(line);
}
```

---

## 6. Как записать данные в файл

### Строки

```dart
await file.writeAsString('Привет, мир!');
```

### Байты

```dart
Uint8List bytes = Uint8List.fromList([1, 2, 3, 4]);
await file.writeAsBytes(bytes);
```

### Добавление данных (append)

```dart
await file.writeAsString('\nНовая строка', mode: FileMode.append);
```

## Пример полного кода

```dart
import 'package:flutter/material.dart';
import 'package:path_provider/path_provider.dart';
import 'dart:io';

class FileManagerExample extends StatefulWidget {
  @override
  _FileManagerExampleState createState() => _FileManagerExampleState();
}

class _FileManagerExampleState extends State<FileManagerExample> {
  Future<String> get _localPath async {
    final directory = await getApplicationDocumentsDirectory();
    return directory.path;
  }

  Future<File> get _localFile async {
    final path = await _localPath;
    return File('$path/todo.txt');
  }

  Future<void> _writeToFile(String content) async {
    final file = await _localFile;
    await file.writeAsString(content);
  }

  Future<String> _readFromFile() async {
    try {
      final file = await _localFile;
      return await file.readAsString();
    } catch (e) {
      return 'Ошибка чтения файла';
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Работа с файлами')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            ElevatedButton(
              onPressed: () => _writeToFile('Hello, Flutter!'),
              child: Text('Записать в файл'),
            ),
            SizedBox(height: 10),
            ElevatedButton(
              onPressed: () async {
                String content = await _readFromFile();
                print(content);
              },
              child: Text('Прочитать из файла'),
            ),
          ],
        ),
      ),
    );
  }
}
```
