# Лекция: Работа с WebSocket в Flutter

## Введение

WebSocket — это протокол связи, обеспечивающий двустороннюю связь между клиентом (в нашем случае — мобильным приложением на Flutter) и сервером. Он работает поверх TCP и предоставляет полнодуплексный канал обмена данными, что позволяет серверу отправлять данные клиенту в любое время без необходимости делать HTTP-запросы.

Это особенно важно для таких приложений, как:
- Чаты
- Игры в реальном времени
- Системы уведомлений
- Мониторинг данных (например, цена акций)

WebSocket использует специальный заголовок `Upgrade` в HTTP-запросе, чтобы «обновить» соединение с обычного HTTP на WebSocket. После этого обмен происходит по специальному протоколу WebSocket, который не требует повторных рукопожатий.

## 1. Описание механизма WebSocket

### Что такое WebSocket?

WebSocket — это протокол, обеспечивающий полнодуплексную связь между клиентом и сервером через одно постоянное соединение. Это означает, что:

- Клиент и сервер могут отправлять данные в любую сторону без необходимости создавать новый HTTP-запрос.
- Данные передаются в виде сообщений (фреймов), которые могут быть текстовыми или бинарными.
- Соединение остается открытым, пока клиент или сервер не закроют его.

### Как происходит установка соединения?

1. Клиент отправляет HTTP-запрос с заголовком `Upgrade: websocket`.
2. Сервер отвечает `101 Switching Protocols`, если согласен на переход на WebSocket.
3. После этого начинается обмен данными по протоколу WebSocket.

### Преимущества WebSocket:

- **Низкая задержка** — данные отправляются сразу, без ожидания HTTP-запросов.
- **Эффективность** — нет необходимости повторно передавать заголовки.
- **Поддержка бинарных данных** — можно передавать любые данные (файлы, JSON и т.д.).

### Недостатки:

- Требуется поддержка на стороне сервера.
- Не все прокси поддерживают WebSocket.
- При разрыве соединения необходимо реализовать логику восстановления.

## 2. Пакет `web_socket_channel`

`web_socket_channel` — это пакет Flutter, который позволяет работать с WebSocket-соединениями. Он предоставляет удобный способ создания и управления каналами обмена данными через WebSocket.

### Установка

```yaml
dependencies:
  web_socket_channel: ^2.4.0
```

### Основные классы:

#### `WebSocketChannel`
Класс, представляющий WebSocket-канал. Он предоставляет:

- `stream` — поток входящих сообщений.
- `sink` — для отправки сообщений на сервер.
- `close()` — закрытие соединения.

#### `WebSocketChannel.connect()`
Создает подключение к WebSocket-серверу.

### Пример использования:

```dart
import 'package:web_socket_channel/web_socket_channel.dart';

void connectToWebSocket() {
  final channel = WebSocketChannel.connect(
    Uri.parse('ws://localhost:8080/websocket'),
  );

  // Получаем данные от сервера
  channel.stream.listen(
    (message) {
      print('Получено сообщение: $message');
    },
    onError: (error) {
      print('Ошибка: $error');
    },
    onDone: () {
      print('Соединение закрыто');
    },
  );

  // Отправляем данные на сервер
  channel.sink.add('Привет, сервер!');

  // Закрываем соединение при необходимости
  // channel.sink.close();
}
```

### Особенности:

- `channel.stream` — это `Stream<String>` или `Stream<Uint8List>`, в зависимости от типа данных.
- `channel.sink.add()` — отправляет данные на сервер.
- Важно обрабатывать `onError` и `onDone`, чтобы корректно управлять соединением.

### Пример: Чат с WebSocket

Представим, что мы делаем простой чат в Flutter:

```dart
class ChatScreen extends StatefulWidget {
  @override
  _ChatScreenState createState() => _ChatScreenState();
}

class _ChatScreenState extends State<ChatScreen> {
  late WebSocketChannel channel;
  List<String> messages = [];
  final TextEditingController controller = TextEditingController();

  @override
  void initState() {
    super.initState();
    channel = WebSocketChannel.connect(
      Uri.parse('ws://localhost:8080/chat'),
    );

    channel.stream.listen(
      (message) {
        setState(() {
          messages.add(message);
        });
      },
      onError: (error) {
        print('Ошибка: $error');
      },
      onDone: () {
        print('Соединение закрыто');
      },
    );
  }

  @override
  void dispose() {
    channel.sink.close();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Чат')),
      body: Column(
        children: [
          Expanded(
            child: ListView.builder(
              itemCount: messages.length,
              itemBuilder: (context, index) {
                return ListTile(title: Text(messages[index]));
              },
            ),
          ),
          TextField(
            controller: controller,
            onSubmitted: (value) {
              channel.sink.add(value);
              controller.clear();
            },
          )
        ],
      ),
    );
  }
}
```

## 3. Centrifuge

Centrifuge — это клиентская библиотека для работы с WebSocket-серверами, которая предоставляет расширенные возможности:

- Поддержка **пространств имен (channels)**.
- **Автоматическое восстановление соединения**.
- **Поддержка JWT токенов**.
- **Многопоточная работа с событиями**.
- **Расширяемость через middleware**.

### Для Flutter есть пакет `centrifuge_flutter`, который позволяет использовать Centrifuge в приложениях.

#### Установка:

```yaml
dependencies:
  centrifuge_flutter: ^0.1.0
```

#### Пример использования:

```dart
import 'package:centrifuge_flutter/centrifuge_flutter.dart';

void connectToCentrifuge() {
  final client = CentrifugeClient(
    'ws://localhost:8000/connection/websocket',
    options: ClientOptions(
      token: 'your-jwt-token', // если используется авторизация
    ),
  );

  client.onConnect = (event) {
    print('Подключено к Centrifuge');
  };

  client.onDisconnect = (event) {
    print('Отключено от Centrifuge');
  };

  final channel = client.newChannel('chat');

  channel.onSubscribe = (event) {
    print('Подписка на канал успешна');
  };

  channel.onPublish = (event) {
    print('Получено сообщение: ${event.data}');
  };

  channel.subscribe();

  // Отправка сообщения
  channel.publish('Привет, мир!');
}
```

### Преимущества Centrifuge:

- **Автоматическое восстановление соединений**.
- **Поддержка токенов (JWT)**.
- **Масштабируемость** — может работать с большим количеством каналов.
- **Публикация/подписка** — удобно для чатов, уведомлений и т.п.
