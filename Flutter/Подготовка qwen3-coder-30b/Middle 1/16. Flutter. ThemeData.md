# Лекция: Flutter. ThemeData

## Введение в ThemeData

**ThemeData** — это мощный инструмент в Flutter, позволяющий управлять внешним видом всех элементов приложения. Он определяет стили для различных компонентов, таких как кнопки, текстовые поля, заголовки и другие виджеты. Используя `ThemeData`, вы можете создать единую цветовую схему и стиль приложения, который будет применяться ко всем элементам.

Важно понимать, что `ThemeData` — это не просто набор цветов, а полноценный объект, содержащий множество параметров, которые могут быть настроены под любые требования дизайна. Это особенно полезно при создании темной/светлой темы, или при необходимости использовать разные стили для разных частей приложения.

---

## Что такое ThemeData и как с помощью нее можно управлять внешним видом элементов

`ThemeData` — это класс в Flutter, который содержит набор свойств, определяющих внешний вид всех виджетов в рамках темы. Он используется внутри виджета `MaterialApp`, чтобы задать глобальные стили для всего приложения.

Вот как выглядит базовое использование:

```dart
MaterialApp(
  theme: ThemeData(
    primaryColor: Colors.blue,
    scaffoldBackgroundColor: Colors.grey[100],
    appBarTheme: AppBarTheme(
      backgroundColor: Colors.blue,
      titleTextStyle: TextStyle(color: Colors.white),
    ),
  ),
  home: MyHomePage(),
)
```

В этом примере:
- `primaryColor` задаёт основной цвет приложения (используется для кнопок, заголовков и т.д.).
- `scaffoldBackgroundColor` устанавливает фоновый цвет страницы.
- `appBarTheme` задаёт тему для `AppBar`.

Таким образом, `ThemeData` позволяет управлять стилем элементов глобально — вы не должны вручную указывать цвета и стили для каждого виджета.

## Какие параметры можно настроить в ThemeData

`ThemeData` содержит множество свойств. Ниже приведены основные категории:

### 1. Цветовая тема
- `primaryColor`: Основной цвет приложения (используется для кнопок, заголовков).
- `accentColor`: Вторичный цвет (в некоторых виджетах).
- `backgroundColor`: Фоновый цвет всего приложения.
- `textSelectionColor`: Цвет выделения текста.
- `primarySwatch`: Сет цветов (например, `Colors.blue`), используется для автоматического подбора цветов в теме.

### 2. Текст
- `textTheme`: Тема текста — задаёт шрифты, размеры и цвета заголовков.
- `textSelectionTheme`: Стиль выделенного текста.
- `inputDecorationTheme`: Стиль полей ввода (`TextField`, `TextFormField`).

### 3. AppBar
- `appBarTheme`: Тема для `AppBar`.
- `toolbarHeight`: Высота панели инструментов.

### 4. Кнопки и элементы управления
- `buttonTheme`: Тема для кнопок.
- `floatingActionButtonTheme`: Тема для `FloatingActionButton`.
- `checkboxTheme`, `radioTheme`, `switchTheme`: Темы для чекбоксов, радио-кнопок и переключателей.

### 5. Стили для Material компонентов
- `cardTheme`: Тема для `Card`.
- `bottomSheetTheme`: Тема для `BottomSheet`.
- `dialogTheme`: Тема для диалоговых окон.

### 6. Стили для списков и таблиц
- `listTileTheme`: Тема для `ListTile`.

Пример полной настройки:

```dart
ThemeData(
  primaryColor: Colors.blue,
  scaffoldBackgroundColor: Colors.grey[100],
  appBarTheme: AppBarTheme(
    backgroundColor: Colors.blue,
    titleTextStyle: TextStyle(color: Colors.white, fontSize: 20),
    elevation: 0,
  ),
  textTheme: TextTheme(
    headlineLarge: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
    bodyMedium: TextStyle(fontSize: 16, color: Colors.black87),
  ),
  inputDecorationTheme: InputDecorationTheme(
    border: OutlineInputBorder(),
    filled: true,
    fillColor: Colors.white,
  ),
)
```

## Как сделать поддержку разных цветовых схем с использованием ThemeData

Чтобы реализовать поддержку светлой и темной темы, необходимо создать несколько объектов `ThemeData` и переключаться между ними. Это можно сделать с помощью `ChangeNotifier`, `Provider`, или просто через `StatefulWidget`.

Пример:

```dart
class ThemeProvider extends ChangeNotifier {
  ThemeData _currentTheme = lightTheme;

  ThemeData get currentTheme => _currentTheme;

  void toggleTheme() {
    _currentTheme = _currentTheme == lightTheme ? darkTheme : lightTheme;
    notifyListeners();
  }
}

final lightTheme = ThemeData(
  brightness: Brightness.light,
  primaryColor: Colors.blue,
  scaffoldBackgroundColor: Colors.white,
);

final darkTheme = ThemeData(
  brightness: Brightness.dark,
  primaryColor: Colors.blueAccent,
  scaffoldBackgroundColor: Colors.grey[900],
);
```

Затем в `MaterialApp`:

```dart
ChangeNotifierProvider(
  create: (_) => ThemeProvider(),
  child: Consumer<ThemeProvider>(
    builder: (context, themeProvider, _) {
      return MaterialApp(
        theme: themeProvider.currentTheme,
        home: MyHomePage(),
      );
    },
  ),
);
```

Таким образом, вы можете переключать тему в зависимости от настроек пользователя или состояния приложения.

## Как для разных тем оформления кастомизировать произвольные параметры, например тени

`ThemeData` предоставляет возможность настраивать даже такие сложные элементы, как тени. Для этого можно использовать `elevation` и `shadowColor` в соответствующих темах:

```dart
cardTheme: CardTheme(
  elevation: 4,
  shadowColor: Colors.black.withOpacity(0.2),
  shape: RoundedRectangleBorder(
    borderRadius: BorderRadius.circular(12),
  ),
)
```

Вы также можете задавать тени для `FloatingActionButton` или других элементов через их темы:

```dart
floatingActionButtonTheme: FloatingActionButtonThemeData(
  elevation: 6,
  shadowColor: Colors.black.withOpacity(0.3),
)
```

Также можно использовать `BoxShadow` в кастомных виджетах, но для глобального стиля лучше использовать `ThemeData`.
