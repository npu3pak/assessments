# Лекция: Flutter. ValueNotifier

## Введение

В мире Flutter разработки, особенно на уровне Middle, важно понимать механизмы управления состоянием приложения. Один из ключевых инструментов для работы с локальным состоянием — это **ValueNotifier**. Он используется для отслеживания изменений данных и уведомления виджетов о необходимости перерисовки.

## 1. Что такое ValueNotifier?

### Описание механизма

**ValueNotifier** — это класс из пакета `flutter` (входит в основную библиотеку Flutter), который реализует паттерн **Observer (Наблюдатель)**. Он предназначен для уведомления других объектов о том, что значение внутри него изменилось.

### Основные особенности ValueNotifier:

- Является наследником `ChangeNotifier`, который предоставляет методы `notifyListeners()` и `addListener()`.
- Хранит одно значение (value) типа T.
- При изменении значения вызывает `notifyListeners()`, что приводит к перерисовке виджетов, подписанных на изменения.
- Используется для простых случаев управления состоянием без необходимости в сложных архитектурных паттернах.

### Пример использования ValueNotifier:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: HomeScreen(),
    );
  }
}

class HomeScreen extends StatefulWidget {
  @override
  _HomeScreenState createState() => _HomeScreenState();
}

class _HomeScreenState extends State<HomeScreen> {
  final ValueNotifier<int> counter = ValueNotifier<int>(0);

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('ValueNotifier Example')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(
              'Count: ${counter.value}',
              style: TextStyle(fontSize: 24),
            ),
            SizedBox(height: 20),
            ElevatedButton(
              onPressed: () {
                counter.value++; // Изменение значения
              },
              child: const Text('Increment'),
            ),
          ],
        ),
      ),
    );
  }
}
```

### Как это работает:

1. Мы создаём `ValueNotifier<int>` с начальным значением `0`.
2. В виджете мы используем `counter.value`, чтобы получить текущее значение.
3. При нажатии на кнопку, мы изменяем значение через `counter.value = newValue`.
4. Когда значение меняется, автоматически вызывается `notifyListeners()`, и все виджеты, подписанные на изменения (`ValueListenableBuilder` или `ValueNotifier`), перерисовываются.

## 2. Важные методы ValueNotifier

### 1. `value`
Это свойство позволяет получить или установить текущее значение. Это ключевая часть механизма.

```dart
ValueNotifier<int> notifier = ValueNotifier<int>(5);
print(notifier.value); // 5

notifier.value = 10;
print(notifier.value); // 10
```

### 2. `addListener()`
Подписывает функцию на изменения значения. Когда значение изменяется, вызывается переданная функция.

```dart
ValueNotifier<int> notifier = ValueNotifier<int>(0);

notifier.addListener(() {
  print('Value changed to: ${notifier.value}');
});

notifier.value = 5; // Вывод: Value changed to: 5
```

### 3. `removeListener()`
Отписывает функцию от изменений.

```dart
void myCallback() {
  print('Value changed');
}

notifier.addListener(myCallback);
notifier.removeListener(myCallback); // Удаление подписки
```

## 3. Как ValueNotifier используется в виджетах

### С использованием `ValueListenableBuilder`

`ValueListenableBuilder` — это удобный способ автоматически перерисовывать виджет при изменении `ValueNotifier`.

```dart
ValueListenableBuilder<int>(
  valueListenable: counter,
  builder: (context, value, child) {
    return Text('Count: $value');
  },
)
```

### Пример с несколькими ValueNotifier

```dart
class MultiValueExample extends StatefulWidget {
  @override
  _MultiValueExampleState createState() => _MultiValueExampleState();
}

class _MultiValueExampleState extends State<MultiValueExample> {
  final ValueNotifier<int> counter = ValueNotifier<int>(0);
  final ValueNotifier<String> name = ValueNotifier<String>('Flutter');

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Multi ValueNotifier')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            ValueListenableBuilder<int>(
              valueListenable: counter,
              builder: (context, value, child) {
                return Text('Counter: $value');
              },
            ),
            ValueListenableBuilder<String>(
              valueListenable: name,
              builder: (context, value, child) {
                return Text('Name: $value');
              },
            ),
            ElevatedButton(
              onPressed: () {
                counter.value++;
                name.value = 'Dart';
              },
              child: const Text('Update'),
            ),
          ],
        ),
      ),
    );
  }
}
```

## 4. Когда использовать ValueNotifier?

### Преимущества:

- Простота использования.
- Нет необходимости в дополнительных пакетах (встроен в Flutter).
- Подходит для небольших частей состояния, где не нужна сложная архитектура.

### Когда использовать:

- Для простых локальных значений, например, счетчиков.
- Для управления состоянием внутри одного виджета или StatefulWidget.
- В качестве временного решения до перехода на более мощные инструменты (например, Riverpod, Bloc и т.д.).

### Когда не использовать:

- Для глобального состояния приложения.
- При сложной логике управления данными.
- Если нужна реактивность или межвиджетная связь.

## 5. Примеры практического использования

### 1. Счётчик с ValueNotifier

```dart
class CounterScreen extends StatefulWidget {
  @override
  _CounterScreenState createState() => _CounterScreenState();
}

class _CounterScreenState extends State<CounterScreen> {
  final ValueNotifier<int> _counter = ValueNotifier<int>(0);

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Counter with ValueNotifier')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            ValueListenableBuilder<int>(
              valueListenable: _counter,
              builder: (context, value, child) {
                return Text(
                  'Count: $value',
                  style: TextStyle(fontSize: 32),
                );
              },
            ),
            SizedBox(height: 20),
            Row(
              mainAxisAlignment: MainAxisAlignment.spaceEvenly,
              children: [
                ElevatedButton(
                  onPressed: () {
                    _counter.value--;
                  },
                  child: const Text('-'),
                ),
                ElevatedButton(
                  onPressed: () {
                    _counter.value = 0;
                  },
                  child: const Text('Reset'),
                ),
                ElevatedButton(
                  onPressed: () {
                    _counter.value++;
                  },
                  child: const Text('+'),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
```

### 2. Управление темой (простой пример)

```dart
class ThemeSwitcher extends StatefulWidget {
  @override
  _ThemeSwitcherState createState() => _ThemeSwitcherState();
}

class _ThemeSwitcherState extends State<ThemeSwitcher> {
  final ValueNotifier<bool> _isDarkMode = ValueNotifier<bool>(false);

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      theme: ThemeData.light(),
      darkTheme: ThemeData.dark(),
      themeMode: _isDarkMode.value ? ThemeMode.dark : ThemeMode.light,
      home: Scaffold(
        appBar: AppBar(title: const Text('Theme Switcher')),
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              ValueListenableBuilder<bool>(
                valueListenable: _isDarkMode,
                builder: (context, isDark, child) {
                  return Text('Current Theme: ${isDark ? "Dark" : "Light"}');
                },
              ),
              SizedBox(height: 20),
              ElevatedButton(
                onPressed: () {
                  _isDarkMode.value = !_isDarkMode.value;
                },
                child: const Text('Toggle Theme'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

## 6. Сравнение с другими средствами управления состоянием

| Средство         | Описание                                                                 |
|------------------|--------------------------------------------------------------------------|
| ValueNotifier    | Простое управление локальным состоянием, встроено в Flutter              |
| ChangeNotifier   | Базовый класс для ValueNotifier, используется для более сложных изменений |
| Provider         | Мощный инструмент для управления состоянием, использует InheritedWidget   |
| Riverpod         | Современный и гибкий способ управления состоянием                        |
| Bloc             | Архитектурный паттерн для управления состоянием                          |
