# Лекция: Адаптирование Flutter-приложений для разных экранов

В этом разделе мы рассмотрим ключевые аспекты адаптации Flutter-приложений под разные устройства и экраны. Это особенно важно, поскольку мобильные устройства имеют различные размеры экрана, плотность пикселей, ориентацию и настройки системы. В рамках этой лекции мы научимся создавать гибкие интерфейсы, которые будут корректно отображаться на всех устройствах.

---

## 1. Плотность пикселей (Pixel Density)

**Плотность пикселей** — это количество пикселей на дюйм (PPI - Pixels Per Inch). Разные устройства имеют разную плотность пикселей, что влияет на размер и четкость отображения элементов интерфейса.

### Что такое DPI?

- **DPI (dots per inch)** — количество точек на дюйм.
- В мобильных устройствах часто используются следующие классы:
  - `mdpi` (medium density) — 160 DPI
  - `hdpi` (high density) — 240 DPI
  - `xhdpi` (extra high density) — 320 DPI
  - `xxhdpi` — 480 DPI
  - `xxxhdpi` — 640 DPI

### Важность плотности пикселей в Flutter

Flutter использует **logical pixels** (логические пиксели), а не физические. Это означает, что разработчик пишет код в логических единицах, а система автоматически масштабирует элементы под устройство.

### Пример:

```dart
Container(
  width: 100, // Логический пиксель
  height: 100,
)
```

Если на устройстве плотность 2x (например, iPhone 6), то 100 логических пикселей будут отображаться как 200 физических пикселей.

## 2. Возможность настройки масштабирования текста в iOS и Android

Современные мобильные операционные системы позволяют пользователям увеличивать размер текста для лучшей читаемости, особенно в целях доступности (accessibility).

### Настройка масштабирования текста

- В **Android** это можно настроить через:
  - Настройки → Доступность → Размер шрифта
- В **iOS** — через:
  - Настройки → Доступность → Размер шрифта

### Как Flutter реагирует на изменение размера текста?

Flutter использует **ThemeData**, который автоматически адаптируется под изменения размера шрифта. Если вы используете `Text` с `TextStyle`, то система сама увеличит или уменьшит размер, если пользователь изменил масштаб.

### Пример:

```dart
Text(
  'Привет, мир!',
  style: Theme.of(context).textTheme.headlineMedium,
)
```

Если вы используете `TextStyle(fontSize: 16)` — размер будет меняться в зависимости от настроек системы. Использование `Theme.of(context).textTheme` автоматически адаптируется.

## 3. Поддержка и ограничения масштабирования текста

### Поддержка

Flutter полностью поддерживает масштабирование текста:

- `Text` — использует `TextStyle`, который автоматически реагирует на системные настройки.
- `ThemeData` — позволяет настраивать темы с учетом доступности.

### Ограничения

Если вы используете фиксированные размеры (например, `fontSize: 16.0`), то текст может не масштабироваться корректно. Поэтому рекомендуется использовать:

```dart
style: TextStyle(fontSize: Theme.of(context).textTheme.bodyMedium!.fontSize!)
```

Или лучше — использовать темы и `TextTheme`.

## 4. Виджет SafeArea

**SafeArea** — это виджет, который обеспечивает правильное отображение содержимого в зонах с нестандартным дизайном экрана (например, уведомления, динамические кнопки, выступы).

### Когда использовать?

- В Android: если есть системные панели (например, статус-бар).
- В iOS: для отображения контента в зоне "не безопасной области" (напр., сенсорная панель).

### Пример:

```dart
SafeArea(
  child: Scaffold(
    body: Center(
      child: Text("Текст внутри SafeArea"),
    ),
  ),
)
```

### Примечание:

`SafeArea` автоматически учитывает отступы в зависимости от устройства и ориентации.

## 5. MediaQuery

**MediaQuery** — это класс, предоставляющий информацию о размерах экрана, плотности пикселей, ориентации и других параметрах устройства.

### Основные свойства:

```dart
MediaQuery.of(context).size; // Размер экрана (ширина и высота)
MediaQuery.of(context).orientation; // Ориентация: portrait или landscape
MediaQuery.of(context).devicePixelRatio; // Плотность пикселей
MediaQuery.of(context).textScaleFactor; // Масштаб текста
```

### Пример использования:

```dart
class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final size = MediaQuery.of(context).size;
    final orientation = MediaQuery.of(context).orientation;

    return Container(
      width: orientation == Orientation.portrait ? size.width : size.height,
      height: orientation == Orientation.portrait ? size.height : size.width,
      color: Colors.blue,
    );
  }
}
```

### Как использовать для адаптации?

Можно создавать адаптивные компоненты, например:

```dart
double screenWidth = MediaQuery.of(context).size.width;
double screenHeight = MediaQuery.of(context).size.height;

if (screenWidth < 400) {
  // Для маленьких экранов
} else if (screenWidth >= 400 && screenWidth < 768) {
  // Для средних экранов
} else {
  // Для больших экранов
}
```

## 6. LayoutBuilder

**LayoutBuilder** — виджет, который предоставляет информацию о размерах родительского контейнера. Он полезен для создания адаптивных интерфейсов.

### Принцип работы:

- `LayoutBuilder` вызывает функцию `builder`, передавая `BoxConstraints`.
- Эти ограничения можно использовать для построения адаптивного UI.

### Пример:

```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 400) {
      return Text("Маленький экран");
    } else {
      return Text("Большой экран");
    }
  },
)
```

### Когда использовать?

- Для создания адаптивных макетов.
- Вместо `MediaQuery` в сложных случаях, где важно отслеживать изменения размера родительского элемента.

## 7. GridView

**GridView** — это виджет для отображения коллекции элементов в виде сетки (таблицы).

### Основные параметры:

```dart
GridView.count(
  crossAxisCount: 3, // Количество колонок
  children: [
    Container(color: Colors.red),
    Container(color: Colors.blue),
    Container(color: Colors.green),
  ],
)
```

### Адаптивность:

Для адаптации под разные экраны можно использовать `LayoutBuilder` или `MediaQuery`:

```dart
GridView.builder(
  itemCount: items.length,
  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: MediaQuery.of(context).size.width > 600 ? 4 : 2,
  ),
  itemBuilder: (context, index) {
    return Text(items[index]);
  },
)
```

## 8. Ограничение поворота экрана

Иногда нужно запретить поворот экрана в приложении.

### Решение:

В `AndroidManifest.xml` (для Android):

```xml
<activity
    android:name=".MainActivity"
    android:screenOrientation="portrait" />
```

Для iOS — в `Info.plist`:

```xml
<key>UISupportedInterfaceOrientations</key>
<array>
  <string>UIInterfaceOrientationPortrait</string>
</array>
```

### Альтернатива — через Flutter

Используя библиотеку `device_info_plus`, можно программно проверить и запретить поворот:

```dart
import 'package:device_info_plus/device_info_plus.dart';

Future<void> lockOrientation() async {
  if (Platform.isAndroid) {
    await SystemChrome.setPreferredOrientations([
      DeviceOrientation.portraitUp,
    ]);
  }
}
```

## 9. Определение поворота экрана

Чтобы определить, в каком положении находится экран, можно использовать:

```dart
MediaQuery.of(context).orientation;
```

Возвращает `Orientation.portrait` или `Orientation.landscape`.

### Пример:

```dart
class OrientationWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final orientation = MediaQuery.of(context).orientation;

    return Text(
      orientation == Orientation.portrait ? 'Портрет' : 'Ландшафт',
    );
  }
}
```

## 10. Best Practices

### 1. Используйте `MediaQuery` и `LayoutBuilder`
- Не полагайтесь только на фиксированные размеры.
- Пишите адаптивный UI, который меняется под разные экраны.

### 2. Проверяйте масштабирование текста
- Используйте темы (`ThemeData`) вместо жестко заданных размеров.
- Не используйте `fontSize: 16.0` без учета системных настроек.

### 3. Используйте `SafeArea`
- Обязательно оборачивайте основной контент в `SafeArea`.
- Особенно это важно при работе с системными панелями.

### 4. Избегайте абсолютного позиционирования
- Предпочтительнее использовать `Column`, `Row`, `Stack` и другие адаптивные виджеты.

### 5. Используйте `Flexible` и `Expanded`
- Для правильного распределения пространства между элементами.
