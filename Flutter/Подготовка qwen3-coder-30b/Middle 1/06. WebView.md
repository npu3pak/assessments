# Лекция: WebView в Flutter (Middle уровень)

## Введение

WebView — это компонент, позволяющий отображать веб-контент внутри мобильного приложения. Это особенно полезно, когда необходимо интегрировать веб-сайты, онлайн-сервисы или использовать внешние API без необходимости создавать полноценный мобильный интерфейс.

В Flutter есть несколько способов реализовать WebView:
1. `webview_flutter` — официальный пакет от Google.
2. `flutter_inappwebview` — более продвинутая альтернатива с богатым функционалом.

Рассмотрим эти два решения подробно, а также обсудим работу с cookies и использование Custom Tabs на Android.

---

## 1. Сравнение flutter_inappwebview и webview_flutter

### 1.1. flutter_inappwebview

`flutter_inappwebview` — это мощная библиотека для отображения веб-контента внутри Flutter приложений. Она предоставляет более широкий набор возможностей по сравнению с `webview_flutter`, особенно при работе с JavaScript, куками и взаимодействием между JS и Dart.

#### Преимущества flutter_inappwebview:
- Поддержка JavaScript
- Полный контроль над загрузкой страницы (`onLoadStart`, `onLoadStop`)
- Работа с cookies (в том числе удаление, установка)
- Возможность перехвата запросов (`shouldOverrideUrlLoading`)
- Поддержка SSL/TLS
- Встроенная поддержка обработки HTTP заголовков

#### Недостатки:
- Более сложная настройка
- Может быть тяжелее по ресурсам
- Требует дополнительных разрешений и конфигурации для Android (например, `usesCleartextTraffic`)

#### Пример использования:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_inappwebview/flutter_inappwebview.dart';

class MyWebViewScreen extends StatefulWidget {
  @override
  _MyWebViewScreenState createState() => _MyWebViewScreenState();
}

class _MyWebViewScreenState extends State<MyWebViewScreen> {
  late InAppWebViewController webViewController;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("InAppWebView")),
      body: InAppWebView(
        initialUrlRequest: URLRequest(url: Uri.parse("https://flutter.dev")),
        onWebViewCreated: (controller) {
          webViewController = controller;
        },
        onLoadStop: (controller, url) async {
          // Получаем cookies после загрузки
          var cookies = await controller.getCookies();
          print(cookies);
        },
      ),
    );
  }
}
```

### 1.2. webview_flutter

`webview_flutter` — официальный пакет от Google, который поддерживает WebView на iOS и Android. Он легковесный, прост в использовании и хорошо интегрируется с Flutter.

#### Преимущества:
- Легковесный
- Простота использования
- Хорошая документация
- Официальная поддержка

#### Недостатки:
- Не поддерживает JavaScript напрямую (но можно использовать `evaluateJavascript`)
- Меньше возможностей для взаимодействия с JS и куками
- Ограниченная настройка запросов

#### Пример использования:

```dart
import 'package:flutter/material.dart';
import 'package:webview_flutter/webview_flutter.dart';

class MyWebViewScreen extends StatefulWidget {
  @override
  _MyWebViewScreenState createState() => _MyWebViewScreenState();
}

class _MyWebViewScreenState extends State<MyWebViewScreen> {
  late WebViewController controller;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("WebView Flutter")),
      body: WebView(
        initialUrl: 'https://flutter.dev',
        javascriptMode: JavascriptMode.unrestricted,
        onWebViewCreated: (WebViewController webViewController) {
          controller = webViewController;
        },
      ),
    );
  }
}
```

---

### 1.3. Когда использовать что?

| Критерий                | flutter_inappwebview                 | webview_flutter                      |
|------------------------|--------------------------------------|--------------------------------------|
| Простота использования  | Сложнее                              | Проще                                |
| JavaScript              | Полная поддержка                     | Ограниченная                         |
| Cookies                 | Полный контроль                      | Ограниченное                         |
| Платформы               | iOS, Android                         | iOS, Android                         |
| Поддержка запросов      | Есть                                 | Нет                                  |
| Обновления              | Часто                                | Медленнее                            |

**Вывод**:  
Если нужна простая интеграция веб-страницы и не требуется работа с JS или куками — `webview_flutter` подходит. Если же нужно полноценное управление, JS, куки, перехват запросов — используйте `flutter_inappwebview`.

## 2. Работа с cookies в flutter_inappwebview

Cookies играют важную роль при работе с веб-приложениями, особенно если вы интегрируете авторизованные сервисы.

### 2.1. Получение cookies

```dart
var cookies = await webViewController.getCookies();
print(cookies);
```

### 2.2. Установка cookie

```dart
await webViewController.setCookie(
  name: "session_id",
  value: "abc123",
  domain: ".example.com",
  path: "/",
);
```

### 2.3. Удаление cookie

```dart
await webViewController.deleteCookie(
  name: "session_id",
  domain: ".example.com",
  path: "/",
);
```

### 2.4. Пример полного взаимодействия с cookies

```dart
class WebViewWithCookies extends StatefulWidget {
  @override
  _WebViewWithCookiesState createState() => _WebViewWithCookiesState();
}

class _WebViewWithCookiesState extends State<WebViewWithCookies> {
  late InAppWebViewController webViewController;

  Future<void> loadPageWithCookies() async {
    await webViewController.loadUrl(url: "https://example.com/login");
    await webViewController.setCookie(
      name: "auth_token",
      value: "secret_token",
      domain: ".example.com",
      path: "/",
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("WebView с Cookie")),
      body: InAppWebView(
        initialUrlRequest: URLRequest(url: Uri.parse("https://example.com")),
        onWebViewCreated: (controller) {
          webViewController = controller;
        },
        onLoadStop: (controller, url) async {
          var cookies = await controller.getCookies();
          print(cookies);
        },
      ),
    );
  }
}
```

## 3. Custom Tabs в Android

### 3.1. Что такое Custom Tabs?

Custom Tabs — это способ открытия веб-страниц внутри Android-приложения без перехода на внешний браузер, но при этом с использованием браузера системы (например, Chrome) в фоне.

Они предоставляют:
- Более быструю загрузку страниц
- Возможность кастомизации UI (например, цвет панели инструментов)
- Безопасность и приватность (в отличие от `Intent`)

### 3.2. Как использовать Custom Tabs в Flutter?

Для этого используется пакет `android_intent_plus`, который позволяет открывать URL через системный браузер с поддержкой Custom Tabs.

#### Установка:

```yaml
dependencies:
  android_intent_plus: ^4.0.1
```

#### Пример использования:

```dart
import 'package:android_intent_plus/android_intent.dart';
import 'package:android_intent_plus/flag.dart';

Future<void> openUrlInCustomTab(String url) async {
  final intent = AndroidIntent(
    action: 'android.intent.action.VIEW',
    data: url,
    flags: [Flag.FLAG_ACTIVITY_NEW_TASK],
  );
  await intent.launch();
}
```

> ⚠️ Для корректной работы Custom Tabs на Android нужно убедиться, что:
- Установлен Chrome или другой браузер, поддерживающий Custom Tabs
- В `AndroidManifest.xml` добавлена нужная конфигурация (в большинстве случаев — автоматически)

### 3.3. Возможности и ограничения

| Возможность             | Поддержка |
|------------------------|-----------|
| Открытие веб-страницы   | ✅        |
| Кастомизация UI         | ✅ (через `CustomTabsIntent`) |
| Управление куками       | ❌ (не поддерживает, куки управляются браузером) |
| Обработка JS            | ❌        |
| Привязка к приложению   | ✅        |

### 3.4. Плюсы и минусы

#### Плюсы:
- Более быстрое открытие страниц
- Отсутствие переключения на внешний браузер
- Возможность кастомизации (цвета, титул)

#### Минусы:
- Не все функции WebView доступны
- Ограниченный контроль над JS и cookies
- Требуется наличие браузера системы
