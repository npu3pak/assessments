# Лекция 15: Flutter. Inherited Widgets

## Введение в Inherited Widgets

Inherited Widgets — это мощный механизм в Flutter, позволяющий передавать данные из родительского виджета в дочерние без использования прямого передачи параметров. Это особенно полезно при работе с глобальными состояниями, темами, конфигурациями и другими данными, которые должны быть доступны на нескольких уровнях дерева виджетов.

Когда вы используете стандартные способы передачи данных (через параметры), вы сталкиваетесь с проблемой "прокидывания" данных через множество вложенных виджетов — это называется **prop drilling**. Inherited Widgets позволяют избежать этой проблемы, предоставляя централизованное хранилище данных, к которым могут обращаться любые дочерние виджеты.

---

## Что такое Inherited Widgets?

Inherited Widget в Flutter — это специальный тип виджета, который предоставляет данные, которые могут быть доступны всем дочерним элементам дерева виджетов. Он работает по принципу "обновление только тех виджетов, которые зависят от изменений".

Основные особенности Inherited Widgets:

- Они не пересоздаются при изменениях данных.
- При изменении данных они уведомляют только те виджеты, которые используют эти данные.
- Они обеспечивают эффективную передачу данных и обновление интерфейса.

Используя `InheritedWidget`, вы можете реализовать:
- Темы приложения (ThemeData)
- Локализацию (Localizations)
- Глобальные настройки
- Состояния, которые не изменяются часто

---

## Как пользоваться Inherited Widgets?

Чтобы создать и использовать `InheritedWidget`, необходимо:

1. Создать класс, который наследуется от `InheritedWidget`.
2. Реализовать метод `updateShouldNotify` — он определяет, когда виджет должен быть перерисован.
3. Использовать `InheritedWidget.of(context)` для получения данных в дочерних виджетах.

### Шаг 1: Создание InheritedWidget

Рассмотрим пример создания простого `InheritedWidget`, который будет передавать тему приложения:

```dart
class AppTheme extends InheritedWidget {
  final ThemeData themeData;

  const AppTheme({
    Key? key,
    required this.themeData,
    required Widget child,
  }) : super(key: key, child: child);

  @override
  bool updateShouldNotify(covariant AppTheme oldWidget) {
    return themeData != oldWidget.themeData;
  }

  static AppTheme of(BuildContext context) {
    final AppTheme? result = context.dependOnInheritedWidgetOfExactType<AppTheme>();
    assert(result != null, 'No AppTheme found in context');
    return result!;
  }
}
```

### Шаг 2: Использование InheritedWidget

Теперь мы можем использовать этот `InheritedWidget` в дереве виджетов:

```dart
class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: AppTheme(
        themeData: ThemeData.light(),
        child: MyHomePage(),
      ),
    );
  }
}
```

В дочерних виджетах мы можем получить доступ к теме:

```dart
class MyHomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final appTheme = AppTheme.of(context); // Получаем данные из InheritedWidget

    return Scaffold(
      appBar: AppBar(
        title: Text('InheritedWidget Example'),
        backgroundColor: appTheme.themeData.primaryColor,
      ),
      body: Center(
        child: Text(
          'Hello World',
          style: appTheme.themeData.textTheme.headlineMedium,
        ),
      ),
    );
  }
}
```

### Шаг 3: Обновление данных

Если вы захотите изменить тему, вы можете просто пересоздать `AppTheme` с новыми данными:

```dart
// Изменяем тему в другом месте
AppTheme(
  themeData: ThemeData.dark(),
  child: MyHomePage(),
)
```

Flutter автоматически обновит виджеты, которые зависят от `InheritedWidget`.

## Примеры стандартных Inherited Widgets

В Flutter уже реализовано несколько `InheritedWidget`, которые вы используете повседневно:

### 1. `ThemeData` (Theme.of(context))

```dart
final theme = Theme.of(context);
```

Это стандартный `InheritedWidget`, который передает тему приложения. Он позволяет получать доступ к цветам, шрифтам и другим настройкам темы.

### 2. `Localizations` (Localization.of(context))

```dart
final localization = Localizations.of(context, AppLocalizations);
```

Используется для работы с локализацией приложения, например, для получения переводов строк.

### 3. `MediaQuery` (MediaQuery.of(context))

```dart
final mediaQuery = MediaQuery.of(context);
final size = mediaQuery.size;
final orientation = mediaQuery.orientation;
```

Предоставляет информацию о размерах экрана, ориентации и других параметрах устройства.

---

## Как работает обновление InheritedWidget

Когда вы изменяете данные в `InheritedWidget`, Flutter проверяет, изменились ли они по сравнению с предыдущим значением (с помощью метода `updateShouldNotify`). Если данные изменились, Flutter автоматически обновляет все виджеты, которые зависят от этого `InheritedWidget`.

Это делает Inherited Widgets очень эффективными для передачи данных, которые не меняются часто, но требуются в разных частях приложения.

## Заключение

Inherited Widgets — это мощный инструмент для управления глобальными данными в Flutter-приложениях. Они позволяют эффективно передавать информацию через дерево виджетов, минимизируя количество прокидываемых параметров. Хотя в современном Flutter часто используются более высокоуровневые решения (например, `Provider`, `Riverpod`, `Bloc`), знание `InheritedWidget` помогает понять внутреннюю работу Flutter и даёт возможность реализовывать кастомные решения.
