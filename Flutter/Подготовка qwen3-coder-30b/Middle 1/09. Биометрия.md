# Лекция 09: Биометрия в Flutter

## Введение

Биометрия — это технология, позволяющая идентифицировать человека по уникальным физическим или поведенческим характеристикам, таким как отпечатки пальцев, сканирование лица, распознавание голоса и т. д.

В мобильной разработке биометрия играет ключевую роль в обеспечении безопасности приложений. Особенно это актуально для финансовых, медицинских, корпоративных и других приложений, где требуется высокий уровень защиты данных пользователя.

Flutter предоставляет мощные возможности для работы с биометрией через пакет `local_auth`. Он позволяет интегрировать функции аутентификации на уровне устройства — как на iOS, так и на Android. В этой лекции мы рассмотрим:

1. Возможности биометрической аутентификации на iOS.
2. Возможности биометрической аутентификации на Android.
3. Как использовать пакет `local_auth` в Flutter для реализации аутентификации.

---

## 1. Возможности биометрической аутентификации на iOS

На устройствах Apple (iPhone, iPad) биометрическая аутентификация поддерживается через **Touch ID** и **Face ID**, а также **Apple Watch** (в некоторых случаях).

### Touch ID
- Использует отпечатки пальцев.
- Поддерживается на устройствах с сенсором Touch ID (iPhone 5s и выше, iPad Air и выше).
- Используется для подтверждения операций, таких как покупка в App Store, авторизация в приложении и т. д.

### Face ID
- Использует распознавание лица с помощью TrueDepth камеры.
- Поддерживается на iPhone X и выше.
- Также может быть использован для авторизации в приложениях.

### Системные возможности iOS:
iOS предоставляет следующие типы биометрической аутентификации:

| Тип аутентификации | Описание |
|-------------------|----------|
| `biometricAny`    | Любой доступный биометрический метод (Touch ID, Face ID) |
| `face`            | Только Face ID |
| `touch`           | Только Touch ID |
| `fingerprint`     | Только отпечаток пальца |

### Примечание:
- Для использования биометрии в приложениях необходимо добавить соответствующие разрешения в `Info.plist`.
- Важно обработать случай, когда устройство не поддерживает биометрию или пользователь отключил её.

## 2. Возможности биометрической аутентификации на Android

Android также предоставляет мощные возможности для биометрической аутентификации через **Biometric Prompt API** (начиная с Android 6.0, API level 23).

### Поддерживаемые методы:
- Отпечатки пальцев (Fingerprint)
- Лицо (Face Recognition)
- Сканирование венозной сетки (Iris)
- Сканер голоса (Voice Recognition) — редко используется

### Особенности:
Android предоставляет более гибкий подход к биометрической аутентификации:

| Тип аутентификации | Описание |
|--------------------|----------|
| `biometricAny`     | Любой доступный метод (отпечаток, лицо и т.д.) |
| `face`             | Только распознавание лица |
| `fingerprint`      | Только отпечатки пальцев |
| `iris`             | Сканирование зрачка |
| `voice`            | Голосовое распознавание |

### Важно:
- Android не предоставляет прямого доступа к биометрическим данным (данные хранятся в защищённом контексте).
- Для использования биометрии необходимо добавить разрешения в `AndroidManifest.xml`.
- Приложение должно проверять, поддерживает ли устройство биометрию и доступна ли она.

## 3. Пакет `local_auth` в Flutter

Пакет `local_auth` — это официальный Flutter пакет для работы с локальной аутентификацией на устройствах (Touch ID, Face ID, Fingerprint и т.д.). Он предоставляет универсальный интерфейс для работы с биометрией как на iOS, так и на Android.

### Установка

Для использования пакета нужно добавить его в `pubspec.yaml`:

```yaml
dependencies:
  local_auth: ^2.1.6
```

Затем выполните:

```bash
flutter pub get
```

### Использование

#### 1. Проверка наличия биометрии

Перед тем как запрашивать аутентификацию, важно проверить, доступна ли она на устройстве.

```dart
import 'package:local_auth/local_auth.dart';

Future<bool> canCheckBiometrics() async {
  final LocalAuthentication auth = LocalAuthentication();
  bool canCheckBiometrics = await auth.canCheckBiometrics;
  return canCheckBiometrics;
}
```

#### 2. Получение списка доступных типов биометрии

```dart
Future<List<BiometricType>> getAvailableBiometrics() async {
  final LocalAuthentication auth = LocalAuthentication();
  List<BiometricType> availableBiometrics = await auth.getAvailableBiometrics();
  return availableBiometrics;
}
```

#### 3. Запрос аутентификации

Пример простого запроса на аутентификацию:

```dart
Future<bool> authenticate() async {
  final LocalAuthentication auth = LocalAuthentication();
  bool authenticated = false;

  try {
    authenticated = await auth.authenticate(
      localizedReason: 'Пожалуйста, подтвердите вашу личность',
      options: const AuthenticationOptions(
        stickyAuth: true,
        biometricOnly: true,
      ),
    );
  } catch (e) {
    print('Ошибка аутентификации: $e');
  }

  return authenticated;
}
```

#### 4. Подробное описание параметров `authenticate`

- `localizedReason`: Текст, который будет отображён пользователю при запросе аутентификации.
- `options`:
  - `stickyAuth`: Если true — аутентификация сохраняется на время сессии.
  - `biometricOnly`: Если true — разрешены только биометрические методы (без ввода пароля).
  - `allowBack`: Если true — можно вернуться к предыдущему экрану.

### Пример полноценного экрана аутентификации

```dart
class BiometricAuthScreen extends StatefulWidget {
  @override
  _BiometricAuthScreenState createState() => _BiometricAuthScreenState();
}

class _BiometricAuthScreenState extends State<BiometricAuthScreen> {
  bool _isAuthenticating = false;
  String _authStatus = 'Готов к аутентификации';

  Future<void> _authenticate() async {
    setState(() {
      _isAuthenticating = true;
      _authStatus = 'Идёт проверка...';
    });

    final LocalAuthentication auth = LocalAuthentication();
    bool authenticated = false;

    try {
      authenticated = await auth.authenticate(
        localizedReason: 'Подтвердите свою личность',
        options: const AuthenticationOptions(
          stickyAuth: true,
          biometricOnly: true,
        ),
      );
    } catch (e) {
      print('Ошибка аутентификации: $e');
    }

    setState(() {
      _isAuthenticating = false;
      if (authenticated) {
        _authStatus = 'Успешная аутентификация!';
      } else {
        _authStatus = 'Аутентификация не удалась';
      }
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Биометрическая аутентификация')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(_authStatus),
            SizedBox(height: 20),
            ElevatedButton(
              onPressed: _isAuthenticating ? null : _authenticate,
              child: Text(_isAuthenticating ? 'Проверка...' : 'Аутентифицироваться'),
            ),
          ],
        ),
      ),
    );
  }
}
```

## 4. Обработка ошибок

Важно обрабатывать различные ошибки, которые могут возникнуть при попытке аутентификации:

| Ошибка | Описание |
|--------|----------|
| `PlatformException` с кодом `not_available` | Биометрия недоступна (например, нет сенсора) |
| `PlatformException` с кодом `unavailable` | Устройство не поддерживает аутентификацию |
| `PlatformException` с кодом `user_cancel` | Пользователь отменил аутентификацию |
| `PlatformException` с кодом `device_locked` | Устройство заблокировано |

Пример обработки ошибок:

```dart
try {
  authenticated = await auth.authenticate(
    localizedReason: 'Подтвердите свою личность',
    options: const AuthenticationOptions(biometricOnly: true),
  );
} on PlatformException catch (e) {
  if (e.code == 'not_available') {
    print('Биометрия недоступна');
  } else if (e.code == 'user_cancel') {
    print('Пользователь отменил аутентификацию');
  } else if (e.code == 'device_locked') {
    print('Устройство заблокировано');
  }
}
```

## 5. Дополнительные рекомендации

- Используйте биометрию **только для важных операций** (например, вход в приложение, перевод средств).
- Не злоупотребляйте `stickyAuth`, так как это может быть воспринято как неудобство.
- Обеспечьте альтернативный способ аутентификации (например, пароль) на случай, если биометрия недоступна.
- Проверяйте наличие биометрии при запуске приложения и в нужных точках.
