## **1. GestureDetector**

### **Что такое GestureDetector?**

`GestureDetector` — это виджет, который позволяет распознавать и обрабатывать различные жесты пользователя. Он не отображает ничего на экране, но служит контейнером для других виджетов, к которым применяются слушатели событий жестов.

### **Как работает GestureDetector?**

`GestureDetector` принимает в качестве дочернего элемента другой виджет и предоставляет возможности обработки следующих типов жестов:

- **Tap** — однократное нажатие.
- **DoubleTap** — двойное нажатие.
- **LongPress** — длительное нажатие.
- **VerticalDrag** — вертикальное перемещение.
- **HorizontalDrag** — горизонтальное перемещение.
- **Scale** — масштабирование (пинч).
- **Rotation** — вращение.

### **Основные параметры GestureDetector**

```dart
GestureDetector(
  onTap: () {
    print("Тап");
  },
  onDoubleTap: () {
    print("Двойной тап");
  },
  onLongPress: () {
    print("Долгое нажатие");
  },
  onPanUpdate: (DragUpdateDetails details) {
    print("Перемещение: ${details.localPosition}");
  },
  onScaleUpdate: (ScaleUpdateDetails details) {
    print("Масштаб: ${details.scale}");
  },
  child: Container(
    width: 200,
    height: 200,
    color: Colors.blue,
  ),
)
```

### **Пример использования**

В этом примере мы создаем виджет, который реагирует на разные жесты:

```dart
class GestureExample extends StatefulWidget {
  @override
  _GestureExampleState createState() => _GestureExampleState();
}

class _GestureExampleState extends State<GestureExample> {
  String _message = "Ожидание жеста";

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("Жесты")),
      body: Center(
        child: GestureDetector(
          onTap: () => setState(() => _message = "Тап"),
          onDoubleTap: () => setState(() => _message = "Двойной тап"),
          onLongPress: () => setState(() => _message = "Долгое нажатие"),
          onPanUpdate: (details) {
            setState(() => _message = "Перемещение: ${details.localPosition}");
          },
          child: Container(
            width: 200,
            height: 200,
            color: Colors.green,
            child: Center(child: Text(_message)),
          ),
        ),
      ),
    );
  }
}
```

## **2. InkWell**

### **Что такое InkWell?**

`InkWell` — это виджет, который предоставляет визуальную обратную связь при нажатии (например, анимация сглаживания или подсветка). Он основан на `GestureDetector`, но уже преднастроен для работы с нажатиями.

### **Преимущества InkWell**

- Автоматическая анимация при нажатии.
- Простота использования (меньше кода).
- Используется в качестве фундамента для кнопок, списков и других элементов.

### **Основные параметры InkWell**

```dart
InkWell(
  onTap: () {
    print("Кнопка нажата");
  },
  splashColor: Colors.blue, // Цвет эффекта нажатия
  highlightColor: Colors.red, // Цвет выделения
  child: Container(
    width: 200,
    height: 100,
    color: Colors.grey,
    child: Center(child: Text("Нажми меня")),
  ),
)
```

### **Пример использования**

```dart
class InkWellExample extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("InkWell")),
      body: Center(
        child: InkWell(
          onTap: () => print("Нажатие"),
          splashColor: Colors.blue,
          highlightColor: Colors.yellow,
          child: Container(
            width: 200,
            height: 100,
            color: Colors.purple,
            child: Center(child: Text("Тапни меня")),
          ),
        ),
      ),
    );
  }
}
```

## **3. Drag and Drop (Перетаскивание)**

### **Введение в Drag and Drop**

Drag and Drop — это механизм, при котором пользователь может перетаскивать элементы между различными частями интерфейса. В Flutter реализуется с помощью:

- `Draggable` — виджет, который можно перетаскивать.
- `DragTarget` — место, куда можно отпустить перетаскиваемый объект.

### **Пример Drag and Drop**

```dart
class DragDropExample extends StatefulWidget {
  @override
  _DragDropExampleState createState() => _DragDropExampleState();
}

class _DragDropExampleState extends State<DragDropExample> {
  List<String> items = ['Item 1', 'Item 2', 'Item 3'];
  List<String> targetItems = [];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("Drag and Drop")),
      body: Row(
        children: [
          Expanded(
            child: ListView.builder(
              itemCount: items.length,
              itemBuilder: (context, index) {
                return Draggable<String>(
                  data: items[index],
                  feedback: Container(
                    width: 100,
                    height: 50,
                    color: Colors.blue,
                    child: Center(child: Text(items[index])),
                  ),
                  child: Container(
                    margin: EdgeInsets.all(8),
                    padding: EdgeInsets.all(16),
                    color: Colors.grey,
                    child: Text(items[index]),
                  ),
                );
              },
            ),
          ),
          Expanded(
            child: DragTarget<String>(
              onAccept: (data) {
                setState(() {
                  targetItems.add(data);
                });
              },
              builder: (context, candidateData, rejectedData) {
                return Container(
                  height: double.infinity,
                  width: double.infinity,
                  color: Colors.green.withOpacity(0.3),
                  child: Center(child: Text("Drop here")),
                );
              },
            ),
          )
        ],
      ),
    );
  }
}
```

### **Объяснение работы**

- `Draggable` — делает элемент перетаскиваемым.
- `feedback` — показывается во время перетаскивания.
- `DragTarget` — принимает данные и реагирует на них.
