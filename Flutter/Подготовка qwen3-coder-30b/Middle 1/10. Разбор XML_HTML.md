# Лекция: Разбор XML/HTML в Dart и Flutter

## Введение

В современном мире мобильной разработки, особенно при работе с Flutter, важно уметь обрабатывать данные, поступающие из внешних источников — будь то REST API, RSS-каналы, веб-страницы или XML-файлы. Одним из часто встречающихся форматов данных является **XML (eXtensible Markup Language)**, который используется для хранения и передачи структурированных данных.

В этой лекции мы рассмотрим, как работать с XML и HTML в Dart/Flutter, используя различные подходы:

- DOM-парсер
- SAX-парсер
- XPath
- XSLT

Эти темы особенно важны при разработке мобильных приложений, где требуется обработка данных из интернета или файлов.

## 1. Работа с DOM-парсером в Dart

### Что такое DOM?

**DOM (Document Object Model)** — это объектная модель представления структуры XML/HTML документа. В DOM весь документ представляется как дерево узлов, где каждый узел может быть элементом, текстом, атрибутом и т.д.

### Преимущества DOM-парсера:

- Простота использования
- Возможность манипуляции с документом
- Подходит для небольших документов

### Недостатки DOM-парсера:

- Высокое потребление памяти (все дерево загружается в память)
- Неэффективен при работе с большими файлами

### Пример использования DOM-парсера в Dart

Для работы с DOM в Dart можно использовать пакет `xml`.

#### Шаг 1: Установка зависимости

```yaml
dependencies:
  xml: ^6.3.0
```

#### Шаг 2: Парсинг XML с помощью DOM

```dart
import 'package:xml/xml.dart' as xml;

void main() {
  final xmlString = '''
    <books>
      <book id="1">
        <title>Flutter for Beginners</title>
        <author>John Doe</author>
        <year>2023</year>
      </book>
      <book id="2">
        <title>Dart Programming Guide</title>
        <author>Jane Smith</author>
        <year>2022</year>
      </book>
    </books>
  ''';

  final document = xml.parse(xmlString);

  // Получаем все элементы book
  final books = document.findElements('book');

  for (final book in books) {
    final id = book.getAttribute('id');
    final title = book.findElements('title').first.text;
    final author = book.findElements('author').first.text;
    final year = book.findElements('year').first.text;

    print('ID: $id, Title: $title, Author: $author, Year: $year');
  }
}
```

**Вывод:**
```
ID: 1, Title: Flutter for Beginners, Author: John Doe, Year: 2023
ID: 2, Title: Dart Programming Guide, Author: Jane Smith, Year: 2022
```

### Плюсы и минусы DOM-парсера в Flutter

| Плюсы | Минусы |
|-------|--------|
| Простота и понятность | Высокое потребление памяти |
| Подходит для маленьких документов | Не эффективен при больших XML файлах |
| Возможность манипуляции с узлами | Невозможно обрабатывать документ по частям |

## 2. Работа с SAX-парсером в Dart

### Что такое SAX?

**SAX (Simple API for XML)** — это событийный парсер, который не загружает весь документ в память. Вместо этого он вызывает события при встрече с различными частями XML-документа: начало тега, конец тега, текст и т.д.

### Преимущества SAX:

- Экономия памяти
- Подходит для больших файлов
- Быстрое время обработки

### Недостатки SAX:

- Сложнее использовать (требуется реализация обработчиков)
- Невозможно обратиться к произвольному узлу документа

### Пример использования SAX-парсера в Dart

```dart
import 'package:xml/xml.dart' as xml;

class BookHandler extends xml.XmlVisitor {
  String currentElement = '';
  String? title;
  String? author;
  String? year;
  final List<Map<String, String>> books = [];

  @override
  void onOpenTag(xml.XmlElement element) {
    currentElement = element.name.local;
    if (element.name.local == 'book') {
      title = null;
      author = null;
      year = null;
    }
  }

  @override
  void onText(xml.XmlText text) {
    switch (currentElement) {
      case 'title':
        title = text.text;
        break;
      case 'author':
        author = text.text;
        break;
      case 'year':
        year = text.text;
        break;
    }
  }

  @override
  void onCloseTag(xml.XmlElement element) {
    if (element.name.local == 'book') {
      books.add({
        'title': title ?? '',
        'author': author ?? '',
        'year': year ?? ''
      });
    }
  }
}

void main() {
  final xmlString = '''
    <books>
      <book id="1">
        <title>Flutter for Beginners</title>
        <author>John Doe</author>
        <year>2023</year>
      </book>
      <book id="2">
        <title>Dart Programming Guide</title>
        <author>Jane Smith</author>
        <year>2022</year>
      </book>
    </books>
  ''';

  final document = xml.parse(xmlString);
  final handler = BookHandler();
  document.visit(handler);

  for (final book in handler.books) {
    print(book);
  }
}
```

**Вывод:**
```dart
{title: Flutter for Beginners, author: John Doe, year: 2023}
{title: Dart Programming Guide, author: Jane Smith, year: 2022}
```

## 3. Понятие XSLT

### Что такое XSLT?

**XSLT (eXtensible Stylesheet Language Transformations)** — это язык преобразования XML-документов в другие форматы (например, HTML, текст или другой XML).

### Зачем нужен XSLT?

XSLT используется для:

- Преобразования структуры XML
- Форматирования данных (например, из XML в HTML)
- Фильтрации и сортировки данных

### Пример XSLT преобразования

```xml
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
  <xsl:template match="/">
    <html>
      <body>
        <h2>Книги</h2>
        <ul>
          <xsl:for-each select="books/book">
            <li><xsl:value-of select="title"/> - <xsl:value-of select="author"/></li>
          </xsl:for-each>
        </ul>
      </body>
    </html>
  </xsl:template>
</xsl:stylesheet>
```

### Как использовать XSLT в Dart?

В Dart нет встроенной поддержки XSLT, но можно использовать сторонние библиотеки, например `xslt_transform`.

Пример:

```yaml
dependencies:
  xslt_transform: ^0.3.0
```

```dart
import 'package:xslt_transform/xslt_transform.dart';

void main() {
  final xml = '''
    <books>
      <book id="1">
        <title>Flutter for Beginners</title>
        <author>John Doe</author>
      </book>
    </books>
  ''';

  final xsl = '''
    <xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
      <xsl:template match="/">
        <html><body>
          <h2>Книги</h2>
          <ul>
            <xsl:for-each select="books/book">
              <li><xsl:value-of select="title"/> - <xsl:value-of select="author"/></li>
            </xsl:for-each>
          </ul>
        </body></html>
      </xsl:template>
    </xsl:stylesheet>
  ''';

  final result = transform(xml, xsl);
  print(result);
}
```

> **Примечание**: XSLT в Dart не всегда удобен, и его использование требует дополнительных усилий. В большинстве случаев рекомендуется использовать DOM или SAX для парсинга и визуализации данных.

## 4. Работа с XPath в Dart

### Что такое XPath?

**XPath (XML Path Language)** — это язык запросов, который позволяет навигироваться по XML-документу и выбирать элементы или узлы.

Пример XPath:

```xpath
//book[@id='1']/title
```

Этот запрос выбирает название книги с `id=1`.

### Пример использования XPath в Dart

```dart
import 'package:xml/xml.dart' as xml;

void main() {
  final xmlString = '''
    <books>
      <book id="1">
        <title>Flutter for Beginners</title>
        <author>John Doe</author>
      </book>
      <book id="2">
        <title>Dart Programming Guide</title>
        <author>Jane Smith</author>
      </book>
    </books>
  ''';

  final document = xml.parse(xmlString);

  // Используем XPath для выбора элементов
  final titles = document.findAllElements('title');
  for (final title in titles) {
    print(title.text);
  }

  // Выбор конкретного элемента по id
  final book = document.findElements('book').firstWhere(
        (e) => e.getAttribute('id') == '1',
      );
  final title = book.findElements('title').first.text;
  print('Title of book #1: $title');
}
```

**Вывод:**
```
Flutter for Beginners
Dart Programming Guide
Title of book #1: Flutter for Beginners
```

### Как работать с XPath в Dart?

Для более сложных запросов можно использовать библиотеку `xpath`:

```yaml
dependencies:
  xpath: ^1.0.0
```

Пример:

```dart
import 'package:xpath/xpath.dart';
import 'package:xml/xml.dart' as xml;

void main() {
  final xmlString = '''
    <books>
      <book id="1">
        <title>Flutter for Beginners</title>
        <author>John Doe</author>
      </book>
    </books>
  ''';

  final document = xml.parse(xmlString);
  final xpath = XPath('/books/book[@id="1"]/title');
  final nodes = xpath.evaluate(document);

  for (final node in nodes) {
    print(node.text);
  }
}
```
