# Лекция: **Foreground Geolocation в Flutter**

---

## 🧠 Введение

**Геолокация** — это процесс определения местоположения пользователя устройства. Она широко используется в мобильных приложениях для создания интерактивных сервисов, таких как карты, навигация, доставка, социальные сети и т.д.

В Flutter геолокация может работать в двух режимах:

1. **Foreground** — когда приложение активно и отображается на экране.
2. **Background** — когда приложение работает в фоновом режиме, даже если оно не открыто.

Сегодня мы сосредоточимся на **Foreground Geolocation**, которая является базовой и наиболее распространённой формой работы с геолокацией в мобильных приложениях. Эта тема особенно важна для разработчиков, стремящихся к уровню **Middle 1**.

---

## 🔍 Отличия Foreground и Background Geolocation

| Характеристика | **Foreground Geolocation** | **Background Geolocation** |
|----------------|----------------------------|-----------------------------|
| Работает ли приложение активно? | Да | Нет (работает в фоне) |
| Доступ к данным геолокации | Полный доступ | Ограниченный (зависит от платформы) |
| Требования к разрешениям | `ACCESS_FINE_LOCATION` | `ACCESS_FINE_LOCATION`, `FOREGROUND_SERVICE` (Android), `LOCATION` (iOS) |
| Энергопотребление | Низкое (если не используется часто) | Высокое |
| Сложность реализации | Простая | Сложная, требует обработки lifecycle, сервисов, уведомлений |
| Использование | Приложения с активным взаимодействием | Добавление трекинга пользователя в реальном времени (например, спорт, доставка) |

> ⚠️ **Примечание:** В Android 10+ и выше, фоновая геолокация требует явного разрешения на работу в фоновом режиме и уведомления. Для Flutter это реализуется через библиотеки, например `geolocator` или `flutter_background_geolocation`.

## 📍 Определение местоположения пользователя в режиме Foreground

### 1. Что такое "местоположение"?

Местоположение — это набор координат (широта и долгота), а также дополнительные данные, такие как точность, высота, скорость, направление.

### 2. Как получить геолокацию в Flutter?

Для получения геолокации мы используем библиотеку **`geolocator`**. Это одна из самых популярных и стабильных библиотек для работы с геолокацией.

### 📦 Установка

```yaml
dependencies:
  geolocator: ^9.0.2
```

### 🔐 Разрешения

Перед началом работы нужно запросить разрешения:

#### Android (`android/app/src/main/AndroidManifest.xml`)
```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

#### iOS (`ios/Runner/Info.plist`)
```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Это приложение использует ваше местоположение для отображения карты и навигации.</string>
```

### 🧪 Пример кода: Получение текущей геолокации

```dart
import 'package:geolocator/geolocator.dart';

Future<Position> getCurrentLocation() async {
  try {
    bool serviceEnabled = await Geolocator.isLocationServiceEnabled();
    if (!serviceEnabled) {
      print('Сервис геолокации отключен');
      return Future.error('Сервис геолокации отключен');
    }

    LocationPermission permission = await Geolocator.checkPermission();
    if (permission == LocationPermission.denied) {
      permission = await Geolocator.requestPermission();
      if (permission == LocationPermission.denied) {
        print('Разрешение на геолокацию отклонено');
        return Future.error('Разрешение на геолокацию отклонено');
      }
    }

    if (permission == LocationPermission.deniedForever) {
      print('Разрешение на геолокацию запрещено навсегда');
      return Future.error('Разрешение на геолокацию запрещено навсегда');
    }

    Position position = await Geolocator.getCurrentPosition(
      desiredAccuracy: LocationAccuracy.high,
    );
    print('Широта: ${position.latitude}, Долгота: ${position.longitude}');
    return position;
  } catch (e) {
    print("Ошибка получения местоположения: $e");
    return Future.error(e);
  }
}
```

## 🧭 Отслеживание перемещений пользователя в режиме Foreground

### Что такое отслеживание?

**Отслеживание перемещений** — это постоянное получение данных о местоположении пользователя с заданной частотой (например, каждые 5 секунд), даже если он двигается.

### Как это реализовать?

Для этого мы используем метод `Geolocator.getPositionStream()`:

```dart
import 'package:geolocator/geolocator.dart';

StreamSubscription<Position> positionStream = Geolocator.getPositionStream(
  desiredAccuracy: LocationAccuracy.high,
  distanceFilter: 10, // Минимальное расстояние между обновлениями (в метрах)
  intervalDuration: Duration(seconds: 5), // Интервал между обновлениями
).listen((Position position) {
  print('Новое местоположение: ${position.latitude}, ${position.longitude}');
});
```

> 📌 `distanceFilter` — минимальное расстояние в метрах, которое должен пройти пользователь, чтобы было отправлено новое обновление.

### ⚠️ Важно:

- Не забывайте **отписываться от потока**, иначе это может вызвать утечки памяти.
- При завершении работы с потоком:
```dart
positionStream.cancel();
```

## 🧰 Сторонние библиотеки для работы с геолокацией

### 1. `geolocator` (наиболее популярная)

**Особенности:**
- Простая интеграция.
- Поддерживает как foreground, так и background режимы.
- Отличная документация.
- Использует системные API Android/iOS.

### 2. `flutter_background_geolocation` (для background)

**Особенности:**
- Подходит для сложных задач отслеживания в фоне.
- Требует дополнительной настройки, особенно на iOS.
- Используется при разработке приложений для трекинга (например, приложения для бега).

### 3. `location` (альтернатива)

**Особенности:**
- Простая и лёгкая.
- Немного менее функциональна по сравнению с `geolocator`.

## 🌐 Прямое и обратное геокодирование

### 1. **Прямое геокодирование**

Это преобразование координат в адрес.

Пример:  
Широта: 55.7558, Долгота: 37.6176 → Москва, Россия

### 2. **Обратное геокодирование**

Преобразование адреса в координаты.

Пример:  
Адрес: "Москва, ул. Ленина, д. 10" → Широта: 55.7558, Долгота: 37.6176

### 📦 Используем `geocoding` библиотеку:

```yaml
dependencies:
  geocoding: ^2.0.1
```

#### Пример прямого геокодирования:

```dart
import 'package:geocoding/geocoding.dart';

Future<List<Placemark>> getPlaceFromCoordinates(double lat, double lng) async {
  List<Placemark> placemarks = await placemarkFromCoordinates(lat, lng);
  Placemark place = placemarks[0];
  print('${place.locality}, ${place.country}');
  return placemarks;
}
```

#### Пример обратного геокодирования:

```dart
Future<List<Location>> getCoordinatesFromAddress(String address) async {
  List<Location> locations = await locationFromAddress(address);
  Location loc = locations[0];
  print('Широта: ${loc.latitude}, Долгота: ${loc.longitude}');
  return locations;
}
```
