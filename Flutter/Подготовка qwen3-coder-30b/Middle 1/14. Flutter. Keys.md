# Лекция 14: Flutter. Keys

В этом уроке мы рассмотрим один из важных аспектов работы с виджетами в Flutter — **ключи (Keys)**. Ключи играют ключевую роль при управлении жизненным циклом виджетов, особенно в случае перерисовки и взаимодействия между `StatefulWidget` и их дочерними элементами.

Ключи позволяют Flutter точно определять, какие виджеты были изменены, добавлены или удалены, а также помогают избежать ненужных перерисовок. Важно понимать, как они работают и когда их использовать — особенно на уровне Middle-разработчика.

---

## Что такое Key?

В Flutter **ключ (Key)** — это метаданные, которые можно привязать к любому виджету (`Widget`) или `StatefulWidget`. Ключ используется для того, чтобы Flutter мог различать виджеты и эффективно обновлять их в DOM при изменении дерева виджетов.

Ключи помогают Flutter:

- Определить, какие виджеты были изменены.
- Связать `StatefulWidget` с конкретным экземпляром виджета.
- Избежать ненужных перерисовок.
- Управлять состоянием при пересоздании виджетов.

---

## Типы ключей

Flutter предоставляет несколько типов ключей, каждый из которых имеет своё назначение:

### 1. `const Key(String key)`

Это самый простой и часто используемый тип ключа. Он используется, когда вы хотите дать виджету уникальное имя или идентификатор.

```dart
Text('Hello', key: const Key('hello_text'))
```

**Применение:**  
- Для простого различения виджетов.
- Используется в тестах, когда нужно найти конкретный элемент по ключу.

### 2. `ValueKey<T>(T value)`

Этот ключ принимает значение любого типа и используется, когда вы хотите использовать значение для сравнения.

```dart
Text('User Name', key: ValueKey<String>('user_name'))
```

**Применение:**  
- Когда нужно изменить виджет при изменении значения.
- Используется в списке элементов, где каждый элемент имеет уникальное значение.

### 3. `UniqueKey()`

Этот ключ генерирует уникальный идентификатор для каждого экземпляра виджета, независимо от того, были ли они созданы в одном и том же месте.

```dart
Container(key: UniqueKey(), child: Text('Unique widget'))
```

**Применение:**  
- Используется, когда вы хотите быть уверенным, что виджет всегда будет пересоздан.
- Часто применяется при динамическом добавлении/удалении элементов.

### 4. `GlobalKey<T extends State<StatefulWidget>>`

Это самый мощный и сложный тип ключа. Он позволяет получить доступ к состоянию виджета извне.

```dart
final GlobalKey _globalKey = GlobalKey();

Text('My Text', key: _globalKey)
```

**Применение:**  
- Получение ссылки на `State` конкретного `StatefulWidget`.
- Доступ к методам, переменным и состоянию виджета.
- Используется в сложных случаях, когда требуется манипуляция с внутренним состоянием.

## Использование GlobalKey для получения информации об отображении объектов

`GlobalKey` особенно полезен, когда вы хотите получить доступ к `State` виджета извне. Это может понадобиться при работе с формами, модальными окнами, или когда вам нужно вызвать методы внутри `StatefulWidget`.

Пример:

```dart
class MyForm extends StatefulWidget {
  @override
  _MyFormState createState() => _MyFormState();
}

class _MyFormState extends State<MyForm> {
  final TextEditingController _controller = TextEditingController();

  void submitForm() {
    print(_controller.text);
  }

  @override
  Widget build(BuildContext context) {
    return TextField(
      controller: _controller,
      decoration: InputDecoration(hintText: "Enter text"),
    );
  }
}

class MyApp extends StatelessWidget {
  final GlobalKey<_MyFormState> _formKey = GlobalKey();

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('GlobalKey Example')),
      body: Column(
        children: [
          MyForm(key: _formKey),
          ElevatedButton(
            onPressed: () {
              _formKey.currentState?.submitForm(); // Вызов метода из состояния
            },
            child: Text("Submit"),
          )
        ],
      ),
    );
  }
}
```

В этом примере `GlobalKey` используется для получения ссылки на состояние виджета `_MyFormState`, где есть метод `submitForm()`. Таким образом, мы можем вызвать метод извне.

**Важно:**  
- Использование `GlobalKey` увеличивает сложность архитектуры.
- Используйте его только тогда, когда нет других способов достичь цели.
- Неправильное использование может привести к утечкам памяти.

## Использование ключей для перерисовки Stateful Widgets

Ключи позволяют Flutter точно определять, какие виджеты были изменены. Если вы используете ключ и значение ключа меняется, Flutter понимает, что нужно заменить старый виджет на новый.

### Пример: Динамический список с использованием `ValueKey`

```dart
class DynamicList extends StatefulWidget {
  @override
  _DynamicListState createState() => _DynamicListState();
}

class _DynamicListState extends State<DynamicList> {
  List<String> items = ['Item 1', 'Item 2', 'Item 3'];

  void addItem(String item) {
    setState(() {
      items.add(item);
    });
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        ...items.map((item) => Text(item, key: ValueKey(item))).toList(),
        ElevatedButton(
          onPressed: () => addItem('Item ${items.length + 1}'),
          child: Text("Add Item"),
        ),
      ],
    );
  }
}
```

В этом примере `ValueKey` используется для каждого элемента списка. Когда мы добавляем новый элемент, Flutter знает, что нужно обновить только новый элемент, а не перерисовывать весь список.

**Применение ключей при перерисовке:**

- Если вы хотите, чтобы Flutter пересоздал виджет (например, при изменении данных), используйте `UniqueKey`.
- Если данные одного виджета изменились, но сама структура осталась прежней, используйте `ValueKey`.

---

## Когда использовать какой тип ключа?

| Тип ключа     | Когда использовать |
|---------------|--------------------|
| `const Key`   | Для простой идентификации виджетов |
| `ValueKey<T>` | При динамическом изменении данных (например, в списке) |
| `UniqueKey`   | При необходимости пересоздания виджета |
| `GlobalKey`   | Когда нужно получить доступ к состоянию виджета извне |
