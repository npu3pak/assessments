# Лекция: Работа с камерой в Flutter (Камера, QR-сканер, кастомизация интерфейса)

## 📌 Введение

В современных мобильных приложениях камера — это мощный инструмент, позволяющий реализовать широкий спектр функций: от простого получения фото до сканирования QR-кодов и интеграции с AI-моделями. Flutter предоставляет богатые возможности для работы с камерой через пакеты, такие как `camera`, `qr_code_scanner`, `image_picker` и другие.

В рамках этой лекции мы рассмотрим:

1. **Получение фото с камеры**
2. **Запись видео с камеры**
3. **Сканирование QR-кодов**
4. **Кастомизация интерфейса камеры**

## 1. Получение фото с камеры

### 📌 Описание
Чтобы получить фото с камеры, нам нужно:
- Инициализировать камеру
- Открыть предпросмотр (preview)
- Сделать фото через метод `takePicture()`
- Сохранить или обработать изображение

Для работы с камерой в Flutter используется пакет [`camera`](https://pub.dev/packages/camera).

### 🔧 Установка и настройка
В `pubspec.yaml`:

```yaml
dependencies:
  camera: ^0.10.4
```

Не забудьте добавить разрешения в `AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.CAMERA" />
```

И в `Info.plist` (iOS):

```xml
<key>NSCameraUsageDescription</key>
<string>Для получения фото</string>
```

### 📌 Пример кода

```dart
import 'package:camera/camera.dart';
import 'package:flutter/material.dart';

List<CameraDescription> cameras = [];

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  cameras = await availableCameras();
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({Key? key}) : super(key: key);

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: CameraScreen(cameras: cameras),
    );
  }
}

class CameraScreen extends StatefulWidget {
  final List<CameraDescription> cameras;

  const CameraScreen({Key? key, required this.cameras}) : super(key: key);

  @override
  State<CameraScreen> createState() => _CameraScreenState();
}

class _CameraScreenState extends State<CameraScreen> {
  late CameraController controller;
  XFile? photo;

  @override
  void initState() {
    super.initState();
    initCamera();
  }

  Future<void> initCamera() async {
    if (widget.cameras.isEmpty) return;
    controller = CameraController(
      widget.cameras.first,
      ResolutionPreset.medium,
    );
    await controller.initialize();
    setState(() {});
  }

  Future<void> takePicture() async {
    try {
      final image = await controller.takePicture();
      setState(() {
        photo = image;
      });
    } catch (e) {
      print('Ошибка при съемке: $e');
    }
  }

  @override
  Widget build(BuildContext context) {
    if (!controller.value.isInitialized) {
      return const Scaffold(
        body: Center(child: CircularProgressIndicator()),
      );
    }

    return Scaffold(
      appBar: AppBar(title: const Text('Фото с камеры')),
      body: Column(
        children: [
          Expanded(
            child: CameraPreview(controller),
          ),
          IconButton(
            icon: const Icon(Icons.camera_alt),
            onPressed: takePicture,
          ),
        ],
      ),
    );
  }

  @override
  void dispose() {
    controller.dispose();
    super.dispose();
  }
}
```

### 🔍 Подробности:
- `CameraController` — главный класс для работы с камерой.
- `takePicture()` — возвращает `XFile`, который содержит путь к фото.
- `CameraPreview` — отображает предпросмотр камеры.

## 2. Получение видео с камеры

### 📌 Описание
Запись видео — более сложная задача, но также реализуемая через `camera`. Для этого используется метод `startVideoRecording()` и `stopVideoRecording()`.

### 🔧 Пример кода

```dart
Future<void> startRecording() async {
  try {
    await controller.startVideoRecording();
    print("Видео записывается...");
  } catch (e) {
    print('Ошибка записи видео: $e');
  }
}

Future<void> stopRecording() async {
  try {
    final video = await controller.stopVideoRecording();
    print("Видео сохранено в: ${video.path}");
  } catch (e) {
    print('Ошибка остановки записи: $e');
  }
}
```

### 📌 Важно:
- Не забудьте разрешения на запись видео.
- В `AndroidManifest.xml` добавить:

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
```

## 3. Сканирование QR-кодов

### 📌 Описание
Для сканирования QR-кодов в Flutter используется пакет [`qr_code_scanner`](https://pub.dev/packages/qr_code_scanner). Он предоставляет удобный интерфейс для сканирования кодов с камеры.

### 🔧 Установка

```yaml
dependencies:
  qr_code_scanner: ^1.0.1
```

### 🔧 Пример использования

```dart
import 'package:flutter/material.dart';
import 'package:qr_code_scanner/qr_code_scanner.dart';

class QRScannerScreen extends StatefulWidget {
  @override
  _QRScannerScreenState createState() => _QRScannerScreenState();
}

class _QRScannerScreenState extends State<QRScannerScreen> {
  final GlobalKey qrKey = GlobalKey(debugLabel: 'QR');
  QRViewController? controller;
  String? result;

  void onQRViewCreated(QRViewController qrController) {
    this.controller = qrController;
    qrController.scannedDataStream.listen((scanData) {
      setState(() {
        result = scanData.code;
      });
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Сканирование QR')),
      body: Column(
        children: [
          Expanded(
            child: QRView(
              key: qrKey,
              onQRViewCreated: onQRViewCreated,
              overlay: QrScannerOverlayShape(
                borderColor: Colors.red,
                borderRadius: 10,
                borderLength: 30,
                borderWidth: 5,
                cutOutSize: 300,
              ),
            ),
          ),
          if (result != null) Text("Результат: $result"),
        ],
      ),
    );
  }

  @override
  void dispose() {
    controller?.dispose();
    super.dispose();
  }
}
```

### 📌 Особенности:
- `QRView` отображает камеру с оверлеем для сканирования.
- `scannedDataStream` — поток, который получает результаты сканирования.
- Можно кастомизировать форму сканирующего поля (`QrScannerOverlayShape`).

## 4. Кастомизация интерфейса камеры

### 📌 Описание
Flutter предоставляет возможность полностью кастомизировать интерфейс камеры. Можно:
- Добавить кнопки управления (переключение фронт/задняя камера)
- Управлять яркостью, фокусом и т.д.
- Сделать свой UI поверх `CameraPreview`.

### 🔧 Пример кастомизации

```dart
class CustomCameraScreen extends StatefulWidget {
  final List<CameraDescription> cameras;

  const CustomCameraScreen({Key? key, required this.cameras}) : super(key: key);

  @override
  State<CustomCameraScreen> createState() => _CustomCameraScreenState();
}

class _CustomCameraScreenState extends State<CustomCameraScreen> {
  late CameraController controller;
  int cameraIndex = 0;

  @override
  void initState() {
    super.initState();
    initCamera();
  }

  Future<void> initCamera() async {
    if (widget.cameras.isEmpty) return;
    controller = CameraController(
      widget.cameras[cameraIndex],
      ResolutionPreset.medium,
    );
    await controller.initialize();
    setState(() {});
  }

  Future<void> switchCamera() async {
    cameraIndex = cameraIndex == 0 ? 1 : 0;
    await initCamera();
  }

  @override
  Widget build(BuildContext context) {
    if (!controller.value.isInitialized) {
      return const Scaffold(
        body: Center(child: CircularProgressIndicator()),
      );
    }

    return Scaffold(
      appBar: AppBar(title: Text('Кастомизированная камера')),
      body: Column(
        children: [
          Expanded(child: CameraPreview(controller)),
          Row(
            mainAxisAlignment: MainAxisAlignment.spaceEvenly,
            children: [
              IconButton(
                icon: Icon(Icons.flip_camera_ios),
                onPressed: switchCamera,
              ),
              IconButton(
                icon: Icon(Icons.camera_alt),
                onPressed: () => controller.takePicture().then((file) {
                  print("Фото сохранено в ${file.path}");
                }),
              ),
            ],
          ),
        ],
      ),
    );
  }

  @override
  void dispose() {
    controller.dispose();
    super.dispose();
  }
}
```

### 📌 Возможности кастомизации:
- Переключение между камерами (фронт/задняя)
- Свои кнопки управления
- Управление настройками камеры (яркость, фокус и т.д.)
