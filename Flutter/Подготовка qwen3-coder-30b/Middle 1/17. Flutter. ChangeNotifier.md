# Лекция: Flutter. ChangeNotifier

## Введение

**ChangeNotifier** — это один из ключевых классов в экосистеме Flutter, который используется для реализации паттерна проектирования **Observer (Наблюдатель)** в контексте управления состоянием приложения. Он применяется в сочетании с **Provider** для обеспечения реактивного обновления UI при изменении данных.

Для разработчиков на Flutter, стремящихся достичь уровня Middle и выше, понимание `ChangeNotifier` — обязательное условие. Это позволяет строить масштабируемые, читаемые и поддерживаемые приложения, особенно когда мы работаем с архитектурой, где состояние приложения должно быть прозрачно и управляется централизованно.

---

## 1. Что такое ChangeNotifier?

`ChangeNotifier` — это класс из пакета `flutter/src/foundation/change_notifier.dart`, который является частью ядра Flutter. Он реализует паттерн **Observer**, позволяя объектам уведомлять об изменениях своих состояний.

### Основные особенности:

- `ChangeNotifier` — это базовый класс, который предоставляет методы для добавления и удаления наблюдателей (`addListener`, `removeListener`) и уведомления их о событиях (`notifyListeners()`).
- Он не сам по себе управляет состоянием — он просто предоставляет механизм оповещения.
- Для использования `ChangeNotifier` обычно применяется в связке с **Provider** (или другими инструментами управления состоянием, например, Riverpod, Bloc и т.д.).

---

## 2. Как работает ChangeNotifier?

Работа `ChangeNotifier` основана на следующем принципе:

1. Состояние приложения хранится в классе, который наследуется от `ChangeNotifier`.
2. Когда состояние изменяется, вызывается метод `notifyListeners()`, который уведомляет всех зарегистрированных слушателей.
3. Слушатели (обычно виджеты) получают обновление и перерисовываются.

---

## 3. Основные методы ChangeNotifier

### a) `addListener(Listener listener)`
Добавляет функцию-слушатель, которая будет вызвана при вызове `notifyListeners()`.

```dart
void addListener(VoidCallback listener);
```

### b) `removeListener(Listener listener)`
Удаляет ранее добавленного слушателя.

```dart
void removeListener(VoidCallback listener);
```

### c) `notifyListeners()`
Вызывает всех слушателей, чтобы они обновили свой UI.

```dart
void notifyListeners();
```

## 4. Пример: простое использование ChangeNotifier

Представим, что мы хотим создать простое приложение, в котором есть счётчик. При нажатии кнопки счётчик увеличивается, и это отображается на экране.

### Шаг 1: Создаем класс, наследующий `ChangeNotifier`

```dart
import 'package:flutter/foundation.dart';

class CounterProvider extends ChangeNotifier {
  int _counter = 0;

  int get counter => _counter;

  void increment() {
    _counter++;
    notifyListeners(); // Уведомляем всех подписчиков о изменении
  }

  void decrement() {
    _counter--;
    notifyListeners();
  }
}
```

Здесь:

- `_counter` — внутреннее состояние.
- `counter` — getter для получения значения.
- `increment()` и `decrement()` — методы, изменяющие состояние и вызывающие `notifyListeners()`.

### Шаг 2: Используем Provider в UI

```dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (context) => CounterProvider(),
      child: MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('ChangeNotifier Example')),
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Consumer<CounterProvider>(
                builder: (context, counterProvider, child) {
                  return Text(
                    '${counterProvider.counter}',
                    style: TextStyle(fontSize: 30),
                  );
                },
              ),
              SizedBox(height: 20),
              ElevatedButton(
                onPressed: () => context.read<CounterProvider>().increment(),
                child: Text('Increment'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

Здесь:

- `ChangeNotifierProvider` — оборачивает приложение и предоставляет экземпляр `CounterProvider`.
- `Consumer<CounterProvider>` — слушает изменения в `CounterProvider` и перерисовывает содержимое.
- `context.read<CounterProvider>()` — получает доступ к `CounterProvider` внутри виджета.

---

## 5. Когда использовать ChangeNotifier?

### ✅ Подходит для:

- Простых состояний, которые легко управляются в одном классе.
- Небольших приложений или модулей.
- Использования с `Provider`.

### ❌ Не подходит для:

- Сложных архитектур (например, когда нужно передавать состояние между экранами или использовать его глобально).
- Когда состояние изменяется часто и требует оптимизации.

## 6. Дополнительные возможности

### a) Уведомление только при изменении значения

Можно использовать `notifyListeners()` только при реальном изменении:

```dart
void increment() {
  if (_counter < 100) { // Пример условия
    _counter++;
    notifyListeners();
  }
}
```

### b) Сложные состояния с поддержкой отмены

Можно реализовать более сложную логику, например, с историей изменений:

```dart
class HistoryProvider extends ChangeNotifier {
  List<int> _history = [];
  int _currentValue = 0;

  int get currentValue => _currentValue;
  List<int> get history => _history;

  void update(int value) {
    _history.add(_currentValue);
    _currentValue = value;
    notifyListeners();
  }

  void undo() {
    if (_history.isNotEmpty) {
      _currentValue = _history.removeLast();
      notifyListeners();
    }
  }
}
```

---

## 7. Важные моменты при работе с ChangeNotifier

1. **Не забывайте вызывать `notifyListeners()`** — без этого UI не обновится.
2. **Используйте `Consumer`, `Selector` или `context.watch`** — для подписки на изменения.
3. **Не используйте `ChangeNotifier` в качестве глобального хранилища** — это может привести к утечке памяти и неэффективности.
4. **Рассмотрите использование `ChangeNotifierProvider` вместе с `context.read()` и `context.watch()`**.

---

## 8. Альтернативы ChangeNotifier

Существуют более современные и продвинутые способы управления состоянием в Flutter:

- **Riverpod** — более гибкий и мощный инструмент, чем Provider.
- **Bloc / BLoC pattern** — хорош для сложных бизнес-логик.
- **GetX** — популярная альтернатива с простым API.

Однако `ChangeNotifier` остаётся базовым и важным инструментом, особенно при использовании `Provider`.
