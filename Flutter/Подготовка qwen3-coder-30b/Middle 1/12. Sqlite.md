# Лекция: SQLite в Flutter. Работа с локальной базой данных на уровне Middle разработчика

---

## 1. Описание SQLite

SQLite — это **легковесная, без серверного компонента СУБД (система управления базами данных)**, которая хранит данные в одном файле и работает без установки отдельного сервера. Она поддерживает стандартный SQL язык запросов и широко используется в мобильных приложениях, особенно в Android и iOS, благодаря своей простоте и надежности.

### Основные особенности SQLite:

- **Локальное хранение данных** — данные хранятся на устройстве пользователя.
- **Нет необходимости в сервере** — всё происходит локально.
- **Поддержка SQL** — можно использовать обычные SQL-запросы.
- **Потокобезопасность** — поддерживает одновременные операции чтения и записи (в зависимости от конфигурации).
- **Легковесность** — не требует большого объема памяти.
- **Поддержка ACID-транзакций** — обеспечивает целостность данных.

В Flutter, для работы с SQLite используются плагины, такие как:

- `sqflite` — основной и популярный плагин для работы с SQLite в Flutter.
- `flutter_secure_io` — для дополнительной безопасности данных (например, шифрование).
- `moor` или `drift` — более продвинутые ORM-библиотеки для работы с базами данных.

## 2. Работа в командной строке

Для работы с SQLite в Flutter вы можете использовать **SQLite CLI (Command Line Interface)**, если у вас есть доступ к командной строке на устройстве или через эмулятор.

### Пример использования SQLite CLI:

```bash
# Открываем файл базы данных
sqlite3 my_database.db

# Создаем таблицу
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

# Вставляем данные
INSERT INTO users (name, email) VALUES ('Иван', 'ivan@example.com');

# Выбираем данные
SELECT * FROM users;

# Закрываем соединение
.quit
```

> **Примечание**: в Flutter вы обычно не используете SQLite CLI напрямую, но знание SQL и команд позволяет вам тестировать запросы перед их внедрением в код.

## 3. Поддерживаемые типы данных

SQLite **не строго типизирована**, как в других СУБД. Вместо этого SQLite использует **динамическую типизацию** с типами, которые зависят от значения поля. Однако при создании таблицы вы можете указать типы, и SQLite будет использовать их как рекомендации.

### Основные типы данных:

| Тип | Описание |
|-----|----------|
| `INTEGER` | Целое число |
| `TEXT` | Строка (текст) |
| `REAL` | Число с плавающей точкой |
| `BLOB` | Двоичные данные (например, изображения) |
| `NUMERIC` | Число, может быть целым или вещественным |
| `BOOLEAN` | Не поддерживается напрямую, обычно реализуется через INTEGER |

> **Примечание**: в SQLite нет истинного типа `BOOLEAN`, но его часто имитируют через `INTEGER` (1 = true, 0 = false).

### Пример создания таблицы с типами:

```dart
final String createTableQuery = '''
  CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    age INTEGER,
    is_active BOOLEAN DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  );
''';
```

## 4. Плагины для работы с SQLite

### Основной плагин: `sqflite`

- **Описание**: Плагин для работы с SQLite в Flutter.
- **Поддержка**: Android, iOS.
- **Функционал**:
  - Создание таблиц.
  - Вставка, обновление и удаление записей.
  - Выполнение SQL-запросов.
  - Транзакции.

#### Установка:

```yaml
dependencies:
  sqflite: ^2.3.0
```

#### Пример базового использования:

```dart
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';

Future<Database> initDatabase() async {
  String path = await getDatabasesPath();
  return openDatabase(
    join(path, 'my_database.db'),
    version: 1,
    onCreate: (db, version) {
      db.execute('''
        CREATE TABLE users (
          id INTEGER PRIMARY KEY AUTOINCREMENT,
          name TEXT NOT NULL,
          email TEXT UNIQUE
        )
      ''');
    },
  );
}
```

## 5. Инструменты для проектирования и генерации таблиц

### Рекомендуемые инструменты:

1. **DB Browser for SQLite (SQLite Browser)** — графический интерфейс для работы с SQLite.
2. **DBeaver** — универсальная среда для работы с БД, включая SQLite.
3. **Flutter DevTools** — для отладки и анализа баз данных при разработке.
4. **sqflite_generator** (неофициальный) — для автоматической генерации кода из таблиц.

### Пример создания таблицы через DB Browser:

1. Открываем `DB Browser for SQLite`.
2. Создаем новый файл БД.
3. Вкладка "Create Table".
4. Определяем поля, типы и ограничения.
5. Сохраняем и копируем SQL-запрос в код Flutter.

## 6. Что такое миграции и как их выполнять

**Миграции** — это процесс изменения структуры базы данных при обновлении приложения. Например, добавление нового поля, изменение типа или удаление таблицы.

В SQLite миграции не поддерживаются автоматически, поэтому разработчик сам должен реализовать механизм миграций.

### Пример реализации миграции:

```dart
Future<Database> initDatabase() async {
  String path = await getDatabasesPath();
  return openDatabase(
    join(path, 'my_database.db'),
    version: 2,
    onCreate: (db, version) {
      db.execute('''
        CREATE TABLE users (
          id INTEGER PRIMARY KEY AUTOINCREMENT,
          name TEXT NOT NULL,
          email TEXT UNIQUE
        )
      ''');
    },
    onUpgrade: (db, oldVersion, newVersion) async {
      if (oldVersion < 2) {
        await db.execute('ALTER TABLE users ADD COLUMN age INTEGER DEFAULT 0;');
      }
    },
  );
}
```

> **Важно**: При изменении `version` базы данных, `onUpgrade` вызывается автоматически.
