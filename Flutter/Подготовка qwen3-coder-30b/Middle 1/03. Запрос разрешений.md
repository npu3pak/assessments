# Лекция 03: Запрос разрешений

## Введение

В мире мобильной разработки безопасность и приватность пользователей — ключевые аспекты. Приложение не может просто так получить доступ к системным ресурсам, таким как камера, геолокация или файловая система, без явного согласия пользователя. В Android и iOS есть строгие правила по управлению разрешениями, которые необходимо соблюдать при создании приложений.

В этой лекции мы рассмотрим, какие разрешения требуются для доступа к различным системным функциям на платформах Android и iOS, а также научимся реализовывать запросы разрешений в Flutter с использованием плагина `permission_handler`.

---

## 1. Разрешения для доступа к каталогу на Android

На Android приложения не имеют прямого доступа к файловой системе пользователя без специального разрешения. Для доступа к общим каталогам, таким как "Загрузки", "Фотографии" или "Документы", нужно запросить соответствующее разрешение.

### Важные разрешения:
- `android.permission.READ_EXTERNAL_STORAGE` — чтение данных из внешнего хранилища.
- `android.permission.WRITE_EXTERNAL_STORAGE` — запись в внешнее хранилище.

> ⚠️ **Важно:** Начиная с Android 10 (API level 29), приложение не может получить доступ к файлам вне своей приватной папки без разрешения `MANAGE_EXTERNAL_STORAGE`. Это связано с политикой изоляции хранилища.

### Практический пример:
Допустим, вы хотите открыть файл из каталога "Загрузки". Сначала нужно запросить разрешение:

```dart
import 'package:permission_handler/permission_handler.dart';

Future<void> requestStoragePermission() async {
  final status = await Permission.storage.request();
  if (status.isGranted) {
    print('Разрешение на доступ к хранилищу получено');
  } else {
    print('Разрешение отклонено или запрошено повторно');
  }
}
```

> 🧠 **Важно:** На устройствах с Android 10 и выше рекомендуется использовать `Permission.manageExternalStorage` вместо `Permission.storage`.

## 2. Разрешения для доступа к камере и микрофону

Для использования камеры или микрофона в приложении необходимо запросить соответствующие разрешения.

### Разрешения:
- `android.permission.CAMERA` — доступ к камере.
- `android.permission.RECORD_AUDIO` — доступ к микрофону.

На iOS аналогичные разрешения требуются через Info.plist и специальные запросы, например:

```xml
<key>NSCameraUsageDescription</key>
<string>Приложение использует камеру для сканирования QR-кодов.</string>

<key>NSMicrophoneUsageDescription</key>
<string>Приложение использует микрофон для записи аудио.</string>
```

### Пример запроса разрешений:

```dart
Future<void> requestCameraAndMicrophonePermission() async {
  final cameraStatus = await Permission.camera.request();
  final microphoneStatus = await Permission.microphone.request();

  if (cameraStatus.isGranted && microphoneStatus.isGranted) {
    print('Разрешения на камеру и микрофон получены');
  } else {
    print('Разрешения не предоставлены');
  }
}
```

## 3. Разрешения для доступа к геолокации в режиме foreground

Геолокация — одна из самых часто используемых функций приложений. В зависимости от того, нужно ли использовать местоположение только когда приложение активно (foreground), или постоянно (background), нужны разные разрешения.

### Android:
- `android.permission.ACCESS_FINE_LOCATION` — точное местоположение.
- `android.permission.ACCESS_COARSE_LOCATION` — приблизительное местоположение.

### iOS:
- `NSLocationWhenInUseUsageDescription` — для запроса разрешения в режиме foreground.

### Пример:

```dart
Future<void> requestLocationPermission() async {
  final status = await Permission.location.request();
  if (status.isGranted) {
    print('Разрешение на геолокацию получено');
  } else {
    print('Разрешение не предоставлено');
  }
}
```

---

## 4. Разрешения для доступа к геолокации в режиме background

Если ваше приложение должно работать с геолокацией в фоне, то на iOS и Android нужно запросить дополнительные разрешения.

### Android:
- `android.permission.ACCESS_BACKGROUND_LOCATION` — разрешение на фоновое местоположение.
> ⚠️ На Android 10+ это требует также `ACCESS_FINE_LOCATION`.

### iOS:
- `NSLocationAlwaysAndWhenInUseUsageDescription` — разрешение на использование геолокации всегда и когда приложение в фоне.

> 📌 Обратите внимание, что Apple строго контролирует использование фоновой геолокации. Приложения, которые не используют эту функцию, могут быть отклонены из App Store.

### Пример запроса:

```dart
Future<void> requestBackgroundLocationPermission() async {
  final foregroundStatus = await Permission.locationWhenInUse.request();
  final backgroundStatus = await Permission.locationAlways.request();

  if (foregroundStatus.isGranted && backgroundStatus.isGranted) {
    print('Разрешения на геолокацию в foreground и background получены');
  } else {
    print('Разрешения не предоставлены');
  }
}
```

## 5. Разрешения для доступа к каталогу файловой системы на Android

На Android для доступа к файлам вне приватной директории приложения (например, к файлам в "Загрузках") нужно:

1. Запросить `Permission.storage` или `Permission.manageExternalStorage`.
2. Использовать специальные API, такие как `Storage Access Framework (SAF)`.

> 📌 Пользователь может выбрать конкретную папку для доступа через SAF, что делает процесс более безопасным и прозрачным.

### Пример:

```dart
Future<void> requestFileAccessPermission() async {
  final status = await Permission.storage.request();
  if (status.isGranted) {
    print('Доступ к файлам разрешён');
  } else {
    print('Доступ к файлам отклонён');
  }
}
```

## 6. Плагин `permission_handler`. Настройка и возможности

`permission_handler` — один из самых популярных плагинов в Flutter для работы с разрешениями. Он поддерживает все основные платформы (Android, iOS) и предоставляет простой интерфейс для запроса и проверки статуса разрешений.

### Установка:
```yaml
dependencies:
  permission_handler: ^10.4.3
```

> 📌 Плагин поддерживает не только базовые разрешения, но и более сложные, такие как `Bluetooth`, `Notifications`, `Sensors`, и другие.

### Основные возможности:

#### 1. Запрос разрешений:
```dart
final status = await Permission.camera.request();
```

#### 2. Проверка статуса разрешения:
```dart
final status = await Permission.camera.status;
if (status.isGranted) {
  // Разрешение уже предоставлено
} else if (status.isDenied) {
  // Пользователь отклонил запрос
} else if (status.isPermanentlyDenied) {
  // Пользователь отклонил и запретил повторный запрос
}
```

#### 3. Открытие настроек приложения:
```dart
openAppSettings(); // Открывает настройки приложения для управления разрешениями
```

#### 4. Поддержка различных типов разрешений:
```dart
Permission.camera,
Permission.location,
Permission.microphone,
Permission.storage,
Permission.bluetooth,
Permission.sensors,
Permission.notification,
Permission.accessMediaLocation,
Permission.manageExternalStorage,
```
