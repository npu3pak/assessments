# Лекция: Продвинутые возможности VSCode для Flutter-разработки

## Введение

VS Code — это мощная и гибкая среда разработки, которая стала стандартом для мобильной и веб-разработки. Особенно популярна она среди Flutter-разработчиков благодаря богатой экосистеме плагинов и интеграции с Dart. Однако не все пользователи знают о продвинутых возможностях VS Code, которые могут значительно повысить эффективность работы.

В этой лекции мы рассмотрим три важных аспекта использования VS Code в контексте Flutter-разработки:

1. **CodeLens** — функционал, который добавляет дополнительную информацию прямо в коде.
2. **Настройка workspace** — управление проектами и их конфигурацией в VS Code.
3. **Snippets** — шаблоны кода, позволяющие быстрее писать повторяющийся код.

Все примеры будут приведены на языке Dart и Flutter.

---

## 1. CodeLens

### Что такое CodeLens?

**CodeLens** — это функционал VS Code, который отображает дополнительную информацию прямо в редакторе кода. Он позволяет видеть ссылки, количество вызовов метода, информацию о тестах и многое другое без необходимости переключаться на другие окна.

### Зачем использовать CodeLens?

CodeLens особенно полезен при работе с большими проектами, где сложно отследить:

- Сколько раз вызывается тот или иной метод.
- Какие методы используются в конкретном файле.
- Что тестирует определенный класс или метод.

### Пример использования CodeLens в Flutter

Вот как может выглядеть использование CodeLens в Flutter-проекте:

```dart
class MyHomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Home')),
      body: Center(child: Text('Hello World')),
    );
  }
}
```

Если вы включите CodeLens, то увидите рядом с `build` методом информацию о том, сколько раз он вызывается или какие тесты его используют.

### Включение и настройка CodeLens

1. Откройте **Настройки VS Code** (`Ctrl/Cmd + ,`).
2. Найдите раздел **"Editor > Code Lens"**.
3. Включите опцию `Editor: Code Lens`.

Также можно настроить отдельно для Dart:

```json
{
  "dart.enableCodeLens": true,
  "dart.codeLensReferences": true,
  "dart.codeLensTest": true
}
```

### Практический пример

Предположим, у нас есть класс с методом `calculate` и несколько тестов, которые его используют:

```dart
class Calculator {
  int calculate(int a, int b) {
    return a + b;
  }
}
```

В CodeLens вы увидите количество вызовов метода `calculate`, а также ссылки на тесты, которые его тестируют.

## 2. Настройка Workspace

### Что такое Workspace?

**Workspace** — это концепция VS Code, позволяющая работать с несколькими проектами в одном окне. Это особенно удобно, когда вы работаете над крупными приложениями или над несколькими связанными Flutter-проектами.

### Зачем использовать Workspace?

Workspace позволяет:

- Хранить настройки, которые применяются ко всем проектам в группе.
- Управлять открытыми папками.
- Настраивать разные конфигурации для разных сред разработки (dev, prod и т.д.).

### Как создать и использовать Workspace?

#### Шаг 1: Открытие нескольких папок

1. Откройте VS Code.
2. Выберите **File → Add Folder to Workspace** или просто перетащите папку в окно VS Code.
3. Сохраните workspace как `.code-workspace` файл.

Пример файла `my_flutter_workspace.code-workspace`:

```json
{
  "folders": [
    {
      "path": "./app1"
    },
    {
      "path": "./app2"
    }
  ],
  "settings": {
    "dart.promptToGetPackages": false,
    "dart.previewFlutterUiGuides": true,
    "dart.showTodos": true
  }
}
```

#### Шаг 2: Настройка Workspace-specific настроек

Вы можете задать специфичные для workspace настройки, например:

```json
{
  "settings": {
    "dart.analyzeAngularTemplates": true,
    "dart.previewDart2": true,
    "editor.rulers": [80],
    "files.exclude": {
      "**/build": true,
      "**/*.log": true
    }
  }
}
```

#### Шаг 3: Открытие workspace

1. Выберите **File → Open Workspace from File**.
2. Укажите путь к `.code-workspace` файлу.

### Полезные настройки в workspace

- `files.exclude`: Скрывает ненужные файлы и папки.
- `editor.rulers`: Отображает вертикальные линии для отступов.
- `dart.previewFlutterUiGuides`: Показывает направляющие в Flutter UI.

### Использование Workspace в командной разработке

Если вы работаете в команде, вы можете использовать workspace для:

- Синхронизации настроек между участниками.
- Упрощения настройки среды разработки.
- Хранения общих конфигураций, таких как `launch.json`, `settings.json` и т.д.

## 3. Snippets

### Что такое Snippets?

**Snippets** — это шаблоны кода, которые вы можете быстро вставить в ваш проект. Они особенно полезны для часто повторяющихся конструкций, таких как:

- `StatefulWidget`
- `ListView.builder`
- `FutureBuilder`

VS Code поддерживает пользовательские и предопределенные Snippets.

### Как создавать собственные Snippets?

#### Шаг 1: Открытие Snippet Editor

1. Откройте **File → Preferences → User Snippets**.
2. Выберите язык `Dart`.

#### Шаг 2: Пример создания своего Snippet

```json
{
  "Flutter StatefulWidget": {
    "prefix": "stf",
    "body": [
      "class ${1:MyWidget} extends StatefulWidget {",
      "  @override",
      "  _${1:MyWidget}State createState() => _${1:MyWidget}State();",
      "}",
      "",
      "class _${1:MyWidget}State extends State<${1:MyWidget}> {",
      "  @override",
      "  Widget build(BuildContext context) {",
      "    return Container();",
      "  }",
      "}"
    ],
    "description": "Create a StatefulWidget"
  }
}
```

#### Шаг 3: Использование Snippet

При вводе `stf` и нажатии `Tab`, VS Code автоматически вставит шаблон StatefulWidget.

### Полезные Flutter Snippets

Ниже приведены примеры часто используемых Snippets для Flutter:

#### 1. `ListView.builder`

```json
{
  "Flutter ListView.builder": {
    "prefix": "lvb",
    "body": [
      "ListView.builder(",
      "  itemCount: ${1:list.length},",
      "  itemBuilder: (context, index) {",
      "    return ${2:Widget};",
      "  },",
      ")"
    ]
  }
}
```

#### 2. `FutureBuilder`

```json
{
  "Flutter FutureBuilder": {
    "prefix": "fb",
    "body": [
      "FutureBuilder<${1:Type}>(",
      "  future: ${2:future},",
      "  builder: (context, snapshot) {",
      "    if (snapshot.connectionState == ConnectionState.waiting) {",
      "      return CircularProgressIndicator();",
      "    } else if (snapshot.hasError) {",
      "      return Text('Error: ${3:snapshot.error}');",
      "    } else {",
      "      return ${4:Widget};",
      "    }",
      "  },",
      ")"
    ]
  }
}
```

#### 3. `StreamBuilder`

```json
{
  "Flutter StreamBuilder": {
    "prefix": "sb",
    "body": [
      "StreamBuilder<${1:Type}>(",
      "  stream: ${2:stream},",
      "  builder: (context, snapshot) {",
      "    if (!snapshot.hasData) {",
      "      return CircularProgressIndicator();",
      "    } else {",
      "      return ${3:Widget};",
      "    }",
      "  },",
      ")"
    ]
  }
}
```

### Как импортировать Snippets?

Вы можете создать общий файл `snippets/dart.json` и импортировать его в VS Code.

### Советы по использованию Snippets

- Используйте понятные префиксы.
- Делайте сниппеты максимально гибкими (с `$1`, `$2` и т.д.).
- Не забывайте про документацию в `description`.
