# Лекция 07: Отправка Form Data

## Введение

В мобильной разработке на Flutter, особенно при создании приложений с авторизацией, регистрацией или отправкой данных пользователя, очень часто возникает необходимость отправлять данные формы (Form Data) на сервер. Эти данные могут быть как текстовыми, так и бинарными — например, изображения, файлы и т.д.

Формат Form Data используется для передачи данных в HTTP-запросах методом `POST`. В Flutter для работы с сетью мы часто используем библиотеку `dio`, которая предоставляет удобный способ отправки запросов, включая отправку форм данных. В этой лекции мы подробно рассмотрим, что такое Form Data, как оно работает и как отправлять его на сервер с использованием `dio`.

---

## 1. Описание и назначение Form Data

### Что такое Form Data?

Form Data — это способ кодирования данных для передачи в HTTP-запросе. Он используется при отправке формы на сервер, например, в случае регистрации пользователя, загрузки файла или отправки данных из формы веб-приложения.

В формате `multipart/form-data` данные разбиваются на части (boundaries), каждая часть может содержать:

- **Поле формы** — текстовые данные
- **Файл** — бинарные данные

Формат `multipart/form-data` используется, когда необходимо отправить файлы или смешанные данные (текст + файлы).

### Пример формата Form Data:

```http
POST /upload HTTP/1.1
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW

------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="username"

john_doe
------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="avatar"; filename="photo.jpg"
Content-Type: image/jpeg

<binary data>
------WebKitFormBoundary7MA4YWxkTrZu0gW--
```

Как видно, формат состоит из частей, разделённых `boundary`. Каждая часть может содержать заголовки и тело.

## 2. Использование Dio для отправки Form Data

Для работы с HTTP-запросами в Flutter мы используем библиотеку `dio`. Она предоставляет удобный способ формирования запросов, включая отправку данных в формате `multipart/form-data`.

### Установка dio:

Добавьте в `pubspec.yaml`:

```yaml
dependencies:
  dio: ^5.4.0
```

Затем выполните:

```bash
flutter pub get
```

---

## 3. Пример отправки Form Data с помощью Dio

Допустим, у нас есть форма с полями `username`, `email` и файлом `avatar`.

### Полный пример:

```dart
import 'package:dio/dio.dart';
import 'dart:io';

Future<void> uploadFormData() async {
  final dio = Dio();

  // Подготовка данных формы
  final formData = FormData.fromMap({
    'username': 'john_doe',
    'email': 'john@example.com',
    'avatar': await MultipartFile.fromFile(
      '/path/to/image.jpg',
      filename: 'photo.jpg',
      contentType: MediaType('image', 'jpeg'),
    ),
  });

  try {
    final response = await dio.post(
      'https://your-server.com/api/upload',
      data: formData,
      options: Options(
        headers: {
          'Content-Type': 'multipart/form-data',
        },
      ),
    );

    print('Response: ${response.data}');
  } catch (e) {
    print('Error: $e');
  }
}
```

### Пояснение:

- `FormData.fromMap()` — создаёт форму с полями из `Map`.
- `MultipartFile.fromFile()` — позволяет отправить файл.
- `filename` и `contentType` — важны для корректной обработки файла на сервере.
- `Options` с `headers` могут быть полезны, если сервер ожидает специфичные заголовки.

## 4. Отправка текстовых полей и файлов

Можно смешивать текстовые данные и файлы в одной форме:

```dart
final formData = FormData.fromMap({
  'name': 'John',
  'age': '25',
  'avatar': await MultipartFile.fromFile(
    '/path/to/photo.jpg',
    filename: 'profile.jpg',
  ),
});
```

Также можно добавлять несколько файлов:

```dart
final formData = FormData.fromMap({
  'files': [
    await MultipartFile.fromFile('/path/to/file1.jpg'),
    await MultipartFile.fromFile('/path/to/file2.png'),
  ],
});
```

## 5. Обработка ошибок и логирование

Важно обрабатывать ошибки при отправке данных:

```dart
try {
  final response = await dio.post(
    'https://your-server.com/api/upload',
    data: formData,
  );

  if (response.statusCode == 200) {
    print('Успешно отправлено');
  } else {
    print('Ошибка сервера: ${response.statusCode}');
  }
} on DioException catch (e) {
  if (e.type == DioExceptionType.connectionTimeout) {
    print('Таймаут соединения');
  } else if (e.response?.statusCode == 400) {
    print('Неверные данные формы');
  } else {
    print('Ошибка: ${e.message}');
  }
}
```

## 6. Пример с UI-интерфейсом (Flutter)

Допустим, у нас есть форма с текстовыми полями и кнопкой загрузки:

```dart
class UploadForm extends StatefulWidget {
  @override
  _UploadFormState createState() => _UploadFormState();
}

class _UploadFormState extends State<UploadForm> {
  final formKey = GlobalKey<FormState>();
  final usernameController = TextEditingController();
  final emailController = TextEditingController();
  File? selectedFile;

  Future<void> upload() async {
    if (!formKey.currentState!.validate()) return;

    final dio = Dio();

    final formData = FormData.fromMap({
      'username': usernameController.text,
      'email': emailController.text,
      'avatar': selectedFile != null
          ? await MultipartFile.fromFile(selectedFile!.path)
          : null,
    });

    try {
      final response = await dio.post(
        'https://your-server.com/api/upload',
        data: formData,
      );

      if (response.statusCode == 200) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text('Успешно отправлено')),
        );
      }
    } catch (e) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Ошибка: $e')),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: formKey,
      child: Column(
        children: [
          TextFormField(
            controller: usernameController,
            decoration: InputDecoration(labelText: 'Имя пользователя'),
            validator: (value) => value!.isEmpty ? 'Введите имя' : null,
          ),
          TextFormField(
            controller: emailController,
            decoration: InputDecoration(labelText: 'Email'),
            keyboardType: TextInputType.emailAddress,
            validator: (value) => value!.isEmpty ? 'Введите email' : null,
          ),
          ElevatedButton.icon(
            onPressed: () async {
              // Загрузка файла
              final image = await ImagePicker().pickImage(source: ImageSource.gallery);
              if (image != null) {
                setState(() {
                  selectedFile = File(image.path);
                });
              }
            },
            icon: Icon(Icons.upload),
            label: Text('Выбрать файл'),
          ),
          ElevatedButton(
            onPressed: upload,
            child: Text('Отправить'),
          ),
        ],
      ),
    );
  }

  @override
  void dispose() {
    usernameController.dispose();
    emailController.dispose();
    super.dispose();
  }
}
```
