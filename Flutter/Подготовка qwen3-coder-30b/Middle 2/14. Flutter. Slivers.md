# Лекция: Flutter Slivers — Продвинутая прокрутка и сложные UI

---

## 1. Объяснение концепции Sliver-виджетов

**Sliver-виджеты** — это специфические виджеты в Flutter, предназначенные для работы внутри `CustomScrollView`. Они позволяют создавать сложные и гибкие интерфейсы с прокруткой, где отдельные элементы могут вести себя по-разному: например, один элемент может быть "закреплённым", другой — "прокручиваемым", третий — "закреплённым на верху" при прокрутке.

Ключевая особенность Sliver-виджетов:

> **Они не отображаются напрямую в обычном `ListView` или `Column`. Они работают внутри `CustomScrollView`, который сам управляет их отрисовкой и прокруткой.**

### Важно знать:
- Sliver-виджеты используются только внутри `CustomScrollView`.
- Они имеют **различные поведения** при прокрутке: могут быть закреплёнными, скрытыми, растягиваемыми и т.д.
- Следует использовать их, когда вам нужна более гибкая и продуманная архитектура UI с прокруткой.

---

## 2. Отличие Sliver-виджетов от обычных виджетов

| Характеристика | Обычные виджеты (`ListView`, `Column`) | Sliver-виджеты (`SliverList`, `SliverAppBar`) |
|----------------|------------------------------------------|------------------------------------------------|
| Вложенность    | Прямая (просто вложены друг в друга)     | Только внутри `CustomScrollView`               |
| Управление     | Простое прокручивание                   | Управляется через `ScrollView` и `SliverGeometry` |
| Гибкость       | Низкая                                  | Высокая                                        |
| Использование  | Для простых списков                     | Для сложных интерфейсов с эффектами            |

**Пример:**

```dart
// Обычный ListView
ListView(
  children: [
    Text('Item 1'),
    Text('Item 2'),
    Text('Item 3'),
  ],
);

// Sliver в CustomScrollView
CustomScrollView(
  slivers: [
    SliverAppBar(
      title: Text('My App'),
    ),
    SliverList(
      delegate: SliverChildBuilderDelegate(
        (context, index) => ListTile(title: Text('Item $index')),
        childCount: 10,
      ),
    ),
  ],
);
```

## 3. Виджет `SliverToBoxAdapter`

**`SliverToBoxAdapter`** — это виджет, который позволяет «обернуть» обычный виджет (например, `Text`, `Container`) и использовать его внутри `CustomScrollView`.

### Когда используется:
- Вы хотите вставить обычный виджет в сложную структуру с `Sliver`-элементами.
- Нужно использовать `SliverAppBar`, `SliverList`, и обычный `Text` или `Container` одновременно.

### Пример:

```dart
CustomScrollView(
  slivers: [
    SliverAppBar(
      title: Text('Title'),
    ),
    SliverToBoxAdapter(
      child: Container(
        height: 100,
        color: Colors.blue,
        child: Center(child: Text('Regular Widget')),
      ),
    ),
    SliverList(
      delegate: SliverChildBuilderDelegate(
        (context, index) => ListTile(title: Text('Item $index')),
        childCount: 5,
      ),
    ),
  ],
);
```

## 4. Виджет `SliverAppBar`

**`SliverAppBar`** — это специальный `Sliver`, который представляет собой AppBar, который может быть закреплён или раскрыт при прокрутке.

### Основные параметры:

| Параметр         | Назначение |
|------------------|------------|
| `title`          | Заголовок |
| `floating`       | Если `true`, AppBar будет "всплывать" при прокрутке |
| `pinned`         | Если `true`, AppBar закрепляется наверх |
| `snap`           | Если `true`, AppBar "прилипает" к верху при прокрутке |
| `expandedHeight` | Высота раскрытого AppBar |
| `flexibleSpace`  | Содержимое, которое раскрывается при прокрутке |

### Пример:

```dart
CustomScrollView(
  slivers: [
    SliverAppBar(
      title: Text('My App'),
      pinned: true,
      expandedHeight: 200,
      flexibleSpace: FlexibleSpaceBar(
        title: Text('Expanded Title'),
        background: Image.asset('assets/background.jpg', fit: BoxFit.cover),
      ),
    ),
    SliverList(
      delegate: SliverChildBuilderDelegate(
        (context, index) => ListTile(title: Text('Item $index')),
        childCount: 20,
      ),
    ),
  ],
);
```

## 5. Виджеты `SliverList` и `SliverGrid`

### `SliverList`

**`SliverList`** — отображает список элементов, которые могут быть сконструированы динамически.

#### Пример:

```dart
SliverList(
  delegate: SliverChildBuilderDelegate(
    (context, index) => ListTile(title: Text('Item $index')),
    childCount: 50,
  ),
)
```

### `SliverGrid`

**`SliverGrid`** — отображает элементы в виде сетки (например, колонок или строк).

#### Пример:

```dart
SliverGrid(
  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
    crossAxisSpacing: 10,
    mainAxisSpacing: 10,
  ),
  delegate: SliverChildBuilderDelegate(
    (context, index) => Container(
      color: Colors.blue,
      child: Center(child: Text('Item $index')),
    ),
    childCount: 20,
  ),
)
```

## 6. Виджет `CustomScrollView`

**`CustomScrollView`** — это контейнер для `Sliver`-виджетов, который позволяет создавать сложные интерфейсы с прокруткой.

### Основные свойства:

| Параметр     | Назначение |
|--------------|------------|
| `slivers`    | Список Sliver-виджетов |
| `scrollDirection` | Направление прокрутки (`Axis.vertical`, `Axis.horizontal`) |
| `reverse`    | Обратное направление прокрутки |

### Пример полного экрана с `CustomScrollView`:

```dart
class MySliverScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: CustomScrollView(
        slivers: [
          SliverAppBar(
            title: Text('My App'),
            pinned: true,
            expandedHeight: 200,
            flexibleSpace: FlexibleSpaceBar(
              title: Text('Title'),
              background: Image.asset('assets/background.jpg', fit: BoxFit.cover),
            ),
          ),
          SliverToBoxAdapter(
            child: Padding(
              padding: EdgeInsets.all(16),
              child: Text('Some text'),
            ),
          ),
          SliverList(
            delegate: SliverChildBuilderDelegate(
              (context, index) => ListTile(title: Text('Item $index')),
              childCount: 20,
            ),
          ),
          SliverGrid(
            gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
              crossAxisCount: 2,
              crossAxisSpacing: 10,
              mainAxisSpacing: 10,
            ),
            delegate: SliverChildBuilderDelegate(
              (context, index) => Container(color: Colors.green),
              childCount: 10,
            ),
          ),
        ],
      ),
    );
  }
}
```
