# Лекция: Сигнальные Push-уведомления в Flutter

## Введение

Push-уведомления — это важный инструмент взаимодействия с пользователями приложений. Они позволяют отправлять информацию в реальном времени, даже если приложение не запущено. Среди различных типов push-уведомлений особое внимание заслуживают **сигнальные Push**, которые используются для передачи важной информации, например, системных сообщений, критических уведомлений, или даже для синхронизации данных в реальном времени.

В этой лекции мы подробно рассмотрим:

- Что такое сигнальные Push
- Как они отличаются от обычных уведомлений
- Как отправлять сигнальные Push на iOS и Android
- Как обрабатывать сигнальные Push в foreground и background режимах

---

## 1. Что такое сигнальные Push?

Сигнальные Push — это тип push-уведомлений, которые не отображаются пользователю как обычные уведомления, но могут активировать приложение и передавать данные в фоновом режиме. Они особенно полезны для:

- Синхронизации данных между устройством и сервером
- Обновления состояния приложения
- Передачи важных сообщений, которые не требуют отображения пользователю

В отличие от обычных уведомлений, сигнальные Push не показываются в шторке уведомлений. Их основная цель — передать данные приложению без необходимости отображения интерфейса.

---

## 2. Отличие сигнальных Push от обычных уведомлений

| Характеристика | Обычное уведомление | Сигнальный Push |
|----------------|---------------------|------------------|
| Визуальное отображение | Да | Нет |
| Активация приложения | При нажатии на уведомление | При получении в фоне |
| Цель | Уведомление пользователя | Обмен данными |
| Показывается в шторке | Да | Нет |
| Используется в background | Да | Да, но без отображения |
| Содержание | Текст + заголовок | Данные (payload) |

Пример:  
Если вы работаете с системой чатов, вы можете использовать сигнальные Push для получения новых сообщений и обновления состояния приложения, не показывая уведомление пользователю.

## 3. Отправка сигнальных Push на iOS и Android

### 3.1. Настройка сервера

Для отправки push-уведомлений необходимо использовать специфичные API:

#### iOS (APNs — Apple Push Notification Service)
1. Создайте SSL-сертификат для APNs.
2. Используйте **HTTP/2** для отправки уведомлений.
3. Убедитесь, что ваше приложение поддерживает **silent push notifications**.

Пример заголовка запроса:

```http
POST /3/device/<device_token> HTTP/2
Authorization: Bearer <jwt_token>
apns-push-type: background
apns-topic: com.yourcompany.app
content-type: application/json
```

#### Android (Firebase Cloud Messaging — FCM)
1. Включите FCM в проекте.
2. Установите `content_available: true` в payload.
3. Отправьте push с `priority: high`.

Пример JSON payload:

```json
{
  "to": "<device_token>",
  "content_available": true,
  "priority": "high",
  "data": {
    "message": "Новое сообщение"
  }
}
```

### 3.2. Flutter-фреймворк и библиотека `firebase_messaging`

Для работы с Push-уведомлениями в Flutter используется библиотека `firebase_messaging`.

#### Подключение Firebase:
1. Добавьте `firebase_core` и `firebase_messaging`.
2. Сконфигурируйте Firebase в проекте (iOS и Android).

```yaml
dependencies:
  firebase_core: ^2.14.0
  firebase_messaging: ^14.7.9
```

#### Обработка входящих push-уведомлений:

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

void main() {
  Firebase.initializeApp();
  
  // Обработка уведомлений в фоне
  FirebaseMessaging.onBackgroundMessage(_handleBackgroundMessage);

  runApp(MyApp());
}

Future<void> _handleBackgroundMessage(RemoteMessage message) async {
  print('Получено background сообщение: ${message.data}');
}
```

## 4. Прием сигнальных Push в foreground и background

### 4.1. В foreground (при активном приложении)

Когда приложение запущено и находится на переднем плане, все push-уведомления обрабатываются через `onMessage`:

```dart
FirebaseMessaging.onMessage.listen((RemoteMessage message) {
  print('Получено сообщение в foreground: ${message.data}');
});
```

### 4.2. В background (при свернутом приложении)

Для обработки push-уведомлений в фоновом режиме используется `onBackgroundMessage`:

```dart
Future<void> _handleBackgroundMessage(RemoteMessage message) async {
  print('Получено сообщение в background: ${message.data}');

  // Можно выполнить фоновую задачу, например, обновление данных
}
```

### 4.3. Обработка нажатий на уведомления (если они отображаются)

Если вы используете обычные уведомления, можно обрабатывать клики:

```dart
FirebaseMessaging.onMessageOpenedApp.listen((RemoteMessage message) {
  print('Пользователь нажал на push: ${message.data}');
});
```

## 5. Пример: Реализация сигнального Push в Flutter

### Шаг 1: Подключение Firebase

```yaml
dependencies:
  firebase_core: ^2.14.0
  firebase_messaging: ^14.7.9
```

### Шаг 2: Инициализация

```dart
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_messaging/firebase_messaging.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp();

  FirebaseMessaging.onBackgroundMessage(_handleBackgroundMessage);

  runApp(MyApp());
}
```

### Шаг 3: Обработка foreground и background

```dart
FirebaseMessaging.onMessage.listen((RemoteMessage message) {
  print('Foreground: ${message.data}');
});

Future<void> _handleBackgroundMessage(RemoteMessage message) async {
  print('Background: ${message.data}');
}
```

## 6. Особенности iOS Silent Push

На iOS для работы сигнальных push-уведомлений нужно:

1. Включить **Background Modes** → **Remote notifications**
2. Отправить push с заголовком `apns-push-type: background`
3. Использовать `content-available: 1` в payload

Пример payload для iOS:

```json
{
  "aps": {
    "content-available": 1
  },
  "custom_data": {
    "message": "Обновление данных"
  }
}
```

---

## 7. Особенности Android FCM Silent Push

На Android:

1. Установите `content_available: true`
2. Убедитесь, что приложение запущено (или может быть запущено через background service)

Пример payload для Android:

```json
{
  "to": "<device_token>",
  "content_available": true,
  "priority": "high",
  "data": {
    "message": "Сигнал"
  }
}
```
