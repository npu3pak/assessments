# Лекция: Загрузка файлов по сети

## Введение

В современных мобильных приложениях загрузка файлов по сети — одна из ключевых задач, особенно когда речь идёт о медиа-контенте, таких как изображения, видео или документы. В Flutter для этой задачи используются различные подходы и библиотеки. В данной лекции мы подробно рассмотрим:

1. **Загрузка изображений по сети**
2. **Кэширование загруженных изображений**
3. **Проблемы при загрузке документов по сети на iOS и Android**
4. **Сравнение плагинов для загрузки файлов по сети**

## 1. Загрузка изображений по сети

Загрузка изображений — одна из самых распространённых задач в мобильной разработке. В Flutter это делается с помощью `Image.network()` или более продвинутых решений, таких как пакет `cached_network_image`.

### Пример базовой загрузки изображения:

```dart
Image.network(
  'https://example.com/image.jpg',
  fit: BoxFit.cover,
)
```

Этот подход прост и удобен, но не обеспечивает кэширование, что может привести к повторной загрузке одного и того же изображения при каждом открытии экрана.

### Использование `cached_network_image`:

Пакет `cached_network_image` — это мощное решение для загрузки и кэширования изображений. Он автоматически обрабатывает кэширование, показывает placeholder'ы и поддерживает различные состояния загрузки.

#### Установка:
```yaml
dependencies:
  cached_network_image: ^3.2.3
```

#### Пример использования:

```dart
import 'package:cached_network_image/cached_network_image.dart';

CachedNetworkImage(
  imageUrl: "https://example.com/image.jpg",
  placeholder: (context, url) => CircularProgressIndicator(),
  errorWidget: (context, url, error) => Icon(Icons.error),
)
```

- `imageUrl` — URL изображения.
- `placeholder` — виджет, отображаемый во время загрузки.
- `errorWidget` — виджет при ошибке загрузки.

## 2. Кэширование загруженных изображений

Кэширование — ключевая часть эффективной работы с сетью. Оно позволяет избежать повторной загрузки одних и тех же данных, экономит трафик и улучшает пользовательский опыт.

### Почему кэширование важно?

- Уменьшает нагрузку на сервер.
- Снижает время отклика.
- Повышает производительность приложения.

### Как работает `cached_network_image`:

Пакет автоматически кэширует изображения в памяти и на диске. Для более точного контроля можно использовать `ImageCache`:

```dart
import 'package:flutter/painting.dart';

// Очистка кэша
ImageCache().clear();

// Установка размера кэша
ImageCache().maximumSize = 100;
```

### Вручную реализовать кэширование:

Можно создать свою систему кэширования с помощью `SharedPreferences` или `sqflite`, но это более сложная задача. Для большинства случаев рекомендуется использовать готовые решения.

## 3. Проблемы при загрузке документов по сети на iOS и Android

Загрузка файлов, отличных от изображений (например PDF, Word, Excel), требует особых подходов, особенно на разных платформах.

### Общие проблемы:

1. **Ограничения безопасности** — на iOS и Android существуют ограничения на доступ к файловой системе.
2. **Проблемы с SSL/TLS** — некоторые серверы могут использовать устаревшие или неподдерживаемые протоколы.
3. **Ошибки в заголовках запроса** — неправильно указанные заголовки могут привести к 403/401 ошибкам.
4. **Проблемы с размером файла** — большие файлы могут вызвать MemoryError или TimeOut.

### iOS:

- В `Info.plist` нужно добавить разрешение на загрузку файлов через HTTP (если используется HTTP):
```xml
<key>NSAppTransportSecurity</key>
<dict>
  <key>NSAllowsArbitraryLoads</key>
  <true/>
</dict>
```

### Android:

- В `AndroidManifest.xml` добавьте разрешение:
```xml
<uses-permission android:name="android.permission.INTERNET" />
```

Также нужно учитывать, что Android 9+ требует HTTPS.

## 4. Сравнение плагинов для загрузки файлов по сети

### Плагины:

#### 1. `http` (пакет `http`)
- Базовый HTTP-клиент.
- Подходит для простых задач, но не имеет встроенных возможностей кэширования или обработки ошибок.
- Используется в других библиотеках как основа.

Пример:

```dart
import 'package:http/http.dart' as http;

Future<Uint8List> downloadFile(String url) async {
  final response = await http.get(Uri.parse(url));
  return response.bodyBytes;
}
```

#### 2. `dio`
- Популярная и мощная библиотека для работы с сетью.
- Поддерживает интерцепторы, логирование, кэширование (через плагины).
- Подходит как для загрузки файлов, так и для работы с API.

Пример:

```dart
import 'package:dio/dio.dart';

final dio = Dio();
final response = await dio.get(
  'https://example.com/file.pdf',
  options: Options(responseType: ResponseType.bytes),
);
```

#### 3. `flutter_downloader`
- Плагин для загрузки файлов в фоне.
- Подходит для больших файлов, таких как PDF, видео и т.п.
- Поддерживает уведомления и отслеживание прогресса.

Пример:

```dart
import 'package:flutter_downloader/flutter_downloader.dart';

await FlutterDownloader.enqueue(
  url: 'https://example.com/document.pdf',
  headers: <String, String>{'auth': 'token'},
  fileName: 'document.pdf',
  saveInPublicStorage: true,
);
```

#### 4. `cached_network_image`
- Специализированный пакет для изображений.
- Используется для загрузки и кэширования изображений с поддержкой placeholder'ов, ошибок и прогресса.
