# Лекция: Flutter. Accessibility

---

## Введение в Accessibility

**Accessibility (доступность)** — это принцип разработки программного обеспечения, при котором приложения становятся удобными для использования всеми пользователями, включая людей с ограниченными возможностями (например, слабовидящих, глухих, с нарушениями моторики и т.п.).

В мире мобильной разработки **доступность** — это не просто "дополнительная функция", а важный элемент пользовательского опыта. В современных приложениях важно обеспечить:

- Правильную работу с экранами чтения (Screen Readers)
- Поддержку жестов и клавиатурных навигаций
- Удобство взаимодействия через голосовые команды и специальные устройства

Flutter — платформа, которая предоставляет богатый набор инструментов для создания доступных приложений. Она поддерживает все ключевые аспекты accessibility на уровне фреймворка.

---

## 1. Что нужно учитывать при разработке приложений для людей с ограниченными возможностями?

### 1.1. Визуальная доступность

Пользователи с нарушениями зрения могут использовать экраны чтения (например, VoiceOver на iOS или TalkBack на Android), которые читают вслух содержимое интерфейса.

#### Основные принципы:

- **Контрастность**: цвета должны быть достаточно контрастными для различения текста.
- **Размер шрифта**: шрифты должны быть достаточно крупными.
- **Повторяющиеся элементы**: навигация, кнопки и другие элементы должны быть легко распознаваемыми.

#### Пример: цвета с высоким контрастом

```dart
Text(
  'Привет, мир!',
  style: TextStyle(
    color: Colors.black, // Темный текст на светлом фоне
    fontSize: 18,
  ),
)
```

---

### 1.2. Адаптация к экранам чтения (Screen Readers)

Экраны чтения используют **элементы управления интерфейса** (UI elements) для воспроизведения информации на экране.

#### Что важно:

- Указывайте **вспомогательные текстовые метки** (`semanticsLabel`).
- Используйте **`AccessibilityLabel` и `AccessibilityHint`**.
- Не используйте визуальные элементы как единственный способ передачи информации.

---

### 1.3. Навигация с клавиатуры

Пользователи могут использовать клавиатуру для навигации по приложению. Важно:

- Убедиться, что все интерактивные элементы можно выбрать с клавиатуры.
- Использовать `FocusNode` для управления фокусом.

---

### 1.4. Поддержка голосовых команд

Flutter позволяет использовать **VoiceOver**, **TalkBack** и другие технологии, которые позволяют управлять приложением голосом. Это требует правильного использования семантики (semantics) в UI-компонентах.

---

## 2. Адаптирование приложения для использования со Screen Readers

### 2.1. Использование `Semantics` и `AccessibilityLabel`

Flutter предоставляет компонент `Semantics`, который позволяет добавлять семантическую информацию к элементам интерфейса.

#### Пример:

```dart
Semantics(
  label: 'Кнопка отправки формы',
  hint: 'Нажмите, чтобы отправить данные',
  child: ElevatedButton(
    onPressed: () {
      // логика
    },
    child: Text('Отправить'),
  ),
)
```

- `label` — это краткое описание элемента.
- `hint` — дополнительная информация о том, что делает элемент.

---

### 2.2. Использование `accessibleNavigation`

Flutter поддерживает автоматическую навигацию по элементам с помощью экранов чтения. Чтобы это работало:

- Все интерактивные элементы должны быть **объявлены как доступные**.
- Используйте `Focusable` и `FocusNode`.

#### Пример:

```dart
Focus(
  focusNode: FocusNode(),
  child: TextButton(
    onPressed: () {
      print('Кнопка нажата');
    },
    child: Text('Нажми меня'),
  ),
)
```

---

### 2.3. Объекты с `excludeSemantics` и `includeInSemantics`

Иногда нужно исключить элемент из семантики, например, если это вспомогательная иконка.

```dart
Semantics(
  excludeSemantics: true,
  child: Icon(Icons.star),
)
```

---

### 2.4. Использование `Tooltip` и `AccessibilityLabel`

Пользователи могут использовать **подсказки (tooltips)** для получения дополнительной информации:

```dart
Tooltip(
  message: 'Это кнопка отправки формы',
  child: ElevatedButton(
    onPressed: () {},
    child: Text('Отправить'),
  ),
)
```

---

### 2.5. Правильная структура элементов

Важно организовать элементы интерфейса в правильной логической последовательности, чтобы экран чтения читал их по порядку.

#### Используйте `Column`, `Row`, и т.п., чтобы правильно строить дерево семантики.

Пример:

```dart
Column(
  children: [
    Text('Заголовок'),
    Text('Подзаголовок'),
    ElevatedButton(
      onPressed: () {},
      child: Text('Кнопка'),
    ),
  ],
)
```

Элементы будут прочитаны по порядку, как в DOM-дереве.

## 3. Пример полного компонента с доступностью

```dart
class AccessibleButton extends StatelessWidget {
  final String label;
  final VoidCallback onPressed;

  const AccessibleButton({
    Key? key,
    required this.label,
    required this.onPressed,
  }) : super(key: key);

  @override
  Widget build(BuildContext context) {
    return Semantics(
      label: label,
      hint: 'Нажмите, чтобы выполнить действие',
      child: ElevatedButton(
        onPressed: onPressed,
        child: Text(label),
      ),
    );
  }
}
```

Создайте простое Flutter-приложение с несколькими элементами интерфейса:

1. **Заголовок**
2. **Текстовое поле с подсказкой**
3. **Кнопка отправки с описанием**
4. **Иконка с дополнительным текстом**

- Используйте `Semantics` с `label` и `hint`.

- Убедитесь, что элементы читаются по порядку.
