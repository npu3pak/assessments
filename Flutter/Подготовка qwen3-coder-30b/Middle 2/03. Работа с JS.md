# Лекция: Работа с JavaScript в Flutter через flutter_js

## Введение

В современном мире мобильной разработки часто возникает необходимость интеграции JavaScript-кода в приложения на Flutter. Это может быть связано с использованием сторонних библиотек, уже существующих JS-библиотек или специфических задач, которые проще реализовать на JavaScript. Для решения этой задачи в Flutter используется пакет `flutter_js`.

## 1. Пакет flutter_js

### Что такое flutter_js?

`flutter_js` — это Flutter пакет, который позволяет выполнять JavaScript-код прямо внутри Flutter-приложения. Он предоставляет возможность вызова JS-функций из Dart и наоборот, что делает возможным интеграцию JavaScript-логики в мобильные приложения.

### Зачем нужен flutter_js?

1. **Интеграция существующих JS-библиотек** — когда у вас есть готовая JS-библиотека, которую вы хотите использовать в Flutter.
2. **Сложные вычисления** — JavaScript может быть более эффективным для определённых задач (например, математические операции, парсинг данных).
3. **Работа с DOM или Web API** — если вам нужно взаимодействовать с веб-технологиями внутри мобильного приложения.
4. **Конвертация между языками** — например, преобразование данных из одного формата в другой.

### Установка flutter_js

Для начала работы с `flutter_js` необходимо добавить пакет в ваш проект:

```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_js: ^0.7.0 # актуальная версия на момент написания лекции
```

После этого выполните команду:

```bash
flutter pub get
```

> ⚠️ Обратите внимание, что `flutter_js` работает только на Android и iOS (в режиме WebView), так как он использует встроенный JavaScript-движок внутри нативных платформ.

## 2. Вызов функции JS из Dart

Для вызова JavaScript-функций из Dart мы используем метод `evaluate()` или `callMethod()`, а также можем передавать параметры и получать результаты.

### Простой пример вызова JS-функции

Сначала создадим простую JS-функцию, которую потом будем использовать в Dart:

```javascript
// В нашем JS-коде
function greet(name) {
  return "Hello, " + name;
}

function addNumbers(a, b) {
  return a + b;
}
```

Теперь попробуем вызвать эти функции из Dart:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_js/flutter_js.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final jsContext = await JsContext.create();

  // Вызываем JS-функцию greet()
  final result = await jsContext.evaluate('greet("Dart")');
  print(result); // Выведет: Hello, Dart

  // Вызываем JS-функцию addNumbers()
  final sum = await jsContext.evaluate('addNumbers(5, 3)');
  print(sum); // Выведет: 8
}
```

### Передача параметров в JS-функции

Параметры передаются через JS-код, и они могут быть любыми типами: строки, числа, массивы, объекты.

Пример:

```dart
// Dart
final jsContext = await JsContext.create();

String name = "Flutter";
int age = 25;

// Передаем параметры в JS-функцию
var result = await jsContext.evaluate(
  'sayHello("$name", $age)',
);
print(result); // Выведет: Hello, Flutter! You are 25 years old.
```

```javascript
// JS
function sayHello(name, age) {
  return `Hello, ${name}! You are ${age} years old.`;
}
```

### Работа с объектами

JS-объекты можно передавать и получать через Dart:

```dart
// Dart
final jsContext = await JsContext.create();

Map<String, dynamic> person = {
  'name': 'Alice',
  'age': 30,
};

// Передаем объект в JS
await jsContext.evaluate('processPerson(${jsonEncode(person)})');

// Получаем результат из JS
final result = await jsContext.evaluate('getProcessedData()');
print(result); // Результат, возвращенный JS-функцией
```

```javascript
// JS
function processPerson(person) {
  console.log("Processing person:", person);
  return person.name + " is " + person.age + " years old.";
}
```

## 3. Вызов функции Dart из JS

Одним из мощных преимуществ `flutter_js` является возможность вызывать Dart-функции из JavaScript.

### Регистрация Dart-функций в JS

Для этого нужно использовать метод `registerFunction()`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_js/flutter_js.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final jsContext = await JsContext.create();

  // Регистрируем Dart-функцию в JS-среде
  jsContext.registerFunction('dartAdd', (List<dynamic> args) {
    int a = args[0];
    int b = args[1];
    return a + b;
  });

  // Теперь можем вызвать эту функцию из JS
  final result = await jsContext.evaluate('dartAdd(10, 20)');
  print(result); // Выведет: 30
}
```

### Вызов Dart-функции с параметрами и возвратом

```dart
// Dart
jsContext.registerFunction('calculateArea', (List<dynamic> args) {
  double width = args[0];
  double height = args[1];
  return width * height;
});

// JS вызов:
final area = await jsContext.evaluate('calculateArea(5.5, 4.2)');
print(area); // Выведет: 23.1
```

### Вызов Dart-функции с объектами

```dart
// Dart
jsContext.registerFunction('processUserData', (List<dynamic> args) {
  Map<String, dynamic> userData = args[0];
  String name = userData['name'];
  int age = userData['age'];
  return "User: $name, Age: $age";
});

// JS вызов:
final result = await jsContext.evaluate('processUserData({name: "John", age: 28})');
print(result); // Выведет: User: John, Age: 28
```

## 4. Полный пример приложения

Вот полный пример Flutter-приложения, которое демонстрирует работу с `flutter_js`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_js/flutter_js.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'flutter_js Demo',
      home: HomeScreen(),
    );
  }
}

class HomeScreen extends StatefulWidget {
  @override
  _HomeScreenState createState() => _HomeScreenState();
}

class _HomeScreenState extends State<HomeScreen> {
  late JsContext jsContext;

  @override
  void initState() {
    super.initState();
    initJsContext();
  }

  Future<void> initJsContext() async {
    jsContext = await JsContext.create();

    // Регистрируем Dart-функцию
    jsContext.registerFunction('getGreeting', (List<dynamic> args) {
      return "Hello from Dart: ${args[0]}";
    });

    // Выполняем JS-код
    await jsContext.evaluate('''
      function sayHello(name) {
        return "Hello, " + name;
      }
      
      function add(a, b) {
        return a + b;
      }
    ''');
  }

  Future<void> callJsFunction() async {
    final result = await jsContext.evaluate('sayHello("Flutter")');
    print(result);
  }

  Future<void> callDartFunction() async {
    final result = await jsContext.evaluate('getGreeting("World")');
    print(result);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('flutter_js Example')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            ElevatedButton(
              onPressed: callJsFunction,
              child: Text("Call JS Function"),
            ),
            ElevatedButton(
              onPressed: callDartFunction,
              child: Text("Call Dart Function from JS"),
            ),
          ],
        ),
      ),
    );
  }
}
```
