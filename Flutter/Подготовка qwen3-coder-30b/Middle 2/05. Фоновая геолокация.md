# Лекция: Фоновая геолокация в Flutter

---

## Введение

В современных мобильных приложениях фоновая геолокация — это мощный инструмент, позволяющий отслеживать местоположение пользователя даже тогда, когда приложение не активно. Это особенно важно для таких приложений, как навигационные системы, сервисы доставки, фитнес-трекеры и другие, где точное местоположение критично.

Эта лекция охватывает:

- **Технологии фоновой геолокации**
- **Geofencing: описание, особенности и ограничения**
- **Запрос разрешений на iOS и Android**
- **Требования к публикации в App Store и Google Play**
- **Отслеживание значительных перемещений**

---

## 1. Технологии, использующие фоновую геолокацию

Фоновая геолокация позволяет приложениям получать информацию о местоположении пользователя даже в фоновом режиме. Она используется в следующих типах приложений:

### Примеры использования:
1. **Навигационные приложения** — отслеживание маршрута, реальное время до пункта назначения.
2. **Сервисы доставки** — отслеживание местоположения курьера в реальном времени.
3. **Фитнес-приложения** — запись тренировок и маршрутов.
4. **Уведомления по геолокации** — уведомления при входе/выходе из определённой зоны.
5. **Системы безопасности** — отслеживание пропажи устройства или уведомление о смене местоположения.

### Технологии:
- **Location Services (iOS)**
- **Google Play Services (Android)**
- **Flutter plugins:**
  - `geolocator` — для получения геолокации.
  - `geofencing` — для работы с geofences.
  - `background_location` — для фонового отслеживания.

## 2. Geofencing: описание технологии

### Что такое Geofencing?

**Geofencing** — это технология, которая создаёт виртуальные границы вокруг конкретных географических точек или регионов (геозоны). Когда пользователь приближается к или покидает эту зону, система уведомляет приложение.

### Принцип работы:

1. Приложение регистрирует **геозону** — например, радиус 100 метров вокруг магазина.
2. Операционная система отслеживает местоположение пользователя.
3. Когда пользователь **входит** или **выходит** из зоны, запускается событие (например, уведомление).
4. Это может происходить даже если приложение работает в фоновом режиме.

### Преимущества:

- Экономия ресурсов — не нужно постоянно отслеживать местоположение.
- Уведомления по геолокации.
- Подходит для уведомлений и событий на основе местоположения.

---

## 3. Geofencing: ограничения iOS и Android

### Ограничения Android:

1. **Частота обновления** — Android может не сообщать о событиях чаще, чем раз в 5-10 минут.
2. **Ограничение на количество geofences** — обычно 100 геозон на устройстве.
3. **Фоновая работа** — приложение должно быть запущено хотя бы один раз, чтобы зарегистрировать geofence.
4. **Battery optimization** — некоторые устройства могут ограничивать работу в фоне.

### Ограничения iOS:

1. **Максимальное количество геозон** — около 20 геозон.
2. **Точность** — точка центра зоны может быть смещена на несколько метров.
3. **Ограничения на фоновую работу** — iOS строго ограничивает фоновые задачи.
4. **Нет прямого API для отслеживания входа/выхода** — нужно использовать `CLLocationManager` и `CLRegion`.

## 4. Geofencing: запрос разрешений на iOS и Android

### Запрос разрешений на Android:

1. В файле `AndroidManifest.xml` необходимо добавить разрешения:
   ```xml
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
   <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
   ```

2. Для Android 6.0+ нужно запросить разрешения вручную:

```dart
import 'package:permission_handler/permission_handler.dart';

Future<void> requestLocationPermission() async {
  var status = await Permission.location.request();
  if (status == PermissionStatus.granted) {
    // Разрешение получено, можно использовать геолокацию
  }
}
```

### Запрос разрешений на iOS:

1. В `Info.plist` добавить:
   ```xml
   <key>NSLocationWhenInUseUsageDescription</key>
   <string>Нужно для отслеживания вашего местоположения</string>
   <key>NSLocationAlwaysAndWhenInUseUsageDescription</key>
   <string>Нужно для фонового отслеживания местоположения</string>
   ```

2. Запрос разрешений:
```dart
import 'package:permission_handler/permission_handler.dart';

Future<void> requestLocationPermission() async {
  var status = await Permission.locationWhenInUse.request();
  if (status == PermissionStatus.granted) {
    // Можно использовать геолокацию
  }
}
```

## 5. Требования к публикации в App Store и Google Play

### Google Play:

1. Добавить разрешение `ACCESS_FINE_LOCATION` и `ACCESS_BACKGROUND_LOCATION`.
2. В описании приложения указать, как используется фоновая геолокация.
3. Убедиться, что приложение не нарушает политику Google по использованию геолокации.

### App Store (iOS):

1. Указать в `Info.plist` строку `NSLocationAlwaysAndWhenInUseUsageDescription`.
2. Приложение должно объяснять, зачем нужно разрешение на фоновое местоположение.
3. Apple может отклонить приложение, если оно не предоставляет чёткое описание использования геолокации.

## 6. Отслеживание значительных перемещений пользователя

### Что такое "значительные перемещения"?

Это специальный режим отслеживания местоположения, при котором система уведомляет приложение только при **значительном изменении** местоположения (например, больше 100 метров).

### Важно:

- Не используется для точного отслеживания.
- Экономит батарею.
- Подходит для приложений, где важен лишь переход из одной области в другую.

### Пример с использованием `geolocator`:

```dart
import 'package:geolocator/geolocator.dart';

Future<void> startSignificantLocationUpdates() async {
  await Geolocator.startSignificantLocationChanges(
    (Position position) {
      print('Значительное перемещение: ${position.latitude}, ${position.longitude}');
    },
  );
}
```

- Использовать `geofencing` или `background_location`.
- Реализовать отображение уведомлений при входе/выходе.
