# **Лекция 15: Flutter. Canvas и CustomPainter**

## Введение

В рамках разработки мобильных приложений на Flutter, мы часто сталкиваемся с необходимостью отрисовки пользовательских элементов интерфейса, которые не могут быть реализованы с помощью стандартных виджетов Flutter. Для таких задач в Flutter предусмотрена система `Canvas` и класс `CustomPainter`. Эта система позволяет выполнять низкоуровневую графическую отрисовку на экране, используя методы рисования, такие как линии, круги, прямоугольники, текст и другие фигуры.

В этой лекции мы подробно рассмотрим:
- Что такое `Canvas` и зачем он нужен
- Как использовать `CustomPainter`
- Когда следует применять `Canvas` вместо обычных виджетов
- Какие виджеты используются в дереве виджетов для `CustomPainter`
- Примеры кода на Dart и Flutter

## 1. Что такое Canvas и зачем он нужен?

### Определение Canvas

`Canvas` — это низкоуровневый инструмент отрисовки, предоставляемый в Flutter. Он позволяет рисовать примитивы (линии, круги, прямоугольники), текст, изображения и даже сложные графические эффекты на экране.

В `Canvas` вы можете:
- Рисовать линии (`drawLine`)
- Рисовать фигуры (`drawRect`, `drawCircle`, `drawOval`)
- Рисовать текст (`drawText`)
- Использовать `Paint` для задания цвета, толщины, стиля и других атрибутов
- Применять матрицы трансформаций (`transform`)
- Работать с масками, градиентами, тенями и другими эффектами

### Когда использовать Canvas?

Canvas обычно применяется, когда:
- Требуется создать **кастомный элемент UI**, например, индикатор прогресса в виде круга или сложной анимации
- Нужно отрисовать **графики**, диаграммы, схемы
- Необходимо создать **анимированные компоненты** с непредсказуемыми формами
- Требуется высокая степень контроля над визуальным представлением

### Пример: простой круг с помощью Canvas

```dart
class CustomCirclePainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final Paint paint = Paint()
      ..color = Colors.blue
      ..style = PaintingStyle.fill;

    canvas.drawCircle(
      Offset(size.width / 2, size.height / 2),
      size.width / 2,
      paint,
    );
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}

// Использование в виджете
Container(
  width: 100,
  height: 100,
  child: CustomPaint(painter: CustomCirclePainter()),
)
```

В этом примере мы создали `CustomPainter`, который рисует синий круг по центру контейнера. Такой подход позволяет легко создавать сложные и уникальные элементы, не используя стандартные виджеты.

## 2. Дерево виджетов для использования CustomPainter

Чтобы использовать `CustomPainter`, нужно создать виджет `CustomPaint`, который будет содержать наш `CustomPainter`.

### Основной виджет: `CustomPaint`

`CustomPaint` — это виджет, который позволяет рисовать с помощью `CustomPainter`. Он принимает следующие параметры:

- `painter`: экземпляр класса `CustomPainter`, который отвечает за рисование
- `child`: дочерний виджет (может быть `null`), который будет отображаться поверх рисунка

### Пример: CustomPaint с дочерним элементом

```dart
class CustomCircleWithText extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Container(
      width: 150,
      height: 150,
      child: CustomPaint(
        painter: CustomCirclePainter(),
        child: Center(
          child: Text("Круг"),
        ),
      ),
    );
  }
}
```

В этом примере мы рисуем круг, а поверх него размещаем текст — таким образом, `CustomPaint` позволяет комбинировать рисование и стандартные виджеты.

### Структура виджетов при использовании CustomPainter

```
Container
└── CustomPaint
    ├── painter: CustomPainter (отвечает за отрисовку)
    └── child: Text("Круг") (внешний элемент, отображается поверх Canvas)
```

Таким образом, дерево виджетов включает:
1. `Container` — основной контейнер
2. `CustomPaint` — виджет для рисования
3. `CustomPainter` — логика рисования
4. `child` (опционально) — стандартный виджет, который может быть нарисован поверх

## 3. Какие методы Canvas предоставляет?

### Основные методы Canvas:

#### Рисование примитивов:
- `drawRect(Offset offset, Size size, Paint paint)` – рисует прямоугольник
- `drawCircle(Offset center, double radius, Paint paint)` – рисует круг
- `drawOval(Rect rect, Paint paint)` – рисует овал
- `drawLine(Offset start, Offset end, Paint paint)` – рисует линию

#### Работа с текстом:
- `drawText(TextSpan text, Offset position)` – рисует текст

#### Работа с изображениями:
- `drawImage(Image image, Offset position, Paint paint)` – рисует изображение

#### Трансформации:
- `transform(Matrix4 matrix)` – применяет матрицу трансформации

#### Пример: рисование нескольких фигур

```dart
class ShapePainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final Paint redPaint = Paint()..color = Colors.red;
    final Paint bluePaint = Paint()..color = Colors.blue;

    // Рисуем круг
    canvas.drawCircle(
      Offset(size.width / 2, size.height / 2),
      50,
      redPaint,
    );

    // Рисуем прямоугольник
    canvas.drawRect(
      Rect.fromLTWH(10, 10, 100, 50),
      bluePaint,
    );
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}
```

## 4. Когда использовать Canvas вместо стандартных виджетов?

### Виджеты vs Canvas:

| Применение | Стандартные виджеты | Canvas |
|------------|---------------------|--------|
| Простые элементы (кнопки, текст) | ✅ | ❌ |
| Кастомные формы (например, звездочка) | ❌ | ✅ |
| Сложные анимации | ❌ | ✅ |
| Графики и диаграммы | ❌ | ✅ |
| Нестандартный UI | ❌ | ✅ |

### Когда использовать Canvas:

- Когда стандартных виджетов не хватает для создания нужного эффекта
- Когда вы хотите создать **анимированный элемент**, например, индикатор прогресса или анимированный график
- Когда требуется точный контроль над отображением (например, сложные тени, градиенты)

## 5. Пример: Кастомный индикатор прогресса на основе Canvas

```dart
class CircularProgressPainter extends CustomPainter {
  final double progress;
  final Color color;

  CircularProgressPainter({required this.progress, required this.color});

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final radius = min(size.width, size.height) / 2 - 10;
    final paint = Paint()
      ..color = color
      ..strokeWidth = 10
      ..style = PaintingStyle.stroke
      ..strokeCap = StrokeCap.round;

    // Фон круга
    canvas.drawCircle(center, radius, paint..color = Colors.grey);

    // Прогресс
    final progressPaint = Paint()
      ..color = color
      ..strokeWidth = 10
      ..style = PaintingStyle.stroke
      ..strokeCap = StrokeCap.round;

    final sweepAngle = 2 * pi * progress;
    canvas.drawArc(
      Rect.fromCenter(center: center, width: radius * 2, height: radius * 2),
      -pi / 2,
      sweepAngle,
      false,
      progressPaint,
    );
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => true;
}
```

Этот пример показывает, как создать кастомный индикатор прогресса с помощью `Canvas`, который отображает дугу в зависимости от значения `progress`.
