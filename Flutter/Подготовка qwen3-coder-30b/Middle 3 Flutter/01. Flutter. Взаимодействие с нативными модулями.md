# Flutter. Взаимодействие с нативными модулями

Привет! Сегодня мы поговорим о **взаимодействии Flutter-приложения с нативными модулями** через механизм, называемый **Platform Channels**.

---

## 🎯 Цель лекции:
Понять, как Flutter может обмениваться данными с нативным кодом (Android и iOS) и научиться реализовывать такой обмен на практике.

---

## 🔧 Что такое Platform Channels?

**Platform Channels** — это механизм взаимодействия между Flutter-приложением и нативными платформами (Android и iOS). Он позволяет выполнять вызовы к коду, написанному на Kotlin или Swift, из Dart-кода.

### Как это работает:
1. **Flutter приложение** отправляет сообщение через **Platform Channel**.
2. **Нативный код** (на Android или iOS) получает это сообщение и выполняет нужную логику.
3. Результат передается обратно в Flutter-приложение.

---

## 🧱 Структура Platform Channels

Platform Channels используются для следующих видов взаимодействия:
- Вызов нативных функций из Dart
- Передача данных между Flutter и нативными частями
- Обработка событий, происходящих на уровне нативной платформы

---

## 🧩 Основные компоненты Platform Channels

Все взаимодействие строится вокруг:
1. **MethodChannel** — используется для вызова методов (функций)
2. **EventChannel** — используется для получения потока событий (например, изменения состояния)
3. **BasicMessageChannel** — используется для передачи произвольных сообщений

## 🛠 Пример реализации: MethodChannel

Представим, что нам нужно получить текущее местоположение устройства из нативного кода.

### 1️⃣ На стороне Flutter (Dart)

Создадим `MethodChannel`:

```dart
import 'package:flutter/services.dart';

class LocationService {
  static const MethodChannel _channel = MethodChannel('com.example.location');

  static Future<String> getCurrentLocation() async {
    try {
      final String result = await _channel.invokeMethod('getCurrentLocation');
      return result;
    } on PlatformException catch (e) {
      print("Ошибка: ${e.message}");
      rethrow;
    }
  }
}
```

### 2️⃣ На стороне Android (Kotlin)

Добавим в `MainActivity.kt`:

```kotlin
import io.flutter.embedding.android.FlutterActivity
import io.flutter.plugin.common.MethodChannel
import android.os.Bundle

class MainActivity: FlutterActivity() {
    private val CHANNEL = "com.example.location"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        MethodChannel(flutterEngine?.dartExecutor?.binaryMessenger!!, CHANNEL)
            .setMethodCallHandler { call, result ->
                if (call.method == "getCurrentLocation") {
                    // Здесь мы получаем текущее местоположение
                    val location = "Широта: 55.7512, Долгота: 37.6016"
                    result.success(location)
                } else {
                    result.notImplemented()
                }
            }
    }
}
```

## 📦 Как реализовать несколько каналов?

Можно создать несколько `MethodChannel` или использовать один и тот же канал с разными методами.

### Пример: два разных канала

```dart
// Канал для геолокации
static const MethodChannel _locationChannel = MethodChannel('com.example.location');

// Канал для камеры
static const MethodChannel _cameraChannel = MethodChannel('com.example.camera');
```

На стороне Android:

```kotlin
MethodChannel(flutterEngine?.dartExecutor?.binaryMessenger!!, "com.example.location")
    .setMethodCallHandler { call, result ->
        when (call.method) {
            "getCurrentLocation" -> {
                result.success("Широта: 55.7512")
            }
            else -> result.notImplemented()
        }
    }

MethodChannel(flutterEngine?.dartExecutor?.binaryMessenger!!, "com.example.camera")
    .setMethodCallHandler { call, result ->
        when (call.method) {
            "takePicture" -> {
                // Логика получения фото
                result.success("photo.jpg")
            }
            else -> result.notImplemented()
        }
    }
```

## 🧮 Поддерживаемые типы данных

Platform Channels поддерживают следующие типы данных:

| Тип Dart       | Соответствующий тип Android / iOS |
|----------------|----------------------------------|
| `String`       | `String`                         |
| `int`          | `int`                            |
| `double`       | `float` / `double`               |
| `bool`         | `boolean`                        |
| `List<dynamic>`| `ArrayList`                      |
| `Map<String, dynamic>` | `HashMap`                |
| `Uint8List`    | `byte[]`                         |
| `null`         | `null`                           |

> ⚠️ **Важно**: Все данные передаются в сериализованном виде. Напрямую передать объекты Dart нельзя.

## 📤 Передача результата через канал

Результат передается через callback-функцию `result.success()`.

Пример:

```dart
static Future<String> getCurrentLocation() async {
  try {
    final String result = await _channel.invokeMethod('getCurrentLocation');
    return result;
  } on PlatformException catch (e) {
    print("Ошибка: ${e.message}");
    rethrow;
  }
}
```

---

## ❗ Передача ошибок через канал

Ошибки можно передать с помощью метода `result.error()`:

```kotlin
MethodChannel(flutterEngine?.dartExecutor?.binaryMessenger!!, CHANNEL)
    .setMethodCallHandler { call, result ->
        if (call.method == "getCurrentLocation") {
            try {
                val location = getCurrentLocation()
                result.success(location)
            } catch (e: Exception) {
                result.error("ERROR", "Не удалось получить местоположение", e.message)
            }
        } else {
            result.notImplemented()
        }
    }
```

## 🧪 Пример: Полный код

### Dart:

```dart
import 'package:flutter/services.dart';

class NativeBridge {
  static const MethodChannel _channel = MethodChannel('com.example.native');

  static Future<String> getDeviceName() async {
    try {
      final String result = await _channel.invokeMethod('getDeviceName');
      return result;
    } on PlatformException catch (e) {
      print("Ошибка: ${e.message}");
      rethrow;
    }
  }

  static Future<String> makeToast(String message) async {
    try {
      final String result = await _channel.invokeMethod('makeToast', {'message': message});
      return result;
    } on PlatformException catch (e) {
      print("Ошибка: ${e.message}");
      rethrow;
    }
  }
}
```

### Android:

```kotlin
class MainActivity: FlutterActivity() {
    private val CHANNEL = "com.example.native"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        MethodChannel(flutterEngine?.dartExecutor?.binaryMessenger!!, CHANNEL)
            .setMethodCallHandler { call, result ->
                when (call.method) {
                    "getDeviceName" -> {
                        val name = Build.MODEL
                        result.success(name)
                    }
                    "makeToast" -> {
                        val message = call.argument<String>("message")
                        Toast.makeText(this, message, Toast.LENGTH_SHORT).show()
                        result.success("Toast shown")
                    }
                    else -> result.notImplemented()
                }
            }
    }
}
```
