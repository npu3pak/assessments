# Лекция: **Dart. Замыкания и вложенные функции**

---

## Введение

В этом уроке мы поговорим о двух важных концепциях в языке Dart — **замыкания (closures)** и **вложенных функциях (nested functions)**. Эти темы являются ключевыми для понимания современного программирования на Dart, особенно при разработке мобильных приложений с использованием Flutter.

---

## 1. Замыкания (Closures)

### Что такое замыкание?

**Замыкание** — это функция, которая имеет доступ к переменным из своей внешней области видимости даже после того, как внешняя функция завершена. В Dart любая функция может быть замыканием.

### Пример простого замыкания:

```dart
void main() {
  int outerVariable = 10;

  // Это замыкание имеет доступ к outerVariable
  var closure = () {
    print("outerVariable = $outerVariable");
  };

  // Вызов замыкания
  closure(); // Вывод: outerVariable = 10
}
```

Здесь `closure` — это функция, которая «запоминает» значение переменной `outerVariable`, даже если сама функция вызывается вне области видимости этой переменной.

### Замыкания в Flutter

Часто замыкания используются при работе с событиями, например, при нажатии кнопки:

```dart
class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    String message = "Привет";

    return ElevatedButton(
      onPressed: () {
        print(message); // Выведет "Привет"
      },
      child: Text("Нажми меня"),
    );
  }
}
```

Здесь анонимная функция, переданная в `onPressed`, является замыканием. Она имеет доступ к переменной `message` из области видимости метода `build`.

### Многократное использование замыканий

Можно создать функцию, которая возвращает замыкание:

```dart
Function(int) makeMultiplier(int multiplier) {
  return (int value) {
    return value * multiplier;
  };
}

void main() {
  var doubleIt = makeMultiplier(2);
  var tripleIt = makeMultiplier(3);

  print(doubleIt(5)); // 10
  print(tripleIt(4)); // 12
}
```

В этом примере `makeMultiplier` возвращает замыкание, которое запоминает значение `multiplier`.

### Замыкания и изменяемые переменные

Если вы изменяете переменную, к которой обращается замыкание, то замыкание будет использовать новое значение:

```dart
void main() {
  int counter = 0;

  var increment = () {
    counter++;
    print(counter);
  };

  increment(); // 1
  increment(); // 2
}
```

## 2. Вложенные функции (Nested Functions)

### Что такое вложенная функция?

**Вложенная функция** — это функция, определённая внутри другой функции. Она видна только внутри своей внешней функции.

### Пример:

```dart
void outerFunction() {
  print("Внешняя функция");

  void innerFunction() {
    print("Внутренняя функция");
  }

  innerFunction(); // Вызов вложенной функции
}

void main() {
  outerFunction(); // Вывод:
  // Внешняя функция
  // Внутренняя функция
}
```

### Вложенные функции и замыкания

Вложенные функции могут использовать переменные из внешней области видимости:

```dart
void processUser(String name) {
  String greeting = "Привет, $name";

  void printGreeting() {
    print(greeting); // Доступ к переменной из внешней функции
  }

  printGreeting();
}

void main() {
  processUser("Анна"); // Вывод: Привет, Анна
}
```

### Использование в Flutter

В Flutter вложенные функции часто используются для создания сложных логик внутри `build()` метода или обработчиков событий:

```dart
class CounterWidget extends StatefulWidget {
  @override
  _CounterWidgetState createState() => _CounterWidgetState();
}

class _CounterWidgetState extends State<CounterWidget> {
  int count = 0;

  void increment() {
    setState(() {
      count++;
    });
  }

  @override
  Widget build(BuildContext context) {
    // Вложенная функция для генерации кнопки
    Widget buildButton(String label, VoidCallback onPressed) {
      return ElevatedButton(
        onPressed: onPressed,
        child: Text(label),
      );
    }

    return Column(
      children: [
        Text("Счётчик: $count"),
        buildButton("Увеличить", increment),
      ],
    );
  }
}
```

Здесь `buildButton` — это вложенная функция, которая принимает параметры и возвращает виджет. Она имеет доступ к переменным `context`, `count`, и методу `setState`.

## 3. Использование typedef для описания типа замыканий

### Что такое typedef?

**`typedef`** — это способ создать псевдоним для типа данных. В случае с замыканиями он позволяет более читаемо описывать сигнатуры функций.

### Пример:

```dart
// Объявляем тип для функции, которая принимает int и возвращает String
typedef IntToString = String Function(int value);

// Используем typedef
void main() {
  IntToString converter = (int num) {
    return "Число: $num";
  };

  print(converter(42)); // Вывод: Число: 42
}
```

### Пример с замыканием и typedef

```dart
typedef Calculate = int Function(int a, int b);

Calculate add = (int x, int y) {
  return x + y;
};

Calculate multiply = (int x, int y) {
  return x * y;
};

void main() {
  print(add(3, 5));      // 8
  print(multiply(3, 5)); // 15
}
```

### typedef в Flutter

В Flutter `typedef` часто используется для описания типов callback-функций:

```dart
typedef OnPressedCallback = void Function();

class MyButton extends StatelessWidget {
  final OnPressedCallback? onPressed;

  MyButton({this.onPressed});

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: onPressed,
      child: Text("Нажми меня"),
    );
  }
}
```

Такой подход делает код более понятным, особенно если функция `onPressed` передаётся в несколько виджетов.

## Резюме

- **Замыкания** — это функции, которые имеют доступ к переменным из внешней области видимости.
- **Вложенные функции** — это функции, определённые внутри других функций. Они могут использовать переменные внешней функции.
- **typedef** позволяет создавать удобные псевдонимы для типов функций, особенно полезно при работе с callback'ами в Flutter.
