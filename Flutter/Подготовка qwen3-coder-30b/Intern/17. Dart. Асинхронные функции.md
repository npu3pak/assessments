# Лекция: Асинхронные функции в Dart (Dart Async Functions)

Привет, будущий Flutter-разработчик! Сегодня мы поговорим о **асинхронных функциях** в языке Dart — одном из ключевых понятий для разработки современных мобильных приложений. Мы рассмотрим такие темы, как:

1. `Future`, `async`/`await`
2. `Future.wait`
3. Класс `Completer`

Эти темы важны не только для понимания работы Dart, но и для того, чтобы эффективно работать с сетевыми запросами, базами данных, файловой системой и другими операциями, которые могут занять время.

---

## 1. Future, async/await

### Что такое Future?

В Dart `Future` — это объект, представляющий **асинхронную операцию**, которая может завершиться либо успешно (с результатом), либо с ошибкой.

Проще говоря, `Future` — это обещание, что значение будет доступно позже. Он используется, когда вы хотите выполнить какую-то задачу **асинхронно** — например, сделать HTTP-запрос или прочитать файл.

### Пример простого Future:

```dart
Future<String> fetchUserData() {
  return Future.delayed(Duration(seconds: 2), () {
    return "Пользователь загружен";
  });
}

void main() {
  print("Начинаем загрузку данных...");
  fetchUserData().then((value) {
    print(value); // Выведет через 2 секунды: "Пользователь загружен"
  });
}
```

Здесь мы создали `Future`, который возвращает строку через 2 секунды. Метод `.then()` вызывается, когда `Future` завершится успешно.

---

### async/await — синтаксический сахар для работы с Future

`async` и `await` — это удобный способ работы с `Future` без использования `.then()`. Они делают код более читаемым и похожим на синхронный.

#### Пример:

```dart
Future<String> fetchUserData() async {
  await Future.delayed(Duration(seconds: 2));
  return "Пользователь загружен";
}

void main() async {
  print("Начинаем загрузку данных...");
  String result = await fetchUserData();
  print(result); // Выведет через 2 секунды: "Пользователь загружен"
}
```

Обратите внимание:

- `async` указывается перед функцией, которая работает с `await`.
- `await` можно использовать только внутри функции, помеченной как `async`.
- `await` **приостанавливает выполнение** текущей функции до завершения `Future`.

---

### Обработка ошибок

Если Future завершится с ошибкой, вы можете её обработать через `.catchError()` или `try/catch`.

#### Пример:

```dart
Future<String> fetchUserData() async {
  await Future.delayed(Duration(seconds: 2));
  if (DateTime.now().second % 2 == 0) {
    throw Exception("Ошибка при загрузке данных");
  }
  return "Пользователь загружен";
}

void main() async {
  try {
    String result = await fetchUserData();
    print(result);
  } catch (e) {
    print("Произошла ошибка: $e");
  }
}
```

## 2. Future.wait

`Future.wait()` — это удобный способ дождаться завершения **нескольких Future** одновременно.

#### Пример:

```dart
Future<String> fetchUser() async {
  await Future.delayed(Duration(seconds: 1));
  return "Пользователь";
}

Future<String> fetchPosts() async {
  await Future.delayed(Duration(seconds: 2));
  return "Посты";
}

void main() async {
  List<Future<String>> futures = [fetchUser(), fetchPosts()];
  
  List<String> results = await Future.wait(futures);
  print(results); // ["Пользователь", "Посты"]
}
```

`Future.wait()` возвращает `List<T>` с результатами, когда все Future завершатся.

---

### Важно: Future.wait() — не возвращает ошибку при одной неудачной Future

Если один из Future завершится с ошибкой, `Future.wait()` также завершится с ошибкой. Чтобы избежать этого, используйте `Future.wait` с параметром `onError`.

#### Пример:

```dart
Future<String> fetchUser() async {
  await Future.delayed(Duration(seconds: 1));
  return "Пользователь";
}

Future<String> fetchPosts() async {
  await Future.delayed(Duration(seconds: 2));
  throw Exception("Ошибка при загрузке постов");
}

void main() async {
  List<Future<String>> futures = [fetchUser(), fetchPosts()];
  
  try {
    List<String> results = await Future.wait(futures);
    print(results);
  } catch (e) {
    print("Ошибка: $e");
  }
}
```

## 3. Класс Completer

`Completer` — это вспомогательный класс, который позволяет вручную управлять завершением `Future`.

### Зачем нужен Completer?

Иногда вы хотите создать `Future`, который будет завершён не автоматически (например, в результате HTTP-запроса), а вручную — когда вы сами решите, что он завершён.

#### Пример:

```dart
Future<String> fetchFromAPI() {
  Completer<String> completer = Completer<String>();

  // Имитируем асинхронную операцию (например, HTTP-запрос)
  Future.delayed(Duration(seconds: 2), () {
    completer.complete("Данные получены");
  });

  return completer.future;
}

void main() async {
  String result = await fetchFromAPI();
  print(result); // "Данные получены"
}
```

Здесь мы создаём `Completer`, и вручную вызываем `completer.complete()` после задержки.

---

### Completer с ошибкой

Также можно завершить Future с ошибкой:

```dart
Future<String> fetchFromAPI() {
  Completer<String> completer = Completer<String>();

  Future.delayed(Duration(seconds: 2), () {
    completer.completeError(Exception("Ошибка сети"));
  });

  return completer.future;
}
```

---

## Важные моменты

1. **async/await работает только внутри функций, помеченных как async**.
2. `Future` — это не магия, а способ работы с асинхронными задачами.
3. `Future.wait()` полезен, когда нужно дождаться нескольких операций.
4. `Completer` даёт больше контроля, но используется редко — обычно вы просто используете `async/await`.

## Практическое задание

### Задача: Симуляция загрузки данных из API

Напиши приложение на Flutter, которое:

1. Имитирует загрузку двух видов данных: пользователь и посты.
2. Используй `Future.delayed()` для имитации задержки (например, 1 секунда и 2 секунды).
3. Покажи в интерфейсе текст "Загружаем данные...".
4. После завершения всех Future — отобрази данные в списке.

Пример:

```dart
class DataLoadingScreen extends StatefulWidget {
  @override
  _DataLoadingScreenState createState() => _DataLoadingScreenState();
}

class _DataLoadingScreenState extends State<DataLoadingScreen> {
  List<String> data = [];

  Future<void> loadData() async {
    setState(() {
      data = [];
    });

    Future<String> fetchUser() async {
      await Future.delayed(Duration(seconds: 1));
      return "Пользователь: Иван";
    }

    Future<String> fetchPosts() async {
      await Future.delayed(Duration(seconds: 2));
      return "Посты: Привет, мир!";
    }

    List<String> results = await Future.wait([
      fetchUser(),
      fetchPosts()
    ]);

    setState(() {
      data = results;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("Загрузка данных")),
      body: Column(
        children: [
          ElevatedButton(
            onPressed: loadData,
            child: Text("Загрузить данные"),
          ),
          if (data.isNotEmpty)
            ...data.map((item) => Text(item)).toList(),
        ],
      ),
    );
  }
}
```
