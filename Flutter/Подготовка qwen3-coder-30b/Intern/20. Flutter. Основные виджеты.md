## Введение

Flutter — это мощная платформа для создания кроссплатформенных мобильных приложений с использованием языка Dart. В основе Flutter лежит архитектура, где всё представлено как виджеты (widgets). Виджеты — это элементы интерфейса, которые можно комбинировать друг с другом для создания сложных UI.

В этой лекции мы рассмотрим **основные виджеты Flutter**, которые необходимы для разработки приложений уровня Intern. Мы будем использовать примеры на Dart и Flutter, чтобы сделать материал максимально понятным и применимым.

## 1. Icon

**Icon** — это виджет, который отображает иконку из набора иконок Material Design или Cupertino.

### Основные параметры:
- `icon`: Иконка из `Icons` (например, `Icons.home`)
- `size`: Размер иконки
- `color`: Цвет иконки

### Пример:
```dart
Icon(
  Icons.home,
  size: 30.0,
  color: Colors.blue,
)
```

**Почему важно:** Используется для создания понятных интерфейсов, где иконки помогают пользователю быстро ориентироваться.

---

## 2. AppBar

**AppBar** — это стандартная панель заголовка в Flutter, которая обычно отображается сверху экрана.

### Основные параметры:
- `title`: Заголовок (обычно `Text`)
- `leading`: Левая иконка (например, меню)
- `actions`: Правые иконки (например, поисковая строка)

### Пример:
```dart
AppBar(
  title: Text("Мое приложение"),
  leading: IconButton(
    icon: Icon(Icons.menu),
    onPressed: () {},
  ),
  actions: [
    IconButton(icon: Icon(Icons.search), onPressed: () {}),
  ],
)
```

**Почему важно:** Виджет используется в большинстве приложений для создания стандартного интерфейса с заголовком.

---

## 3. Container

**Container** — универсальный виджет, который позволяет добавлять отступы, границы, цвета и другие свойства к другим виджетам.

### Основные параметры:
- `width`, `height`: Размер
- `color`: Цвет фона
- `margin`: Внешние отступы
- `padding`: Внутренние отступы
- `decoration`: Стили (например, фон, границы)

### Пример:
```dart
Container(
  width: 200,
  height: 100,
  color: Colors.blue,
  margin: EdgeInsets.all(10),
  padding: EdgeInsets.all(15),
  child: Text("Hello"),
)
```

**Почему важно:** Используется как основной элемент для оформления и стилизации других виджетов.

---

## 4. LayoutBuilder

**LayoutBuilder** — это виджет, который предоставляет информацию о размере родительского контейнера. Полезно для адаптивного дизайна.

### Пример:
```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth > 600) {
      return Text("Широкий экран");
    } else {
      return Text("Узкий экран");
    }
  },
)
```

**Почему важно:** Позволяет создавать адаптивный интерфейс, который меняется в зависимости от размера экрана.

---

## 5. Scaffold

**Scaffold** — это базовая структура экрана в Flutter. Он предоставляет стандартную архитектуру с AppBar, body и другими элементами.

### Основные параметры:
- `appBar`: Панель заголовка
- `body`: Основное содержимое экрана

### Пример:
```dart
Scaffold(
  appBar: AppBar(title: Text("Пример")),
  body: Center(child: Text("Текст в центре")),
)
```

**Почему важно:** Основной виджет для построения экранов в Flutter.

---

## 6. Text и кастомизация текста

**Text** — это простой виджет для отображения текста. Он поддерживает множество параметров для стилизации.

### Основные параметры:
- `data`: Текст
- `style`: Стиль (цвет, размер, шрифт)
- `textAlign`: Выравнивание
- `maxLines`: Максимальное количество строк

### Пример:
```dart
Text(
  "Привет мир!",
  style: TextStyle(
    fontSize: 20,
    color: Colors.red,
    fontWeight: FontWeight.bold,
  ),
  textAlign: TextAlign.center,
)
```

**Почему важно:** Всякий раз, когда нужно отобразить текст, используется `Text`.

---

## 7. Column и Row

**Column** и **Row** — это виджеты для вертикального и горизонтального расположения элементов.

### Column:
```dart
Column(
  children: [
    Text("Строка 1"),
    Text("Строка 2"),
  ],
)
```

### Row:
```dart
Row(
  children: [
    Icon(Icons.star),
    Text("Звезда"),
  ],
)
```

**Почему важно:** Основные элементы компоновки UI. Используются для создания макетов.

---

## 8. AspectRatio

**AspectRatio** — позволяет задать пропорции дочернего виджета (например, изображения).

### Пример:
```dart
AspectRatio(
  aspectRatio: 16 / 9,
  child: Container(color: Colors.blue),
)
```

**Почему важно:** Полезно при отображении изображений или других элементов с фиксированным соотношением сторон.

---

## 9. ConstrainedBox и UnconstrainedBox

**ConstrainedBox** ограничивает размер дочернего виджета, **UnconstrainedBox** позволяет ему занимать всё доступное пространство.

### Пример:
```dart
ConstrainedBox(
  constraints: BoxConstraints(maxWidth: 200),
  child: Container(color: Colors.red),
)
```

**Почему важно:** Используются для точного управления размерами элементов.

---

## 10. Expanded и Flex

**Expanded** позволяет виджету занимать всё доступное пространство в `Row` или `Column`.

### Пример:
```dart
Row(
  children: [
    Text("Левый"),
    Expanded(child: Container(color: Colors.blue)), // Занимает всё оставшееся место
    Text("Правый"),
  ],
)
```

**Почему важно:** Позволяет создавать гибкие и адаптивные интерфейсы.

---

## 11. FittedBox

**FittedBox** масштабирует дочерний виджет, чтобы он полностью заполнил доступное пространство.

### Пример:
```dart
FittedBox(
  child: Text("Текст"),
)
```

**Почему важно:** Полезно для адаптации текста или других элементов под размер контейнера.

---

## 12. Offstage

**Offstage** скрывает дочерний виджет, но не удаляет его из дерева виджетов.

### Пример:
```dart
Offstage(
  offstage: true,
  child: Text("Скрытый текст"),
)
```

**Почему важно:** Используется для временного скрытия элементов без полной перерисовки UI.

---

## 13. OverflowBox

**OverflowBox** позволяет дочернему виджету выходить за пределы своих ограничений.

### Пример:
```dart
OverflowBox(
  child: Container(width: 200, height: 100, color: Colors.blue),
)
```

**Почему важно:** Полезно для создания эффектов, где элемент может выходить за границы.

---

## 14. IntrinsicHeight и IntrinsicWidth

**IntrinsicHeight** делает дочерний виджет по высоте таким же, как самый высокий из его дочерних элементов.

**IntrinsicWidth** — то же самое для ширины.

### Пример:
```dart
IntrinsicHeight(
  child: Row(
    children: [
      Text("Короткий"),
      Text("Длинный текст"),
    ],
  ),
)
```

**Почему важно:** Полезно при необходимости выровнять элементы по высоте или ширине.

---

## 15. Opacity

**Opacity** делает дочерний виджет полупрозрачным.

### Пример:
```dart
Opacity(
  opacity: 0.5,
  child: Text("Полупрозрачный текст"),
)
```

**Почему важно:** Используется для создания анимаций или визуальных эффектов.

---

## 16. Transform

**Transform** позволяет применять трансформации к дочернему виджету (вращение, масштабирование и т.д.).

### Пример:
```dart
Transform.rotate(
  angle: 0.5,
  child: Text("Повёрнутый текст"),
)
```

**Почему важно:** Полезно для создания анимаций и сложных визуальных эффектов.

---

## 17. ClipRect

**ClipRect** обрезает дочерний виджет по прямоугольной области.

### Пример:
```dart
ClipRect(
  child: Container(width: 100, height: 100, color: Colors.red),
)
```

**Почему важно:** Позволяет создавать нестандартные формы и обрезку элементов.

---

## 18. ListView и GridView

**ListView** — вертикальный список элементов.

### Пример:
```dart
ListView(
  children: [
    ListTile(title: Text("Элемент 1")),
    ListTile(title: Text("Элемент 2")),
  ],
)
```

**GridView** — сетка элементов.

### Пример:
```dart
GridView.count(
  crossAxisCount: 2,
  children: [
    Container(color: Colors.red),
    Container(color: Colors.blue),
  ],
)
```

**Почему важно:** Основные виджеты для отображения списков и сеток.
