# Лекция 05: Принципы ООП в Flutter и Dart

## Введение

Объектно-ориентированное программирование (ООП) — это один из ключевых подходов к разработке программного обеспечения. В контексте Flutter и Dart, понимание принципов ООП позволяет создавать более структурированный, читаемый, поддерживаемый и масштабируемый код.

В этой лекции мы рассмотрим **четыре основных принципа ООП**:
1. Инкапсуляция
2. Наследование
3. Полиморфизм
4. Абстракция

Эти принципы помогут вам не только писать код, но и строить архитектуру приложений, которая будет легко масштабироваться и изменяться.

---

## 1. Инкапсуляция (Encapsulation)

### Что такое инкапсуляция?

**Инкапсуляция** — это механизм, который объединяет данные и методы, работающие с этими данными, в одном классе, а также скрывает внутренние детали реализации от внешнего мира. Это позволяет контролировать доступ к данным и предотвращает непреднамеренное изменение состояния объекта.

### Почему это важно?

Инкапсуляция обеспечивает:
- Защиту данных
- Контроль доступа к полям класса
- Повышение безопасности и надежности кода

### Пример на Dart

```dart
class Person {
  // Приватные поля (начинаются с нижнего подчеркивания)
  String _name;
  int _age;

  // Конструктор
  Person(this._name, this._age);

  // Публичные методы для получения данных (геттеры)
  String get name => _name;
  int get age => _age;

  // Публичные методы для изменения данных (сеттеры)
  set age(int value) {
    if (value >= 0) {
      _age = value;
    } else {
      throw ArgumentError("Возраст не может быть отрицательным");
    }
  }

  void introduce() {
    print("Привет, меня зовут $_name и мне $_age лет.");
  }
}

void main() {
  Person person = Person("Анна", 25);
  person.introduce(); // Привет, меня зовут Анна и мне 25 лет.

  person.age = 30; // Используем сеттер
  print(person.age); // 30

  // person._age = -1; // Ошибка компиляции — поле приватное
}
```

### Зачем использовать приватные поля?

- Предотвращают случайное изменение данных.
- Позволяют добавить логику проверки при установке значения (например, валидация).
- Упрощают рефакторинг: можно менять реализацию без изменения интерфейса.

## 2. Наследование (Inheritance)

### Что такое наследование?

**Наследование** — это механизм, позволяющий создавать новые классы на основе уже существующих. Новый класс (дочерний) получает все поля и методы родительского класса (базового), а также может добавлять свои собственные.

### Зачем нужно наследование?

- Повторное использование кода
- Упрощение поддержки и развития проекта
- Создание иерархии классов

### Пример на Dart

```dart
// Базовый класс
class Animal {
  String name;
  int age;

  Animal(this.name, this.age);

  void eat() {
    print("$name ест.");
  }

  void sleep() {
    print("$name спит.");
  }
}

// Дочерний класс
class Dog extends Animal {
  String breed;

  Dog(String name, int age, this.breed) : super(name, age);

  void bark() {
    print("$name лает: Гав-гав!");
  }

  // Переопределение метода
  @override
  void eat() {
    print("$name ест косточку.");
  }
}

void main() {
  Dog dog = Dog("Барбос", 3, "Дворняга");

  dog.eat(); // Барбос ест косточку.
  dog.sleep(); // Барбос спит.
  dog.bark(); // Барбос лает: Гав-гав!
}
```

### Важно:

- Ключевое слово `super` используется для вызова конструктора родителя или методов родителя.
- Методы можно переопределять с помощью `@override`.

## 3. Полиморфизм (Polymorphism)

### Что такое полиморфизм?

**Полиморфизм** — это способность объекта принимать множество форм. В ООП это означает, что один и тот же метод может вести себя по-разному в зависимости от типа объекта, к которому он применяется.

### Типы полиморфизма:

1. **Статический полиморфизм** — используется в случае перегрузки методов (в Dart это не поддерживается напрямую).
2. **Динамический полиморфизм** — реализуется через наследование и переопределение методов.

### Пример на Dart

```dart
class Shape {
  double area() {
    return 0;
  }

  void draw() {
    print("Рисую фигуру");
  }
}

class Rectangle extends Shape {
  double width;
  double height;

  Rectangle(this.width, this.height);

  @override
  double area() {
    return width * height;
  }

  @override
  void draw() {
    print("Рисую прямоугольник с площадью ${area()}");
  }
}

class Circle extends Shape {
  double radius;

  Circle(this.radius);

  @override
  double area() {
    return 3.14 * radius * radius;
  }

  @override
  void draw() {
    print("Рисую круг с площадью ${area()}");
  }
}

void main() {
  List<Shape> shapes = [
    Rectangle(5, 4),
    Circle(3),
    Rectangle(2, 6)
  ];

  for (var shape in shapes) {
    shape.draw(); // Разные действия в зависимости от типа объекта
  }

  // Вывод:
  // Рисую прямоугольник с площадью 20.0
  // Рисую круг с площадью 28.26
  // Рисую прямоугольник с площадью 12.0
}
```

### Почему полиморфизм полезен?

- Позволяет работать с объектами одинаковым образом, не зная их конкретного типа.
- Упрощает код и делает его более гибким.

## 4. Абстракция (Abstraction)

### Что такое абстракция?

**Абстракция** — это процесс выделения важных характеристик объекта, игнорируя ненужные детали. В программировании абстракция позволяет создавать обобщенные классы или интерфейсы, которые описывают поведение, но не реализуют его полностью.

### Абстрактные классы и методы

В Dart можно использовать **абстрактные классы** (`abstract class`) и **абстрактные методы** (методы без реализации). Они служат основой для наследования.

### Пример на Dart

```dart
// Абстрактный класс
abstract class Vehicle {
  String brand;

  Vehicle(this.brand);

  // Абстрактный метод — должен быть реализован в подклассах
  void start();

  // Обычный метод с реализацией
  void displayBrand() {
    print("Марка: $brand");
  }
}

class Car extends Vehicle {
  int doors;

  Car(String brand, this.doors) : super(brand);

  @override
  void start() {
    print("Машина $brand завелась!");
  }

  void honk() {
    print("Бип-бип!");
  }
}

class Motorcycle extends Vehicle {
  bool hasSidecar;

  Motorcycle(String brand, this.hasSidecar) : super(brand);

  @override
  void start() {
    print("Мотоцикл $brand завелся!");
  }

  void wheelie() {
    print("Мотоцикл делает велосипедную поездку!");
  }
}

void main() {
  Car car = Car("Toyota", 4);
  Motorcycle bike = Motorcycle("Harley", false);

  car.start(); // Машина Toyota завелась!
  bike.start(); // Мотоцикл Harley завелся!

  car.displayBrand(); // Марка: Toyota
  bike.displayBrand(); // Марка: Harley

  car.honk(); // Бип-бип!
  bike.wheelie(); // Мотоцикл делает велосипедную поездку!
}
```

### Зачем нужна абстракция?

- Скрывает сложность реализации
- Обеспечивает единообразие в интерфейсе
- Позволяет создавать иерархии классов с общими чертами

## Объединение всех принципов

Давайте соберем всё вместе в одном примере:

```dart
// Абстрактный класс
abstract class Device {
  String model;

  Device(this.model);

  void turnOn();
  void turnOff();

  void showInfo() {
    print("Устройство: $model");
  }
}

// Класс, наследующий от абстрактного
class Smartphone extends Device {
  int memoryGB;

  Smartphone(String model, this.memoryGB) : super(model);

  @override
  void turnOn() {
    print("$model включён.");
  }

  @override
  void turnOff() {
    print("$model выключен.");
  }
}

// Использование
void main() {
  Smartphone phone = Smartphone("iPhone 15", 256);
  phone.turnOn(); // iPhone 15 включён.
  phone.showInfo(); // Устройство: iPhone 15
}
```
