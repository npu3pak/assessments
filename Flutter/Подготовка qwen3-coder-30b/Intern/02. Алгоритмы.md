# Лекция 02: Алгоритмы

Привет, будущий Flutter-разработчик! Сегодня мы поговорим о **алгоритмах**, которые лежат в основе большинства программ и приложений, особенно в мобильной разработке. Умение понимать и применять алгоритмы — это один из ключевых навыков любого разработчика, особенно на уровне Intern.

## Что такое алгоритм?

Алгоритм — это **последовательность шагов**, выполнение которых позволяет решить определённую задачу. В программировании алгоритмы помогают нам эффективно обрабатывать данные, находить информацию, сортировать массивы и многое другое.

В мобильной разработке Flutter мы часто сталкиваемся с задачами, где важно не только написать правильный код, но и **выполнить его как можно быстрее**. Для этого используются оптимизированные алгоритмы, которые уменьшают количество операций и время выполнения.

## 1. Бинарный поиск (Binary Search)

### Что такое бинарный поиск?

Бинарный поиск — это эффективный алгоритм поиска элемента в **отсортированном массиве**. Он работает по принципу "разделяй и властвуй": на каждом шаге он сокращает область поиска вдвое, сравнивая искомый элемент с элементом в середине текущего диапазона.

### Почему это эффективно?

Бинарный поиск работает за **O(log n)** — то есть, если у нас массив из 1024 элементов, мы максимум за 10 сравнений найдем нужный элемент. Это намного быстрее линейного поиска, который может потребовать до n шагов.

### Пример на Dart

Давайте реализуем бинарный поиск в Dart:

```dart
int binarySearch(List<int> arr, int target) {
  int left = 0;
  int right = arr.length - 1;

  while (left <= right) {
    int mid = (left + right) ~/ 2; // Центральный индекс

    if (arr[mid] == target) {
      return mid; // Нашли элемент, возвращаем его индекс
    } else if (arr[mid] < target) {
      left = mid + 1; // Ищем в правой половине
    } else {
      right = mid - 1; // Ищем в левой половине
    }
  }

  return -1; // Не нашли элемент
}

void main() {
  List<int> sortedList = [1, 3, 5, 7, 9, 11, 13, 15];
  int target = 7;

  int result = binarySearch(sortedList, target);
  print('Индекс элемента $target: $result'); // Выведет: 3
}
```

### Когда использовать бинарный поиск?

- Массив **отсортирован**
- Нужно быстро найти конкретный элемент
- Примеры: поиск по телефонной книге, в базе данных, в списке товаров по цене и т.д.

## 2. Быстрая сортировка (Quick Sort)

### Что такое быстрая сортировка?

Быстрая сортировка — это **алгоритм сортировки**, который использует принцип "разделяй и властвуй". Он выбирает один элемент из массива (опорный элемент) и разделяет массив на две части: элементы меньше опорного и больше. Затем он рекурсивно применяет сортировку к обеим частям.

### Почему она так называется?

- **Быстрая**: в среднем работает за O(n log n)
- **Не требует дополнительной памяти** (in-place)
- **Хорошо подходит для больших массивов**

### Принцип работы

1. Выбрать опорный элемент (pivot)
2. Разделить массив на две части: элементы меньше и больше pivot
3. Рекурсивно применить быструю сортировку к обеим частям

### Пример на Dart

```dart
void quickSort(List<int> arr, int low, int high) {
  if (low < high) {
    int pi = partition(arr, low, high); // Индекс опорного элемента

    quickSort(arr, low, pi - 1); // Сортировка левой части
    quickSort(arr, pi + 1, high); // Сортировка правой части
  }
}

int partition(List<int> arr, int low, int high) {
  int pivot = arr[high]; // Опорный элемент — последний элемент
  int i = low - 1; // Индекс меньшего элемента

  for (int j = low; j < high; j++) {
    if (arr[j] < pivot) {
      i++;
      swap(arr, i, j);
    }
  }

  swap(arr, i + 1, high);
  return i + 1;
}

void swap(List<int> arr, int i, int j) {
  int temp = arr[i];
  arr[i] = arr[j];
  arr[j] = temp;
}

void main() {
  List<int> arr = [10, 80, 30, 90, 40, 50, 70];
  print('Исходный массив: $arr');

  quickSort(arr, 0, arr.length - 1);
  print('Отсортированный массив: $arr');
}
```

### Результат:

```
Исходный массив: [10, 80, 30, 90, 40, 50, 70]
Отсортированный массив: [10, 30, 40, 50, 70, 80, 90]
```

### Когда использовать быструю сортировку?

- Нужно отсортировать большой массив
- Оптимизация по памяти важна (in-place)
- Средний случай: O(n log n) — очень хорошая производительность
