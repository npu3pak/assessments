# Лекция: XML для Flutter разработчика (уровень Intern)

## Введение

XML (eXtensible Markup Language) — это язык разметки, который используется для хранения и передачи данных. Хотя в мире Flutter больше внимания уделяется Dart-коду, знание XML важно при работе с:

- **Flutter-приложениями**, где используются `.xml` файлы (например, ресурсы, локализация)
- **Android-зависимостями** — если вы работаете с Android Native API или Flutter-плагинами
- **Работой с данными из API и конфигурационными файлами**

Сегодня мы рассмотрим базовые концепции XML, необходимые для понимания работы Flutter-приложений.

---

## 1. Краткое описание назначения XML

**XML (eXtensible Markup Language)** — это язык разметки, предназначенный для хранения и передачи структурированных данных между приложениями или системами.

### Основные цели:
- **Хранение данных**: XML позволяет хранить данные в структурированном виде.
- **Передача данных**: Читаемость XML-документов делает его удобным для передачи между системами.
- **Интероперабельность**: XML поддерживается практически всеми языками программирования и платформами.

### Пример использования в Flutter:
XML может использоваться в файлах `strings.xml` (локализация), или в Android-проекте, если вы используете native-плагины.

```xml
<resources>
    <string name="app_name">MyApp</string>
</resources>
```

## 2. Doctype

**Doctype** — это объявление типа документа (Document Type Declaration), которое определяет, как должен быть интерпретирован XML-документ.

Оно указывается в начале документа и служит для описания структуры и правил, по которым должен быть построен документ.

### Синтаксис:
```xml
<!DOCTYPE root-element SYSTEM "dtd-file">
```

Или если DTD встроено:
```xml
<!DOCTYPE root-element [
    <!-- внутренние определения -->
]>
```

### Пример:

```xml
<!DOCTYPE note [
  <!ELEMENT note (to,from,heading,body)>
  <!ELEMENT to (#PCDATA)>
  <!ELEMENT from (#PCDATA)>
  <!ELEMENT heading (#PCDATA)>
  <!ELEMENT body (#PCDATA)>
]>
<note>
  <to>Tove</to>
  <from>Jani</from>
  <heading>Reminder</heading>
  <body>Don't forget me this weekend!</body>
</note>
```

**Важно**: В Flutter-приложениях `DOCTYPE` редко используется, но он может быть полезен при работе с внешними API или в Android-составляющих.

## 3. Кодирование запрещенных символов

XML имеет определённые запрещённые символы, которые нельзя использовать напрямую в тексте без кодирования:

| Символ | Код |
|--------|-----|
| `&`    | `&amp;` |
| `<`    | `&lt;` |
| `>`    | `&gt;` |
| `"`    | `&quot;` |
| `'`    | `&apos;` |

### Пример:

```xml
<description>He said &quot;Hello&quot;</description>
```

Если не закодировать символы, XML-документ будет некорректным.

---

## 4. Комментарии

Комментарии в XML используются для пояснений и не влияют на работу программы.

### Синтаксис:
```xml
<!-- Это комментарий -->
```

### Пример:

```xml
<root>
    <!-- Значение для пользователя -->
    <user>John</user>
    <!-- Не используется -->
    <!-- <admin>Admin</admin> -->
</root>
```

---

## 5. Теги

**Теги** — это основные элементы XML-документа, которые определяют структуру данных.

### Типы тегов:
- **Открывающий тег**: `<tagname>`
- **Закрывающий тег**: `</tagname>`
- **Самозакрывающийся тег**: `<tagname />`

### Пример:

```xml
<user>
    <name>John</name>
    <age>30</age>
    <active>true</active>
</user>
```

В Flutter можно использовать XML для работы с ресурсами, например в `pubspec.yaml` или в `AndroidManifest.xml`.

---

## 6. Атрибуты

**Атрибуты** — это дополнительные данные, которые прикрепляются к тегу.

### Синтаксис:
```xml
<tag attribute="value">Content</tag>
```

### Пример:

```xml
<user id="123" role="admin">John</user>
```

Здесь `id` и `role` — это атрибуты тега `user`.

### Важно:
- Атрибуты не могут быть вложенными.
- Значения атрибутов должны быть заключены в кавычки.

---

## 7. DOM (Document Object Model)

**DOM** — это представление XML-документа в виде дерева объектов, которое позволяет программно читать и изменять содержимое документа.

В Flutter вы не будете напрямую работать с DOM-деревом, но при использовании плагинов или взаимодействии с Android-кодом вам может понадобиться знать о нём.

### Пример (логический):

```xml
<books>
    <book id="1" author="Author1">
        <title>Book Title 1</title>
    </book>
    <book id="2" author="Author2">
        <title>Book Title 2</title>
    </book>
</books>
```

DOM представление будет:
- `books` — корневой элемент
- `book` — дочерние элементы
- `id`, `author` — атрибуты
- `title` — содержимое

## 8. Что такое валидатор

**Валидатор** — это программа, которая проверяет корректность XML-документа по определённым правилам (DTD или XSD).

### Для чего используется:
- Проверка синтаксиса
- Проверка структуры и типов данных
- Проверка соответствия схеме

### Пример:

Если вы используете XML для ресурсов в Android, то `lint` или IDE могут проверять корректность файла через валидатор.

---

## 9. Что такое парсер

**Парсер (XML-парсер)** — это программа или библиотека, которая разбирает XML-документ и создаёт его структуру в памяти (DOM или SAX).

### Типы парсеров:
1. **DOM Parser** — загружает весь документ в память как дерево объектов.
2. **SAX Parser** — читает документ последовательно, событие за событием.

### Пример (в Dart):

```dart
import 'dart:html';

void parseXml() {
  final xmlString = '''
    <user>
        <name>John</name>
        <age>30</age>
    </user>
  ''';

  final document = parse(xmlString);
  final name = document.querySelector('name')?.text;
  print(name); // John
}
```

> **Важно**: В Flutter для работы с XML в основном используется `xml` пакет, а не DOM-парсеры из браузера.

```xml

    </user>

    </user>
</users>
```

   - Считывает содержимое файла
   - Парсит XML
   - Выводит имя и роль каждого пользователя
