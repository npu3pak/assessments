# Лекция: Протокол HTTP

Привет! Сегодня мы поговорим о **протоколе HTTP (HyperText Transfer Protocol)** — основе взаимодействия между клиентом и сервером в интернете. Это знание жизненно важно для мобильных разработчиков, особенно тех, кто работает с Flutter, поскольку практически все приложения обмениваются данными с серверами через HTTP/HTTPS.

---

## 🧠 1. Что такое URL?

**URL (Uniform Resource Locator)** — это адрес ресурса в интернете. Он указывает, как получить конкретный ресурс: например, страницу сайта, изображение или API-эндпоинт.

### Пример:
```
https://api.example.com/users/123?format=json&include=profile
```

### Составные части URL:

| Часть        | Описание |
|--------------|----------|
| `https`      | Протокол (HTTP или HTTPS) |
| `api.example.com` | Доменное имя сервера |
| `/users/123`  | Путь к ресурсу на сервере |
| `?format=json&include=profile` | Параметры запроса (query parameters) |
| `#section-1`  | Фрагмент (часть страницы, например, якорь) |

### Пример в Dart / Flutter:

```dart
final url = Uri.parse('https://api.example.com/users/123?format=json&include=profile');
print(url.scheme); // https
print(url.host);   // api.example.com
print(url.path);   // /users/123
print(url.queryParameters['format']); // json
```

> ⚠️ В Flutter используй `Uri.parse()` для работы с URL.

---

## 🧠 2. Типы запросов (HTTP Methods)

В HTTP есть несколько **методов запроса**, каждый из которых имеет своё предназначение:

| Метод | Назначение |
|-------|------------|
| **GET** | Получение данных с сервера |
| **POST** | Отправка новых данных на сервер |
| **PUT** | Обновление существующего ресурса |
| **DELETE** | Удаление ресурса |
| **PATCH** | Частичное обновление ресурса |

### Примеры:

#### GET — получение данных:
```dart
final response = await http.get(
  Uri.parse('https://api.example.com/users/123'),
);
```

#### POST — создание нового пользователя:
```dart
final response = await http.post(
  Uri.parse('https://api.example.com/users'),
  body: {
    'name': 'Иван',
    'email': 'ivan@example.com'
  },
);
```

#### PUT — обновление пользователя:
```dart
final response = await http.put(
  Uri.parse('https://api.example.com/users/123'),
  body: {
    'name': 'Иван Петров',
  },
);
```

#### DELETE — удаление пользователя:
```dart
final response = await http.delete(Uri.parse('https://api.example.com/users/123'));
```

> ⚠️ В Flutter для работы с HTTP используется пакет `http`.

## 🧠 3. Что такое Headers?

**Headers (заголовки)** — это дополнительная информация, передаваемая в запросе или ответе. Они позволяют серверу понять, как обрабатывать запрос.

### Пример заголовков:

```dart
final headers = {
  'Content-Type': 'application/json',
  'Authorization': 'Bearer your_token_here',
  'Accept': 'application/json'
};
```

#### Использование в Flutter:

```dart
final response = await http.get(
  Uri.parse('https://api.example.com/users/123'),
  headers: {
    'Authorization': 'Bearer token123',
    'Accept': 'application/json'
  },
);
```

### Часто используемые заголовки:

| Заголовок | Назначение |
|-----------|------------|
| `Content-Type` | Тип данных, передаваемых в теле запроса (например, `application/json`) |
| `Authorization` | Для передачи токена аутентификации (например, `Bearer token`) |
| `Accept` | Ожидаемый тип ответа от сервера |
| `User-Agent` | Информация о клиенте (браузере или приложении) |

---

## 🧠 4. Что такое тело запроса?

**Тело запроса (Request Body)** — это данные, которые передаются на сервер в рамках POST, PUT и PATCH-запросов.

### Пример:

```dart
final response = await http.post(
  Uri.parse('https://api.example.com/users'),
  body: {
    'name': 'Иван',
    'email': 'ivan@example.com'
  },
);
```

> В Flutter при использовании `http` пакета, данные в виде `Map<String, String>` автоматически сериализуются в JSON.

Также можно передать JSON напрямую:

```dart
final response = await http.post(
  Uri.parse('https://api.example.com/users'),
  headers: {
    'Content-Type': 'application/json'
  },
  body: jsonEncode({
    'name': 'Иван',
    'email': 'ivan@example.com'
  }),
);
```

## 🧠 5. Типовые коды ответа (HTTP Status Codes)

Коды ответов сервера говорят, успешно ли выполнен запрос и какая ошибка произошла.

### Коды ответа:

| Код | Название         | Описание |
|-----|------------------|----------|
| `200` | OK               | Запрос успешный |
| `201` | Created          | Ресурс создан |
| `204` | No Content       | Запрос выполнен, но нет содержимого |
| `301` | Moved Permanently| Перенаправление на другой URL |
| `400` | Bad Request      | Ошибка в запросе |
| `401` | Unauthorized     | Необходима аутентификация |
| `404` | Not Found        | Ресурс не найден |
| `500` | Internal Server Error | Внутренняя ошибка сервера |

### Пример обработки ответов:

```dart
final response = await http.get(Uri.parse('https://api.example.com/users/123'));

if (response.statusCode == 200) {
  print('Данные получены успешно');
  final data = jsonDecode(response.body);
} else if (response.statusCode == 404) {
  print('Пользователь не найден');
} else if (response.statusCode == 401) {
  print('Необходима авторизация');
} else {
  print('Ошибка: ${response.statusCode}');
}
```

## 🧠 6. Резюме

Вот основные моменты, которые нужно знать:

- **URL** — адрес ресурса.
- **Методы HTTP**: GET, POST, PUT, DELETE и т.д.
- **Headers** — дополнительная информация в запросе.
- **Body** — данные, передаваемые в запросе (например, при создании пользователя).
- **Коды ответов** — помогают понять, успешно ли выполнен запрос.
