# Лекция: Растровая и векторная графика для Flutter разработчиков

## Введение

Прежде чем мы начнем разбирать тему растровой и векторной графики, важно понять, что такое **графика** в контексте мобильной разработки. Графика — это изображения, используемые в приложениях для отображения интерфейса, иконок, иллюстраций, анимаций и т.д.

В Flutter, как и в большинстве современных мобильных фреймворков, изображения играют ключевую роль в создании привлекательного пользовательского опыта. Однако не все изображения одинаково подходят для использования в мобильных приложениях. В этом разделе мы подробно рассмотрим разницу между растровой и векторной графикой, а также их применение в Flutter.

---

## 1. Отличие растровой и векторной графики

### 1.1 Растровая графика (Raster Graphics)

**Растровая графика** — это изображение, состоящее из пикселей (точек), расположенных в сетке. Каждый пиксель содержит информацию о цвете и прозрачности.

#### Примеры растровых форматов:
- **PNG**
- **JPG/JPEG**
- **BMP**
- **GIF**

#### Характеристики растровой графики:

- **Размер изображения фиксирован** — при увеличении изображение теряет четкость (появляются пиксели).
- **Занимает больше места на диске**, особенно при высоком разрешении.
- **Подходит для сложных изображений** с градиентами, фотографиями и т.д.

#### Как это выглядит в Flutter:

```dart
Image.asset('assets/images/photo.jpg');
```

Здесь мы подключаем растровое изображение (например, JPG или PNG). При увеличении масштаба оно может выглядеть размытым.

---

### 1.2 Векторная графика (Vector Graphics)

**Векторная графика** — это изображение, созданное с помощью математических формул и геометрических фигур (линии, кривые, фигуры). Эти элементы можно масштабировать без потери качества.

#### Примеры векторных форматов:
- **SVG** (Scalable Vector Graphics)
- **EPS**
- **AI** (Adobe Illustrator)

#### Характеристики векторной графики:

- **Масштабируется без потери качества** — можно увеличивать до бесконечности.
- **Занимает меньше места на диске**, особенно если изображение простое.
- **Подходит для иконок, логотипов, простых графических элементов.**

#### Как это выглядит в Flutter:

Flutter поддерживает векторные изображения через пакет `flutter_svg`.

```yaml
dependencies:
  flutter_svg: ^2.0.7
```

Пример использования SVG:

```dart
SvgPicture.asset('assets/icons/heart.svg');
```

---

### Сравнение растровой и векторной графики

| Критерий               | Растровая графика       | Векторная графика         |
|------------------------|-------------------------|----------------------------|
| Формат                 | PNG, JPG                | SVG                        |
| Масштабирование        | Потеря качества         | Без потери качества        |
| Размер файла           | Больше                    | Меньше                     |
| Сложность изображения  | Подходит для фото       | Подходит для иконок        |
| Применение             | Фотографии, сложные изображения | Иконки, логотипы, UI элементы |

## 2. Редактирование растровой и векторной графики

### 2.1 Редактирование растровой графики

Для редактирования растровых изображений используются программы:

- **Adobe Photoshop**
- **GIMP**
- **Paint.NET**

#### Что можно делать с растровой графикой:

- Изменять цвета
- Обрезать/маскировать
- Применять фильтры
- Редактировать пиксели

**Пример**: Если вы хотите создать иконку для приложения в Photoshop, вы можете рисовать пиксель за пикселем, работая с низкой детализацией.

---

### 2.2 Редактирование векторной графики

Для редактирования векторных изображений используются программы:

- **Adobe Illustrator**
- **Inkscape**
- **Figma**

#### Что можно делать с векторной графикой:

- Менять форму и размер фигур
- Изменять цвета
- Добавлять эффекты (тени, градиенты)
- Масштабировать без потери качества

**Пример**: Если вы создали SVG-иконку в Figma, вы можете легко изменить размер и цвет, и она всегда будет чёткой.

## 3. Преобразование SVG в PNG

Иногда требуется преобразовать векторную графику (SVG) в растровую (PNG), особенно если вы работаете с Flutter и используете изображения в `Image.asset` или `Image.network`.

### Почему это нужно?

- Некоторые устройства могут не поддерживать SVG напрямую.
- Для определённых форматов (например, иконки в разных размерах) лучше использовать PNG.

### Как преобразовать SVG в PNG:

#### Вариант 1: Использование онлайн-инструментов

1. Зайдите на сайт [https://svgtopng.com/](https://svgtopng.com/)
2. Загрузите SVG файл
3. Скачайте PNG

#### Вариант 2: Визуальный редактор (Figma, Illustrator)

1. Откройте SVG в Figma или Illustrator
2. Выберите «Export» → «PNG»

#### Вариант 3: Использование Flutter с пакетом `flutter_svg`

Если вы хотите использовать **SVG напрямую** в Flutter, без конвертации:

```dart
import 'package:flutter_svg/flutter_svg.dart';

class MyIconWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return SvgPicture.asset(
      'assets/icons/my_icon.svg',
      width: 50,
      height: 50,
    );
  }
}
```

Если же вы хотите **создать PNG** для конкретного размера:

1. Откройте SVG в редакторе
2. Экспортируйте как PNG с разрешением 2x или 3x (для высоких DPI экранов)
3. Используйте в Flutter:

```dart
Image.asset('assets/icons/my_icon_2x.png');
```

## Заключение

Понимание разницы между растровой и векторной графикой — ключ к созданию качественного интерфейса в Flutter-приложениях. Векторные изображения обеспечивают высокое качество при любом масштабе, а растровые — подходят для сложных сценариев, таких как фотографии.

Используйте правильный формат в зависимости от задачи: SVG для иконок и простых элементов, PNG для фото и сложных изображений. Это поможет вам создавать быстрые, качественные и адаптивные приложения.
