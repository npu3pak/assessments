# Лекция 04: Рекурсия

## Введение в рекурсию

**Рекурсия** — это мощный и важный концепт в программировании, который позволяет функции вызывать саму себя. Это может показаться абсурдным или сложным на первый взгляд, но на деле рекурсия — это очень логичный способ решения задач, особенно тех, которые имеют **самоподобную структуру** или **подзадачи**, похожие на исходную задачу.

### Что такое рекурсия?

В программировании рекурсия — это когда функция вызывает саму себя. При этом важно понимать, что такая функция должна иметь **базовый случай**, чтобы не зациклиться и не привести к ошибке переполнения стека (Stack Overflow).

### Почему используется рекурсия?

Рекурсия особенно полезна в следующих случаях:

- Когда задача может быть разделена на подзадачи, аналогичные исходной.
- Для обработки структур данных с вложенными элементами (например, деревья, графы).
- При решении математических задач, где формула определяется через себя.

## Принцип работы рекурсии

Представьте, что вы хотите подняться по лестнице, где на каждом шаге можно подняться на 1 или 2 ступени. Сколько способов есть подняться на n-ую ступень?

Эту задачу можно решить с помощью рекурсии:

```dart
int countWays(int n) {
  if (n == 0) return 1; // Базовый случай: один способ — не двигаться
  if (n < 0) return 0;  // Невозможно подняться на отрицательную ступень

  return countWays(n - 1) + countWays(n - 2); // Рекурсивный вызов
}
```

Вот как это работает:
- `countWays(3)` вызывает `countWays(2)` и `countWays(1)`
- Каждый из этих вызовов снова делит задачу на подзадачи, пока не дойдет до `countWays(0)` или `countWays(< 0)`

---

## Основные компоненты рекурсии

Чтобы функция работала корректно, она должна содержать:

1. **Базовый случай (Base Case)** — условие, при котором рекурсия завершается.
2. **Рекурсивный случай (Recursive Case)** — вызов функции самой себя с изменёнными параметрами.

### Пример: Вычисление факториала

Факториал числа `n` — это произведение всех целых чисел от 1 до n. Формула:

```
n! = n * (n - 1)!
```

Базовый случай: `0! = 1`.

Пример на Dart:

```dart
int factorial(int n) {
  if (n == 0 || n == 1) {
    return 1; // Базовый случай
  }
  return n * factorial(n - 1); // Рекурсивный вызов
}
```

Вызов `factorial(4)` будет выглядеть так:

```dart
factorial(4) = 4 * factorial(3)
             = 4 * 3 * factorial(2)
             = 4 * 3 * 2 * factorial(1)
             = 4 * 3 * 2 * 1
             = 24
```

## Сравнение рекурсивного и итеративного подхода

Рассмотрим задачу: вычислить сумму чисел от 1 до n.

### Итеративный способ (через цикл):

```dart
int sumIterative(int n) {
  int sum = 0;
  for (int i = 1; i <= n; i++) {
    sum += i;
  }
  return sum;
}
```

### Рекурсивный способ:

```dart
int sumRecursive(int n) {
  if (n == 0) return 0;
  return n + sumRecursive(n - 1);
}
```

Оба подхода дают одинаковый результат, но рекурсивный вариант:

- Проще читается и логичнее с математической точки зрения.
- Может быть менее эффективен по памяти (из-за вызовов функций).
- Удобно использовать при работе с деревьями или графами.

## Практический пример: Обход дерева в Flutter

Представим, что у нас есть дерево элементов, и мы хотим подсчитать общее количество элементов. Это отличный пример использования рекурсии.

### Структура дерева:

```dart
class TreeNode {
  int value;
  List<TreeNode> children;

  TreeNode(this.value, [this.children = const []]);
}
```

### Рекурсивная функция подсчета:

```dart
int countNodes(TreeNode node) {
  int count = 1; // Считаем текущий узел

  for (var child in node.children) {
    count += countNodes(child); // Рекурсивный вызов для каждого потомка
  }

  return count;
}
```

Пример использования:

```dart
void main() {
  var root = TreeNode(1, [
    TreeNode(2, [
      TreeNode(4),
      TreeNode(5),
    ]),
    TreeNode(3),
  ]);

  print(countNodes(root)); // Вывод: 5 (узлы 1, 2, 3, 4, 5)
}
```

## Ограничения рекурсии

- **Переполнение стека**: Если рекурсивная функция не достигает базового случая или вызывает себя слишком глубоко, может возникнуть ошибка `Stack Overflow`.
- **Потребление памяти**: Каждый вызов функции сохраняет состояние в стеке, что требует памяти.

### Пример плохой рекурсии:

```dart
int badRecursion(int n) {
  return badRecursion(n - 1); // Нет базового случая!
}
```

---

## Когда использовать рекурсию?

Рекурсия — не всегда лучший выбор, но она полезна, когда:

- Задача имеет **самоподобную структуру**.
- Сложно строить итеративное решение.
- Используется для обхода деревьев, графов, разбора выражений.

### Задача 1: Рекурсивный поиск максимального элемента в списке

Написать рекурсивную функцию `findMax(List<int> list)`, которая возвращает наибольший элемент в списке. Если список пустой, вернуть `null`.

**Пример:**
```dart
print(findMax([3, 5, 2, 8, 1])); // Вывод: 8
```

### Задача 2: Рекурсивная функция для проверки, является ли число простым

Написать рекурсивную функцию `isPrime(int n, int divisor)`, которая проверяет, является ли число `n` простым. Начальный вызов: `isPrime(17)`.

**Подсказка:** если `n` делится на `divisor`, то оно не простое. Если `divisor * divisor > n`, то `n` — простое.
