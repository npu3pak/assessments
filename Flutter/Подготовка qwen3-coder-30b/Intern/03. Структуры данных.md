## 1. Списки

### Что такое список?

**Список** — это упорядоченная коллекция элементов. В Dart это реализуется через класс `List`.

Списки в Dart могут быть:
- **Изменяемые** (`List<int> myNumbers = [1, 2, 3];`)
- **Неизменяемые** (`List<int> myNumbers = const [1, 2, 3];`)

### Примеры использования:

```dart
void main() {
  // Создание списка
  List<String> fruits = ['яблоко', 'банан', 'апельсин'];

  // Добавление элемента в конец
  fruits.add('груша');

  // Добавление по индексу
  fruits.insert(1, 'киви');

  print(fruits); // [яблоко, киви, банан, апельсин, груша]

  // Получение элемента по индексу
  print(fruits[0]); // яблоко

  // Изменение элемента
  fruits[0] = 'мандарин';
  print(fruits); // [мандарин, киви, банан, апельсин, груша]

  // Удаление по индексу
  fruits.removeAt(1);
  print(fruits); // [мандарин, банан, апельсин, груша]

  // Длина списка
  print(fruits.length); // 4

  // Итерация по списку
  for (String fruit in fruits) {
    print(fruit);
  }
}
```

### Полезные методы:
- `add(item)` — добавить элемент в конец  
- `insert(index, item)` — вставить элемент по индексу  
- `removeAt(index)` — удалить элемент по индексу  
- `indexOf(item)` — найти индекс элемента  
- `contains(item)` — проверяет, есть ли элемент  
- `length` — длина списка

## 2. Словари

### Что такое словарь?

**Словарь (Map)** — это коллекция пар "ключ-значение". В Dart используется класс `Map`.

Ключи должны быть уникальными, а значения могут повторяться.

### Пример:

```dart
void main() {
  Map<String, int> ages = {
    'Анна': 25,
    'Борис': 30,
    'Виктор': 28
  };

  // Добавление пары
  ages['Галина'] = 22;

  // Получение значения по ключу
  print(ages['Анна']); // 25

  // Обновление значения
  ages['Анна'] = 26;
  print(ages); // {Анна: 26, Борис: 30, Виктор: 28, Галина: 22}

  // Удаление пары
  ages.remove('Борис');
  print(ages); // {Анна: 26, Виктор: 28, Галина: 22}

  // Итерация по ключам и значениям
  for (String key in ages.keys) {
    print('$key: ${ages[key]}');
  }

  // Итерация по парам
  for (var entry in ages.entries) {
    print('${entry.key}: ${entry.value}');
  }
}
```

### Полезные методы:
- `putIfAbsent(key, value)` — добавить, если ключ отсутствует  
- `keys` и `values` — получить коллекции ключей/значений  
- `containsKey(key)` — проверка наличия ключа  
- `remove(key)` — удаление по ключу

## 3. Стек

### Что такое стек?

**Стек (Stack)** — это структура данных, работающая по принципу **LIFO (Last In, First Out)**: последний добавленный элемент будет первым извлечён.

В Dart можно использовать обычный `List` для реализации стека.

### Пример:

```dart
void main() {
  List<int> stack = [];

  // Добавление в стек (push)
  stack.add(10);
  stack.add(20);
  stack.add(30);

  print(stack); // [10, 20, 30]

  // Извлечение из стека (pop)
  int popped = stack.removeLast();
  print(popped); // 30
  print(stack); // [10, 20]

  // Просмотр последнего элемента (peek)
  if (stack.isNotEmpty) {
    print(stack.last); // 20
  }
}
```

### Зачем нужен стек?

- Для реализации функций обратного вызова  
- Для обработки выражений  
- В алгоритмах поиска в глубину (DFS)

## 4. Очередь

### Что такое очередь?

**Очередь (Queue)** — это структура данных, работающая по принципу **FIFO (First In, First Out)**: первый добавленный элемент будет первым извлечён.

В Dart есть специальный класс `Queue` в пакете `collection`.

### Пример:

```dart
import 'package:collection/collection.dart';

void main() {
  Queue<int> queue = Queue();

  // Добавление элемента (enqueue)
  queue.add(10);
  queue.add(20);
  queue.add(30);

  print(queue); // [10, 20, 30]

  // Извлечение элемента (dequeue)
  int removed = queue.removeFirst();
  print(removed); // 10
  print(queue); // [20, 30]

  // Просмотр первого элемента (peek)
  if (queue.isNotEmpty) {
    print(queue.first); // 20
  }
}
```

### Зачем нужна очередь?

- Для обработки задач в порядке их поступления  
- В алгоритмах поиска в ширину (BFS)  
- При реализации буферов

## 5. Дерево

### Что такое дерево?

**Дерево** — это иерархическая структура данных, состоящая из узлов. У каждого узла может быть ноль или более потомков.

Корневой узел — самый верхний узел дерева.

### Пример реализации простого дерева на Dart:

```dart
class TreeNode {
  int value;
  List<TreeNode> children;

  TreeNode(this.value, [this.children = const []]);

  void addChild(TreeNode child) {
    children.add(child);
  }

  @override
  String toString() {
    return 'TreeNode(value: $value, children: $children)';
  }
}

void main() {
  TreeNode root = TreeNode(1);
  TreeNode child1 = TreeNode(2);
  TreeNode child2 = TreeNode(3);

  root.addChild(child1);
  root.addChild(child2);

  print(root); // TreeNode(value: 1, children: [TreeNode(value: 2, children: []), TreeNode(value: 3, children: [])])
}
```

### Использование в Flutter?

В Flutter дерево используется при построении виджет-дерева (Widget Tree). Каждый виджет — узел дерева.

## 6. Бинарное дерево

### Что такое бинарное дерево?

**Бинарное дерево** — это структура данных, в которой каждый узел имеет **не более двух потомков**: левый и правый.

### Пример реализации:

```dart
class BinaryTreeNode {
  int value;
  BinaryTreeNode? left;
  BinaryTreeNode? right;

  BinaryTreeNode(this.value);

  void insert(int value) {
    if (value <= this.value) {
      if (left == null) {
        left = BinaryTreeNode(value);
      } else {
        left!.insert(value);
      }
    } else {
      if (right == null) {
        right = BinaryTreeNode(value);
      } else {
        right!.insert(value);
      }
    }
  }

  @override
  String toString() {
    return 'BinaryTreeNode(value: $value)';
  }
}

void main() {
  BinaryTreeNode root = BinaryTreeNode(10);

  root.insert(5);
  root.insert(15);
  root.insert(3);

  print(root); // BinaryTreeNode(value: 10)
  print(root.left); // BinaryTreeNode(value: 5)
  print(root.right); // BinaryTreeNode(value: 15)
}
```

### Зачем нужно бинарное дерево?

- Для хранения и поиска данных  
- В алгоритмах сортировки  
- В реализации кэширования (например, в деревьях поиска)
