# Лекция: JSON в Flutter для Intern-разработчика

## Введение

JSON (JavaScript Object Notation) — это легковесный формат обмена данными, который широко используется в мобильной разработке, особенно при взаимодействии с REST API. Он позволяет эффективно передавать структурированные данные между сервером и клиентом.

В Flutter JSON используется повсеместно: для получения данных из API, сохранения локальных данных, обмена информацией между компонентами и т.д. В этой лекции мы разберём основные аспекты работы с JSON в Flutter на примерах на языке Dart.

---

## 1. Краткое описание назначения JSON

### Что такое JSON?

JSON — это текстовый формат, используемый для передачи структурированных данных между клиентом и сервером. Он построен на парах "ключ-значение" и поддерживает вложенные структуры.

Пример:

```json
{
  "name": "Иван",
  "age": 30,
  "isStudent": false,
  "address": {
    "street": "Улица Пушкина",
    "city": "Москва"
  }
}
```

### Зачем нужен JSON в Flutter?

1. **Обмен данными с сервером** — при работе с REST API вы получаете данные в формате JSON.
2. **Хранение данных локально** — можно использовать JSON для сохранения состояния приложения.
3. **Конфигурационные файлы** — для настройки приложения.

### Как Flutter работает с JSON?

Dart предоставляет встроенные средства работы с JSON:
- `dart:convert` — модуль для парсинга и сериализации JSON.
- `json_annotation` + `json_serializable` — для автоматической генерации кода (предпочтительно для больших проектов).

## 2. Типы данных, доступные в JSON

В JSON поддерживаются следующие типы:

| Тип JSON   | Тип Dart       |
|------------|----------------|
| string     | `String`       |
| number     | `int`, `double` |
| boolean    | `bool`         |
| null       | `null`         |
| object     | `Map<String, dynamic>` |
| array      | `List<dynamic>` |

### Пример:

```dart
final json = '''
{
  "name": "Анна",
  "age": 25,
  "isStudent": true,
  "scores": [85, 90, 78],
  "address": {
    "street": "ул. Ленина",
    "city": "Санкт-Петербург"
  }
}
''';

final data = jsonDecode(json);

print(data['name']); // Анна
print(data['age']);   // 25
print(data['isStudent']); // true
print(data['scores'][0]); // 85
print(data['address']['city']); // Санкт-Петербург
```

### Обратите внимание:

Если вы не уверены в типе данных, используйте `dynamic` или `Map<String, dynamic>` для безопасной работы.

## 3. Как описать вложенные объекты

JSON может содержать вложенные структуры, такие как объекты внутри объектов или массивы объектов.

### Пример вложенного JSON:

```json
{
  "id": 1,
  "name": "Продукт",
  "details": {
    "price": 100.5,
    "currency": "RUB",
    "tags": ["новинка", "популярный"]
  },
  "reviews": [
    {
      "user": "Петр",
      "rating": 5
    },
    {
      "user": "Анна",
      "rating": 4
    }
  ]
}
```

### Как обработать такой JSON в Dart:

```dart
final json = '''
{
  "id": 1,
  "name": "Продукт",
  "details": {
    "price": 100.5,
    "currency": "RUB",
    "tags": ["новинка", "популярный"]
  },
  "reviews": [
    {"user": "Петр", "rating": 5},
    {"user": "Анна", "rating": 4}
  ]
}
''';

final data = jsonDecode(json);

int id = data['id'];
String name = data['name'];

// Вложенный объект
double price = data['details']['price'];
String currency = data['details']['currency'];
List<String> tags = List<String>.from(data['details']['tags']);

// Массив вложенных объектов
List<Map<String, dynamic>> reviews = List<Map<String, dynamic>>.from(data['reviews']);
print(reviews[0]['user']); // Петр
```

### Важно:
- Для массивов и вложенных объектов важно проверять наличие ключа и тип данных.
- Используйте `as` или `try-catch`, чтобы избежать ошибок при отсутствии данных.

## 4. Что такое JSON Schema?

**JSON Schema** — это документ, описывающий структуру JSON-данных. Он определяет, какие поля должны быть в объекте, их типы и обязательность.

Пример JSON Schema:

```json
{
  "type": "object",
  "properties": {
    "name": {"type": "string"},
    "age": {"type": "integer", "minimum": 0},
    "email": {"type": "string", "format": "email"}
  },
  "required": ["name", "email"]
}
```

### Зачем нужен JSON Schema?

- Проверка корректности данных.
- Автоматическое создание документации.
- Генерация кода на основе схемы (например, с помощью `json_serializable`).

### В Flutter:

Flutter не имеет встроенной поддержки JSON Schema, но можно использовать сторонние библиотеки:

- [json_schema](https://pub.dev/packages/json_schema) — для валидации данных.
- [json_annotation + json_serializable](https://pub.dev/packages/json_annotation) — генерация кода и типов на основе аннотаций.

## 5. Как использовать JSON с классами (сериализация)

### Простой способ — ручная работа:

```dart
class User {
  final String name;
  final int age;

  User({required this.name, required this.age});

  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      name: json['name'],
      age: json['age'],
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'name': name,
      'age': age,
    };
  }
}
```

### Использование:

```dart
final userJson = '{"name": "Анна", "age": 25}';
final user = User.fromJson(jsonDecode(userJson));

print(user.name); // Анна

final json = user.toJson();
print(json); // {"name": "Анна", "age": 25}
```
