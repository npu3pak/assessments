# Лекция 22: Flutter CLI

## Введение

Flutter CLI (Command Line Interface) — это мощный инструмент командной строки, предоставляемый фреймворком Flutter. Он позволяет разработчикам создавать, собирать, запускать и управлять проектами Flutter без использования графических интерфейсов.

## 1. Сборка приложения

### Что такое сборка?

Сборка (build) — это процесс преобразования исходного кода в исполняемый файл или пакет, который может быть установлен на устройство или запущен в эмуляторе.

### Команды сборки

#### flutter build
Команда `flutter build` используется для создания сборки приложения. Она поддерживает несколько целевых платформ:

```bash
# Сборка для Android (APK)
flutter build apk

# Сборка для Android (AAB - App Bundle)
flutter build appbundle

# Сборка для iOS
flutter build ios

# Сборка для web
flutter build web

# Сборка для macOS
flutter build macos

# Сборка для Windows
flutter build windows

# Сборка для Linux
flutter build linux
```

#### Параметры сборки

```bash
# Создание релизной сборки (оптимизированная версия)
flutter build apk --release

# Создание сборки с определенным профилем
flutter build ios --release --no-codesign

# Создание сборки с определенным архитектурным целевым устройством
flutter build apk --target-platform android-arm64

# Сборка с включенным tree shaking (удаление неиспользуемого кода)
flutter build web --release --dart-define=FLUTTER_WEB_USE_SKIA=true
```

### Пример: Полный процесс сборки Android приложения

```bash
# 1. Проверяем статус проекта
flutter doctor

# 2. Обновляем зависимости
flutter pub get

# 3. Создаем релизную сборку APK
flutter build apk --release

# 4. Результат будет находиться в:
# build/app/outputs/flutter-apk/app-release.apk
```

### Особенности сборки

1. **Debug vs Release**: Debug сборка содержит отладочную информацию и медленнее, Release сборка оптимизирована под производительность.
2. **Архитектуры**: Можно собирать для конкретных архитектур (ARM, x86).
3. **Конфигурации**: Flutter позволяет настраивать различные конфигурации сборки.

## 2. Запуск приложения

### Команда flutter run

Команда `flutter run` — это основной способ запуска приложения Flutter в режиме разработки. Она автоматически выполняет следующие действия:

1. Проверяет наличие подключенных устройств
2. Собирает проект
3. Устанавливает приложение на устройство/эмулятор
4. Запускает приложение с поддержкой hot reload

### Основные команды запуска

```bash
# Запуск на подключенном устройстве (если одно устройство)
flutter run

# Запуск на конкретном устройстве
flutter run -d <device_id>

# Запуск в режиме debug (по умолчанию)
flutter run --debug

# Запуск в режиме release
flutter run --release

# Запуск с определенным портом
flutter run --port=8080

# Запуск с отладкой
flutter run --verbose
```

### Управление устройствами

```bash
# Список подключенных устройств
flutter devices

# Выбор устройства для запуска
flutter run -d <device_name>

# Запуск на iOS simulator
flutter run -d "iPhone 14"

# Запуск на Android emulator
flutter run -d "Pixel 5"
```

### Пример: Запуск приложения с отладкой

```bash
# Проверяем подключенные устройства
flutter devices

# Запускаем приложение
flutter run

# В консоли увидим примерно:
# Launching lib/main.dart on iPhone 14 in debug mode...
# Running with unsafely-allowing platform code...
# lib/main.dart:1
# [INFO] Flutter DevTools connected to the VM service
```

### Режимы запуска

#### Debug режим
```bash
flutter run --debug
```
- Включает отладочную информацию
- Поддерживает hot reload
- Позволяет использовать отладчик

#### Release режим
```bash
flutter run --release
```
- Оптимизированная версия приложения
- Без отладочной информации
- Быстрее в работе

#### Profile режим
```bash
flutter run --profile
```
- Промежуточный режим между debug и release
- Используется для профилирования производительности

## 3. Подключение отладчика к приложению

### Что такое отладчик?

Отладчик — это инструмент, который позволяет анализировать выполнение программы в реальном времени, устанавливать точки останова, просматривать переменные и стек вызовов.

### Flutter DevTools

Flutter DevTools — это набор инструментов для отладки и профилирования приложений Flutter:

```bash
# Запуск DevTools
flutter pub global activate devtools
devtools

# Или запустить через Flutter CLI
flutter pub global run devtools
```

### Подключение к приложению

#### Способ 1: Через команду flutter run

При запуске приложения с `flutter run`, DevTools автоматически подключается:

```bash
flutter run
# В консоли будет строка:
# [INFO] Flutter DevTools connected to the VM service
```

#### Способ 2: Ручное подключение

```bash
# Запуск приложения с включенным отладочным сервером
flutter run --observatory-port=8080

# Затем открыть DevTools по адресу:
# http://localhost:8080
```

### Основные возможности DevTools

1. **Widget Inspector** - просмотр иерархии виджетов
2. **Performance** - анализ производительности
3. **Memory** - анализ использования памяти
4. **Logging** - просмотр логов приложения
5. **CPU Profiler** - профилирование CPU

### Пример: Работа с DevTools

```bash
# Запускаем приложение
flutter run

# Открываем DevTools в браузере по адресу:
# http://localhost:9100

# Используем инструменты:
# 1. Widget Inspector - для анализа UI
# 2. Performance - для проверки FPS
# 3. Memory - для анализа использования памяти
```

### Отладка с помощью breakpoints

```dart
// Пример кода с точкой останова
class MyHomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    int counter = 0; // Точка останова здесь
    
    return Scaffold(
      appBar: AppBar(title: Text('Debug Example')),
      body: Center(
        child: Text('Counter: $counter'),
      ),
    );
  }
}
```

## Практическое задание

### Задание 1: Полный цикл разработки

1. Создайте новый Flutter проект:
   ```bash
   flutter create debug_project
   cd debug_project
   ```

2. Запустите приложение на эмуляторе или устройстве:
   ```bash
   flutter run
   ```

3. Создайте релизную сборку для Android:
   ```bash
   flutter build apk --release
   ```

4. Откройте DevTools и подключитесь к запущенному приложению:
   ```bash
   flutter pub global run devtools
   ```

5. Проверьте все доступные инструменты DevTools на вашем приложении.

### Задание 2: Конфигурация сборки

1. Создайте несколько конфигураций сборки для разных целей:
   ```bash
   # Debug сборка
   flutter build apk
   
   # Release сборка
   flutter build apk --release
   
   # Сборка с определенной архитектурой
   flutter build apk --target-platform android-arm64
   ```

2. Проверьте результаты в папке `build/`.
