# Лекция: Flutter. Загрузка ресурсов из Assets

## Введение

В современной разработке мобильных приложений особое внимание уделяется качеству пользовательского интерфейса и визуальной составляющей. Flutter предоставляет мощные инструменты для работы с ресурсами, такими как изображения, шрифты и другие медиафайлы. В этой лекции мы рассмотрим, как правильно настраивать и использовать **Assets** (ресурсы) в Flutter-приложениях — особенно важный навык для разработчиков уровня **Junior 1**.

---

## Что такое Assets?

**Assets** — это внешние файлы, которые используются в приложении, например:
- Изображения (PNG, JPG, SVG и т.д.)
- Шрифты
- JSON-файлы, конфигурации и другие данные

Все эти файлы хранятся отдельно от основного кода и подключаются в проекте через специальный конфигурационный файл — `pubspec.yaml`.

---

## 1. Как описать Assets в pubspec.yaml

Файл `pubspec.yaml` — это конфигурационный файл Flutter-проекта, где указываются зависимости, метаданные, а также ресурсы проекта.

### Пример базового описания assets:

```yaml
flutter:
  assets:
    - assets/images/logo.png
    - assets/images/background.jpg
    - assets/fonts/custom_font.ttf
```

> **Важно:** Путь указывается относительно папки `lib`, а не корня проекта.

### Пример более сложной структуры:

```yaml
flutter:
  assets:
    - assets/images/
    - assets/icons/
    - assets/data/config.json
```

Здесь мы указываем целые папки, и все файлы внутри будут включены в сборку приложения.

> **Конвенция:** Используйте `/assets/` как основную папку для ресурсов.

### Особенности:
- Все пути должны быть **относительными**.
- Ресурсы добавляются в `pubspec.yaml`, после этого нужно выполнить команду `flutter pub get`.
- Изменения в `pubspec.yaml` требуют перезапуска приложения для отображения новых ресурсов.

## 2. Как показать растровое изображение из assets

Для отображения изображений из `assets` используется виджет **`Image.asset()`**.

### Пример базового использования:

```dart
import 'package:flutter/material.dart';

class MyHomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("Assets Example")),
      body: Center(
        child: Image.asset('assets/images/logo.png'),
      ),
    );
  }
}
```

### Пояснение:
- `Image.asset()` — загружает изображение по пути, указанному в `pubspec.yaml`.
- Важно, чтобы путь точно соответствовал пути в `pubspec.yaml`.
- Если файл не найден, приложение выдаст ошибку.

### Дополнительные параметры:

```dart
Image.asset(
  'assets/images/logo.png',
  width: 100,
  height: 100,
  fit: BoxFit.contain, // или BoxFit.cover и другие
)
```

#### Параметры:
- `width`, `height` — размер изображения.
- `fit` — как изображение должно заполнять доступное пространство:
  - `BoxFit.fill` — растягивает до заполнения.
  - `BoxFit.contain` — умещает в контейнер.
  - `BoxFit.cover` — заполняет полностью, обрезая края.

### Как проверить работу:
1. Убедитесь, что файл находится в нужной папке.
2. Проверьте, что путь указан правильно в `pubspec.yaml`.
3. Выполните команду `flutter pub get`.
4. Запустите приложение.

## 3. Как использовать шрифт из assets

Чтобы использовать шрифты из `assets`, нужно:
1. Добавить шрифт в `pubspec.yaml`.
2. Зарегистрировать его в `flutter` секции.
3. Использовать в коде.

### Пример добавления шрифта:

```yaml
flutter:
  fonts:
    - family: CustomFont
      fonts:
        - asset: assets/fonts/custom_font_regular.ttf
        - asset: assets/fonts/custom_font_bold.ttf
          weight: 700
```

> **family** — это имя, которое вы будете использовать в коде.

### Использование шрифта в тексте:

```dart
Text(
  'Hello World',
  style: TextStyle(
    fontFamily: 'CustomFont', // Имя из pubspec.yaml
    fontSize: 24,
  ),
)
```

> Важно: Имена шрифтов должны совпадать с теми, что указаны в `family`.

### Виджет для использования шрифта:

```dart
TextStyle(
  fontFamily: 'CustomFont',
  fontWeight: FontWeight.bold,
  fontSize: 18,
)
```

> Если вы используете шрифт из Google Fonts — их можно подключить с помощью пакета `google_fonts`.

## Важные моменты при работе с Assets

1. **Всегда указывайте ресурсы в `pubspec.yaml`** — иначе они не будут включены в сборку.
2. **Проверяйте пути** — опечатки в путях могут привести к ошибкам.
3. **Перезапуск приложения необходим после изменений в `pubspec.yaml`** — используйте `flutter pub get`.
4. **Используйте правильный формат изображений**:
   - Для иконок: PNG или SVG.
   - Для фонов: JPG или PNG.
5. **Для шрифтов рекомендуется использовать .ttf или .otf файлы.**

### Задача:

Создайте простое Flutter-приложение с двумя экранами:
1. Главный экран (HomeScreen) с:
   - Логотипом (из assets).
   - Текстом с использованием кастомного шрифта.
2. Экран с информацией (InfoScreen) с:
   - Изображением-фоном из assets.
   - Текстом с кастомным шрифтом.

### Шаги:
1. Создайте папку `assets` в корне проекта.
2. Поместите туда:
   - Логотип (`logo.png`)
   - Фон (`background.jpg`)
   - Шрифт (`custom_font.ttf`)
3. Обновите `pubspec.yaml`, добавив пути к этим файлам.
4. Реализуйте оба экрана с использованием `Image.asset()` и `TextStyle(fontFamily: 'CustomFont')`.
5. Добавьте кнопку на главном экране, которая переходит на InfoScreen.
