# Лекция: Хранение настроек пользователя в Flutter

---

## Введение

При разработке мобильных приложений важно уметь сохранять пользовательские настройки, чтобы обеспечить удобство и персонализацию. Настройки могут включать тему интерфейса (светлая/тёмная), язык приложения, включённые уведомления, предпочитаемый размер шрифта и многое другое.

Существует несколько способов хранения настроек пользователя в Flutter. В этой лекции мы рассмотрим:

- Встроенные механизмы хранения данных (SharedPreferences)
- Библиотеки для работы с настройками
- Как правильно организовать логику хранения и извлечения настроек

---

## 1. Способы хранения настроек пользователя

### 1.1. SharedPreferences — встроенный механизм

В Flutter, как и в Android, существует встроенный способ хранения простых данных — `SharedPreferences`. Это легковесное хранилище, которое сохраняет пары ключ-значение (ключ всегда строка, значение — примитивные типы: String, int, double, bool).

Преимущества:
- Простота использования
- Поддержка только простых типов данных
- Нет необходимости в сложной архитектуре

Недостатки:
- Не подходит для больших объемов данных
- Не поддерживает объекты (как классы)
- Не предназначено для хранения структурированных данных

### 1.2. Использование пакета `shared_preferences`

Для работы с `SharedPreferences` в Flutter используется библиотека [`shared_preferences`](https://pub.dev/packages/shared_preferences).

#### Установка:

```yaml
dependencies:
  shared_preferences: ^2.2.2
```

#### Пример использования:

```dart
import 'package:shared_preferences/shared_preferences.dart';

// Сохранение значения
Future<void> saveThemeMode(bool isDarkMode) async {
  final prefs = await SharedPreferences.getInstance();
  prefs.setBool('isDarkMode', isDarkMode);
}

// Чтение значения
Future<bool> getThemeMode() async {
  final prefs = await SharedPreferences.getInstance();
  return prefs.getBool('isDarkMode') ?? false;
}
```

#### Поддержка разных типов данных:

```dart
prefs.setString('username', 'JohnDoe');
prefs.setInt('age', 25);
prefs.setDouble('height', 175.5);
prefs.setBool('notificationsEnabled', true);

// Получение значений
String? username = prefs.getString('username');
int? age = prefs.getInt('age');
double? height = prefs.getDouble('height');
bool? notifications = prefs.getBool('notificationsEnabled');
```

#### Удаление настроек:

```dart
prefs.remove('username'); // удалить один ключ
prefs.clear(); // очистить все настройки
```

### 1.3. Библиотеки для более сложного хранения

Если вам нужно хранить больше данных или использовать структурированные объекты, можно воспользоваться другими библиотеками:

#### 1.3.1. Hive — легковесная NoSQL база данных

[Hive](https://pub.dev/packages/hive) — это быстрая и простая NoSQL база данных для Flutter.

##### Установка:

```yaml
dependencies:
  hive: ^2.2.3
  hive_flutter: ^1.1.0
```

##### Пример:

```dart
import 'package:hive_flutter/hive_flutter.dart';

// Инициализация Hive
await Hive.initFlutter();
await Hive.openBox('settingsBox');

// Сохранение настроек
Box settings = Hive.box('settingsBox');
settings.put('theme', 'dark');
settings.put('language', 'ru');

// Чтение
String theme = settings.get('theme') ?? 'light';
```

#### 1.3.2. Riverpod / Provider — для управления состоянием и настройками

Для более сложной архитектуры можно использовать `Riverpod` или `Provider` для хранения и управления состоянием настроек в виде объектов.

---

### 1.4. Сравнение способов хранения

| Способ | Тип данных | Простота использования | Подходит для | Недостатки |
|--------|------------|-------------------------|--------------|-------------|
| SharedPreferences | Примитивы | ⭐⭐⭐⭐⭐ | Маленькие данные | Не поддерживает объекты |
| Hive | Объекты, примитивы | ⭐⭐⭐⭐ | Средние данные | Требует настройки |
| Provider/Riverpod | Объекты | ⭐⭐⭐⭐ | Сложные данные | Требуют дополнительного кода |

## 2. Какие библиотеки или встроенные механизмы можно использовать?

### 2.1. Встроенный механизм — SharedPreferences

Как уже упоминалось, это стандартный способ хранения простых данных в Flutter.

#### Пример: сохранение темы приложения

```dart
import 'package:flutter/material.dart';
import 'package:shared_preferences/shared_preferences.dart';

class ThemeManager {
  static const String _themeKey = 'isDarkMode';

  static Future<void> saveTheme(bool isDark) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_themeKey, isDark);
  }

  static Future<bool> loadTheme() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(_themeKey) ?? false;
  }
}
```

#### Использование:

```dart
bool isDarkMode = await ThemeManager.loadTheme();

MaterialApp(
  theme: ThemeData.light(),
  darkTheme: ThemeData.dark(),
  themeMode: isDarkMode ? ThemeMode.dark : ThemeMode.light,
);
```

---

### 2.2. Библиотека Hive

Hive подходит, когда нужно хранить больше информации или структурированные данные (например, классы).

#### Пример:

```dart
import 'package:hive_flutter/hive_flutter.dart';

part 'user_settings.g.dart';

@HiveType(typeId: 0)
class UserSettings {
  @HiveField(0)
  String username;

  @HiveField(1)
  bool notificationsEnabled;

  UserSettings({
    required this.username,
    required this.notificationsEnabled,
  });
}
```

```dart
// Открытие Hive
await Hive.initFlutter();
Hive.registerAdapter(UserSettingsAdapter());
await Hive.openBox<UserSettings>('settings');

// Сохранение
final settings = UserSettings(
  username: 'John',
  notificationsEnabled: true,
);
Hive.box<UserSettings>('settings').put('user', settings);

// Чтение
UserSettings? user = Hive.box<UserSettings>('settings').get('user');
```

## 3. Практическое применение: управление настройками темы

Рассмотрим полноценный пример управления темой приложения с сохранением в `SharedPreferences`.

```dart
import 'package:flutter/material.dart';
import 'package:shared_preferences/shared_preferences.dart';

class SettingsManager {
  static const String _themeKey = 'isDarkMode';
  static const String _languageKey = 'language';

  static Future<void> saveTheme(bool isDark) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_themeKey, isDark);
  }

  static Future<bool> loadTheme() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(_themeKey) ?? false;
  }

  static Future<void> saveLanguage(String language) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_languageKey, language);
  }

  static Future<String> loadLanguage() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(_languageKey) ?? 'en';
  }
}

class MyApp extends StatefulWidget {
  @override
  _MyAppState createState() => _MyAppState();
}

class _MyAppState extends State<MyApp> {
  bool isDarkMode = false;
  String language = 'en';

  @override
  void initState() {
    super.initState();
    _loadSettings();
  }

  _loadSettings() async {
    setState(() {
      isDarkMode = await SettingsManager.loadTheme();
      language = await SettingsManager.loadLanguage();
    });
  }

  _toggleTheme() async {
    setState(() {
      isDarkMode = !isDarkMode;
    });
    await SettingsManager.saveTheme(isDarkMode);
  }

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Settings Demo',
      theme: ThemeData.light(),
      darkTheme: ThemeData.dark(),
      themeMode: isDarkMode ? ThemeMode.dark : ThemeMode.light,
      home: Scaffold(
        appBar: AppBar(title: Text('Settings Demo')),
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              SwitchListTile(
                title: Text('Dark Mode'),
                value: isDarkMode,
                onChanged: (value) => _toggleTheme(),
              ),
              Text('Current language: $language'),
            ],
          ),
        ),
      ),
    );
  }
}
```
