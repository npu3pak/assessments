# Лекция: Чистые функции

## Введение

Привет, будущий Flutter-разработчик! Сегодня мы поговорим о **чистых функциях** — одной из ключевых концепций в программировании, особенно важной при разработке масштабируемых и надежных приложений. Это понятие не зависит от конкретного языка, но мы будем использовать примеры на Dart и Flutter для лучшего понимания.

---

## 1. Что такое чистая функция?

**Чистая функция** — это функция, которая обладает следующими свойствами:

### ✅ Свойства чистой функции:

1. **Одинаковый вход → одинаковый выход (Предсказуемость)**  
   При одном и том же наборе входных параметров чистая функция всегда возвращает один и тот же результат.

2. **Нет побочных эффектов**  
   Функция не изменяет внешнее состояние программы (например, не модифицирует глобальные переменные, не записывает в файлы, не отправляет запросы в сеть и т.п.).

### ❌ Примеры «грязных» функций:

```dart
int counter = 0;

int increment() {
  counter++; // Побочный эффект: изменяет глобальную переменную
  return counter;
}
```

Эта функция **не является чистой**, потому что:
- Она изменяет состояние вне своей области видимости (`counter++`)
- Результат зависит от внешнего состояния

---

## 2. Почему важно использовать чистые функции?

### 🧠 Предсказуемость

Чистые функции легко тестируются, отлаживаются и повторно используются. Если вы знаете входные данные — вы точно знаете, какой результат получите.

### 🔍 Легко тестировать

Вот простой пример:

```dart
int add(int a, int b) {
  return a + b;
}

void main() {
  print(add(2, 3)); // Всегда будет 5
}
```

Эту функцию легко протестировать в юнит-тестах:

```dart
import 'package:test/test.dart';

void main() {
  test('add function works correctly', () {
    expect(add(2, 3), equals(5));
    expect(add(-1, 1), equals(0));
  });
}
```

### 🧩 Легче читать и поддерживать

Если функция не изменяет состояние, вы можете быть уверены, что она не ломает другие части программы.

## 3. Примеры чистых и грязных функций на Dart

### ✅ Чистая функция

```dart
int multiply(int a, int b) {
  return a * b;
}
```

Эта функция:
- Принимает два аргумента
- Не меняет внешние переменные
- Возвращает один и тот же результат при одинаковых входах

### ❌ Грязная функция

```dart
int total = 0;

int addToTotal(int value) {
  total += value; // Побочный эффект: изменяет глобальную переменную
  return total;
}
```

Тут:
- Результат зависит от состояния `total`
- Функция изменяет внешнее состояние

## 4. Чистые функции в Flutter

Представим, что вы создаете экран с отображением счетчика:

```dart
class CounterScreen extends StatelessWidget {
  final int count;

  const CounterScreen({Key? key, required this.count}) : super(key: key);

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Counter')),
      body: Center(
        child: Text('$count'),
      ),
    );
  }
}
```

В этом случае функция `build` — **чистая**, потому что:
- Она зависит только от входных параметров (`context`, `count`)
- Не изменяет внешнее состояние
- Возвращает один и тот же виджет при одних и тех же входных данных

---

## 5. Когда чистые функции не всегда возможны?

Но в реальных Flutter-приложениях мы часто сталкиваемся с ситуациями, где **побочные эффекты** необходимы:

### Пример: обновление состояния

```dart
class CounterPage extends StatefulWidget {
  @override
  _CounterPageState createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int counter = 0;

  void increment() {
    setState(() {
      counter++; // setState — это побочный эффект
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Text('$counter'),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: increment,
        child: Icon(Icons.add),
      ),
    );
  }
}
```

Здесь `increment()` — **грязная функция**, потому что она вызывает `setState`, что изменяет состояние приложения.

### 💡 Но это нормально!

В Flutter мы используем **чистые функции** в бизнес-логике, а **побочные эффекты** обрабатываем через:
- `setState`
- `Bloc` / `Riverpod`
- `Provider`

Таким образом, **логика приложения** (например, расчеты) остаётся чистой, а **изменение UI** — это отдельная задача.

## 6. Как использовать чистые функции в Flutter?

### ✅ Пример: вычисление процента

```dart
double calculatePercentage(double value, double total) {
  if (total == 0) return 0;
  return (value / total) * 100;
}
```

Функция:
- Не изменяет ничего вне себя
- Всегда возвращает один и тот же результат при одних и тех же аргументах
- Легко тестируется

### ✅ Пример: фильтрация списка

```dart
List<String> filterValidNames(List<String> names) {
  return names.where((name) => name.isNotEmpty).toList();
}
```

Функция:
- Не изменяет исходный список
- Возвращает новый отфильтрованный список

## 7. Преимущества чистых функций в разработке Flutter

| Преимущество | Описание |
|--------------|----------|
| **Простота тестирования** | Вы можете легко написать юнит-тест, не беспокоясь о внешнем состоянии |
| **Предсказуемость** | Код ведет себя одинаково в любых условиях |
| **Легко отлаживать** | Если функция возвращает неправильный результат — проблема в её логике, а не в состоянии программы |
| **Повторное использование** | Функции можно использовать в разных частях приложения без побочных эффектов |

## 8. Практическое задание

### 🎯 Задание: Реализуйте чистую функцию

Создайте чистую функцию на Dart, которая:
1. Принимает список чисел
2. Возвращает новый список, где все отрицательные числа заменены на ноль
3. Не изменяет исходный список

### ✅ Пример использования:

```dart
List<int> replaceNegativesWithZero(List<int> numbers) {
  return numbers.map((n) => n < 0 ? 0 : n).toList();
}

void main() {
  final input = [-1, 2, -3, 4];
  final output = replaceNegativesWithZero(input);
  print(output); // [0, 2, 0, 4]
}
```
