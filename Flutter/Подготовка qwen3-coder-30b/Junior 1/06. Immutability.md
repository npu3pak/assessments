# **Лекция 06: Immutability (Неизменяемость)**

## **Введение**

Приветствуем вас, Junior Flutter разработчик! Сегодня мы поговорим о важной концепции программирования — **неизменяемости (Immutability)**. Эта тема часто встречается в современном мире разработки, особенно при работе с состоянием приложения и архитектурой данных.

Несмотря на то, что неизменяемость может показаться простой идеей, она играет ключевую роль в создании стабильных, предсказуемых и легко тестируемых приложений. Особенно это важно в Flutter-приложениях, где состояние играет центральную роль.

---

## **1. Объяснение концепции mutable/immutable объектов**

### **Что такое Mutable (изменяемые) объекты?**

**Mutable** — это объекты, которые **могут быть изменены после их создания**. Это означает, что вы можете изменить значения их полей или свойств напрямую.

#### Пример на Dart:

```dart
void main() {
  var list = [1, 2, 3];
  print("Исходный список: $list");

  list.add(4); // Изменяем объект
  print("После добавления элемента: $list"); // [1, 2, 3, 4]
}
```

Здесь `list` — это изменяемый объект. Мы можем добавлять, удалять или изменять его элементы.

---

### **Что такое Immutable (неизменяемые) объекты?**

**Immutable** — это объекты, которые **не могут быть изменены после создания**. Любая попытка изменить их приведёт к созданию нового объекта.

#### Пример на Dart:

```dart
void main() {
  var list = const [1, 2, 3];
  // list.add(4); // ❌ Ошибка: Cannot add to a constant list

  // Вместо этого создаём новый список:
  var newList = [...list, 4]; // Создаём новый список
  print("Новый список: $newList"); // [1, 2, 3, 4]
}
```

Здесь мы использовали `const` — это ключевое слово, которое говорит Dart, что список является неизменяемым. Если попытаться изменить его, получим ошибку времени компиляции.

---

### **Важные различия**

| Свойство              | Mutable (изменяемый)     | Immutable (неизменяемый)       |
|-----------------------|--------------------------|--------------------------------|
| Можете изменять данные  | ✅ Да                    | ❌ Нет                         |
| Используются в состоянии приложения | ⚠️ Часто, но с риском | ✅ Рекомендуется (особенно в Flutter) |
| Производительность      | Быстрее при изменении    | Может быть медленнее при создании новых объектов |
| Безопасность           | Меньше гарантий          | Высокая, так как данные не меняются |

---

## **2. Преимущества immutable объектов**

### 🔹 1. **Прогнозируемость и предсказуемость**

Когда объекты неизменяемы, вы точно знаете, что их содержимое не изменится в процессе выполнения программы. Это делает код более надежным.

#### Пример:

```dart
class User {
  final String name;
  final int age;

  User(this.name, this.age);
}

void main() {
  var user = User("Алексей", 25);
  print(user.name); // Алексей

  // user.name = "Мария"; // ❌ Ошибка: Cannot assign to a final variable
}
```

Все данные `User` теперь защищены от изменений.

---

### 🔹 2. **Упрощение отладки и тестирования**

Если вы знаете, что объект не меняется, можно быть уверенным, что его состояние не изменилось в какой-то момент выполнения программы. Это упрощает отладку и написание unit-тестов.

---

### 🔹 3. **Параллельное выполнение (thread safety)**

Неизменяемые объекты можно безопасно использовать в многопоточных средах без риска конфликтов. Нет необходимости в синхронизации, блокировках и т.п.

---

### 🔹 4. **Функциональное программирование**

Неизменяемость — одна из ключевых концепций функционального программирования. Она помогает строить более чистый и предсказуемый код.

---

## **3. Реализация immutable объектов в Dart**

Dart предоставляет несколько способов создания неизменяемых объектов:

### ✅ Способ 1: Использование `final` и `const`

```dart
class Point {
  final int x;
  final int y;

  Point(this.x, this.y);
}

void main() {
  var point = Point(10, 20); // Создаём объект
  print(point.x); // 10

  // point.x = 30; // ❌ Ошибка: Cannot assign to a final variable
}
```

Такой подход подходит для простых объектов.

---

### ✅ Способ 2: Использование `const` для константных объектов

```dart
class Person {
  final String name;
  final int age;

  const Person(this.name, this.age);
}

void main() {
  var person1 = const Person("Анна", 30);
  var person2 = const Person("Анна", 30);

  print(identical(person1, person2)); // true — один и тот же объект
}
```

`const` используется для создания константных объектов. Dart может кэшировать их и экономить память.

---

### ✅ Способ 3: Классы с неизменяемыми полями (иммутабельные модели)

Если вы хотите создать иммутабельную модель данных, можно использовать **конструкторы с `final` полями** и **`copyWith` методы** для создания новых объектов с изменёнными значениями.

```dart
class Todo {
  final String title;
  final bool isCompleted;

  Todo({
    required this.title,
    required this.isCompleted,
  });

  Todo copyWith({
    String? title,
    bool? isCompleted,
  }) {
    return Todo(
      title: title ?? this.title,
      isCompleted: isCompleted ?? this.isCompleted,
    );
  }
}

void main() {
  var todo = Todo(title: "Закончить лекцию", isCompleted: false);
  var updatedTodo = todo.copyWith(isCompleted: true);

  print(todo.isCompleted); // false
  print(updatedTodo.isCompleted); // true
}
```

Здесь мы не изменяем оригинальный объект, а создаём новый с нужными значениями.

---

### ✅ Способ 4: Использование `immutable` библиотек

В Flutter-экосистеме есть популярные библиотеки для работы с иммутабельными структурами:

#### 📦 `freezed` (создание immutable моделей)

```yaml
dependencies:
  freezed_annotation: ^2.0.3

dev_dependencies:
  freezed: ^2.0.3
```

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'user.freezed.dart';

@freezed
class User with _$User {
  const factory User({
    required String name,
    required int age,
  }) = _User;
}
```

Эта конструкция создаёт класс с `final` полями, `copyWith`, и `const` конструктором. Очень удобно для работы с данными в Flutter.
