# Лекция: Паттерны проектирования для Flutter-разработчика уровня Junior

## Введение

В мире разработки программного обеспечения паттерны проектирования — это шаблоны, которые помогают решать частые задачи проектирования. Они позволяют создавать более гибкие, читаемые и поддерживаемые приложения.

В этой лекции мы рассмотрим **четыре важных паттерна проектирования**:

1. **Singleton**
2. **Mediator**
3. **Strategy**
4. **Facade**

Каждый паттерн будет подробно описан, с примерами на языке Dart и Flutter.

## 1. Singleton

### Что такое Singleton?

**Singleton** — это паттерн проектирования, который гарантирует создание только одного экземпляра класса в приложении и предоставляет глобальную точку доступа к этому экземпляру.

### Зачем нужен?

- Когда нужно обеспечить уникальность объекта (например, подключение к базе данных).
- Для управления общими ресурсами (настройки приложения, логгирование).
- Чтобы избежать множественного создания объектов с одинаковыми данными.

### Возможные проблемы:

1. **Тестирование**: трудно заменить singleton в unit-тестах.
2. **Нарушение SOLID**: Singleton может нарушать принцип единственной ответственности.
3. **Скрытое состояние**: singleton может содержать скрытые зависимости, усложняющие отладку.

### Пример реализации (Dart + Flutter)

```dart
class DatabaseConnection {
  static DatabaseConnection? _instance;

  // Конструктор приватный
  DatabaseConnection._();

  // Метод для получения экземпляра
  static DatabaseConnection get instance {
    _instance ??= DatabaseConnection._();
    return _instance!;
  }

  void connect() {
    print('Подключение к базе данных');
  }
}
```

### Использование:

```dart
void main() {
  final db1 = DatabaseConnection.instance;
  final db2 = DatabaseConnection.instance;

  print(identical(db1, db2)); // true

  db1.connect(); // Подключение к базе данных
}
```

### Реализация с помощью Kiwi (Dependency Injection)

Kiwi — это библиотека для Dependency Injection в Flutter. Она позволяет создавать singleton-объекты.

#### Установка Kiwi:

```yaml
dependencies:
  kiwi: ^1.0.0
```

#### Пример использования:

```dart
import 'package:kiwi/kiwi.dart';

class DatabaseService {
  void connect() {
    print('Подключение к БД через Kiwi');
  }
}

// Регистрация как singleton
Container.registerSingleton<DatabaseService>(DatabaseService());

// Использование:
void main() {
  final db = Container.get<DatabaseService>();
  db.connect();
}
```

## 2. Mediator

### Что такое Mediator?

**Mediator** — это паттерн, который уменьшает взаимосвязи между объектами, создавая «посредника», через которого они общаются.

### Зачем нужен?

- Для упрощения сложной связи между компонентами.
- Уменьшает связанность классов.
- Упрощает тестирование и модификацию.

### Пример: Чат в Flutter

Представим, что у нас есть несколько пользователей, которые обмениваются сообщениями. Вместо того чтобы каждый пользователь знал всех остальных, они общаются через `ChatMediator`.

```dart
// Посредник (Mediator)
abstract class ChatMediator {
  void sendMessage(String message, User sender);
}

class ChatRoom implements ChatMediator {
  List<User> users = [];

  @override
  void sendMessage(String message, User sender) {
    for (var user in users) {
      if (user != sender) {
        user.receive(message);
      }
    }
  }

  void addUser(User user) {
    users.add(user);
  }
}

// Участник (Colleague)
class User {
  String name;
  ChatMediator mediator;

  User(this.name, this.mediator);

  void send(String message) {
    print('$name отправляет: $message');
    mediator.sendMessage(message, this);
  }

  void receive(String message) {
    print('$name получил: $message');
  }
}
```

### Использование:

```dart
void main() {
  final chatRoom = ChatRoom();

  final alice = User('Alice', chatRoom);
  final bob = User('Bob', chatRoom);

  chatRoom.addUser(alice);
  chatRoom.addUser(bob);

  alice.send('Привет, Боб!');
}
```

## 3. Strategy

### Что такое Strategy?

**Strategy** — это паттерн, который определяет семейство алгоритмов, инкапсулирует каждый из них и делает их взаимозаменяемыми.

### Зачем нужен?

- Когда нужно выбирать алгоритм во время выполнения.
- Для реализации разных способов сортировки, форматирования, обработки данных.

### Пример: Разные способы расчета скидки

```dart
abstract class DiscountStrategy {
  double calculate(double price);
}

class RegularDiscount implements DiscountStrategy {
  @override
  double calculate(double price) {
    return price * 0.9;
  }
}

class HolidayDiscount implements DiscountStrategy {
  @override
  double calculate(double price) {
    return price * 0.7;
  }
}

class ShoppingCart {
  late DiscountStrategy discount;

  void setDiscount(DiscountStrategy strategy) {
    discount = strategy;
  }

  double getTotal(double price) {
    return discount.calculate(price);
  }
}
```

### Использование:

```dart
void main() {
  final cart = ShoppingCart();

  cart.setDiscount(RegularDiscount());
  print(cart.getTotal(100)); // 90

  cart.setDiscount(HolidayDiscount());
  print(cart.getTotal(100)); // 70
}
```

## 4. Facade

### Что такое Facade?

**Facade** — это паттерн, который предоставляет упрощенный интерфейс к сложной системе подсистем.

### Зачем нужен?

- Упрощает взаимодействие с большой системой.
- Скрывает сложность внутренней реализации.
- Повышает удобство использования.

### Пример: Упрощенный интерфейс для работы с сетью и базой данных

```dart
class NetworkService {
  void connect() => print('Подключение к сети');
  void sendData(String data) => print('Отправка данных: $data');
}

class DatabaseService {
  void save(String data) => print('Сохранение данных: $data');
}

class NotificationService {
  void show(String message) => print('Показ уведомления: $message');
}

// Фасад
class AppFacade {
  final NetworkService network = NetworkService();
  final DatabaseService database = DatabaseService();
  final NotificationService notification = NotificationService();

  void processOrder(String orderData) {
    network.connect();
    network.sendData(orderData);
    database.save(orderData);
    notification.show('Заказ обработан');
  }
}
```

### Использование:

```dart
void main() {
  final facade = AppFacade();
  facade.processOrder('Pizza Margherita');
}
```
