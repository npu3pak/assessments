# Лекция 18: Dart. Идентичность объектов

## Введение

В мире программирования, особенно при работе с коллекциями данных или при сравнении объектов, важно понимать, что такое **идентичность объекта** и как она реализуется в языке Dart. Идентичность определяет, являются ли два объекта одним и тем же экземпляром в памяти или же это разные экземпляры с одинаковыми значениями.

В языке Dart (как и во многих других языках программирования), для проверки идентичности двух объектов используется оператор `==`, который по умолчанию сравнивает ссылки на объекты. Однако, если вы хотите сравнить **значения** объектов (а не их ссылки), вам нужно переопределить метод `==` и реализовать логику сравнения.

## 1. Как обеспечить возможность проверки идентичности объектов

### 1.1. Оператор `==` по умолчанию

По умолчанию, когда вы используете оператор `==`, Dart выполняет **сравнение ссылок**. Это означает, что если два переменных указывают на один и тот же объект в памяти, то результат будет `true`. В противном случае — `false`.

Пример:

```dart
void main() {
  var a = Person('Alice', 25);
  var b = Person('Alice', 25);
  var c = a;

  print(a == b); // false — разные объекты, даже если значения одинаковые
  print(a == c); // true — один и тот же объект в памяти
}
```

В данном примере `a` и `b` — это два разных объекта, хотя они содержат одни и те же данные. Поэтому `a == b` возвращает `false`.

### 1.2. Переопределение метода `==`

Чтобы сравнивать **значения** объектов, а не ссылки, вы должны переопределить метод `==` в вашем классе. Также важно переопределить метод `hashCode`, поскольку он используется для хэширования объектов и необходим при работе с коллекциями типа `Set` и `Map`.

Пример:

```dart
class Person {
  final String name;
  final int age;

  Person(this.name, this.age);

  @override
  bool operator ==(Object other) {
    if (identical(this, other)) return true;
    if (other.runtimeType != runtimeType) return false;
    
    final Person person = other;
    return name == person.name && age == person.age;
  }

  @override
  int get hashCode => Object.hash(name, age);
}
```

Здесь:
- `identical(this, other)` проверяет, являются ли два объекта одним и тем же экземпляром.
- `other.runtimeType != runtimeType` — проверяет, что типы совпадают.
- `Object.hash(...)` — это удобный способ генерации хэш-кода из нескольких полей.

После переопределения `==` и `hashCode`, сравнение объектов будет работать по значениям:

```dart
void main() {
  var a = Person('Alice', 25);
  var b = Person('Alice', 25);

  print(a == b); // true — теперь объекты равны по значению
}
```

## 2. Свойство `hashCode`

### 2.1. Что такое хэш-код?

Хэш-код (или просто хэш) — это целое число, которое генерируется на основе данных объекта и используется для быстрого поиска в структурах данных, таких как `Set` или `Map`.

### 2.2. Почему важно переопределять `hashCode`?

Если вы переопределяете метод `==`, вы **обязаны** переопределить и `hashCode`. Это связано с тем, что в коллекциях типа `Set` или `Map` хэш-код используется для определения, где должен находиться объект. Если два объекта равны (по `==`), они должны иметь одинаковый хэш-код.

Если этого не сделать, вы можете столкнуться с непредсказуемым поведением коллекций:

```dart
// Неправильно: переопределили ==, но не hashCode
class BadPerson {
  final String name;
  final int age;

  BadPerson(this.name, this.age);

  @override
  bool operator ==(Object other) {
    if (identical(this, other)) return true;
    if (other.runtimeType != runtimeType) return false;
    
    final BadPerson person = other;
    return name == person.name && age == person.age;
  }
}

void main() {
  var set = <BadPerson>{};
  var a = BadPerson('Alice', 25);
  set.add(a);
  print(set.contains(BadPerson('Alice', 25))); // Может быть false, если hashCode не переопределен
}
```

### 2.3. Как правильно реализовать `hashCode`?

Самый простой способ — использовать `Object.hash`, который учитывает несколько значений:

```dart
@override
int get hashCode => Object.hash(name, age);
```

Также можно использовать `Object.hashAll` для более сложных объектов:

```dart
@override
int get hashCode => Object.hashAll([name, age]);
```

## 3. Пакет `equatable`

### 3.1. Что такое `equatable`?

Пакет **`equatable`** — это удобное решение для автоматизации реализации методов `==` и `hashCode`. Он значительно упрощает работу с объектами, которые нужно сравнивать по значениям.

Установка:

```yaml
dependencies:
  equatable: ^2.0.5
```

### 3.2. Как использовать `equatable`

Классы, которые должны быть сравнимыми по значению, наследуются от `Equatable` и указывают поля, по которым будет происходить сравнение.

Пример:

```dart
import 'package:equatable/equatable.dart';

class Person extends Equatable {
  final String name;
  final int age;

  Person(this.name, this.age);

  @override
  List<Object?> get props => [name, age];
}
```

Теперь `Person` автоматически будет сравниваться по значениям, и у него будут корректно реализованы методы `==` и `hashCode`.

```dart
void main() {
  var a = Person('Alice', 25);
  var b = Person('Alice', 25);

  print(a == b); // true — автоматически реализовано
}
```

### 3.3. Преимущества `equatable`

- Упрощает код
- Снижает вероятность ошибок
- Легко поддерживать при изменении полей
- Подходит для работы с коллекциями
