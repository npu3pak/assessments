# Лекция: Dart. Коллекции

---

## Введение

Коллекции — это основные структуры данных в Dart, которые позволяют хранить и обрабатывать группу элементов. Они играют ключевую роль в Flutter-разработке, поскольку часто используются для представления данных, управления состоянием, отображения списков и т. д.

В этой лекции мы рассмотрим:

1. Стандартные коллекции (List, Map, Set) и их назначение.
2. Spread operator (`...` и `...?`) и его использование в коллекциях.
3. Использование `if` и `for` в объявлении коллекций (условные и циклические выражения).
4. Возможности пакета `collection`.

## 1. Стандартные коллекции

### 1.1 List (Список)

**List** — это упорядоченная коллекция элементов, к которым можно обращаться по индексу.

```dart
List<int> numbers = [1, 2, 3, 4, 5];
List<String> fruits = ['apple', 'banana', 'orange'];
```

- **Можно создавать с помощью литералов** (`[]`) или конструктора `List()`.
- **Списки могут быть изменяемыми (mutable)** или неизменяемыми (immutable).
  - `List<int> mutable = [1, 2, 3];` — изменяемый.
  - `List<int> immutable = const [1, 2, 3];` — неизменяемый.

**Методы List:**

- `add(item)` – добавляет элемент в конец.
- `remove(item)` – удаляет первый найденный элемент.
- `length` – длина списка.
- `indexOf(item)` – индекс элемента.

Пример:
```dart
List<String> animals = ['cat', 'dog'];
animals.add('bird');
print(animals); // [cat, dog, bird]
```

---

### 1.2 Map (Словарь)

**Map** — это коллекция пар ключ-значение. Ключи уникальны.

```dart
Map<String, int> ages = {
  'Alice': 25,
  'Bob': 30,
};
```

- Ключи и значения могут быть любого типа.
- Можно использовать конструктор `Map()` или литерал `{}`.

**Методы Map:**

- `putIfAbsent(key, value)` – добавляет пару, если ключ отсутствует.
- `remove(key)` – удаляет пару по ключу.
- `containsKey(key)` – проверяет наличие ключа.
- `keys`, `values` – получение всех ключей или значений.

Пример:
```dart
Map<String, dynamic> user = {
  'name': 'John',
  'age': 28,
};

user['email'] = 'john@example.com';
print(user); // {name: John, age: 28, email: john@example.com}
```

---

### 1.3 Set (Множество)

**Set** — это коллекция уникальных элементов.

```dart
Set<String> colors = {'red', 'green', 'blue'};
```

- Элементы в `Set` не повторяются.
- Поддерживает операции объединения, пересечения и разности.

Пример:
```dart
Set<int> numbers = {1, 2, 3};
numbers.add(4);
print(numbers); // {1, 2, 3, 4}
```

## 2. Spread operator

### 2.1 Основное применение: `...` (Spread operator)

Spread operator позволяет "развернуть" коллекцию внутри другой коллекции.

#### Пример с List:

```dart
List<int> list1 = [1, 2];
List<int> list2 = [3, 4];

List<int> combined = [...list1, ...list2];
print(combined); // [1, 2, 3, 4]
```

#### Смешанные коллекции:

```dart
List<String> fruits = ['apple', 'banana'];
List<String> moreFruits = ['orange', 'grape'];

List<String> allFruits = [...fruits, 'kiwi', ...moreFruits];
print(allFruits); // [apple, banana, kiwi, orange, grape]
```

#### В Map:

```dart
Map<String, int> map1 = {'a': 1, 'b': 2};
Map<String, int> map2 = {'c': 3};

Map<String, int> merged = {...map1, ...map2};
print(merged); // {a: 1, b: 2, c: 3}
```

---

### 2.2 Null-aware spread operator: `...?`

Используется для безопасного разворачивания коллекций, которые могут быть `null`.

```dart
List<String>? nullableList = null;
List<String> safeList = [...?nullableList]; // Безопасно, если null
```

Если `nullableList` равен `null`, то `safeList` будет пустым.

## 3. Использование if и for в коллекциях

Dart поддерживает условные и циклические выражения внутри литералов коллекций — это называется **collection literals**.

### 3.1 Условные выражения `if` (conditional expressions)

```dart
List<int> numbers = [1, 2, 3, 4, 5];

List<int> evenNumbers = [
  for (int number in numbers)
    if (number.isEven) number
];
print(evenNumbers); // [2, 4]
```

### 3.2 Циклические выражения `for` (for-in expressions)

```dart
List<String> names = ['Alice', 'Bob', 'Charlie'];

List<String> greetings = [
  for (String name in names) 'Hello, $name!'
];
print(greetings); // [Hello, Alice!, Hello, Bob!, Hello, Charlie!]
```

### 3.3 Смешанные условия

```dart
List<int> numbers = [1, 2, 3, 4, 5, 6];

List<int> filtered = [
  for (int number in numbers)
    if (number > 3 && number.isEven) number
];
print(filtered); // [4, 6]
```

## 4. Пакет `collection`

Пакет `collection` предоставляет дополнительные утилиты для работы с коллекциями. Он часто используется в Flutter проектах.

### Установка:

В `pubspec.yaml`:

```yaml
dependencies:
  collection: ^1.17.0
```

### Основные функции:

#### 1. `ListMixin` — расширения для работы со списками

```dart
import 'package:collection/collection.dart';

List<int> list = [1, 2, 3, 4, 5];
int sum = list.reduce((a, b) => a + b);
print(sum); // 15
```

#### 2. `Iterable` методы

```dart
var numbers = [1, 2, 3, 4, 5];

// Сумма всех четных чисел
int evenSum = numbers.where((n) => n.isEven).reduce((a, b) => a + b);
print(evenSum); // 6 (2 + 4)
```

#### 3. `grouping` — группировка элементов

```dart
var people = [
  {'name': 'Alice', 'age': 25},
  {'name': 'Bob', 'age': 30},
  {'name': 'Charlie', 'age': 25}
];

var grouped = groupBy(people, (person) => person['age']);
print(grouped); // {25: [{name: Alice, age: 25}, {name: Charlie, age: 25}], 30: [{name: Bob, age: 30}]}
```
