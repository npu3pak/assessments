# Лекция 08: Работа с JSON в Flutter

## Введение

Работа с JSON (JavaScript Object Notation) — одна из ключевых навыков для любого мобильного разработчика, особенно при работе с API. JSON является стандартом обмена данными между клиентом и сервером, поэтому понимание его использования в Flutter жизненно важно.

В этой лекции мы подробно рассмотрим:
1. Как работать с JSON в Dart через встроенные методы `jsonEncode` и `jsonDecode`.
2. Как использовать библиотеку `typed_json` для упрощения работы с JSON.
3. Как создавать классы, соответствующие структуре JSON-данных.
4. Практические примеры использования этих инструментов.

---

## 1. Введение в JSON

**JSON (JavaScript Object Notation)** — это легковесный формат обмена данными, основанный на синтаксисе JavaScript. Он используется для передачи данных между сервером и клиентом, а также для хранения структурированной информации.

Пример JSON:

```json
{
  "id": 1,
  "name": "Иван Петров",
  "email": "ivan@example.com",
  "isActive": true,
  "age": 25
}
```

В Dart JSON представлен в виде `Map<String, dynamic>` или `List<dynamic>`, если это массив.

## 2. jsonEncode и jsonDecode

Dart предоставляет встроенные методы для работы с JSON:

- `jsonEncode()` — преобразует объект Dart в строку JSON.
- `jsonDecode()` — преобразует строку JSON в объект Dart.

### Импорт библиотеки

Для работы с JSON нужно импортировать стандартную библиотеку `dart:convert`:

```dart
import 'dart:convert';
```

### 2.1. jsonEncode

Метод `jsonEncode()` преобразует объект Dart в строку JSON.

**Пример:**

```dart
void main() {
  final user = {
    'id': 1,
    'name': 'Иван Петров',
    'email': 'ivan@example.com',
    'isActive': true,
    'age': 25
  };

  final jsonString = jsonEncode(user);
  print(jsonString);
  // Вывод: {"id":1,"name":"Иван Петров","email":"ivan@example.com","isActive":true,"age":25}
}
```

### 2.2. jsonDecode

Метод `jsonDecode()` преобразует строку JSON в объект Dart.

**Пример:**

```dart
void main() {
  final jsonString = '''
    {
      "id": 1,
      "name": "Иван Петров",
      "email": "ivan@example.com",
      "isActive": true,
      "age": 25
    }
  ''';

  final userMap = jsonDecode(jsonString);
  print(userMap['name']); // Иван Петров
  print(userMap['age']);  // 25
}
```

### 2.3. Работа с объектами и списками

JSON может содержать вложенные объекты и массивы.

**Пример с вложенными данными:**

```dart
void main() {
  final jsonString = '''
    {
      "id": 1,
      "name": "Иван Петров",
      "address": {
        "street": "Ленина, 50",
        "city": "Москва"
      },
      "hobbies": ["чтение", "плавание"]
    }
  ''';

  final userMap = jsonDecode(jsonString);

  print(userMap['name']); // Иван Петров
  print(userMap['address']['street']); // Ленина, 50
  print(userMap['hobbies'][0]); // чтение
}
```

## 3. Работа с классами: Преобразование JSON в объекты

Для удобства и типобезопасности рекомендуется использовать классы для представления данных из JSON.

### 3.1. Создание классов

Предположим, у нас есть следующий JSON:

```json
{
  "id": 1,
  "name": "Иван Петров",
  "email": "ivan@example.com",
  "isActive": true,
  "age": 25
}
```

Создадим класс `User`:

```dart
class User {
  final int id;
  final String name;
  final String email;
  final bool isActive;
  final int age;

  User({
    required this.id,
    required this.name,
    required this.email,
    required this.isActive,
    required this.age,
  });

  // Конвертация из JSON
  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      id: json['id'],
      name: json['name'],
      email: json['email'],
      isActive: json['isActive'],
      age: json['age'],
    );
  }

  // Конвертация в JSON
  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'name': name,
      'email': email,
      'isActive': isActive,
      'age': age,
    };
  }
}
```

### 3.2. Использование класса

```dart
void main() {
  final jsonString = '''
    {
      "id": 1,
      "name": "Иван Петров",
      "email": "ivan@example.com",
      "isActive": true,
      "age": 25
    }
  ''';

  final userMap = jsonDecode(jsonString);
  final user = User.fromJson(userMap);

  print(user.name); // Иван Петров
}
```

Также можно использовать `jsonEncode`:

```dart
void main() {
  final user = User(
    id: 1,
    name: 'Иван Петров',
    email: 'ivan@example.com',
    isActive: true,
    age: 25,
  );

  final jsonString = jsonEncode(user.toJson());
  print(jsonString);
}
```

## 4. Библиотека `typed_json`

Библиотека `typed_json` — это удобный инструмент, который позволяет автоматически генерировать код для сериализации/десериализации JSON.

### Установка

Добавьте в `pubspec.yaml`:

```yaml
dependencies:
  typed_json: ^1.0.0
```

> **Важно**: `typed_json` — не встроенная библиотека, но она используется в продакшн-проектах и часто применяется при разработке на Flutter.

### 4.1. Использование `typed_json`

Предположим, у нас есть класс:

```dart
import 'package:typed_json/typed_json.dart';

@TypedJson()
class User {
  final int id;
  final String name;
  final String email;
  final bool isActive;
  final int age;

  User({
    required this.id,
    required this.name,
    required this.email,
    required this.isActive,
    required this.age,
  });

  // Конструктор из JSON
  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);

  // Сериализация в JSON
  Map<String, dynamic> toJson() => _$UserToJson(this);
}
```

Команда для генерации кода:

```bash
flutter pub run build_runner build
```

После этого будет сгенерирован файл `user.g.dart`, который содержит методы `_$UserFromJson` и `_$UserToJson`.

### 4.2. Преимущества `typed_json`

- Автоматическая генерация кода.
- Повышение производительности.
- Упрощение работы с большими структурами данных.

## 5. Примеры использования в Flutter

Представим, что вы делаете приложение, которое получает список пользователей через API.

### 5.1. Создание модели

```dart
class User {
  final int id;
  final String name;
  final String email;

  User({
    required this.id,
    required this.name,
    required this.email,
  });

  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      id: json['id'],
      name: json['name'],
      email: json['email'],
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'name': name,
      'email': email,
    };
  }
}
```

### 5.2. Получение данных из API

```dart
import 'dart:convert';
import 'package:http/http.dart' as http;

Future<List<User>> fetchUsers() async {
  final response = await http.get(Uri.parse('https://jsonplaceholder.typicode.com/users'));

  if (response.statusCode == 200) {
    final List<dynamic> data = jsonDecode(response.body);
    return data.map((e) => User.fromJson(e)).toList();
  } else {
    throw Exception('Не удалось загрузить пользователей');
  }
}
```
