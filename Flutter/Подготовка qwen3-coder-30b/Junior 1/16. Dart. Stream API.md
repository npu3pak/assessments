# Лекция: Dart Stream API для Flutter разработчика уровня Junior

## Введение

Stream — это одна из ключевых концепций в Dart, которая позволяет обрабатывать асинхронные данные по мере их поступления. В мире Flutter, где часто требуется работа с событиями (например, нажатия кнопок, изменения состояния, сетевые запросы и т.д.), Stream API играет центральную роль.

В этой лекции мы рассмотрим:
- Что такое Stream и Broadcast Stream
- Как работает Sink
- StreamController
- Функции-генераторы (Stream generators)
  
После прочтения вы получите полное понимание того, как работать с потоками данных в Dart и Flutter.

## 1. Что такое Stream?

**Stream** — это последовательность событий или значений, которые могут быть получены асинхронно по мере их поступления. Он похож на коллекцию, но данные не хранятся полностью — они поступают по частям.

### Пример: простой Stream

```dart
import 'dart:async';

void main() {
  // Создаем простой Stream
  Stream<int> stream = Stream.fromIterable([1, 2, 3, 4]);

  // Подписываемся на поток
  stream.listen((data) {
    print("Получено значение: $data");
  });
}
```

Вывод:
```
Получено значение: 1
Получено значение: 2
Получено значение: 3
Получено значение: 4
```

### Основные методы Stream:

- `listen()` — подписаться на поток и получать данные по мере их поступления.
- `map()` — преобразовать значения в потоке.
- `where()` — фильтровать значения.
- `take()` — взять определенное количество значений.
- `asyncMap()` — асинхронно преобразовать значения.

## 2. Broadcast Stream

**Broadcast Stream** — это особый тип Stream, который может иметь несколько подписчиков (listeners). В отличие от обычного Stream (Single subscription stream), он не закрывается после первого подписчика.

### Пример: Broadcast Stream

```dart
void main() {
  // Создаем Broadcast Stream
  StreamController<int> controller = StreamController<int>.broadcast();
  
  Stream<int> broadcastStream = controller.stream;

  // Первый подписчик
  broadcastStream.listen((data) {
    print("Первый слушатель: $data");
  });

  // Второй подписчик
  broadcastStream.listen((data) {
    print("Второй слушатель: $data");
  });

  // Добавляем данные в поток
  controller.add(1);
  controller.add(2);
  controller.close();
}
```

Вывод:
```
Первый слушатель: 1
Второй слушатель: 1
Первый слушатель: 2
Второй слушатель: 2
```

### Важно:

- Broadcast Stream создается через `StreamController.broadcast()`.
- Он может иметь несколько подписчиков.
- Для закрытия используйте `controller.close()`.

## 3. Sink

**Sink** — это интерфейс, через который можно отправлять данные в поток. В StreamController есть свойство `sink`, которое позволяет добавлять данные в поток.

### Пример: использование Sink

```dart
void main() {
  StreamController<int> controller = StreamController<int>();

  // Получаем Sink для записи данных
  Sink<int> sink = controller.sink;

  // Подписываемся на поток
  controller.stream.listen((data) {
    print("Получено: $data");
  });

  // Добавляем данные через Sink
  sink.add(10);
  sink.add(20);

  sink.close(); // Закрываем Sink
}
```

Вывод:
```
Получено: 10
Получено: 20
```

### Важно:

- Sink — это способ вставки данных в поток.
- `sink.add(data)` — добавляет элемент в поток.
- `sink.close()` — завершает отправку данных.

---

## 4. StreamController

**StreamController** — это класс, который позволяет создавать и управлять потоками данных. Он предоставляет:

- `stream` — поток для подписки
- `sink` — возможность добавлять данные в поток

### Пример: простой StreamController

```dart
void main() {
  StreamController<String> controller = StreamController<String>();

  // Подписываемся на поток
  controller.stream.listen((data) {
    print("Получено: $data");
  });

  // Добавляем данные в поток через Sink
  controller.sink.add('Hello');
  controller.sink.add('World');

  // Закрываем контроллер
  controller.close();
}
```

### Пример: Broadcast StreamController

```dart
void main() {
  StreamController<int> controller = StreamController<int>.broadcast();

  controller.stream.listen((data) {
    print("Подписчик 1: $data");
  });

  controller.stream.listen((data) {
    print("Подписчик 2: $data");
  });

  controller.sink.add(5);
  controller.close();
}
```

### Важно:

- `StreamController()` — создает обычный (single subscription) поток.
- `StreamController.broadcast()` — создает broadcast поток.
- Используйте `controller.close()` для завершения работы с потоком.

## 5. Функции-генераторы (Stream generators)

Функции-генераторы — это функции, которые возвращают `Stream`. Они позволяют создавать потоки данных динамически, по мере их необходимости.

### Синтаксис:

```dart
Stream<DataType> functionName() async* {
  // yield - добавляет элемент в поток
}
```

### Пример: простая функция-генератор

```dart
Stream<int> generateNumbers(int count) async* {
  for (int i = 1; i <= count; i++) {
    yield i;
    await Future.delayed(Duration(milliseconds: 500)); // задержка для демонстрации асинхронности
  }
}

void main() {
  generateNumbers(5).listen((data) {
    print("Получено: $data");
  });
}
```

Вывод:
```
Получено: 1
Получено: 2
Получено: 3
Получено: 4
Получено: 5
```

### Пример: генерация случайных чисел

```dart
Stream<int> randomNumbers(int count) async* {
  for (int i = 0; i < count; i++) {
    yield Random().nextInt(100);
    await Future.delayed(Duration(milliseconds: 300));
  }
}

void main() {
  randomNumbers(5).listen((data) {
    print("Случайное число: $data");
  });
}
```

### Важно:

- `async*` — обозначает, что функция возвращает Stream.
- `yield` — добавляет элемент в поток.
- `await Future.delayed(...)` — имитирует асинхронную задержку.

## Сравнение: Stream vs Iterable

| Параметр           | Stream                        | Iterable                       |
|--------------------|-------------------------------|--------------------------------|
| Тип данных         | Асинхронные значения          | Синхронные значения            |
| Использование      | Для событий, сетевых запросов | Для коллекций                  |
| Подписка           | `listen()`                    | `forEach()` или `for-in`       |
| Количество подписчиков | Множество (Broadcast)     | Один (Single subscription)     |

## Практическое задание

**Задание: Создать приложение на Flutter, которое отображает генерируемые случайные числа в течение 10 секунд.**

### Требования:
- Используйте функцию-генератор для создания Stream.
- Каждые 500 мс добавляется новое случайное число.
- В интерфейсе отображается список чисел, которые поступают в поток.
- После 10 секунд поток должен завершиться.

### Пример структуры:

```dart
class RandomNumberStream extends StatefulWidget {
  @override
  _RandomNumberStreamState createState() => _RandomNumberStreamState();
}

class _RandomNumberStreamState extends State<RandomNumberStream> {
  List<int> numbers = [];

  @override
  void initState() {
    super.initState();
    startStream();
  }

  void startStream() {
    Stream<int> stream = generateNumbers(20); // 20 чисел за 10 секунд

    stream.listen((number) {
      setState(() {
        numbers.add(number);
      });
    });
  }

  Stream<int> generateNumbers(int count) async* {
    for (int i = 0; i < count; i++) {
      yield Random().nextInt(100);
      await Future.delayed(Duration(milliseconds: 500));
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("Stream Demo")),
      body: ListView.builder(
        itemCount: numbers.length,
        itemBuilder: (context, index) {
          return ListTile(title: Text(numbers[index].toString()));
        },
      ),
    );
  }
}
```
