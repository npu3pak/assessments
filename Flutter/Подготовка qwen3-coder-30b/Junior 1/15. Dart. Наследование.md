# **Лекция: Наследование в Dart**

---

## **1. Основные принципы наследования классов**

**Наследование** — это механизм, позволяющий создавать новые классы на основе уже существующих. Это один из ключевых элементов объектно-ориентированного программирования (ООП). В Dart наследование реализуется через ключевое слово `extends`.

Когда один класс наследует другой, он получает все **публичные и защищённые** поля и методы родительского класса. Это позволяет переиспользовать код и строить иерархии классов.

### Пример:

```dart
class Animal {
  String name;
  
  Animal(this.name);

  void eat() {
    print('$name is eating.');
  }
}

class Dog extends Animal {
  Dog(String name) : super(name);

  void bark() {
    print('$name is barking!');
  }
}
```

В данном примере:
- `Animal` — родительский (базовый) класс.
- `Dog` — дочерний класс, который наследуется от `Animal`.
- `super(name)` вызывает конструктор родителя.
- `Dog` имеет доступ к методу `eat()` и полю `name`, даже если они не были объявлены в `Dog`.

## **2. Модификатор `base`**

В Dart модификатор `base` используется при работе с **множественным наследованием** (через **миксины**) и указывает, что класс может быть использован как базовый при реализации миксинов.

Однако, в обычном наследовании (`extends`) этот модификатор не применяется. Он чаще используется в контексте `mixin` и `base class`, особенно когда вы хотите ограничить использование класса как миксина или сделать его базовым для других классов.

Например:

```dart
base class BaseClass {
  void baseMethod() {
    print("Base method");
  }
}
```

Модификатор `base` не является частью стандартного синтаксиса Dart (в отличие от C++ или Java), но используется при определении, каким образом класс может быть использован в иерархии наследования. В Dart он применяется в более сложных случаях с миксинами и интерфейсами.

## **3. Модификатор `abstract`**

Класс, помеченный ключевым словом `abstract`, не может быть создан напрямую. Он предназначен только для наследования.

### Пример:

```dart
abstract class Shape {
  double get area;
  void draw();
}

class Rectangle extends Shape {
  final double width, height;

  Rectangle(this.width, this.height);

  @override
  double get area => width * height;

  @override
  void draw() {
    print("Drawing rectangle with area: $area");
  }
}
```

- `Shape` — абстрактный класс.
- `Rectangle` реализует все методы из `Shape`.
- Невозможно создать объект `Shape` напрямую: `var shape = Shape();` — ошибка компиляции.

### Абстрактные методы

Можно объявлять **абстрактные методы** внутри абстрактного класса:

```dart
abstract class Vehicle {
  void start();
  void stop();
}
```

## **4. Интерфейсы и `interface`**

В Dart **интерфейс** — это не отдельная конструкция, как в Java или C#, а **абстрактный класс**, который может содержать только абстрактные методы и свойства.

Однако, Dart **не имеет ключевого слова `interface`**. Все интерфейсы в Dart реализуются через **абстрактные классы** или **примеси (`mixins`)**.

### Пример:

```dart
abstract class Drawable {
  void draw();
}

class Circle implements Drawable {
  @override
  void draw() {
    print("Drawing a circle");
  }
}
```

> Важно: в Dart `implements` используется для реализации интерфейсов (т.е. абстрактных классов или миксинов).

---

## **5. Абстрактные интерфейсы и `abstract interface`**

В Dart **абстрактный интерфейс** — это просто **абстрактный класс**, который не содержит реализации методов, и его можно использовать только для наследования.

```dart
abstract class Logger {
  void log(String message);
}
```

Если вы хотите создать **реализацию этого интерфейса**, нужно унаследовать его:

```dart
class ConsoleLogger implements Logger {
  @override
  void log(String message) {
    print("Log: $message");
  }
}
```

## **6. Модификатор `final`**

Модификатор `final` используется для объявления переменных, которые не могут быть переназначены после инициализации.

```dart
class Person {
  final String name;
  final int age;

  Person(this.name, this.age);
}
```

- `name` и `age` — **константные** поля, которые нельзя изменить после создания объекта.
- Используется для обеспечения неизменяемости данных.

Также можно использовать `final` с методами:

```dart
class MyClass {
  final void myMethod() {
    print("This method cannot be overridden.");
  }
}
```

> **Важно**: в Dart `final` применяется только к переменным, а не к методам напрямую. Для предотвращения переопределения методов используется `@override` и `sealed` классы.

## **7. Модификатор `sealed`**

Модификатор `sealed` — это новая возможность в Dart 3+, которая позволяет ограничить, какие классы могут наследовать от определённого класса. В отличие от `abstract`, `sealed` класс может быть расширен только **внутри того же файла** или в том же пакете.

### Пример:

```dart
sealed class Status {
  const Status();
}

class Success extends Status {
  final String message;
  Success(this.message);
}

class Error extends Status {
  final String error;
  Error(this.error);
}
```

Теперь `Status` — это **sealed класс**, и только `Success` и `Error` могут быть его подклассами. Это повышает безопасность кода, так как вы не можете случайно создать новый класс, который наследуется от `Status`.

## **8. Extensions**

**Extensions** в Dart позволяют добавлять новые функции к существующим типам данных (включая классы, которые вы не контролируете). Это мощный инструмент для расширения функциональности без изменения исходного кода.

### Пример:

```dart
extension StringExtensions on String {
  bool get isValidEmail => RegExp(r'^[^@]+@[^@]+\.[^@]+').hasMatch(this);

  String get capitalizeFirst {
    if (isEmpty) return this;
    return '${this[0].toUpperCase()}${substring(1).toLowerCase()}';
  }
}

void main() {
  var email = "user@example.com";
  print(email.isValidEmail); // true

  var name = "john doe";
  print(name.capitalizeFirst); // John doe
}
```

### Расширения в Flutter:

Можно использовать расширения для упрощения работы с `BuildContext`, `TextStyle` и т.д.

```dart
extension BuildContextExtensions on BuildContext {
  void showSnackBar(String message) {
    ScaffoldMessenger.of(this).showSnackBar(
      SnackBar(content: Text(message)),
    );
  }
}
```

## **Заключение**

Наследование — мощный инструмент в Dart, который позволяет строить иерархии классов, переиспользовать код и организовать логику по принципу "один класс — один смысл". Важно понимать:
- Различия между `abstract`, `interface`, `sealed`.
- Как использовать `final` для создания неизменяемых объектов.
- Как применять `extensions` для расширения существующих типов.
