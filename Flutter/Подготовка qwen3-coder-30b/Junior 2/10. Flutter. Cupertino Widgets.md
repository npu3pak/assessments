# Flutter: Cupertino Widgets  
## Лекция для Junior разработчика  

---

## 1. Что такое Cupertino Widgets?

**Cupertino Widgets (или iOS-стильные виджеты)** — это набор визуальных элементов интерфейса, созданных по дизайну Apple iOS. Они позволяют разработчикам создавать приложения с характерным для iPhone внешним видом и ощущением, используя Flutter.

В отличие от стандартных Material Design виджетов (`MaterialApp`, `Scaffold`, `AppBar`), которые соответствуют стилю Android и Material Design, **Cupertino Widgets** реализуют интерфейс, близкий к iOS. Эти виджеты находятся в пакете `cupertino` и импортируются из `package:flutter/cupertino.dart`.

### Важно:
- Все Cupertino-виджеты имеют префикс `Cupertino`, например: `CupertinoApp`, `CupertinoButton`, `CupertinoTextField`.
- Они реализуют стиль Apple, поэтому рекомендуются при создании iOS-подобных приложений или приложениях с поддержкой обеих платформ (iOS и Android) с разным стилем.

---

## 2. Основные особенности Cupertino Widgets

- **Стиль**: Использует стиль Apple iOS.
- **Взаимодействие**: Виджеты отвечают на жесты, анимации и визуальные эффекты, характерные для iOS.
- **Интеграция**: Подходят для создания кросс-платформенных приложений с разным стилем под каждую ОС.
- **Темизация**: Используют тему `CupertinoThemeData`, позволяя изменять цвета и стили.

---

## 3. Как использовать Cupertino Widgets

Для использования Cupertino виджетов нужно импортировать:

```dart
import 'package:flutter/cupertino.dart';
```

Или если используется `CupertinoApp`:

```dart
import 'package:flutter/cupertino.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return CupertinoApp(
      title: 'Cupertino App',
      home: const MyHomePage(),
    );
  }
}
```

> Важно: `CupertinoApp` используется вместо `MaterialApp`, чтобы приложение выглядело как iOS-приложение.

## 4. Основные Cupertino Widgets

### 4.1. CupertinoApp

Это главный виджет, который заменяет `MaterialApp`. Он настраивает тему и поведение для iOS-стиля.

```dart
CupertinoApp(
  title: 'My App',
  home: MyHomePage(),
)
```

### 4.2. CupertinoPageScaffold

Аналог `Scaffold` в Material Design, но с iOS-стилем.

```dart
CupertinoPageScaffold(
  navigationBar: CupertinoNavigationBar(
    middle: Text("Home"),
  ),
  child: Center(
    child: Text("Hello, Cupertino!"),
  ),
)
```

### 4.3. CupertinoButton

Кнопка в стиле iOS.

```dart
CupertinoButton(
  onPressed: () {
    print('Pressed');
  },
  child: Text('Press Me'),
)
```

### 4.4. CupertinoTextField

Поле ввода в iOS-стиле.

```dart
CupertinoTextField(
  placeholder: 'Enter text',
  onSubmitted: (value) {
    print(value);
  },
)
```

### 4.5. CupertinoSlider

Слайдер, соответствующий iOS-дизайну.

```dart
CupertinoSlider(
  value: 0.5,
  min: 0.0,
  max: 1.0,
  onChanged: (value) {
    print(value);
  },
)
```

### 4.6. CupertinoSwitch

Переключатель в стиле iOS.

```dart
CupertinoSwitch(
  value: true,
  onChanged: (value) {
    print(value);
  },
)
```

### 4.7. CupertinoSegmentedControl

Группа переключателей, как на iPhone.

```dart
CupertinoSegmentedControl<String>(
  groupValue: 'one',
  children: {
    'one': Text('One'),
    'two': Text('Two'),
  },
  onValueChanged: (String? value) {
    print(value);
  },
)
```

### 4.8. CupertinoDatePicker

Дата и время в стиле iOS.

```dart
CupertinoDatePicker(
  mode: CupertinoDatePickerMode.date,
  onDateTimeChanged: (DateTime newDate) {
    print(newDate);
  },
)
```

### 4.9. CupertinoDialog

Диалоговое окно в стиле iOS.

```dart
showCupertinoDialog(
  context: context,
  builder: (BuildContext context) {
    return CupertinoAlertDialog(
      title: Text('Alert'),
      content: Text('This is an alert dialog.'),
      actions: [
        CupertinoDialogAction(
          child: Text('OK'),
          onPressed: () {
            Navigator.of(context).pop();
          },
        ),
      ],
    );
  },
);
```

### 4.10. CupertinoNavigationBar

Панель навигации, похожая на iOS.

```dart
CupertinoNavigationBar(
  middle: Text("Title"),
  trailing: CupertinoButton(
    child: Text("Done"),
    onPressed: () {},
  ),
)
```

### 4.11. CupertinoTabBar и CupertinoTabView

Используются для создания вкладок (tab bar), как на iPhone.

```dart
CupertinoTabBar(
  items: [
    BottomNavigationBarItem(icon: Icon(CupertinoIcons.home), label: 'Home'),
    BottomNavigationBarItem(icon: Icon(CupertinoIcons.settings), label: 'Settings'),
  ],
)
```

## 5. Темизация Cupertino

Для настройки внешнего вида можно использовать `CupertinoThemeData`.

```dart
CupertinoApp(
  theme: CupertinoThemeData(
    primaryColor: Colors.blue,
    scaffoldBackgroundColor: Colors.white,
  ),
  home: MyHomePage(),
)
```

---

## 6. Когда использовать Cupertino Widgets?

- Если вы хотите создать **iOS-подобное приложение**.
- При необходимости **создания кросс-платформенного приложения**, где интерфейс должен отличаться в зависимости от ОС.
- Если вы разрабатываете приложение для Apple App Store и хотите следовать iOS гайдлайнам.

---

## 7. Пример полного приложения с Cupertino

```dart
import 'package:flutter/cupertino.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return CupertinoApp(
      title: 'Cupertino Demo',
      home: CupertinoPageScaffold(
        navigationBar: CupertinoNavigationBar(
          middle: Text("Demo App"),
        ),
        child: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              CupertinoButton(
                onPressed: () {
                  print('Button pressed');
                },
                child: Text('Press Me'),
              ),
              SizedBox(height: 20),
              CupertinoTextField(
                placeholder: 'Enter text',
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```
