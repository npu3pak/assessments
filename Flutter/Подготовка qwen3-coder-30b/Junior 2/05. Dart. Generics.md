# Лекция 05: Dart. Generics

Привет! Сегодня мы поговорим о **Generics** — одном из самых мощных и важных инструментов в языке Dart. Если вы хотите стать профессиональным Flutter-разработчиком, особенно на уровне **Junior 2**, вы должны понимать, как работают Generics, и уметь их применять.

## Введение в Generics

**Generics** — это способ создания универсальных классов, функций и типов, которые могут работать с разными типами данных, не теряя при этом безопасности типов. Это позволяет писать более гибкий и переиспользуемый код.

В Dart Generics реализуются с помощью **угловых скобок `< >`**, где указывается тип данных.

Например:

```dart
List<String> names = ['Анна', 'Иван'];
List<int> numbers = [1, 2, 3];
```

Здесь `List<String>` и `List<int>` — это обобщенные типы, которые говорят компилятору, что в списке будут храниться строки или числа соответственно.

## Концепция Generics

### Почему нужны Generics?

Допустим, вы хотите создать класс для хранения данных о пользователе. Без Generics вы можете использовать `dynamic`, но это не безопасно с точки зрения типов:

```dart
class User {
  dynamic data;

  User(this.data);
}

void main() {
  var user = User('Иван');
  print(user.data.toUpperCase()); // Работает
}
```

Но если вы передадите число, то получите ошибку во время выполнения:

```dart
var user2 = User(123);
print(user2.data.toUpperCase()); // Ошибка: int не имеет метода toUpperCase()
```

Такая ошибка может быть трудно обнаружена и привести к сбою приложения.

С **Generics** мы можем сделать типобезопасную реализацию:

```dart
class User<T> {
  T data;

  User(this.data);
}

void main() {
  var user = User<String>('Иван');
  print(user.data.toUpperCase()); // OK

  var user2 = User<int>(123);
  // print(user2.data.toUpperCase()); // Ошибка компиляции — int не имеет toUpperCase()
}
```

Таким образом, Generics позволяют:

- Писать универсальный код
- Уменьшить количество ошибок
- Повысить читаемость и поддержку кода

## Ключевое слово `dynamic` и его недостатки по сравнению с Generics

### Что такое `dynamic`?

Ключевое слово `dynamic` в Dart означает, что переменная может содержать значение любого типа. Это очень гибко, но **небезопасно**:

```dart
dynamic value = 'строка';
value = 42;
value = true;
```

Однако `dynamic` не проверяет типы во время компиляции, а значит, ошибки могут возникнуть только во время выполнения.

### Пример: `dynamic` vs `Generic`

#### Без Generics — использование `dynamic`:

```dart
class Container {
  dynamic item;

  Container(this.item);

  void printItem() {
    print(item.toString());
  }
}

void main() {
  var container = Container('Привет');
  container.printItem(); // Привет

  container.item = 123;
  container.printItem(); // 123
}
```

Все работает, но мы теряем типобезопасность.

#### С Generics:

```dart
class Container<T> {
  T item;

  Container(this.item);

  void printItem() {
    print(item.toString());
  }
}

void main() {
  var container = Container<String>('Привет');
  container.printItem(); // Привет

  // Если попробуем передать число:
  // var container2 = Container<String>(123); // Ошибка компиляции
}
```

В этом случае мы получаем **типобезопасность** и **автодополнение в IDE**, что делает код более надежным и удобным для разработки.

## Generics в функциях

Generics можно использовать не только в классах, но и в функциях. Это позволяет создавать универсальные функции, которые работают с любыми типами данных.

### Простой пример:

```dart
T identity<T>(T value) {
  return value;
}

void main() {
  var str = identity<String>('Привет');
  var num = identity<int>(42);
  print(str); // Привет
  print(num); // 42
}
```

### Функция с несколькими параметрами Generics:

```dart
T pair<T, U>(T first, U second) {
  return first;
}

void main() {
  var result = pair<String, int>('Привет', 123);
  print(result); // Привет
}
```

### Использование Generics в функциях с коллекциями:

```dart
List<T> filterByType<T>(List<dynamic> list) {
  return list.where((item) => item is T).cast<T>().toList();
}

void main() {
  List<dynamic> mixedList = [1, 'строка', 2.5, 'еще строка', 42];
  var strings = filterByType<String>(mixedList);
  print(strings); // [строка, еще строка]
}
```

## Generics в классах

Как мы уже видели, Generics можно использовать в классах. Это позволяет создавать универсальные структуры данных.

### Пример: универсальный контейнер:

```dart
class Box<T> {
  T content;

  Box(this.content);

  void printContent() {
    print('Содержимое: $content');
  }

  T getContent() => content;
}

void main() {
  var stringBox = Box<String>('Привет мир');
  var intBox = Box<int>(42);

  stringBox.printContent(); // Содержимое: Привет мир
  intBox.printContent();    // Содержимое: 42

  print(stringBox.getContent()); // Привет мир
}
```

### Пример с несколькими типами:

```dart
class Pair<T, U> {
  T first;
  U second;

  Pair(this.first, this.second);

  void printPair() {
    print('Первое: $first, Второе: $second');
  }
}

void main() {
  var pair = Pair<String, int>('Язык', 2);
  pair.printPair(); // Первое: Язык, Второе: 2
}
```

### Расширение класса с Generics:

```dart
class GenericList<T> {
  List<T> items = [];

  void add(T item) {
    items.add(item);
  }

  T get(int index) => items[index];

  int get length => items.length;
}

void main() {
  var list = GenericList<String>();
  list.add('Привет');
  list.add('Мир');

  print(list.get(0)); // Привет
  print(list.length); // 2
}
```
