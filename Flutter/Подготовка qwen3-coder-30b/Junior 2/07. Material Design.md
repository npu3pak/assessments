# **Лекция: Material Design в Flutter (Уровень Junior 2)**

## 📘 Введение

Material Design — это система дизайна, разработанная Google, которая используется для создания последовательных и эстетичных интерфейсов. Она основана на физических свойствах материалов, таких как тени, движения, цвета и пространство.

Flutter поддерживает Material Design напрямую через пакет `material`, который предоставляет широкий набор компонентов, соответствующих Material Design принципам. Эти компоненты позволяют создавать современные, адаптивные мобильные приложения на Flutter.

## 1️⃣ Базовые принципы и определение Material

### 🔹 Что такое Material Design?

Material Design — это система дизайна, разработанная Google, которая объединяет классические принципы урбанистики с инновациями современных технологий. Основная цель — сделать пользовательский опыт более интуитивным и красивым.

### 🔹 Основные концепции:

- **Материал**: Виртуальный материал, который может иметь тени, подвижность и реалистичное поведение.
- **Поверхности и тени**: Элементы интерфейса представляют собой поверхности с тенями, создающими ощущение глубины.
- **Анимации и переходы**: Они помогают пользователям понимать взаимодействие между элементами.
- **Цвет, типографика и пространство**: Эти элементы используются для создания гармонии и читаемости.

### 🔹 В Flutter

В Flutter, Material Design реализуется через `MaterialApp` — корневой виджет, который обеспечивает:
- Поддержку тем (light/dark)
- Систему навигации
- Анимации переходов между экранами
- Поддержку Material компонентов

Пример:

```dart
void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({Key? key}) : super(key: key);

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Material App',
      theme: ThemeData(
        primarySwatch: Colors.blue,
      ),
      home: const MyHomePage(),
    );
  }
}
```

## 2️⃣ Компоненты 2 редакции (Material 2)

### 🔹 Определение

Material 2 — это первая версия Material Design, выпущенная в 2014 году. Она основана на жёстких правилах и строгих цветовых схемах.

### 🔹 Особенности:

- Строгие правила цветовой палитры
- Чёткие границы элементов
- Многокомпонентные экраны
- Тени и глубина через `Elevation`
- Простые анимации

### 🔹 Основные компоненты:

#### 🧱 `AppBar`:
Создаёт верхнюю панель с заголовком и кнопками.

```dart
AppBar(
  title: const Text('Мой заголовок'),
  actions: [
    IconButton(icon: Icon(Icons.search), onPressed: () {}),
  ],
)
```

#### 🎯 `FloatingActionButton`:
Круглая кнопка, которая обычно используется для главного действия.

```dart
FloatingActionButton(
  onPressed: () {
    // действие
  },
  child: const Icon(Icons.add),
)
```

#### 🧱 `Card`:
Карточка с тенью и скруглёнными углами.

```dart
Card(
  child: Padding(
    padding: EdgeInsets.all(16.0),
    child: Text('Это карточка'),
  ),
)
```

#### 🧱 `Button`:
Кнопки в Material Design — это `ElevatedButton`, `OutlinedButton`, `TextButton`.

```dart
ElevatedButton(
  onPressed: () {},
  child: const Text('Нажми меня'),
)
```

#### 📏 `TextField`:
Поле ввода текста.

```dart
TextField(
  decoration: InputDecoration(
    labelText: 'Введите имя',
    border: OutlineInputBorder(),
  ),
)
```

#### 🔁 `SnackBar`:
Всплывающее сообщение.

```dart
ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(content: Text('Сообщение показано')),
);
```

## 3️⃣ Компоненты 3 редакции (Material 3)

### 🔹 Определение

Material 3 — это обновлённая версия Material Design, выпущенная в 2022 году. Она более гибкая, адаптивная и поддерживает темную тему, темы пользователей и более свободное использование цвета.

### 🔹 Основные изменения:

- **Гибкая палитра цветов**: Используется система Dynamic Color (в Android 12+)
- **Меньше ограничений на дизайн**
- **Упрощённые элементы**
- **Более лёгкие анимации и переходы**
- **Улучшенная поддержка тем и адаптивности**

### 🔹 Примеры компонентов:

#### 🎨 `ColorScheme`:
Определяет цветовую схему приложения.

```dart
final colorScheme = ColorScheme.fromSeed(
  seedColor: Colors.deepPurple,
);

MaterialApp(
  theme: ThemeData(colorScheme: colorScheme),
  home: const MyHomePage(),
)
```

#### 🧱 `ElevatedButton` (новый стиль):
В Material 3 кнопки выглядят более мягкими и сглаженными.

```dart
ElevatedButton(
  onPressed: () {},
  style: ElevatedButton.styleFrom(
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.circular(16),
    ),
  ),
  child: const Text('Кнопка'),
)
```

#### 🧱 `TextField` (с улучшенным стилем):
В Material 3 поля ввода могут использовать более лаконичный дизайн.

```dart
TextField(
  decoration: InputDecoration(
    labelText: 'Введите текст',
    border: OutlineInputBorder(),
    filled: true,
    fillColor: Colors.grey[100],
  ),
)
```

#### 🧱 `BottomNavigationBar`:
Теперь может быть более гибким и подстраиваться под тему.

```dart
BottomNavigationBar(
  items: const [
    BottomNavigationBarItem(icon: Icon(Icons.home), label: 'Главная'),
    BottomNavigationBarItem(icon: Icon(Icons.search), label: 'Поиск'),
  ],
)
```

#### 🎯 `FloatingActionButton` (новый стиль):
Может быть с `extended` свойством.

```dart
FloatingActionButton.extended(
  onPressed: () {},
  icon: const Icon(Icons.add),
  label: const Text('Добавить'),
)
```

## 4️⃣ Отличия между Material 2 и Material 3

| Характеристика       | Material 2                          | Material 3                              |
|----------------------|-------------------------------------|------------------------------------------|
| Цветовая палитра     | Строгие цвета                       | Гибкая палитра с Dynamic Color           |
| Стиль кнопок         | Чёткие формы                        | Более мягкие, сглаженные формы           |
| Анимации             | Простые анимации                    | Упрощённые и гладкие                     |
| Темизация            | Фиксированные темы                  | Гибкая темизация, поддержка Dark Mode    |
| Стиль ввода          | Традиционный                        | Более лаконичный                         |
| Адаптивность         | Ограниченная                        | Высокая адаптивность                     |
