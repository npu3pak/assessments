## 1. Работа со строками

В Dart строки представляют собой объекты типа `String`, которые являются неизменяемыми (immutable).

### Основные методы работы со строками:

#### a) Конкатенация
```dart
String name = "Flutter";
String greeting = "Hello, " + name;
print(greeting); // Hello, Flutter
```

Можно использовать интерполяцию:
```dart
String name = "Dart";
String message = "Привет, $name!";
print(message); // Привет, Dart!
```

#### b) Длина строки
```dart
String str = "Hello";
print(str.length); // 5
```

#### c) Подстроки и извлечение частей строки
```dart
String text = "Flutter is amazing";
String sub = text.substring(0, 6);
print(sub); // Flutter

String lastPart = text.substring(7);
print(lastPart); // is amazing
```

#### d) Поиск подстроки
```dart
String str = "Hello World";
bool contains = str.contains("World");
print(contains); // true

int index = str.indexOf("World");
print(index); // 6
```

#### e) Замена и изменение регистра
```dart
String text = "Hello World";
String replaced = text.replaceAll("World", "Dart");
print(replaced); // Hello Dart

String upperCase = text.toUpperCase();
print(upperCase); // HELLO WORLD

String lowerCase = text.toLowerCase();
print(lowerCase); // hello world
```

#### f) Обрезка пробелов
```dart
String str = "   Hello   ";
String trimmed = str.trim();
print(trimmed); // Hello
```

#### g) Разделение строки на части (split)
```dart
String text = "one,two,three";
List<String> parts = text.split(',');
print(parts); // [one, two, three]
```

#### h) Сравнение строк
```dart
String a = "Hello";
String b = "hello";

bool equal = a == b; // false
bool caseInsensitive = a.toLowerCase() == b.toLowerCase(); // true
```

## 2. Работа с регулярными выражениями

Регулярные выражения позволяют искать, заменять и проверять строки по определённым шаблонам.

### Импорт:
```dart
import 'dart:core';
```

### Основные методы:

#### a) Создание RegExp
```dart
RegExp regExp = RegExp(r'\d+'); // Ищет одну или более цифр
String text = "В номере 123456789 есть цифры";
Iterable<Match> matches = regExp.allMatches(text);
for (Match match in matches) {
  print(match.group(0)); // 123456789
}
```

#### b) Проверка совпадения
```dart
bool isValid = RegExp(r'^[a-zA-Z]+$').hasMatch("Hello");
print(isValid); // true

bool hasNumber = RegExp(r'\d+').hasMatch("abc123");
print(hasNumber); // true
```

#### c) Замена с помощью регулярного выражения
```dart
String text = "Phone: 123-456-7890";
String replaced = text.replaceAllMapped(RegExp(r'\d+'), (Match match) {
  return '[${match.group(0)}]';
});
print(replaced); // Phone: [123]-[456]-[7890]
```

## 3. Работа с URI

URI (Uniform Resource Identifier) — это способ идентификации ресурсов. В Dart есть класс `Uri`, который помогает работать с ними.

### Примеры:

#### a) Создание URI
```dart
Uri uri = Uri.parse("https://example.com/path?query=value");
print(uri.scheme); // https
print(uri.host);   // example.com
print(uri.path);   // /path
print(uri.query);  // query=value
```

#### b) Построение URI
```dart
Uri uri = Uri(
  scheme: 'https',
  host: 'api.example.com',
  path: '/users',
  queryParameters: {
    'page': '1',
    'limit': '20'
  }
);
print(uri.toString()); // https://api.example.com/users?page=1&limit=20
```

#### c) Кодирование и декодирование частей URI
```dart
String encoded = Uri.encodeComponent("Hello World!");
print(encoded); // Hello%20World%21

String decoded = Uri.decodeComponent("Hello%20World%21");
print(decoded); // Hello World!
```

## 4. Разбор и форматирование дат. UTC и Zulu Time Zone

В Dart есть класс `DateTime`, который позволяет работать с датами и временем.

### Основные свойства:

```dart
DateTime now = DateTime.now();
print(now); // 2025-04-05 12:34:56.789

DateTime utcNow = DateTime.now().toUtc();
print(utcNow); // 2025-04-05 09:34:56.789Z
```

### UTC и Zulu Time Zone

**UTC (Coordinated Universal Time)** — всемирное координированное время.  
**Zulu Time Zone** — это сокращение для UTC, часто используется в форматах времени, например, `2025-04-05T12:34:56.789Z`.

В Dart:
```dart
DateTime utc = DateTime.utc(2025, 4, 5, 12, 34, 56);
print(utc); // 2025-04-05 12:34:56.000Z
```

### Время от начала эпохи (Unix timestamp)

Для получения времени с момента начала эпохи (1 января 1970 года):
```dart
DateTime now = DateTime.now();
int timestamp = now.millisecondsSinceEpoch;
print(timestamp); // например: 1712345678901

// Преобразование обратно:
DateTime fromTimestamp = DateTime.fromMillisecondsSinceEpoch(timestamp);
print(fromTimestamp); // 2024-04-05 12:34:56.789
```

### Форматирование даты

Для форматирования можно использовать пакет `intl`:

```yaml
dependencies:
  intl: ^0.18.1
```

```dart
import 'package:intl/intl.dart';

DateTime now = DateTime.now();
String formattedDate = DateFormat('yyyy-MM-dd HH:mm:ss').format(now);
print(formattedDate); // 2025-04-05 12:34:56
```

## 5. Генерация случайных чисел

В Dart можно использовать класс `Random` из стандартной библиотеки.

### Примеры:

```dart
import 'dart:math';

Random random = Random();

int randomInt = random.nextInt(10); // от 0 до 9
print(randomInt);

double randomDouble = random.nextDouble(); // от 0.0 до 1.0
print(randomDouble);

// Генерация числа в диапазоне [start, end)
int range = random.nextInt(50) + 10; // от 10 до 59
print(range);
```

Можно использовать `Random.secure()` для более безопасного генерирования:

```dart
Random secureRandom = Random.secure();
int secureInt = secureRandom.nextInt(1000);
print(secureInt);
```

## 6. Понятие о кодировке символов. Кодирование/декодирование UTF-8

Кодировка UTF-8 — это способ представления текста в виде последовательности байт.

### Примеры:

#### a) Кодирование строки в UTF-8
```dart
String text = "Привет мир";
List<int> bytes = text.codeUnits;
print(bytes); // [1055, 1088, 1080, 1074, 1077, 32, 1084, 1080, 1088]
```

#### b) Декодирование UTF-8 в строку
```dart
List<int> bytes = [1055, 1088, 1080, 1074, 1077, 32, 1084, 1080, 1088];
String decoded = String.fromCharCodes(bytes);
print(decoded); // Привет мир
```

## 7. Класс HttpServer

Класс `HttpServer` из пакета `dart:io` позволяет создавать HTTP-серверы.

### Пример создания простого сервера:

```dart
import 'dart:io';

void main() async {
  HttpServer server = await HttpServer.bind(InternetAddress.anyIPv4, 8080);
  print('Сервер запущен на http://localhost:8080');

  await for (HttpRequest request in server) {
    if (request.uri.path == '/') {
      request.response.write('Привет из Dart!');
      await request.response.close();
    } else {
      request.response.statusCode = HttpStatus.notFound;
      await request.response.close();
    }
  }
}
```
