## Введение в Material Widgets

Если вы начинаете изучать **Flutter**, то наверняка уже сталкивались с термином *Material Design*. Это система дизайна, разработанная Google, которая предоставляет набор рекомендаций и компонентов для создания современных интерфейсов.  
**Material Widgets** — это набор встроенных виджетов Flutter, реализующих принципы Material Design. Они позволяют быстро создавать красивые, интуитивно понятные приложения с использованием стандартных элементов, таких как кнопки, текстовые поля, списки и т.д.

Все эти виджеты построены на основе **Material Design** — иерархии поверхностей (Surfaces), теней, анимаций и взаимодействия с пользователем. Используя Material Widgets, вы получаете приложения, которые выглядят привычно для пользователей Android и iOS.

---

## Что такое Material Widgets?

**Material Widgets** — это набор встроенных виджетов Flutter, которые реализуют дизайн-систему **Material Design** от Google. Эти виджеты обеспечивают:
- Привычное поведение для пользователей (например, кнопки реагируют на нажатие с эффектом).
- Адаптацию под разные устройства и ориентации.
- Поддержку тем, анимаций, теней и других элементов Material Design.

Каждый Material Widget может быть легко стилизован, изменён и использован в рамках вашего приложения. Они не только упрощают разработку, но и делают её более согласованной и профессиональной.

## Виджет Material

### Что такое виджет?

В Flutter **виджет (Widget)** — это основная единица построения пользовательского интерфейса. Он описывает часть экрана: текст, кнопку, изображение или даже целую страницу.

**Material Widget** — это специальный тип виджетов, которые:
- Используют Material Design компоненты.
- Следуют правилам анимации и взаимодействия.
- Поддерживают темы (light/dark).
- Работают с системой `MaterialApp`.

### Пример: простая кнопка

```dart
MaterialButton(
  onPressed: () {
    print("Кнопка нажата!");
  },
  child: Text("Нажми меня"),
)
```

Здесь `MaterialButton` — это Material Widget. Он автоматически добавляет эффекты, такие как тень и анимацию при нажатии.

### Как работает MaterialApp?

Все Material Widgets работают внутри виджета `MaterialApp`, который устанавливает тему, поддерживает навигацию и обеспечивает корректную работу с анимациями и тенями.

```dart
void main() {
  runApp(
    MaterialApp(
      title: 'My App',
      home: Scaffold(
        appBar: AppBar(title: Text('Material App')),
        body: Center(child: Text('Hello, Flutter!')),
      ),
    ),
  );
}
```

## Какие Material Widgets есть в комплекте Flutter

Flutter предоставляет широкий набор **Material Widgets**, которые можно использовать для создания интерфейсов. Ниже приведены наиболее часто используемые:

---

### 1. **AppBar**

Отображает верхнюю панель с заголовком и действиями.

```dart
AppBar(
  title: Text("Заголовок"),
  leading: Icon(Icons.menu),
  actions: [
    IconButton(icon: Icon(Icons.search), onPressed: () {}),
  ],
)
```

---

### 2. **Scaffold**

Базовая структура экрана с `AppBar`, `body` и другими элементами.

```dart
Scaffold(
  appBar: AppBar(title: Text("Главная")),
  body: Center(child: Text("Основное содержимое")),
)
```

---

### 3. **Button Widgets**

#### MaterialButton

Простая кнопка с эффектом при нажатии:

```dart
MaterialButton(
  onPressed: () {},
  child: Text("Кнопка"),
  color: Colors.blue,
)
```

#### RaisedButton / ElevatedButton (новый вариант)

```dart
ElevatedButton(
  onPressed: () {},
  child: Text("Поднять кнопку"),
)
```

#### FlatButton / TextButton

Текстовая кнопка без фона:

```dart
TextButton(
  onPressed: () {},
  child: Text("Текстовая кнопка"),
)
```

---

### 4. **TextField**

Виджет для ввода текста.

```dart
TextField(
  decoration: InputDecoration(
    labelText: "Введите имя",
    border: OutlineInputBorder(),
  ),
)
```

---

### 5. **ListView / ListTile**

Для отображения списков элементов:

```dart
ListView(
  children: [
    ListTile(
      title: Text("Элемент 1"),
      subtitle: Text("Описание"),
    ),
    ListTile(
      title: Text("Элемент 2"),
      subtitle: Text("Описание"),
    ),
  ],
)
```

---

### 6. **Dialog**

Диалоговое окно:

```dart
showDialog(
  context: context,
  builder: (context) {
    return AlertDialog(
      title: Text("Заголовок"),
      content: Text("Текст диалога"),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(context),
          child: Text("Отмена"),
        ),
      ],
    );
  },
);
```

---

### 7. **SnackBar**

Всплывающее уведомление:

```dart
ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(content: Text("Сообщение")),
);
```

---

### 8. **BottomNavigationBar / BottomAppBar**

Навигационная панель внизу экрана:

```dart
BottomNavigationBar(
  items: [
    BottomNavigationBarItem(icon: Icon(Icons.home), label: "Главная"),
    BottomNavigationBarItem(icon: Icon(Icons.settings), label: "Настройки"),
  ],
)
```

---

### 9. **Card**

Карточка — популярный элемент Material Design:

```dart
Card(
  child: Padding(
    padding: EdgeInsets.all(16),
    child: Column(
      children: [
        Text("Заголовок"),
        Text("Описание"),
      ],
    ),
  ),
)
```

---

### 10. **Checkbox / Switch**

Флажки и переключатели:

```dart
Checkbox(
  value: isChecked,
  onChanged: (value) {
    setState(() {
      isChecked = value!;
    });
  },
)

Switch(
  value: isOn,
  onChanged: (value) {
    setState(() {
      isOn = value;
    });
  },
)
```

---

### 11. **Slider / RangeSlider**

Ползунок для выбора значения:

```dart
Slider(
  value: _currentValue,
  min: 0,
  max: 100,
  onChanged: (value) {
    setState(() {
      _currentValue = value;
    });
  },
)
```

---

### 12. **ProgressIndicator**

Индикатор загрузки:

```dart
CircularProgressIndicator() // Круглый индикатор
LinearProgressIndicator() // Линейный индикатор
```
