# Лекция 04: Интеграционное тестирование Flutter

## Введение

Добро пожаловать в лекцию по интеграционному тестированию в Flutter. Эта тема является важной частью разработки качественных мобильных приложений, поскольку интеграционные тесты позволяют проверять взаимодействие между различными частями вашего приложения как единым целым.

## 1. Назначение и возможности интеграционного тестирования

### Что такое интеграционное тестирование?

Интеграционное тестирование (Integration Testing) — это тип тестирования, при котором проверяется взаимодействие между разными модулями или компонентами программного обеспечения. В контексте Flutter это означает тестирование взаимодействия между виджетами, логикой бизнес-процессов и другими частями приложения.

### Цели интеграционного тестирования:

1. **Проверка взаимодействия компонентов**: Убедиться, что различные части приложения работают вместе корректно.
2. **Обнаружение ошибок на границах модулей**: Найти проблемы, возникающие при взаимодействии между различными частями системы.
3. **Проверка бизнес-логики**: Убедиться, что логика работы приложения соответствует ожиданиям.
4. **Обеспечение стабильности**: Предотвратить регрессию (возникновение новых ошибок) при внесении изменений.

### Особенности интеграционных тестов в Flutter:

В Flutter интеграционные тесты выполняются на уровне "реального" приложения. Они запускаются на эмуляторе или реальном устройстве и позволяют проверить:
- Правильность отображения интерфейса
- Работу с состоянием приложения
- Взаимодействие между экранами
- Поток данных между различными частями приложения

### Преимущества интеграционного тестирования:

1. **Реалистичная проверка**: Тесты работают в условиях, максимально приближенных к реальному использованию.
2. **Покрытие сложных сценариев**: Позволяет проверить сложные пользовательские сценарии.
3. **Обнаружение проблем на ранней стадии**: Помогает выявить ошибки до их появления у пользователей.

## 2. Написание интеграционных тестов

### Структура интеграционного теста

Интеграционные тесты в Flutter обычно создаются в папке `test_driver` и используют фреймворк `integration_test`.

Пример базовой структуры:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  group('Main App Test', () {
    testWidgets('should display home screen correctly', (WidgetTester tester) async {
      // Тестирование отображения главного экрана
      await tester.pumpWidget(const MyApp());
      await tester.pumpAndSettle();
      
      expect(find.text('Welcome'), findsOneWidget);
    });
  });
}
```

### Основные элементы интеграционного теста

#### 1. Инициализация тестовой среды

```dart
import 'package:integration_test/integration_test.dart';

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();
  // Здесь происходит инициализация среды для запуска интеграционных тестов
}
```

#### 2. Группировка тестов

Используйте `group()` для структурирования тестов:

```dart
group('User Authentication Flow', () {
  testWidgets('should login successfully with valid credentials', (WidgetTester tester) async {
    // Тест логина
  });

  testWidgets('should show error message for invalid password', (WidgetTester tester) async {
    // Тест ошибки входа
  });
});
```

#### 3. Основные методы тестирования

##### a) `pumpWidget()`
Метод для отображения виджета на экране:

```dart
await tester.pumpWidget(MyApp());
```

##### b) `pumpAndSettle()`
Ожидание завершения всех анимаций и изменений:

```dart
await tester.pumpAndSettle();
```

##### c) `tap()`
Симуляция нажатия на элемент:

```dart
await tester.tap(find.byText('Login'));
```

##### d) `enterText()`
Ввод текста в поле ввода:

```dart
await tester.enterText(find.byType(TextField), 'test@example.com');
```

#### 4. Поиск виджетов

Используйте различные методы для поиска элементов:

```dart
// По тексту
find.text('Welcome')

// По типу виджета
find.byType(TextButton)

// По ключу
find.byKey(const ValueKey('login_button'))

// По ID (если установлен)
find.byWidgetPredicate((widget) => widget is Text && widget.data == 'Hello')
```

### Пример комплексного интеграционного теста

Рассмотрим пример приложения с формой регистрации:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';

class RegistrationForm extends StatefulWidget {
  const RegistrationForm({Key? key}) : super(key: key);

  @override
  State<RegistrationForm> createState() => _RegistrationFormState();
}

class _RegistrationFormState extends State<RegistrationForm> {
  final _formKey = GlobalKey<FormState>();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Registration')),
      body: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                controller: _emailController,
                decoration: const InputDecoration(labelText: 'Email'),
                validator: (value) {
                  if (value == null || value.isEmpty) {
                    return 'Please enter email';
                  }
                  return null;
                },
              ),
              TextFormField(
                controller: _passwordController,
                decoration: const InputDecoration(labelText: 'Password'),
                obscureText: true,
                validator: (value) {
                  if (value == null || value.isEmpty) {
                    return 'Please enter password';
                  }
                  return null;
                },
              ),
              ElevatedButton(
                onPressed: () {
                  if (_formKey.currentState!.validate()) {
                    // Обработка регистрации
                    Navigator.pushReplacementNamed(context, '/success');
                  }
                },
                child: const Text('Register'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  group('Registration Form Test', () {
    testWidgets('should show validation error for empty fields', (WidgetTester tester) async {
      // Подготовка
      await tester.pumpWidget(MaterialApp(
        home: const RegistrationForm(),
      ));

      // Нажимаем кнопку регистрации без заполнения полей
      await tester.tap(find.text('Register'));
      await tester.pumpAndSettle();

      // Проверяем, что появилось сообщение об ошибке
      expect(find.text('Please enter email'), findsOneWidget);
      expect(find.text('Please enter password'), findsOneWidget);
    });

    testWidgets('should navigate to success screen with valid input', (WidgetTester tester) async {
      // Подготовка
      await tester.pumpWidget(MaterialApp(
        home: const RegistrationForm(),
        routes: {
          '/success': (context) => const Scaffold(body: Text('Success')),
        },
      ));

      // Заполняем поля
      await tester.enterText(find.byPlaceholder('Email'), 'test@example.com');
      await tester.enterText(find.byPlaceholder('Password'), 'password123');

      // Нажимаем кнопку регистрации
      await tester.tap(find.text('Register'));
      await tester.pumpAndSettle();

      // Проверяем, что перешли на экран успеха
      expect(find.text('Success'), findsOneWidget);
    });
  });
}
```

### Тестирование асинхронных операций

```dart
testWidgets('should handle API call correctly', (WidgetTester tester) async {
  // Подготовка mock-сервиса
  final mockApiService = MockApiService();
  when(mockApiService.login(any, any)).thenAnswer((_) async => 'token');

  await tester.pumpWidget(MaterialApp(
    home: LoginScreen(apiService: mockApiService),
  ));

  await tester.enterText(find.byPlaceholder('Email'), 'user@example.com');
  await tester.enterText(find.byPlaceholder('Password'), 'password');

  await tester.tap(find.text('Login'));
  
  // Ожидание завершения асинхронной операции
  await tester.pumpAndSettle();

  verify(mockApiService.login('user@example.com', 'password')).called(1);
});
```

## 3. Запуск интеграционных тестов

### Подготовка к запуску

Для запуска интеграционных тестов необходимо:
1. Создать файл в папке `test_driver`
2. Убедиться, что `integration_test` добавлен в зависимости
3. Настроить файл конфигурации

### Зависимости

В `pubspec.yaml`:

```yaml
dev_dependencies:
  integration_test:
    sdk: flutter
  flutter_test:
    sdk: flutter
```

### Запуск тестов через командную строку

#### Запуск всех интеграционных тестов:

```bash
flutter test integration_test/app_test.dart
```

#### Запуск на конкретном устройстве:

```bash
flutter test integration_test/app_test.dart --device-id=emulator-5554
```

#### Запуск с определённым логированием:

```bash
flutter test integration_test/app_test.dart --verbose
```

### Использование конфигурационного файла

Создайте файл `integration_test/app_test.dart`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  testWidgets('Main app functionality', (WidgetTester tester) async {
    // Ваш код теста здесь
    await tester.pumpWidget(const MyApp());
    await tester.pumpAndSettle();
    
    // Добавьте ваши проверки
    expect(find.text('Hello'), findsOneWidget);
  });
}
```

### Запуск в CI/CD

Для автоматизации запуска тестов в CI/CD:

```yaml
# .github/workflows/flutter_test.yml
name: Flutter Integration Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v2
      - uses: subosito/flutter-action@v1
        with:
          channel: 'stable'
          
      - run: flutter pub get
      - run: flutter test integration_test/app_test.dart
```
