# Лекция: Android. REST-клиент

## Введение

В современном мобильном приложении, особенно в Flutter-приложениях, работа с сетью — это один из ключевых навыков разработчика. REST-клиент позволяет взаимодействовать с сервером, получать данные, отправлять запросы и обрабатывать ответы. В этой лекции мы рассмотрим, как реализовать REST-клиент в Android-приложениях с использованием популярных библиотек: **Gson**, **Retrofit** и **OkHttp**, а также рассмотрим, как работать с JSON-данными.

---

## 1. Работа с JSON с помощью Gson, Jackson или Moshi

### Что такое JSON?

JSON (JavaScript Object Notation) — это текстовый формат обмена данными, который используется для передачи данных между клиентом и сервером. В Android приложениях мы часто получаем JSON-ответы от API, а затем должны их преобразовать в объекты, чтобы использовать их в коде.

Пример JSON:

```json
{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com"
}
```

### 1.1. Gson

**Gson** — это библиотека от Google, которая используется для преобразования Java-объектов в JSON и обратно.

#### Установка

В `pubspec.yaml` добавьте:

```yaml
dependencies:
  gson: ^0.2.2
```

#### Пример использования

Создадим модель данных:

```dart
class User {
  final int id;
  final String name;
  final String email;

  User({
    required this.id,
    required this.name,
    required this.email,
  });

  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      id: json['id'],
      name: json['name'],
      email: json['email'],
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'name': name,
      'email': email,
    };
  }
}
```

Пример использования:

```dart
import 'dart:convert';

void main() {
  String jsonString = '''
    {
      "id": 1,
      "name": "John Doe",
      "email": "john@example.com"
    }
  ''';

  Map<String, dynamic> jsonMap = jsonDecode(jsonString);
  User user = User.fromJson(jsonMap);

  print(user.name); // John Doe
}
```

### 1.2. Jackson

**Jackson** — это мощная библиотека для работы с JSON в Java (используется в Android). Однако в Flutter мы используем Dart, и Jackson неприменим напрямую.

> ❗ В Dart-проектах Jackson не используется. Вместо этого мы используем `jsonDecode` и `jsonEncode` из стандартной библиотеки `dart:convert`.

### 1.3. Moshi

**Moshi** — это современная библиотека для работы с JSON в Android, разработанная Square. В Dart она также не используется напрямую.

> ❗ В Flutter мы используем стандартные средства Dart (`jsonDecode`, `jsonEncode`) или сторонние пакеты типа `json_annotation` + `json_serializable`.

## 2. Отправка запросов с помощью OkHttp или Retrofit

### 2.1. OkHttp

**OkHttp** — это библиотека для работы с HTTP-запросами в Android. Она предоставляет низкоуровневый доступ к сетевым вызовам и поддерживает такие функции, как:

- Логирование запросов
- Обработка ошибок
- Поддержка SSL/TLS
- Прокси и т.д.

#### Установка

В `pubspec.yaml` добавьте:

```yaml
dependencies:
  http: ^0.13.5
```

> ❗ В Flutter для работы с HTTP используется пакет `http`. Он построен на основе `OkHttp` для Android, но предоставляет удобный Dart-интерфейс.

#### Пример использования

```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

Future<void> fetchUser() async {
  final response = await http.get(
    Uri.parse('https://jsonplaceholder.typicode.com/users/1'),
  );

  if (response.statusCode == 200) {
    Map<String, dynamic> userData = jsonDecode(response.body);
    print(userData['name']); // Leanne Graham
  } else {
    throw Exception('Failed to load user');
  }
}
```

#### Отправка POST-запроса

```dart
Future<void> createUser() async {
  final response = await http.post(
    Uri.parse('https://jsonplaceholder.typicode.com/users'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({
      'name': 'John Doe',
      'email': 'john@example.com',
    }),
  );

  if (response.statusCode == 201) {
    print('User created');
  } else {
    throw Exception('Failed to create user');
  }
}
```

### 2.2. Retrofit

**Retrofit** — это высокоуровневая библиотека для работы с REST API, которая использует OkHttp в качестве底层 HTTP-клиента.

В Flutter нет прямой поддержки Retrofit, но можно использовать аналоги.

#### Как работает Retrofit?

Retrofit позволяет описывать API в виде интерфейсов и автоматически генерирует код для вызова методов.

Пример:

```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

class ApiService {
  static const String baseUrl = 'https://jsonplaceholder.typicode.com';

  static Future<List<dynamic>> fetchUsers() async {
    final response = await http.get(
      Uri.parse('$baseUrl/users'),
    );

    if (response.statusCode == 200) {
      return jsonDecode(response.body);
    } else {
      throw Exception('Failed to load users');
    }
  }

  static Future<Map<String, dynamic>> fetchUser(int id) async {
    final response = await http.get(
      Uri.parse('$baseUrl/users/$id'),
    );

    if (response.statusCode == 200) {
      return jsonDecode(response.body);
    } else {
      throw Exception('Failed to load user');
    }
  }

  static Future<Map<String, dynamic>> createUser(Map<String, dynamic> userData) async {
    final response = await http.post(
      Uri.parse('$baseUrl/users'),
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode(userData),
    );

    if (response.statusCode == 201) {
      return jsonDecode(response.body);
    } else {
      throw Exception('Failed to create user');
    }
  }
}
```

## 3. Работа с JSON-моделями и их маппингом

### Использование `json_serializable` (рекомендуется)

Для автоматического маппинга JSON в Dart-объекты можно использовать пакет `json_annotation` и `json_serializable`.

#### Установка:

```yaml
dependencies:
  json_annotation: ^4.8.1

dev_dependencies:
  build_runner: ^2.4.7
  json_serializable: ^6.7.1
```

#### Пример:

```dart
import 'package:json_annotation/json_annotation.dart';

@JsonSerializable()
class User {
  final int id;
  final String name;
  final String email;

  User({
    required this.id,
    required this.name,
    required this.email,
  });

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);

  Map<String, dynamic> toJson() => _$UserToJson(this);
}
```

#### Генерация кода:

Запустите:

```bash
flutter pub run build_runner build
```

Теперь вы можете использовать:

```dart
String json = '''
{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com"
}
''';

User user = User.fromJson(jsonDecode(json));
print(user.name); // John Doe
```

## 4. Практические рекомендации

### Лучшие практики:

- Используйте `http` или `dio` для выполнения HTTP-запросов.
- Применяйте `json_serializable` для автоматического маппинга JSON.
- Обрабатывайте ошибки (например, сетевые сбои, неверный статус).
- Используйте `Future` и `async/await`.
- Используйте `try/catch` при работе с сетью.
