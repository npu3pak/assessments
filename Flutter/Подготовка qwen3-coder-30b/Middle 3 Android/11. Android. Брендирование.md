# **Лекция: Android. Брендирование приложения в Flutter**

---

## **Введение**

Брендирование — это процесс создания уникального внешнего вида и восприятия приложения пользователем. В контексте Android-разработки брендирование включает настройку темы, логотипа, названия, экрана запуска (splash screen) и других элементов интерфейса, которые формируют первое впечатление о вашем приложении.

Flutter — кроссплатформенный фреймворк, который позволяет создавать красивые и функциональные мобильные приложения. Однако важно понимать, как настраивать брендирование на уровне Android-сборки (в том числе с использованием Dart/Flutter), особенно если вы работаете в среде, где нужно учитывать системные настройки и требования к внешнему виду.

---

## **1. Базовая настройка темы приложения с помощью XML**

### **Что такое тема приложения?**

Тема — это набор стилей, которые определяют внешний вид элементов интерфейса в Android-приложении. Темы могут включать цвета, шрифты, размеры и другие параметры.

В Flutter темы управляются через `ThemeData`, но приложение может использовать системные темы Android (например, Dark/Light mode) или настраивать собственные темы с помощью XML-файлов в Android-проекте.

### **Где находятся темы?**

Темы задаются в файле `styles.xml` в директории:
```
android/app/src/main/res/values/styles.xml
```

### **Пример базовой настройки темы:**

```xml
<resources>
    <!-- Основная тема приложения -->
    <style name="AppTheme" parent="Theme.AppCompat.Light.DarkActionBar">
        <!-- Цвет основной панели инструментов (Toolbar) -->
        <item name="colorPrimary">@color/colorPrimary</item>
        <!-- Цвет статус-бара -->
        <item name="colorPrimaryDark">@color/colorPrimaryDark</item>
        <!-- Цвет элементов интерфейса (кнопки, текст и т.д.) -->
        <item name="colorAccent">@color/colorAccent</item>
    </style>
</resources>
```

### **Комментарии:**

- `colorPrimary` — основной цвет приложения (обычно используется в AppBar).
- `colorPrimaryDark` — цвет статус-бара.
- `colorAccent` — используется для акцентных элементов, например, кнопок и чекбоксов.

### **Как использовать тему в AndroidManifest.xml:**

В файле `AndroidManifest.xml` указывается, какая тема будет применяться к приложению:

```xml
<activity
    android:name=".MainActivity"
    android:theme="@style/AppTheme">
</activity>
```

### **Применение темы в Flutter:**

Flutter предоставляет свой способ управления темами через `MaterialApp`, но вы можете использовать системные темы Android, если настроите их правильно.

Пример:

```dart
MaterialApp(
  theme: ThemeData(
    primarySwatch: Colors.blue,
    brightness: Brightness.light,
  ),
  darkTheme: ThemeData(
    primarySwatch: Colors.blue,
    brightness: Brightness.dark,
  ),
  home: MyHomePage(),
)
```

### **Важно:**  
Если вы используете `MaterialApp` с темами, они могут конфликтовать с темами Android, особенно при использовании темной темы. В этом случае рекомендуется настраивать темы как в Flutter, так и в XML.

## **2. Кастомизация названия приложения**

### **Что такое название приложения?**

Название приложения отображается в меню приложений, на экране запуска и в системной информации.

### **Где задается название?**

В файле `AndroidManifest.xml`:

```xml
<activity
    android:name=".MainActivity"
    android:label="@string/app_name">
</activity>
```

### **Что такое `@string/app_name`?**

Это ссылка на строку в файле `strings.xml`:

```xml
<!-- android/app/src/main/res/values/strings.xml -->
<resources>
    <string name="app_name">Моё Приложение</string>
</resources>
```

### **Различные названия:**

Вы можете использовать разные строки для разных языков:

```xml
<!-- android/app/src/main/res/values-en/strings.xml -->
<resources>
    <string name="app_name">My App</string>
</resources>
```

## **3. Кастомизация значка приложения (Icon)**

### **Что такое значок приложения?**

Значок — это изображение, которое отображается в меню приложений, на экране запуска и в системных уведомлениях.

### **Форматы значков:**

- `png`
- `webp` (рекомендуется для Android 8.0+)
- Размеры:
  - `mdpi` — 48x48 px
  - `hdpi` — 72x72 px
  - `xhdpi` — 96x96 px
  - `xxhdpi` — 144x144 px
  - `xxxhdpi` — 192x192 px

### **Расположение значков:**

Папки для иконок:

```
android/app/src/main/res/mipmap-mdpi/
android/app/src/main/res/mipmap-hdpi/
android/app/src/main/res/mipmap-xhdpi/
android/app/src/main/res/mipmap-xxhdpi/
android/app/src/main/res/mipmap-xxxhdpi/
```

### **Задание иконки в AndroidManifest.xml:**

```xml
<activity
    android:name=".MainActivity"
    android:icon="@mipmap/ic_launcher">
</activity>
```

### **Создание иконок:**

Для генерации иконок рекомендуется использовать:

- [https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html](https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html)
- Или визуальные редакторы в Android Studio.

## **4. Кастомизация экрана запуска (Splash Screen)**

### **Что такое экран запуска?**

Экран запуска — это изображение, которое отображается при старте приложения до того, как интерфейс будет полностью загружен.

### **Настройка через XML:**

Создайте папку `drawable` в `res`:

```
android/app/src/main/res/drawable/splash_screen.xml
```

Пример файла `splash_screen.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<layer-list xmlns:android="http://schemas.android.com/apk/res/android">
    <item android:drawable="@color/splash_background"/>
    <item>
        <bitmap
            android:gravity="center"
            android:src="@mipmap/splash_logo"/>
    </item>
</layer-list>
```

### **Использование в теме:**

В `styles.xml`:

```xml
<style name="SplashTheme" parent="Theme.AppCompat.Light.NoActionBar">
    <item name="android:windowBackground">@drawable/splash_screen</item>
</style>
```

### **Применение темы к MainActivity:**

```xml
<activity
    android:name=".MainActivity"
    android:theme="@style/SplashTheme">
</activity>
```

> ⚠️ В новых версиях Android (API 29+) рекомендуется использовать `SplashScreen` API.
