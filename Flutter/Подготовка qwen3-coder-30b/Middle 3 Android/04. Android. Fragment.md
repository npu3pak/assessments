# Лекция: **Android Fragment**

---

## Введение

Фрагменты (Fragment) в Android — это составные части интерфейса, которые можно использовать внутри активности (Activity). Они позволяют создавать гибкие и многоразовые UI-компоненты, которые могут быть объединены в одну активность или использованы в нескольких активностях. Фрагменты особенно полезны при разработке адаптивных интерфейсов, особенно для мобильных устройств с различными размерами экранов.

---

## 1. Назначение Fragment

Фрагменты были введены в Android API 11 (Android 3.0) как способ создания более гибкой и многоразовой архитектуры UI. Они позволяют:

- **Разделить логику и UI** на более мелкие компоненты.
- **Использовать один и тот же фрагмент в разных активностях**.
- **Создавать адаптивные интерфейсы**, которые изменяются в зависимости от размера экрана (например, в планшетах фрагменты могут быть размещены параллельно).
- **Управлять состоянием фрагмента** во время пересоздания активности.

> В Flutter фрагменты аналогичны `Widget`'ам, которые можно переиспользовать и встраивать в другие виджеты — но с более глубоким управлением жизненным циклом и состоянием.

## 2. Как создать фрагмент с простой версткой в XML

### 2.1 Создание Fragment класса

Для создания фрагмента необходимо создать класс, который наследуется от `Fragment`. В этом классе реализуются методы жизненного цикла и логика отображения.

Пример:

```dart
import 'package:flutter/material.dart';

class MyFragment extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Мой фрагмент')),
      body: Center(
        child: Text('Это контент фрагмента'),
      ),
    );
  }
}
```

> В Flutter нет прямого аналога `Fragment` класса, но можно использовать `StatelessWidget` или `StatefulWidget`, чтобы создать компонент, который может быть встроен в другой виджет.

Если ты хочешь имитировать поведение фрагмента — используй `PageView`, `BottomSheet`, или просто вкладки (`TabBar`) внутри `Scaffold`.

---

### 2.2 Как сделать фрагмент с XML-версткой (в Android)

В Android, чтобы создать фрагмент с версткой из XML:

1. Создаем `fragment_layout.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView
        android:id="@+id/textView"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Привет из фрагмента!" />

</LinearLayout>
```

2. Создаем класс `MyFragment.java`:

```java
public class MyFragment extends Fragment {
    @Override
    public View onCreateView(LayoutInflater inflater, ViewGroup container,
                             Bundle savedInstanceState) {
        // Загружаем layout фрагмента
        View view = inflater.inflate(R.layout.fragment_layout, container, false);
        return view;
    }
}
```

## 3. Операции над фрагментами. Fragment Manager

В Android фрагменты управляются через `FragmentManager`. Это основной класс для добавления, удаления, замены фрагментов в активности.

### 3.1 Основные операции с фрагментами:

- `add()` — добавляет фрагмент в контейнер.
- `replace()` — заменяет фрагмент.
- `remove()` — удаляет фрагмент.
- `hide()` / `show()` — скрывает или показывает фрагмент.
- `commit()` — применяет изменения.

### 3.2 Пример использования FragmentManager в Java:

```java
FragmentManager fragmentManager = getSupportFragmentManager();
FragmentTransaction transaction = fragmentManager.beginTransaction();

MyFragment fragment = new MyFragment();
transaction.add(R.id.fragment_container, fragment);
transaction.commit();
```

> В Flutter фрагменты можно эмулировать с помощью `Navigator` и `PageView`, или же использовать `BottomSheet`, `Dialog`, `TabBar`, и т.д., чтобы создавать "фрагментоподобные" элементы.

## 4. Жизненный цикл фрагментов

Жизненный цикл фрагмента очень важен для управления ресурсами, состоянием и обработки событий. Он включает следующие методы:

### 4.1 Основные методы жизненного цикла:

| Метод | Описание |
|-------|----------|
| `onAttach()` | Вызывается при присоединении фрагмента к активности |
| `onCreate()` | Создание фрагмента |
| `onCreateView()` | Создание UI фрагмента (возвращает View) |
| `onViewCreated()` | После создания view, можно работать с элементами |
| `onStart()` | Фрагмент стал видимым |
| `onResume()` | Фрагмент активен и взаимодействует с пользователем |
| `onPause()` | Потеря фокуса |
| `onStop()` | Фрагмент больше не виден |
| `onDestroyView()` | UI фрагмента уничтожено |
| `onDestroy()` | Уничтожение фрагмента |
| `onDetach()` | Фрагмент отсоединен от активности |

### 4.2 Пример реализации жизненного цикла в Android:

```java
public class MyFragment extends Fragment {
    @Override
    public void onCreate(@Nullable Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        Log.d("MyFragment", "onCreate");
    }

    @Nullable
    @Override
    public View onCreateView(@NonNull LayoutInflater inflater, @Nullable ViewGroup container,
                             @Nullable Bundle savedInstanceState) {
        Log.d("MyFragment", "onCreateView");
        return inflater.inflate(R.layout.fragment_layout, container, false);
    }

    @Override
    public void onViewCreated(@NonNull View view, @Nullable Bundle savedInstanceState) {
        super.onViewCreated(view, savedInstanceState);
        Log.d("MyFragment", "onViewCreated");
    }

    @Override
    public void onResume() {
        super.onResume();
        Log.d("MyFragment", "onResume");
    }

    @Override
    public void onDestroy() {
        super.onDestroy();
        Log.d("MyFragment", "onDestroy");
    }
}
```

## 5. Взаимодействие между фрагментами и активностями

Фрагменты могут взаимодействовать с активностями через:

- `getActivity()` — получение ссылки на активность
- `onAttach()` — передача данных от активности к фрагменту
- `setArguments()` / `getArguments()` — передача данных между фрагментами

Пример:

```java
Bundle args = new Bundle();
args.putString("message", "Hello from Activity");
MyFragment fragment = new MyFragment();
fragment.setArguments(args);
```

## 6. В Flutter: аналоги Fragment

Так как Flutter не имеет понятия `Fragment`, для достижения аналогичного поведения можно использовать:

- **`PageView`** — для создания переключаемых фрагментов.
- **`BottomSheet`** — для временного отображения "фрагмента".
- **`TabBarView`** — для вкладок, которые работают как фрагменты.
- **`Navigator.push()`** — переход между экранами (аналогичен `replace()`).
- **`StatefulWidget` и `State`** — для управления состоянием фрагмента.

Пример:

```dart
class MyFragment extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Фрагмент')),
      body: Center(
        child: Text('Это фрагмент'),
      ),
    );
  }
}
```
