# Лекция: Взаимодействие с другими приложениями в Android (Flutter)

## Введение

В мире мобильной разработки взаимодействие между приложениями — это ключевой элемент функциональности. Особенно это важно для Flutter-разработчиков, которые работают с Android и iOS платформами, где Android предоставляет мощные механизмы для обмена данными между приложениями.

В этой лекции мы рассмотрим три важных аспекта взаимодействия приложений в Android:

1. **Использование Intent для открытия других приложений**
2. **Использование IntentFilters для обработки вызовов из других приложений**
3. **AccountManager — назначение и возможности**

Все это применимо как к классическим Android-приложениям, так и к Flutter-проектам, где мы можем использовать **Android Embedding API** или **Platform Channels** для взаимодействия с нативными компонентами.

## 1. Использование Intent для открытия других приложений

### Что такое Intent?

`Intent` — это объект, который позволяет запускать компоненты Android (Activity, Service, Broadcast Receiver) и передавать данные между ними. В контексте взаимодействия с другими приложениями `Intent` используется для отправки сообщений другим приложениям, чтобы они выполняли определённые действия.

### Типы Intent:

- **Explicit Intent** — явный Intent, который указывает конкретный компонент (например, запуск определённой Activity).
- **Implicit Intent** — неявный Intent, который указывает на тип действия, которое должно быть выполнено. Android сам определяет, какое приложение будет обрабатывать такой Intent.

### Пример: Открытие другого приложения

В Flutter мы можем использовать `MethodChannel` для взаимодействия с нативным кодом на Android. Ниже приведён пример, как можно открыть Google Maps из Flutter-приложения:

#### 1. Нативный код (Android):

```java
// MainActivity.java
import io.flutter.embedding.android.FlutterActivity;
import android.content.Intent;
import android.net.Uri;

public class MainActivity extends FlutterActivity {
    private static final String CHANNEL = "com.example.app/native";

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);

        new MethodChannel(getFlutterEngine().getDartExecutor(), CHANNEL)
            .setMethodCallHandler((call, result) -> {
                if ("openMaps".equals(call.method)) {
                    Intent intent = new Intent(Intent.ACTION_VIEW);
                    intent.setData(Uri.parse("geo:0,0?q=Central Park"));
                    startActivity(intent);
                    result.success(true);
                } else {
                    result.notImplemented();
                }
            });
    }
}
```

#### 2. Flutter-код:

```dart
import 'package:flutter/services.dart';

class NativeService {
  static const MethodChannel _channel = MethodChannel('com.example.app/native');

  static Future<void> openMaps() async {
    try {
      await _channel.invokeMethod('openMaps');
    } on PlatformException catch (e) {
      print("Failed to open maps: ${e.message}");
    }
  }
}

// Использование:
ElevatedButton(
  onPressed: () => NativeService.openMaps(),
  child: Text('Открыть Google Maps'),
);
```

### Практические примеры Intent:

#### 1. Открытие URL в браузере:

```java
Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse("https://www.google.com"));
startActivity(intent);
```

#### 2. Открытие телефона для звонка:

```java

startActivity(intent);
```

#### 3. Открытие камеры:

```java

startActivityForResult(intent, REQUEST_CODE);
```

## 2. Использование IntentFilters для обработки вызовов из других приложений

### Что такое IntentFilter?

`IntentFilter` — это механизм, который позволяет указать, какие типы `Intent` может обрабатывать ваше приложение. Он определяет, какие действия (action), категории (category) и данные (data) могут быть обработаны конкретным компонентом (Activity или Broadcast Receiver).

### Пример: Обработка URL-ссылок

Предположим, мы хотим, чтобы наше приложение открытое ссылки вида `https://myapp.com/share` при переходе по такой ссылке.

#### 1. В `AndroidManifest.xml`:

```xml
<activity android:name=".MainActivity"
    android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.VIEW" />
        <category android:name="android.intent.category.DEFAULT" />
        <category android:name="android.intent.category.BROWSABLE" />
        <data android:scheme="https" android:host="myapp.com" android:pathPrefix="/share" />
    </intent-filter>
</activity>
```

#### 2. В `MainActivity.java`:

```java
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);

    Intent intent = getIntent();
    String action = intent.getAction();
    Uri data = intent.getData();

    if (Intent.ACTION_VIEW.equals(action) && data != null) {
        // Обработка URL
        Log.d("MainActivity", "Opened URL: " + data.toString());
    }
}
```

### Как это работает в Flutter?

В Flutter-приложении мы можем получить доступ к `Intent` через `MethodChannel`, если приложение было запущено через `Intent`. Но также можно использовать библиотеку [**url_launcher**](https://pub.dev/packages/url_launcher) для обработки URL.

## 3. AccountManager — назначение и возможности

### Что такое AccountManager?

`AccountManager` — это система Android, которая управляет аккаунтами пользователей на устройстве. Она предоставляет API для:

- Регистрации аккаунтов
- Получения токенов доступа
- Управления учетными данными

Это особенно полезно при работе с OAuth или другими системами аутентификации.

### Основные методы AccountManager:

```java
AccountManager accountManager = AccountManager.get(context);

// Получение списка аккаунтов
Account[] accounts = accountManager.getAccountsByType("com.google");

// Получение токена для аккаунта
accountManager.getAuthToken(account, "oauth2:https://www.googleapis.com/auth/userinfo.email", null, this, null, null);
```

### Важно:

- `AccountManager` — это нативная Android-система. В Flutter мы можем использовать **Platform Channels**, чтобы получить доступ к этим функциям.

#### Пример: Получение списка аккаунтов через Platform Channel:

##### 1. Нативный код (Android):

```java
@override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);

    new MethodChannel(getFlutterEngine().getDartExecutor(), CHANNEL)
        .setMethodCallHandler((call, result) -> {
            if ("getAccounts".equals(call.method)) {
                AccountManager accountManager = AccountManager.get(this);
                Account[] accounts = accountManager.getAccountsByType("com.google");
                List<String> accountNames = new ArrayList<>();
                for (Account acc : accounts) {
                    accountNames.add(acc.name);
                }
                result.success(accountNames);
            } else {
                result.notImplemented();
            }
        });
}
```

##### 2. Flutter-код:

```dart
import 'package:flutter/services.dart';

class AccountService {
  static const MethodChannel _channel = MethodChannel('com.example.app/accounts');

  static Future<List<String>> getAccounts() async {
    try {
      final List<dynamic> result = await _channel.invokeMethod('getAccounts');
      return result.cast<String>();
    } on PlatformException catch (e) {
      print("Failed to fetch accounts: ${e.message}");
      return [];
    }
  }
}

// Использование:
final accounts = await AccountService.getAccounts();
print(accounts);
```

Взаимодействие с другими приложениями в Android — это мощный инструмент, который позволяет создавать гибкие и интерактивные приложения. В Flutter мы можем использовать `MethodChannel` для доступа к нативным API, таким как:
