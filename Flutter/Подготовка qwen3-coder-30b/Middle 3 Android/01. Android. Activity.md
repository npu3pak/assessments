# Лекция: Android Activity для Flutter разработчика

## Введение

В мире Android-разработки **Activity** — это ключевой элемент архитектуры приложения. Хотя вы, как Flutter-разработчик, не работаете напрямую с Java/Kotlin и Android SDK, понимание концепции Activity важно для:

- Понимания жизненного цикла Flutter-приложений
- Интеграции с Native-функциями (плагины)
- Работы с Android-плагинами
- Оптимизации производительности и управления состоянием

В данной лекции мы рассмотрим Activity с точки зрения Android, но с примерами на Dart и Flutter, чтобы вы могли понять, как это работает под капотом и как связать с Flutter-приложением.

---

## 1. Что такое Activity?

**Activity** — это компонент Android-системы, представляющий собой экран пользователя. Каждое приложение Android может содержать несколько Activity, и каждая из них имеет собственный жизненный цикл.

### Основные характеристики Activity:

- **Экранное представление**: Activity отображает UI на экране.
- **Связь с контекстом**: Каждая Activity связана с `Context`, который предоставляет доступ к системным ресурсам.
- **Жизненный цикл**: У каждой Activity есть строго определённый жизненный цикл, в котором она может находиться.
- **Контроль управления**: Activity управляет жизненным циклом экрана.

### Пример: Структура Activity в Android

```java
public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
    }
}
```

В этом примере:
- `MainActivity` — это класс Activity, наследующий от `AppCompatActivity`.
- `onCreate()` — метод, вызываемый при создании Activity.
- `setContentView()` — устанавливает макет XML для Activity.

## 2. Как создать Activity с простой версткой в XML

### Шаги:

1. Создайте новый файл `activity_main.xml` в папке `res/layout`.
2. Определите элементы UI: кнопки, текстовые поля и т.д.
3. Свяжите его с `Activity` через `setContentView()`.

### Пример XML-файла:

```xml
<!-- res/layout/activity_main.xml -->
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView
        android:id="@+id/textView"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Hello, Android!" />

    <Button
        android:id="@+id/button"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Click me" />

</LinearLayout>
```

### Связывание с Activity:

```java
public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        TextView textView = findViewById(R.id.textView);
        Button button = findViewById(R.id.button);

        button.setOnClickListener(v -> {
            textView.setText("Button clicked!");
        });
    }
}
```

## 3. Как запустить Activity и передать в него данные

Для запуска новой Activity используется `Intent`.

### Пример: Запуск Activity с данными

```java
Intent intent = new Intent(this, SecondActivity.class);
intent.putExtra("message", "Hello from MainActivity");
startActivity(intent);
```

### Получение данных в `SecondActivity`:

```java
public class SecondActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_second);

        String message = getIntent().getStringExtra("message");
        TextView textView = findViewById(R.id.textView);
        textView.setText(message);
    }
}
```

## 4. Жизненный цикл Activity. Запуск

### Основные методы жизненного цикла:

| Метод | Описание |
|-------|----------|
| `onCreate()` | Вызывается при создании Activity |
| `onStart()` | Activity становится видимой |
| `onResume()` | Activity получает фокус и готова к взаимодействию |
| `onPause()` | Activity теряет фокус, но ещё видна |
| `onStop()` | Activity больше не видна |
| `onDestroy()` | Activity уничтожается |

### Пример с логами:

```java
public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        Log.d("Activity", "onCreate");
    }

    @Override
    protected void onStart() {
        super.onStart();
        Log.d("Activity", "onStart");
    }

    @Override
    protected void onResume() {
        super.onResume();
        Log.d("Activity", "onResume");
    }

    @Override
    protected void onPause() {
        super.onPause();
        Log.d("Activity", "onPause");
    }

    @Override
    protected void onStop() {
        super.onStop();
        Log.d("Activity", "onStop");
    }

    @Override
    protected void onDestroy() {
        super.onDestroy();
        Log.d("Activity", "onDestroy");
    }
}
```

## 5. Жизненный цикл Activity. Сворачивание и разворачивание

Когда пользователь сворачивает приложение (например, нажимает Home), Activity переходит в состояние `onPause()` → `onStop()`. Когда приложение снова становится активным — `onRestart()` → `onStart()` → `onResume()`.

### Поток событий:

```
MainActivity onCreate
MainActivity onStart
MainActivity onResume
MainActivity onPause (при сворачивании)
MainActivity onStop
MainActivity onRestart
MainActivity onStart
MainActivity onResume
```

## 6. Жизненный цикл Activity. Переход на новый экран

Когда вы запускаете новую Activity:

1. `onPause()` — текущая Activity теряет фокус.
2. `onStop()` — текущая Activity становится невидимой.
3. Новая Activity вызывает свои методы жизненного цикла.

### Пример перехода:

```java
Intent intent = new Intent(this, SecondActivity.class);
startActivity(intent);

// MainActivity onPause()
// MainActivity onStop()
// SecondActivity onCreate()
// SecondActivity onStart()
// SecondActivity onResume()
```

## 7. Сохранение и восстановление состояния. Parcelable

При смене конфигурации (например, поворот экрана) Activity может быть уничтожена и пересоздана. Чтобы сохранить состояние, используется `onSaveInstanceState()` и `onRestoreInstanceState()`.

### Пример: Сохранение строки

```java
@Override
protected void onSaveInstanceState(Bundle outState) {
    super.onSaveInstanceState(outState);
    outState.putString("message", "Hello");
}

@Override
protected void onRestoreInstanceState(Bundle savedInstanceState) {
    super.onRestoreInstanceState(savedInstanceState);
    String message = savedInstanceState.getString("message");
    // восстановить состояние
}
```

### Использование Parcelable для передачи объектов:

```java
public class User implements Parcelable {
    private String name;
    private int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    protected User(Parcel in) {
        name = in.readString();
        age = in.readInt();
    }

    @Override
    public void writeToParcel(Parcel dest, int flags) {
        dest.writeString(name);
        dest.writeInt(age);
    }

    @Override
    public int describeContents() {
        return 0;
    }

    public static final Creator<User> CREATOR = new Creator<User>() {
        @Override
        public User createFromParcel(Parcel in) {
            return new User(in);
        }

        @Override
        public User[] newArray(int size) {
            return new User[size];
        }
    };
}
```

Использование:

```java
Intent intent = new Intent(this, SecondActivity.class);
intent.putExtra("user", user); // Parcelable
startActivity(intent);
```
