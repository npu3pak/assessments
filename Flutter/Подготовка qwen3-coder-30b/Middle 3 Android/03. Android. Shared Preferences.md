# Лекция: Shared Preferences в Android (Flutter)  
## Уровень подготовки: Middle 3 Android

---

## Введение

В мире мобильной разработки часто возникает необходимость хранить небольшие объемы данных на устройстве пользователя — например, настройки приложения, предпочтения пользователя, состояние интерфейса и т.д. Для этого в Android существует механизм **Shared Preferences**, который предоставляет простой способ хранения пар "ключ-значение" в виде XML-файлов.  

В контексте Flutter, мы можем использовать этот механизм через пакет `shared_preferences`, который интегрируется с нативным Android Shared Preferences и позволяет легко взаимодействовать с ними из Dart.

---

## 1. Как фактически хранятся данные в Shared Preferences

### Что такое Shared Preferences?

**Shared Preferences** — это механизм хранения данных в виде простых пар "ключ-значение", аналогичный словарю. Он используется для хранения небольших объемов данных, таких как:

- Настройки пользователя
- Состояния интерфейса
- Предпочтения (например, язык, тема)
- Логины/токены (в ограниченных случаях)

### Как устроена внутренняя реализация?

В Android данные в Shared Preferences хранятся в **XML-файле**, который находится в каталоге:

```
/data/data/<package_name>/shared_prefs/
```

Каждое приложение имеет свой собственный XML-файл, например:

```
shared_prefs/app_preferences.xml
```

Пример содержимого такого файла:

```xml
<?xml version='1.0' encoding='utf-8' standalone='yes' ?>
<map>
    <string name="username">JohnDoe</string>
    <int name="age">25</int>
    <boolean name="is_logged_in">true</boolean>
</map>
```

Все данные хранятся в формате XML, что делает их легко читаемыми и простыми для отладки.

> 📌 **Важно:** Shared Preferences **не предназначены** для хранения больших объемов данных или сложных структур. Они оптимизированы под простые типы: `String`, `int`, `double`, `bool`, `Set<String>`.

### Преимущества:

- Простота использования
- Высокая производительность при доступе к данным
- Автоматическое сохранение (если вы используете `commit()` или `apply()`)
- Поддержка только примитивных типов данных

### Недостатки:

- Не подходит для хранения больших объемов данных
- Отсутствие транзакций и атомарности
- Нет встроенной поддержки сложных структур (например, объектов)
- Риск конфликта при одновременном доступе из нескольких потоков

## 2. Как работать с Shared Preferences в Flutter

### Подключение пакета

Для работы с Shared Preferences в Flutter нужно подключить пакет:

```yaml
dependencies:
  shared_preferences: ^2.2.2
```

Затем выполните команду:

```bash
flutter pub get
```

### Основные методы

#### 1. Получение экземпляра `SharedPreferences`

```dart
import 'package:shared_preferences/shared_preferences.dart';

Future<SharedPreferences> _prefs = SharedPreferences.getInstance();
```

Этот вызов возвращает `Future<SharedPreferences>` — объект, который содержит все методы для работы с настройками.

#### 2. Сохранение данных

##### Простые типы:

```dart
final prefs = await _prefs;

// Сохраняем строку
await prefs.setString('username', 'JohnDoe');

// Сохраняем целое число
await prefs.setInt('age', 25);

// Сохраняем вещественное число
await prefs.setDouble('height', 175.5);

// Сохраняем булево значение
await prefs.setBool('is_logged_in', true);
```

##### Список строк:

```dart
await prefs.setStringList('hobbies', ['reading', 'coding', 'gaming']);
```

#### 3. Чтение данных

```dart
final prefs = await _prefs;

// Получаем строку (если ключ отсутствует, возвращается null)
String? username = prefs.getString('username');

// Получаем число (если ключ отсутствует, возвращается null)
int? age = prefs.getInt('age');

// Получаем список строк
List<String>? hobbies = prefs.getStringList('hobbies');
```

#### 4. Удаление данных

```dart
// Удаляем конкретный ключ
await prefs.remove('username');

// Очищаем все данные
await prefs.clear();
```

### Пример: Полноценное управление пользовательскими настройками

Давайте создадим простой класс `UserPreferences`, который будет инкапсулировать работу с Shared Preferences:

```dart
class UserPreferences {
  static const String _usernameKey = 'username';
  static const String _ageKey = 'age';
  static const String _isLoggedInKey = 'is_logged_in';

  static Future<void> setUsername(String username) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_usernameKey, username);
  }

  static Future<String?> getUsername() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(_usernameKey);
  }

  static Future<void> setAge(int age) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setInt(_ageKey, age);
  }

  static Future<int?> getAge() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getInt(_ageKey);
  }

  static Future<void> setIsLoggedIn(bool isLoggedIn) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_isLoggedInKey, isLoggedIn);
  }

  static Future<bool> getIsLoggedIn() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(_isLoggedInKey) ?? false;
  }
}
```

Теперь мы можем использовать этот класс в любом месте приложения:

```dart
// Установка данных
await UserPreferences.setUsername('Jane');
await UserPreferences.setAge(30);
await UserPreferences.setIsLoggedIn(true);

// Получение данных
String? name = await UserPreferences.getUsername();
int? age = await UserPreferences.getAge();
bool isLoggedIn = await UserPreferences.getIsLoggedIn();

print('Name: $name, Age: $age, Logged In: $isLoggedIn');
```

## 3. Особенности и рекомендации

### Асинхронность

Все операции с Shared Preferences асинхронны, поэтому всегда используйте `await`.

### Применение изменений

В Android существует два способа сохранить изменения:

- `apply()` — асинхронно, не блокирует поток
- `commit()` — синхронно, возвращает результат (true/false)

В Flutter пакет `shared_preferences` использует `apply()` по умолчанию.

### Использование в StatefulWidget

Если вы работаете внутри виджета и хотите отследить изменения, лучше использовать:

```dart
@override
void initState() {
  super.initState();
  _loadPreferences();
}

Future<void> _loadPreferences() async {
  final prefs = await SharedPreferences.getInstance();
  setState(() {
    _username = prefs.getString('username') ?? '';
  });
}
```

### Безопасность данных

> ⚠️ Shared Preferences не шифрует данные. Если вы сохраняете чувствительные данные (например, токены), используйте дополнительную защиту — например, `flutter_secure_storage`.
