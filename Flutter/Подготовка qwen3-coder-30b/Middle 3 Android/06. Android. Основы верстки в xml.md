# Лекция 06: Android. Основы верстки в XML

---

## Введение

В разработке Android-приложений для создания пользовательского интерфейса (UI) используется язык разметки XML (eXtensible Markup Language). XML позволяет описывать элементы интерфейса, их расположение, размеры, стили и взаимодействие с пользователем. Основной принцип работы в Android — это разделение логики приложения и его внешнего вида.

В этой лекции мы рассмотрим:

- Как создавать верстку в XML
- Как использовать XML-файлы в `Activity` и `Fragment`
- Как обрабатывать нажатия кнопок из XML в коде

---

## 1. Создание верстки в XML

В Android для описания пользовательского интерфейса используются **layout-файлы** с расширением `.xml`. Они хранятся в папке `res/layout/` проекта. Каждый layout-файл описывает иерархию View-элементов (например, кнопки, текстовые поля, изображения и т.д.).

### Основные элементы XML

Все View-элементы в XML определяются с помощью тегов, например:

```xml
<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Привет, мир!" />
```

### Структура layout-файла

Каждый XML-файл должен начинаться с корневого элемента. Наиболее часто используются следующие:

- `LinearLayout` — вертикальная или горизонтальная линейка элементов.
- `ConstraintLayout` — гибкая система ограничений, рекомендуется для современных приложений.
- `RelativeLayout` — устаревший способ размещения элементов относительно друг друга.

### Пример простого layout-файла

Создадим файл `activity_main.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:padding="16dp">

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Добро пожаловать!"
        android:textSize="24sp" />

    <EditText
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="Введите ваше имя" />

    <Button
        android:id="@+id/buttonSubmit"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="Отправить" />

</LinearLayout>
```

### Основные атрибуты View

| Атрибут           | Назначение |
|------------------|------------|
| `android:id`     | Уникальный идентификатор элемента, используется для доступа к нему в коде |
| `android:layout_width` | Ширина элемента (например, `match_parent`, `wrap_content`) |
| `android:layout_height` | Высота элемента |
| `android:text`   | Текст, отображаемый в TextView или Button |
| `android:hint`   | Подсказка для EditText |

## 2. Использование XML-верстки в Activity и Fragment

Чтобы использовать XML-макет в `Activity`, нужно вызвать метод `setContentView()` с указанием ID файла layout.

### В Activity

```java
public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main); // Устанавливаем layout
    }
}
```

В Flutter это аналогично — мы используем `MaterialApp` и `Scaffold`, где `body` — это наш UI.

### В Fragment

Для Fragment аналогично, но в методе `onCreateView()`:

```java
public class MainFragment extends Fragment {
    @Override
    public View onCreateView(LayoutInflater inflater, ViewGroup container,
                             Bundle savedInstanceState) {
        View view = inflater.inflate(R.layout.fragment_main, container, false);
        return view;
    }
}
```

## 3. Обработка нажатий кнопки из XML в Activity или Fragment

Для обработки событий (например, нажатие на кнопку), нужно получить ссылку на элемент по ID и установить слушатель.

### Пример: обработка нажатия кнопки в `Activity`

```java
public class MainActivity extends AppCompatActivity {
    private Button buttonSubmit;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        buttonSubmit = findViewById(R.id.buttonSubmit); // Находим кнопку

        buttonSubmit.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                Toast.makeText(MainActivity.this, "Кнопка нажата!", Toast.LENGTH_SHORT).show();
            }
        });
    }
}
```

### Обработка в Fragment

```java
public class MainFragment extends Fragment {
    private Button buttonSubmit;

    @Override
    public View onCreateView(LayoutInflater inflater, ViewGroup container,
                             Bundle savedInstanceState) {
        View view = inflater.inflate(R.layout.fragment_main, container, false);

        buttonSubmit = view.findViewById(R.id.buttonSubmit);

        buttonSubmit.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                Toast.makeText(getContext(), "Кнопка в фрагменте нажата!", Toast.LENGTH_SHORT).show();
            }
        });

        return view;
    }
}
```
