# Лекция: Android SDK Manager

## Введение

В рамках разработки мобильных приложений под Android, особенно в экосистеме Flutter, важно понимать, как управлять компонентами Android SDK. **Android SDK Manager** — это инструмент, который позволяет управлять установленными компонентами Android SDK, включая платформы, инструменты сборки и другие зависимости.

Эта лекция поможет вам стать уверенным разработчиком уровня Middle 3 Android, освоив тему **Android SDK Manager**. Мы подробно рассмотрим:

1. Как просматривать, устанавливать и удалять компоненты SDK.
2. Что такое SDK Platforms и как они работают.
3. SDK Build Tools и их роль в сборке приложений.
4. NDK (Native Development Kit) и его применение.
5. Google Play Services и как они связаны с SDK.

## 1. Просмотр, установка и удаление установленных компонентов SDK

**Android SDK Manager** — это часть Android Studio, которая позволяет управлять всеми установленными компонентами SDK: платформами, инструментами сборки, системными библиотеками и т. д.

### Как открыть SDK Manager в Android Studio:

1. Запустите **Android Studio**.
2. Перейдите в меню:
   - `File` → `Settings` (на Windows/Linux)
   - `Android Studio` → `Preferences` (на macOS)
3. В открывшемся окне выберите раздел `Appearance & Behavior` → `System Settings` → `Android SDK`.

Или, альтернативно:

- Нажмите на иконку **SDK Manager** в правом верхнем углу Android Studio (если вы видите значок с кубиками или "SDK Manager").

### Просмотр установленных компонентов

В SDK Manager вы увидите список всех установленных компонентов, разделённых по категориям:

- **SDK Platforms**
- **SDK Tools**
- **NDK (Side by Side)**
- **Android Emulator**
- **Google Play Services**

Также вы можете выбрать **Show Package Details**, чтобы увидеть все доступные версии компонентов, которые можно установить.

### Установка новых компонентов

Чтобы установить новый компонент:

1. Перейдите в нужную категорию (например, `SDK Platforms`).
2. Поставьте галочку напротив нужной версии.
3. Нажмите **Apply** или **OK**.
4. Android Studio загрузит и установит выбранные компоненты.

### Удаление компонентов

Удаление работает аналогично:

1. В SDK Manager найдите нужный компонент.
2. Снимите галочку.
3. Нажмите **Apply** или **OK**.
4. Компонент будет удалён.

> ⚠️ Важно: Не удаляйте компоненты, которые используются в текущих проектах, иначе сборка может завершиться ошибкой.

## 2. SDK Platforms

**SDK Platforms** — это наборы Android API уровней, которые содержат:

- Базовые библиотеки Android (core framework).
- Системные API (например, `Activity`, `Fragment`, `View`, и т. д.).
- Документацию и примеры.

Каждый уровень SDK соответствует определённой версии Android (например, Android 13, Android 12 и т. д.).

### Пример: Как выбрать нужный уровень SDK

Предположим, вы разрабатываете Flutter-приложение и хотите поддерживать Android API 21 (Android 5.0) и выше.

1. В SDK Manager откройте вкладку **SDK Platforms**.
2. Поставьте галочку рядом с **Android 13 (API 33)** и **Android 12 (API 31)**.
3. Нажмите **Apply**.

В Flutter-проекте это отражается в файле `android/app/build.gradle`:

```gradle
android {
    compileSdkVersion 33

    defaultConfig {
        applicationId "com.example.myapp"
        minSdkVersion 21
        targetSdkVersion 33
    }
}
```

> 🔧 Важно: `compileSdkVersion` должен соответствовать установленному SDK Platform, а `targetSdkVersion` — версии, на которой вы тестируете приложение.

## 3. SDK Build Tools

**SDK Build Tools** — это набор инструментов для сборки проектов Android. Они включают:

- `aapt` (Android Asset Packaging Tool)
- `dx` или `d8` (для компиляции Java/ Kotlin в dex)
- `adb` (Android Debug Bridge)
- `zipalign`, `apksigner` и другие

### Пример: Установка Build Tools

1. В SDK Manager перейдите на вкладку **SDK Tools**.
2. Включите **Show Package Details**.
3. Поставьте галочку рядом с **Android SDK Build-Tools [version]** (например, 33.0.0).
4. Нажмите **Apply**.

После установки Build Tools будут находиться в папке:

```
<Android SDK>/build-tools/<version>
```

Пример пути:

```
~/Android/Sdk/build-tools/33.0.0/
```

В Flutter-проектах Build Tools указываются в файле `android/gradle.properties` или через `build.gradle`.

```gradle
android {
    compileSdkVersion 33
    buildToolsVersion "33.0.0"
}
```

> ⚠️ Убедитесь, что версия Build Tools совпадает с тем, что указано в `build.gradle`. Иначе может возникнуть ошибка сборки.

## 4. NDK (Native Development Kit)

**NDK (Native Development Kit)** — это набор инструментов для разработки нативного кода (на C/C++) и его интеграции с Android-приложениями.

### Зачем нужен NDK?

NDK полезен в следующих случаях:

- Вы используете библиотеки, написанные на C/C++.
- Нужно ускорить производительность (например, при обработке изображений или аудио).
- Вы используете Flutter и хотите использовать native плагины, которые требуют NDK.

### Как установить NDK

1. В SDK Manager перейдите в **SDK Tools**.
2. Включите **Show Package Details**.
3. Поставьте галочку рядом с **NDK (Side by Side)**.
4. Нажмите **Apply**.

После установки NDK будет находиться в:

```
<Android SDK>/ndk/<version>
```

### Пример использования NDK в Flutter

Если вы используете плагин, например `flutter_native_image`, который требует NDK для работы с изображениями:

1. Убедитесь, что NDK установлен.
2. Добавьте в `android/local.properties` путь к NDK:

```properties
ndk.dir=/Users/username/Library/Android/sdk/ndk/23.1.7779620
```

> 📌 Если вы используете Flutter, то NDK автоматически используется при сборке, если он установлен.

## 5. Google Play Services

**Google Play Services** — это набор библиотек и сервисов от Google, которые позволяют использовать:

- Google Maps
- Firebase
- Google Sign-In
- Location Services
- Push-уведомления (Firebase Cloud Messaging)
- Аутентификацию через Google

### Установка Google Play Services

Google Play Services не устанавливаются как отдельный компонент. Они включаются в **SDK Platforms** или подключаются через Gradle.

Пример подключения в `android/app/build.gradle`:

```gradle
dependencies {
    implementation 'com.google.android.gms:play-services-maps:18.1.0'
    implementation 'com.google.firebase:firebase-analytics:21.2.0'
}
```

> ⚠️ При использовании Flutter-плагинов, таких как `google_maps_flutter`, они автоматически добавляют необходимые зависимости.

### Как проверить, установлены ли Google Play Services

В SDK Manager они не отображаются напрямую. Однако вы можете проверить их наличие в проекте:

1. Откройте `build.gradle` в `android/app/`.
2. Найдите строки с `com.google.android.gms`.

Если такие строки есть, значит, Google Play Services подключены.

## Практическое задание

Создайте Flutter-проект и выполните следующие действия:

1. Откройте Android Studio.
2. Перейдите в SDK Manager (`File` → `Settings` → `Android SDK`).
3. Установите:
   - SDK Platform для API 33 (Android 13)
   - Build Tools версии 33.0.0
   - NDK (Side by Side) версии 23.1.7779620
4. Проверьте, что в `android/app/build.gradle` указаны правильные значения:
   ```gradle
   compileSdkVersion 33
   buildToolsVersion "33.0.0"
   ```
5. Удалите один из установленных компонентов (например, Build Tools) и проверьте, как это влияет на сборку.
6. Добавьте в проект плагин `google_maps_flutter` и проверьте, подключаются ли Google Play Services.
