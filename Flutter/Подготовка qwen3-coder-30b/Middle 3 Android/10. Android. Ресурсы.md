# Лекция: Android. Ресурсы

---

## Введение

В Android-разработке ресурсы (resources) — это важный аспект проектирования приложения, который позволяет разделять данные (текст, изображения, цвета и т.п.) от логики кода. Это делает приложение более гибким, локализуемым и поддерживаемым.

Ресурсы в Android хранятся в папках внутри `app/src/main/res/`, где каждая папка содержит ресурсы определённого типа: строки, изображения, цвета, темы и т.д.

---

## 1. Класс R

Все ресурсы Android автоматически генерируют класс `R` (или `R.java`) в каждом проекте. Этот класс содержит статические поля для каждого ресурса, которые позволяют обращаться к ним из кода.

### Пример:
Предположим, у нас есть строковый ресурс с именем `app_name` в файле `strings.xml`:

```xml
<resources>
    <string name="app_name">Моё приложение</string>
</resources>
```

Тогда мы можем получить значение строки в коде:

```dart
String appName = context.getString(R.string.app_name);
```

Но в Flutter это не так — `R` класс существует только в Android-проекте, и его использование в Flutter ограничено. Для Flutter используется другой подход: ресурсы передаются через `AssetBundle`.

Если вы работаете в Flutter, то вы можете использовать `assets`, но если вы используете `Android` (или смешанное приложение), вам нужно понимать работу `R.java`.

---

## 2. Загрузка строковых ресурсов

Строковые ресурсы — это самый распространённый тип ресурсов. Они определяются в файле `strings.xml`, который находится в папке `res/values/`.

### Пример:
```xml
<resources>
    <string name="app_name">Моё приложение</string>
    <string name="welcome_message">Добро пожаловать!</string>
    <string name="button_ok">ОК</string>
</resources>
```

### Использование в коде:
```dart
String welcome = context.getString(R.string.welcome_message);
```

> В Flutter: строковые ресурсы обычно определяются через `pubspec.yaml` и `flutter_localizations`.

---

## 3. Настройка тем в ресурсах

Темы (themes) позволяют задавать общий стиль для всего приложения или конкретных элементов.

В `res/values/themes.xml` можно определить тему:

```xml
<resources>
    <style name="AppTheme" parent="Theme.AppCompat.Light.DarkActionBar">
        <item name="colorPrimary">@color/colorPrimary</item>
        <item name="colorAccent">@color/colorAccent</item>
    </style>
</resources>
```

А в `colors.xml`:

```xml
<resources>
    <color name="colorPrimary">#3F51B5</color>
    <color name="colorAccent">#FF4081</color>
</resources>
```

### Применение темы:
В `AndroidManifest.xml`:

```xml
<application
    android:theme="@style/AppTheme">
</application>
```

> В Flutter темы реализуются через `ThemeData` и `MaterialApp`.

## 4. Растровая графика в ресурсах

Растровые изображения (bmp, png, jpeg) хранятся в папках `res/drawable/`, где могут быть разные версии для разных плотностей экрана:

- `drawable-mdpi`
- `drawable-hdpi`
- `drawable-xhdpi`
- `drawable-xxhdpi`

### Пример:
```xml
<ImageView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:src="@drawable/logo" />
```

> В Flutter вы используете `Image.asset()` и подключаете ресурсы через `pubspec.yaml`.

---

## 5. Векторная графика в ресурсах

Векторные изображения (в формате `VectorDrawable`) определяются в файле `.xml` и позволяют масштабировать без потери качества.

### Пример:
```xml
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="24dp"
    android:height="24dp"
    android:viewportWidth="24.0"
    android:viewportHeight="24.0">
    <path
        android:fillColor="#FF000000"
        android:pathData="M12,2l3.09,6.26L22,9.27l-5,4.87 1.18,6.88L12,17.77l-6.18,3.25L7,14.14 2,9.27l6.91,-1.01L12,2z"/>
</vector>
```

Такой файл сохраняется в `res/drawable/` и используется как ресурс:

```xml
<ImageView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:src="@drawable/star" />
```

> В Flutter вы можете использовать SVG через пакеты, например `flutter_svg`.

---

## 6. Цвета в ресурсах

Цвета определяются в файле `colors.xml` внутри `res/values/`.

### Пример:
```xml
<resources>
    <color name="red">#FF0000</color>
    <color name="blue">#0000FF</color>
    <color name="white">#FFFFFF</color>
    <color name="black">#000000</color>
</resources>
```

### Использование:
```xml
<TextView
    android:textColor="@color/red"
    android:text="Красный текст" />
```

Также можно использовать цвета с прозрачностью:

```xml
<color name="semi_transparent">#80000000</color>
```

> В Flutter: цвета задаются через `Colors`, но если вы работаете с Android-частью, вы можете использовать ресурсы `colors.xml`.

## Заключение

Работа с ресурсами — это фундаментальный навык в разработке Android-приложений. Понимание того, как организованы строки, темы, изображения и цвета, позволяет создавать более гибкие и поддерживаемые приложения.

# 🧠 Практическое задание

1. Создайте новый проект в Android Studio.
2. В `res/values/strings.xml` добавьте следующие строки:
   - `app_name`
   - `welcome_message`
   - `button_cancel`
3. В `res/values/colors.xml` определите:
   - `primary_color`
   - `secondary_color`
4. В `res/drawable/` добавьте растровое и векторное изображение.
5. Создайте `themes.xml`, чтобы применить цвета к теме приложения.
6. В `MainActivity` выведите `welcome_message` на экран с использованием `TextView`.
7. Примените цвет `primary_color` к тексту.
