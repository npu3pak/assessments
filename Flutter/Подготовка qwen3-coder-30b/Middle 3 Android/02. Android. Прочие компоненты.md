# Лекция: Прочие компоненты Android. Service, Broadcast Receiver, Intent, IntentFilter, AndroidManifest.xml

## Введение

В этой лекции мы рассмотрим ключевые компоненты Android-приложений, которые не относятся к основным UI-элементам (Activity, Fragment). Эти компоненты позволяют создавать мощные, гибкие и эффективные приложения. Мы сосредоточимся на следующих элементах:

1. **Service** — фоновый компонент, который может выполнять долгосрочные операции без пользовательского интерфейса.
2. **Broadcast Receiver** — компонент для получения и обработки широковещательных сообщений (broadcasts).
3. **Intent** — объект, который передает информацию между компонентами приложения или между приложениями.
4. **IntentFilter** — фильтр, определяющий типы Intent, которые может обработать компонент.
5. **AndroidManifest.xml** — файл манифеста, описывающий структуру и поведение приложения.

Эти компоненты важны для создания современных мобильных приложений, особенно в контексте Flutter-разработки, где вы можете использовать нативные Android-возможности через `MethodChannel` или `EventChannel`.

## 1. Service

### Что такое Service?

**Service** — это фоновый компонент Android, который выполняет длительные операции в фоне без предоставления пользовательского интерфейса. Он может работать даже тогда, когда пользователь переключился на другое приложение.

### Типы Service

1. **Started Service** — запускается методом `startService()` и продолжает работать до тех пор, пока не будет явно остановлен.
2. **Bound Service** — используется с помощью `bindService()`, позволяет связываться с компонентами через `Binder`.

### Пример: Создание Started Service на Dart (через native Android)

Допустим, вы хотите запустить сервис для фоновой загрузки файла.

#### 1. Создаем Kotlin-класс Service

```kotlin
class DownloadService : Service() {
    private val handler = Handler(Looper.getMainLooper())
    
    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        // Выполняем фоновую работу
        Thread {
            for (i in 1..10) {
                Thread.sleep(1000)
                // Отправляем broadcast для обновления интерфейса
                val broadcastIntent = Intent("DOWNLOAD_PROGRESS")
                broadcastIntent.putExtra("progress", i * 10)
                sendBroadcast(broadcastIntent)
            }
        }.start()

        return START_STICKY // сервис будет перезапущен, если он будет убит системой
    }

    override fun onBind(intent: Intent?): IBinder? {
        return null
    }
}
```

#### 2. Регистрируем Service в `AndroidManifest.xml`

```xml
<service android:name=".DownloadService" />
```

#### 3. Запускаем Service из Flutter

```dart
import 'package:flutter/services.dart';

class AndroidService {
  static const MethodChannel _channel = MethodChannel('com.example.app/service');

  static Future<void> startDownloadService() async {
    try {
      await _channel.invokeMethod('startService');
    } on PlatformException catch (e) {
      print("Failed to start service: ${e.message}");
    }
  }
}
```

#### 4. В Kotlin-коде вызов `startService()`:

```kotlin
class MainActivity : FlutterActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        
        // Запуск сервиса
        val intent = Intent(this, DownloadService::class.java)
        startService(intent)
    }
}
```

## 2. Broadcast Receiver

### Что такое Broadcast Receiver?

**Broadcast Receiver** — это компонент Android, который слушает широковещательные сообщения (broadcasts), отправленные системой или приложениями. Он может реагировать на события, такие как:

- изменение состояния сети
- получение SMS
- завершение загрузки устройства
- изменение уровня заряда батареи

### Пример: Регистрация Broadcast Receiver в Kotlin

```kotlin
class BatteryReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context?, intent: Intent?) {
        if (Intent.ACTION_BATTERY_CHANGED == intent?.action) {
            val level = intent.getIntExtra(BatteryManager.EXTRA_LEVEL, -1)
            println("Battery level: $level%")
        }
    }
}
```

#### Регистрация в `AndroidManifest.xml`:

```xml
<receiver android:name=".BatteryReceiver">
    <intent-filter>
        <action android:name="android.intent.action.BATTERY_CHANGED" />
    </intent-filter>
</receiver>
```

### В Flutter: Получение широковещательных сообщений через EventChannel

Если вы хотите получить данные из `BroadcastReceiver` в Flutter, используйте `EventChannel`.

#### 1. Kotlin:

```kotlin
class BatteryBroadcastReceiver : BroadcastReceiver() {
    private var eventSink: EventSink? = null

    override fun onReceive(context: Context?, intent: Intent?) {
        if (Intent.ACTION_BATTERY_CHANGED == intent?.action) {
            val level = intent.getIntExtra(BatteryManager.EXTRA_LEVEL, -1)
            eventSink?.success(level)
        }
    }

    fun setEventSink(sink: EventSink) {
        this.eventSink = sink
    }
}
```

#### 2. Регистрация в MainActivity:

```kotlin
class MainActivity : FlutterActivity() {
    private val batteryReceiver = BatteryBroadcastReceiver()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        GeneratedPluginRegistrant.registerWith(this)

        // Регистрируем receiver
        val filter = IntentFilter(Intent.ACTION_BATTERY_CHANGED)
        registerReceiver(batteryReceiver, filter)
    }
}
```

#### 3. Flutter:

```dart
EventChannel('battery_channel').receiveBroadcastStream().listen((event) {
  print("Battery level: $event%");
});
```

## 3. Intent

### Что такое Intent?

**Intent** — это объект, который позволяет передавать информацию между компонентами Android. Он может быть:

- **Explicit Intent**: явный, указывает конкретный компонент.
- **Implicit Intent**: неявный, указывает тип действия, и система выбирает подходящий компонент.

### Примеры Intent

#### 1. Открытие Activity с помощью `Intent`

```kotlin
val intent = Intent(this, SecondActivity::class.java)
intent.putExtra("message", "Hello from first activity")
startActivity(intent)
```

#### 2. Неявный Intent: Открытие URL в браузере

```kotlin
val intent = Intent(Intent.ACTION_VIEW, Uri.parse("https://flutter.dev"))
startActivity(intent)
```

#### 3. Вызов системного действия (например, отправка SMS)

```kotlin
val smsIntent = Intent(Intent.ACTION_SENDTO).apply {
    data = Uri.parse("smsto:1234567890")
    putExtra("sms_body", "Привет!")
}
startActivity(smsIntent)
```

## 4. IntentFilter

### Что такое IntentFilter?

**IntentFilter** — это фильтр, который указывает, какие типы `Intent` может обработать компонент (например, Activity или Broadcast Receiver). Он описывается в `AndroidManifest.xml`.

### Пример: IntentFilter для Activity

```xml
<activity android:name=".MainActivity">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>
```

### Пример: IntentFilter для Broadcast Receiver

```xml
<receiver android:name=".BatteryReceiver">
    <intent-filter>
        <action android:name="android.intent.action.BATTERY_CHANGED" />
    </intent-filter>
</receiver>
```

## 5. AndroidManifest.xml

### Что такое AndroidManifest.xml?

**AndroidManifest.xml** — это основной файл манифеста приложения, который описывает его структуру и поведение. В нем указываются:

- активные компоненты (Activity, Service, BroadcastReceiver)
- используемые разрешения
- метаданные
- фильтры намерений

### Пример манифеста с регистрацией всех компонентов

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.example.app">

    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />

    <application
        android:label="MyApp"
        android:theme="@style/AppTheme">

        <!-- MainActivity -->
        <activity
            android:name=".MainActivity"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>

        <!-- Service -->
        <service android:name=".DownloadService" />

        <!-- Broadcast Receiver -->
        <receiver android:name=".BatteryReceiver">
            <intent-filter>
                <action android:name="android.intent.action.BATTERY_CHANGED" />
            </intent-filter>
        </receiver>

    </application>
</manifest>
```
