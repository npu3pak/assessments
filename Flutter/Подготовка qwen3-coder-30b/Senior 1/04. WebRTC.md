## 04. WebRTC

### Краткое описание технологии

**WebRTC (Web Real-Time Communication)** — это открытая технология, позволяющая передавать данные в реальном времени между браузерами и мобильными приложениями без использования промежуточных серверов.

Важно понимать, что WebRTC **не является протоколом** или стандартом, а представляет собой набор технологий, реализующих обмен медиа-данными между клиентами. Он включает:

- **RTCPeerConnection** — управление подключениями между участниками
- **RTCDataChannel** — передача произвольных данных
- **MediaStream** — работа с аудио и видео потоками
- **ICE (Interactive Connectivity Establishment)** — механизм установки соединения
- **DTLS/SRTP** — безопасная передача данных

В Flutter WebRTC реализуется через библиотеки, такие как `webrtc` или `livekit_client`. Основное применение — это **видео- и аудиозвонки**, **стриминг**, **совместные сессии**.

---

## Как работает WebRTC?

1. **Инициация сессии**
   - Клиенты обмениваются **SDP (Session Description Protocol)** — описанием возможностей, поддерживаемых каждым клиентом.
2. **Обмен ICE-кандидатами**
   - Клиенты отправляют друг другу кандидаты для установки соединения (IP-адреса, порты).
3. **Установка соединения**
   - При успешном обмене кандидатами и SDP устанавливается прямое P2P соединение.
4. **Передача данных**
   - После установки соединения, данные передаются напрямую между клиентами.

## LiveKit

**LiveKit** — это open-source платформа для построения видеоконференций и стриминга в реальном времени. Он использует WebRTC и предоставляет готовые решения для разработчиков.

LiveKit предлагает:

- Серверную часть (на Go)
- SDK для клиентов (включая Flutter)
- Инструменты управления комнатами, пользователей, потоков

### LiveKit Client (Flutter)

**LiveKit Client** — это официальный Flutter SDK от LiveKit, позволяющий создавать приложения с поддержкой WebRTC.

#### Установка

```yaml
dependencies:
  livekit_client: ^0.12.0
```

#### Основные классы

- `Room` — управление комнатой
- `Participant` — информация о участнике
- `LocalParticipant`, `RemoteParticipant`
- `Track` — аудио или видео треки
- `LocalAudioTrack`, `LocalVideoTrack`, `RemoteAudioTrack`, `RemoteVideoTrack`

#### Подключение к комнате

```dart
import 'package:livekit_client/livekit_client.dart';

Future<void> connectToRoom() async {
  final room = Room();

  // Подключаемся к серверу
  await room.connect(
    'wss://your-livekit-server.com',
    'room-token',
  );

  // Создаем локальный трек (например, видео)
  final localTrack = await LocalVideoTrack.createCameraTrack();
  await room.localParticipant.publishTrack(localTrack);

  // Подписываемся на участников
  room.onParticipantConnected((participant) {
    print('Участник присоединился: ${participant.sid}');
  });
}
```

#### Обработка потока видео

```dart
// Отображение видео в UI
final videoRenderer = VideoRenderer();
localTrack.attach(videoRenderer);

// Или через Flutter виджеты
VideoWidget(
  renderer: videoRenderer,
)
```

## Структура комнаты и участников

Когда участник подключается к комнате:

- Он становится `Participant`
- Может публиковать или подписываться на треки
- Имеет статус (живой, отключен и т.п.)
- Участники могут быть `Local` или `Remote`

### Пример: Публикация видео

```dart
final localVideoTrack = await LocalVideoTrack.createCameraTrack();
await room.localParticipant.publishTrack(localVideoTrack);
```

### Пример: Отключение участника

```dart
room.onParticipantDisconnected((participant) {
  print('Участник отключился: ${participant.sid}');
});
```

## LiveKit Client — продвинутые возможности

### Работа с данными

```dart
final dataChannel = await room.localParticipant.createDataChannel('chat');
dataChannel.onMessage((message) {
  print('Получено сообщение: $message');
});
```

### Музыкальное и видео-видео потоки

```dart
final localAudioTrack = await LocalAudioTrack.createAudioTrack();
await room.localParticipant.publishTrack(localAudioTrack);
```
