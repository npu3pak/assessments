# Лекция 09: Кодогенерация

## Введение

Кодогенерация — это процесс автоматического создания исходного кода на основе шаблонов, метаданных или спецификаций. В мире Flutter и Dart она играет важную роль в повышении эффективности разработки, снижении количества рутинных операций и уменьшении вероятности ошибок.

Кодогенерация особенно полезна при работе с:

- Сериализацией данных (например, из JSON),
- Создании immutable моделей,
- Генерации boilerplate кода для UI-компонентов,
- Определении структур данных на основе API-спецификаций.

В данной лекции мы рассмотрим пять ключевых инструментов и подходов к кодогенерации в Flutter-разработке:

1. **freezed** – для создания immutable моделей,
2. **json_serializable** – для автоматической сериализации/десериализации JSON,
3. **mason** – для генерации шаблонов проектов и компонентов,
4. **OpenAPI Generator** – для генерации кода из OpenAPI-спецификаций,
5. **Dart Macros** – современный способ генерации кода на этапе компиляции.

## 1. Пакет `freezed`

### Описание

`freezed` — это мощный пакет для создания immutable моделей в Dart, особенно полезен при работе с Flutter. Он позволяет создавать:
- `sealed classes`,
- `copyWith` методы,
- `==` и `hashCode`,
- `toString`.

Это значительно упрощает работу с данными и делает код более безопасным.

### Установка

```yaml
dev_dependencies:
  freezed: ^2.4.1
  freezed_annotation: ^2.4.1
```

Также нужно добавить:

```yaml
flutter pub run build_runner watch
```

или

```yaml
flutter pub run build_runner build --delete-conflicting-outputs
```

### Пример использования

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'user.freezed.dart';
part 'user.g.dart';

@freezed
class User with _$User {
  const User._();

  const factory User({
    required String name,
    required int age,
    String? email,
  }) = _User;

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
}
```

### Что генерируется

При запуске `build_runner` генерируется:

- Класс `_User`, который реализует все необходимые методы (`copyWith`, `==`, `hashCode`, `toString`),
- Фабрика `fromJson` для десериализации из JSON.

### Преимущества

- Автоматическое создание `copyWith`.
- Упрощение работы с immutable структурами.
- Поддержка sealed classes (полезно при использовании `Either` или `Result`).

## 2. Пакет `json_serializable`

### Описание

Пакет `json_serializable` используется для автоматической генерации кода, необходимого для сериализации/десериализации объектов Dart в JSON и обратно.

Он использует аннотации `@JsonSerializable()` и `@JsonEnum()`.

### Установка

```yaml
dev_dependencies:
  json_serializable: ^6.7.1
  build_runner: ^2.4.7
```

### Пример использования

```dart
import 'package:json_annotation/json_annotation.dart';

part 'user.g.dart';
part 'user.json.dart';

@JsonSerializable()
class User {
  final String name;
  final int age;

  User({
    required this.name,
    required this.age,
  });

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);

  Map<String, dynamic> toJson() => _$UserToJson(this);
}
```

### Генерация кода

После запуска `flutter pub run build_runner build` будет сгенерирован файл `user.g.dart`, содержащий методы `fromJson()` и `toJson()`.

### Поддержка дополнительных опций

```dart
@JsonSerializable(fieldRename: FieldRename.snake)
class User {
  final String firstName;
  final int age;

  User({
    required this.firstName,
    required this.age,
  });

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
  Map<String, dynamic> toJson() => _$UserToJson(this);
}
```

### Преимущества

- Упрощает работу с JSON.
- Автоматическая обработка полей, включая `null`.
- Поддержка enum и nested объектов.

## 3. Пакет `mason`

### Описание

`mason` — это мощный инструмент для генерации кода из шаблонов. Он позволяет создавать шаблоны, которые можно использовать как CLI-инструменты или вручную в IDE.

Можно использовать для генерации:
- Базовых классов,
- UI-компонентов,
- Моделей,
- Сервисов и т.д.

### Установка

```bash
dart pub global activate mason_cli
```

### Пример шаблона

Создадим шаблон `flutter_bloc`:

```yaml
# brick.yaml
name: flutter_bloc
version: 0.1.0
description: Generates a Flutter BLoC pattern implementation.

vars:
  name:
    type: string
    description: The name of the bloc
    default: my_bloc

files:
  "lib/blocs/{{name.snakeCase}}_bloc.dart":
    content: |
      import 'package:flutter_bloc/flutter_bloc.dart';

      class {{name.pascalCase}}Bloc extends Bloc<{{name.pascalCase}}Event, {{name.pascalCase}}State> {
        {{name.pascalCase}}Bloc() : super(const {{name.pascalCase}}State()) {
          on<{{name.pascalCase}}Event>((event, emit) {});
        }
      }

  "lib/blocs/{{name.snakeCase}}_event.dart":
    content: |
      abstract class {{name.pascalCase}}Event {}

  "lib/blocs/{{name.snakeCase}}_state.dart":
    content: |
      class {{name.pascalCase}}State {
        const {{name.pascalCase}}State();
      }
```

### Использование

```bash
mason make flutter_bloc --name my_counter
```

Это создаст файлы `my_counter_bloc.dart`, `my_counter_event.dart` и `my_counter_state.dart`.

### Преимущества

- Быстрая генерация стандартных компонентов.
- Повторное использование шаблонов.
- Подходит для командной разработки.

## 4. OpenAPI Generator

### Описание

OpenAPI Generator позволяет автоматически генерировать клиентский код (включая Dart/Flutter) на основе OpenAPI (Swagger) спецификации.

Полезно при работе с REST API, где вы получаете документацию в формате `.yaml` или `.json`.

### Установка

```bash
npm install @openapitools/openapi-generator-cli -g
```

### Пример

Допустим, у нас есть файл `api.yaml`:

```yaml
openapi: 3.0.0
info:
  title: User API
  version: 1.0.0
paths:
  /users:
    get:
      responses:
        '200':
          description: A list of users
          content:
            application/json:
              schema:
                type: array
                items:
                  $ref: '#/components/schemas/User'
components:
  schemas:
    User:
      type: object
      properties:
        id:
          type: integer
        name:
          type: string
```

### Генерация

```bash
openapi-generator-cli generate -i api.yaml -g dart -o generated/
```

После этого будет сгенерирован Dart-код, включая модели и API-клиенты.

### Преимущества

- Автоматическое создание моделей и клиентов.
- Поддержка разных языков и фреймворков.
- Синхронизация с документацией.

## 5. Dart Macros

### Описание

Dart Macros — это экспериментальный механизм, позволяющий генерировать код на этапе компиляции. В отличие от `build_runner`, макросы работают напрямую в процессе компиляции Dart-кода и позволяют:
- Сокращать количество boilerplate,
- Автоматически добавлять методы,
- Добавлять аннотации.

### Пример использования

Пока не все инструменты поддерживают макросы напрямую, но можно использовать `@immutable` и другие аннотации:

```dart
import 'package:meta/meta.dart';

@immutable
class User {
  final String name;
  final int age;

  const User({
    required this.name,
    required this.age,
  });
}
```

Также поддерживается в `freezed` через `@freezed`.

### Будущее

Dart Macros — это направление развития языка, которое может заменить `build_runner` в будущем. Сейчас они находятся на стадии разработки.
