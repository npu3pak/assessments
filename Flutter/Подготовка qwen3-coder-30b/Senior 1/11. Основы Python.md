## 1. Особенности синтаксиса

Python — это интерпретируемый язык программирования, который отличается читаемостью и простотой синтаксиса. Он использует отступы (whitespace) вместо фигурных скобок `{}` для определения блоков кода.

### Пример:
```python
if True:
    print("Это блок кода")
    x = 5
```

### Ключевые особенности:

- **Отступы обязательны**: в Python отступы используются для группировки кода.
- **Не требует объявления типов переменных**: `x = 5` — Python сам понимает, что это целое число.
- **Динамическая типизация**: переменная может менять тип во время выполнения.
- **Комментарии начинаются с `#`**
  
```python
# Это комментарий
name = "Анна"  # Переменная типа string
age = 25      # Переменная типа int
```

## 2. Условные операторы

Условные операторы позволяют выполнять разный код в зависимости от условия.

### Синтаксис:

```python
if условие:
    # код, выполняющийся при истинности условия
elif другое_условие:
    # альтернативный код
else:
    # код по умолчанию
```

### Пример:

```python
age = 18

if age < 13:
    print("Ребенок")
elif age < 18:
    print("Подросток")
else:
    print("Взрослый")
```

## 3. Циклы

Python поддерживает два типа циклов: `for` и `while`.

### Цикл `for`

Используется для перебора элементов последовательности.

```python
fruits = ["яблоко", "банан", "апельсин"]

for fruit in fruits:
    print(fruit)
```

Можно использовать `range()` для генерации чисел:

```python
for i in range(5):
    print(i)  # Вывод: 0, 1, 2, 3, 4
```

### Цикл `while`

Выполняется до тех пор, пока условие истинно.

```python
count = 0

while count < 5:
    print(count)
    count += 1
```

## 4. Функции

Функция — это блок кода, который можно вызывать многократно.

### Синтаксис:

```python
def имя_функции(параметры):
    # тело функции
    return результат
```

### Пример:

```python
def greet(name):
    return f"Привет, {name}!"

print(greet("Анна"))  # Вывод: Привет, Анна!
```

Функции могут иметь необязательные параметры:

```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

print(greet("Анна"))              # Привет, Анна!
print(greet("Анна", "Здравствуй"))  # Здравствуй, Анна!
```

## 5. Списки, множества, словари

### Списки (`list`)

Упорядоченные коллекции элементов, которые можно изменять.

```python
my_list = [1, 2, 3]
my_list.append(4)     # Добавить элемент
my_list[0] = 10       # Изменить элемент
print(my_list)        # [10, 2, 3, 4]
```

### Множества (`set`)

Неупорядоченные коллекции уникальных элементов.

```python
my_set = {1, 2, 2, 3}
print(my_set)  # {1, 2, 3}
```

### Словари (`dict`)

Коллекции пар "ключ — значение".

```python
person = {
    "name": "Анна",
    "age": 25,
    "city": "Москва"
}

print(person["name"])  # Анна
person["age"] = 26   # Изменить значение
```

## 6. Подключение модулей и работа с pip

Python предоставляет богатую стандартную библиотеку и возможность подключения внешних библиотек через `pip`.

### Подключение модуля:

```python

response = requests.get("https://api.github.com")

```

## 8. Чтение и запись файлов

Python позволяет легко работать с файлами.

### Запись в файл:

```python
with open("example.txt", "w") as file:
    file.write("Привет, мир!")
```

### Чтение файла:

```python
with open("example.txt", "r") as file:
    content = file.read()
    print(content)
```

### Режимы открытия файлов:

- `"r"` — чтение
- `"w"` — запись (перезапись)
- `"a"` — добавление
- `"r+"` — чтение и запись

## 9. Обработка исключений

Исключения возникают, когда программа сталкивается с ошибками. Python позволяет перехватывать их с помощью `try-except`.

### Пример:

```python
try:
    number = int(input("Введите число: "))
    result = 10 / number
except ValueError:
    print("Это не число!")
except ZeroDivisionError:
    print("Делить на ноль нельзя!")
```

Можно использовать `else` и `finally`:

```python
try:
    file = open("data.txt", "r")
except FileNotFoundError:
    print("Файл не найден")
else:
    print("Файл открыт успешно")
finally:
    print("Завершение работы с файлом")
```

## 10. Запуск команд bash из Python-скриптов

Python позволяет запускать системные команды через модуль `subprocess`.

### Пример:

```python
import subprocess

# Запустить команду bash
result = subprocess.run(["ls", "-l"], capture_output=True, text=True)
print(result.stdout)
```

Можно запускать и сложные команды:

```python
subprocess.run("echo 'Привет из bash'", shell=True)
```
