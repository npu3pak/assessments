# Лекция: Flutter. Фрагментные шейдеры

## Введение

Фрагментные шейдеры — это важная часть современной графики на мобильных устройствах, особенно при разработке высокопроизводительных приложений с использованием Flutter. В данной лекции мы рассмотрим, что такое фрагментные шейдеры, как они работают, как загружать и использовать их в Flutter-приложениях, а также научимся передавать параметры из виджетов в шейдер и создавать динамический эффект — круг, плавно меняющий цвет с течением времени.

---

## 1. Что такое фрагментные шейдеры и как они работают?

### Определение

Фрагментный шейдер (Fragment Shader) — это программа на языке GLSL (OpenGL Shading Language), которая выполняется на графическом процессоре (GPU). Он отвечает за вычисление цвета каждого пикселя рисуемого объекта.

В Flutter фрагментные шейдеры используются через класс `CustomPaint` и `CustomPainter`, позволяя создавать сложные визуальные эффекты, которые невозможно реализовать с помощью обычных виджетов.

### Принцип работы

Когда вы отрисовываете что-либо в Flutter через `CustomPaint`, система использует **OpenGL** или **Metal / DirectX** (в зависимости от платформы) для рендеринга. Фрагментный шейдер выполняется для каждого пикселя, который попадает в область рисования.

Формально:
- Каждый пиксель имеет свои координаты.
- Шейдер получает информацию о положении пикселя и может изменять его цвет в зависимости от заданных правил.
- Результат — это пиксельный цвет, который отображается на экране.

Примерная последовательность:
1. Система рендерит виджет `CustomPaint`.
2. Выполняется `CustomPainter.paint(...)`.
3. Если в `paint(...)` передан `Shader`, то вызывается фрагментный шейдер.
4. Для каждого пикселя выполняется код шейдера, определяющий цвет.

## 2. Загрузка и использование шейдеров во Flutter-приложении

### Как использовать шейдеры в Flutter?

Для использования фрагментных шейдеров в Flutter нужно:

1. Создать `CustomPainter`.
2. В методе `paint(...)` использовать `Canvas.drawPaint(...)` с передачей `Paint()` с заданным `Shader`.

Flutter поддерживает два типа шейдеров:
- `ui.Gradient` — градиентные шейдеры (простые).
- `ui.Shader` — пользовательские шейдеры (сложные), создаваемые из GLSL.

### Пример: Использование простого градиента

```dart
class GradientPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()
      ..shader = LinearGradient(
        begin: Alignment.topLeft,
        end: Alignment.bottomRight,
        colors: [Colors.red, Colors.blue],
      ).createShader(Rect.fromLTWH(0, 0, size.width, size.height));

    canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height), paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}
```

### Пример: Использование пользовательского шейдера

Для создания пользовательского шейдера нужно написать GLSL-код и передать его в `ui.Shader`. В Flutter для этого есть метод `ui.shaderFromAsset()` или `ui.shaderFromString()`.

```dart
class CustomShaderPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final shader = ui.shaderFromString(
      '''
        precision mediump float;
        uniform vec2 resolution;
        uniform float time;

        void main() {
          vec2 uv = gl_FragCoord.xy / resolution.xy;
          vec3 color = vec3(uv.x, uv.y, 0.5 + 0.5 * sin(time));
          gl_FragColor = vec4(color, 1.0);
        }
      ''',
      [const ui.ShaderStage.fragment],
    );

    final paint = Paint()
      ..shader = shader
      ..blendMode = BlendMode.src;

    canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height), paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => true;
}
```

> **Важно**: `ui.shaderFromString()` работает только в режиме debug и не будет работать в production. Для production используйте `shaderFromAsset`.

## 3. Передача параметров из Flutter-виджета в шейдер

Чтобы передать данные из Flutter-виджета в шейдер, нужно использовать `Uniform` переменные.

### Что такое Uniform?

Uniform — это переменная, которая не меняется при рендеринге одного фрагмента, но может быть изменена между кадрами. В шейдере они объявляются так:

```glsl
uniform float time;
uniform vec2 resolution;
```

### Пример передачи времени и размера экрана

```dart
class ShaderWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return CustomPaint(
      painter: ShaderPainter(),
      size: Size.infinite,
    );
  }
}

class ShaderPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final shader = ui.shaderFromString(
      '''
        precision mediump float;
        uniform vec2 resolution;
        uniform float time;

        void main() {
          vec2 uv = gl_FragCoord.xy / resolution.xy;
          float color = 0.5 + 0.5 * sin(time + uv.x * 10.0);
          gl_FragColor = vec4(color, color, color, 1.0);
        }
      ''',
      [const ui.ShaderStage.fragment],
    );

    final paint = Paint()
      ..shader = shader
      ..blendMode = BlendMode.src;

    canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height), paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => true;
}
```

### Передача через `Shader` и `ui.ShaderParameter`

В реальных приложениях для динамической передачи значений (например, времени) лучше использовать `ShaderParameter`.

```dart
final shader = ui.shaderFromString(
  '''
    precision mediump float;
    uniform vec2 resolution;
    uniform float time;
    void main() {
      vec2 uv = gl_FragCoord.xy / resolution.xy;
      float color = sin(time + uv.x * 10.0);
      gl_FragColor = vec4(color, color, color, 1.0);
    }
  ''',
  [const ui.ShaderStage.fragment],
);

final paint = Paint()
  ..shader = shader
  ..blendMode = BlendMode.src;
```

> Важно: `ShaderParameter` не поддерживается напрямую в Flutter. Для работы с динамическими значениями используйте `CustomPainter`, обновляя его через `setState()` и перерисовку.

## 4. Как сделать фрагментный шейдер, рисующий круг, который плавно меняет свой цвет в течение времени?

### Цель:
Создать круг, который появляется на экране, и его цвет меняется с течением времени.

### Шаги:

1. Определим координаты пикселя.
2. Проверим, находится ли он внутри круга.
3. Если да — меняем цвет в зависимости от времени.

### GLSL-код

```glsl
precision mediump float;
uniform vec2 resolution;
uniform float time;

void main() {
  vec2 uv = gl_FragCoord.xy / resolution.xy;
  vec2 center = vec2(0.5, 0.5);
  float distance = length(uv - center);

  // Рисуем круг
  if (distance < 0.3) {
    float color = 0.5 + 0.5 * sin(time);
    gl_FragColor = vec4(color, 1.0 - color, 0.5, 1.0);
  } else {
    gl_FragColor = vec4(0.0, 0.0, 0.0, 1.0); // фон
  }
}
```

### Полный Dart-код

```dart
class AnimatedCirclePainter extends CustomPainter {
  final double time;

  AnimatedCirclePainter(this.time);

  @override
  void paint(Canvas canvas, Size size) {
    final shader = ui.shaderFromString(
      '''
        precision mediump float;
        uniform vec2 resolution;
        uniform float time;

        void main() {
          vec2 uv = gl_FragCoord.xy / resolution.xy;
          vec2 center = vec2(0.5, 0.5);
          float distance = length(uv - center);

          if (distance < 0.3) {
            float color = 0.5 + 0.5 * sin(time);
            gl_FragColor = vec4(color, 1.0 - color, 0.5, 1.0);
          } else {
            gl_FragColor = vec4(0.0, 0.0, 0.0, 1.0);
          }
        }
      ''',
      [const ui.ShaderStage.fragment],
    );

    final paint = Paint()
      ..shader = shader
      ..blendMode = BlendMode.src;

    canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height), paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => true;
}
```

### Использование

```dart
class MyHomePage extends StatefulWidget {
  @override
  _MyHomePageState createState() => _MyHomePageState();
}

class _MyHomePageState extends State<MyHomePage> with TickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: Duration(seconds: 10),
      vsync: this,
    )..repeat();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: AnimatedBuilder(
        animation: _controller,
        builder: (context, child) {
          return CustomPaint(
            painter: AnimatedCirclePainter(_controller.value * 10),
            size: Size.infinite,
          );
        },
      ),
    );
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }
}
```
