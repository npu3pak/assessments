# Лекция: Основы Bash для Flutter-разработчика

## Введение в Bash

**Bash (Bourne Again Shell)** — это оболочка командной строки, которая используется в операционных системах Linux и macOS. Bash предоставляет интерфейс для взаимодействия с операционной системой через текстовые команды. Он является стандартной оболочкой для большинства Linux-систем и важной частью разработки на Flutter, особенно при работе с CLI-инструментами.

### Аналоги Bash
- **Zsh** — более мощная и гибкая оболочка, чем bash.
- **Fish** — упрощённая и дружелюбная оболочка с автоматическим автозавершением.
- **PowerShell** — используется в Windows, но также доступен в Linux/macOS.

### Hashbang (Shebang)
Hashbang — это специальный символ `#!`, который указывает интерпретатору, какую программу использовать для выполнения скрипта. Например:

```bash
#!/bin/bash
echo "Hello, World!"
```

Когда вы запускаете скрипт с таким hashbang, система знает, что нужно использовать bash для его выполнения.

## Получение помощи. Команда man

Для получения справки по командам используется команда `man` (от *manual*). Например:

```bash
man ls
```

Откроется руководство по команде `ls`. Вы можете использовать стрелки вверх/вниз для прокрутки, `q` — чтобы выйти.

## Навигация по файловой системе

### Основные команды:
- `pwd` — показывает текущую директорию.
- `ls` — показывает содержимое каталога.
  - `ls -l` — подробный список с правами доступа.
  - `ls -a` — показать скрытые файлы.
- `cd` — изменить директорию.
  - `cd ..` — перейти на уровень выше.
  - `cd ~` — перейти в домашнюю директорию.
  - `cd /` — перейти в корневую директорию.

Пример:
```bash
$ pwd
/home/user

$ ls -la
total 20
drwxr-xr-x 3 user user 4096 Apr 5 10:00 .
drwxr-xr-x 5 user user 4096 Apr 5 09:00 ..
-rw-r--r-- 1 user user   24 Apr 5 10:00 file.txt
```

## Запись результатов выполнения команд в файл

### stdout и stderr
- **stdout** (standard output) — стандартный поток вывода.
- **stderr** (standard error) — поток ошибок.

Пример:
```bash
ls /nonexistent > output.txt 2> error.txt
```

Здесь:
- `>` перенаправляет stdout в файл `output.txt`.
- `2>` перенаправляет stderr в файл `error.txt`.

Если вы хотите перенаправить оба потока:
```bash
ls /nonexistent &> all_output.txt
```

## Создание каталогов и файлов

### Создание каталогов:
```bash
mkdir my_folder
mkdir -p folder1/folder2/subfolder
```

### Создание файлов:
```bash
touch new_file.txt
```

Если файл уже существует, `touch` обновит его время модификации.

## Просмотр каталогов и файлов

### Команды:
- `cat` — вывод содержимого файла.
  ```bash
  cat file.txt
  ```

- `tail` — показывает последние строки файла.
  ```bash
  tail -n 10 file.txt  # последние 10 строк
  tail -f file.txt     # отслеживает изменения в файле (полезно для логов)
  ```

## Разрешения. chmod

Команда `chmod` позволяет изменять права доступа к файлам и папкам.

Пример:
```bash
chmod 755 script.sh
```

Число 755 — это восьмеричное представление прав:
- 7 — чтение (4) + запись (2) + выполнение (1)
- 5 — чтение (4) + выполнение (1)
- 5 — чтение (4) + выполнение (1)

Символическая запись:
```bash
chmod u+x script.sh   # добавить право выполнения для пользователя
chmod a-w file.txt    # удалить право записи для всех
```

## Суперпользователь. sudo

Команда `sudo` позволяет выполнять команды от имени суперпользователя (root).

Пример:
```bash
sudo apt update
```

Важно: не рекомендуется использовать `sudo` для повседневных задач.

## Фильтрация вывода. grep

Команда `grep` используется для поиска строк в тексте.

Пример:
```bash
cat log.txt | grep "error"
```

Или поиск по файлам:
```bash
grep -r "TODO" .
```

Флаги:
- `-i` — игнорировать регистр.
- `-n` — показать номера строк.
- `-v` — показать строки, не содержащие шаблон.

## Поиск и остановка запущенных процессов. ps, kill

### Просмотр процессов:
```bash
ps aux | grep flutter
```

Команда `ps` выводит информацию о запущенных процессах.

### Остановка процесса:
```bash
kill PID
```

Или:
```bash
kill -9 PID  # принудительное завершение
```

Чтобы получить PID:
```bash
pgrep flutter
```

## Команда echo

Команда `echo` выводит текст в консоль.

Пример:
```bash
echo "Hello, Flutter Developer!"
```

Можно использовать переменные:
```bash
name="Flutter"
echo "Welcome to $name development!"
```

## Условный оператор

В Bash можно использовать условные конструкции:

```bash
if [ "$USER" = "root" ]; then
  echo "You are root"
else
  echo "You are not root"
fi
```

### Операторы сравнения:
- `[ ]` — проверка условия.
- `=` — равно.
- `!=` — не равно.
- `-f file` — файл существует.
- `-d dir` — директория существует.

## Цикл for

Циклы позволяют выполнять команды несколько раз:

```bash
for i in 1 2 3 4; do
  echo "Number: $i"
done
```

Также можно использовать диапазоны:
```bash
for i in {1..5}; do
  echo "Count: $i"
done
```

---

## Функции

Функции позволяют группировать команды и повторно использовать их:

```bash
my_function() {
  echo "Hello from function!"
  ls -la
}

# Вызов функции
my_function
```

Можно передавать аргументы:
```bash
greet_user() {
  echo "Hello, $1!"
}

greet_user "Flutter Developer"
```
