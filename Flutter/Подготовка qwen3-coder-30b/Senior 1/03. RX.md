## Введение в Reactive Programming (RX)

**Реактивное программирование (Reactive Programming)** — это парадигма программирования, ориентированная на асинхронную обработку потоков данных и событий. Основной принцип заключается в том, что программа реагирует на изменения в источниках данных (например, пользовательские действия, сетевые запросы, таймеры) и автоматически обновляет соответствующие части интерфейса или логики.

### Почему Rx?

В мире мобильной разработки (особенно с использованием Flutter), где важны реактивные обновления интерфейса и управление асинхронными операциями, Rx помогает:

- Легко обрабатывать асинхронные данные (HTTP-запросы, таймеры, пользовательские действия).
- Упрощать логику взаимодействия между частями приложения.
- Снижать количество "callback hell" и управлять сложными цепочками событий.

Flutter использует **RxDart** — библиотеку для реактивного программирования на Dart. Она предоставляет все ключевые элементы RX: `Observable`, `Stream`, `Subject`, операции (`map`, `filter`, `flatMap` и т.д.).

## 1. Основные концепции Rx

### Что такое Observable?

**Observable (наблюдаемый)** — это объект, который может производить поток данных. Он может:

- Выдать одно или несколько значений.
- Сгенерировать ошибку.
- Завершиться.

Пример: `Stream` в Dart — это реализация Observable из Rx.

```dart
final observable = Stream.fromIterable([1, 2, 3]);
observable.listen((value) => print(value)); // Выведет 1, 2, 3
```

### Что такое Single?

**Single** — это особый тип Observable, который **возвращает только одно значение** или одну ошибку.

Используется, например, для HTTP-запросов:

```dart
final single = http.get(Uri.parse('https://api.example.com/data'));
single.then((response) => print(response.body));
```

В RxDart `Single` — это специальный класс, который гарантирует, что будет вызван `onSuccess` или `onError`.

## 2. Subject

**Subject** — это особый тип Observable, который позволяет:

- Подписываться на него (`listen()`).
- Иметь возможность отправлять данные вручную через `add()` или `addError()`.

Есть несколько типов Subject:

### BehaviorSubject

Содержит последнее значение и при новой подписке сразу отправляет его.

```dart
final subject = BehaviorSubject<String>();
subject.add('Hello');
subject.listen(print); // Выведет 'Hello'
subject.add('World');  // Выведет 'World'
```

### PublishSubject

Не хранит значения. Только новые данные, которые поступают после подписки.

```dart
final subject = PublishSubject<String>();
subject.listen(print); // Ничего не выведет
subject.add('Hello');  // Теперь выведет 'Hello'
```

### ReplaySubject

Хранит последние N значений и при новой подписке отправляет их.

```dart
final subject = ReplaySubject<String>(capacity: 2);
subject.add('A');
subject.add('B');
subject.add('C');
subject.listen(print); // Выведет 'B', 'C'
```

## 3. Schedulers (Планировщики)

**Scheduler** — это механизм, управляющий выполнением операций в потоках.

Например:

```dart
import 'package:rxdart/rxdart.dart';

final observable = Observable.fromIterable([1, 2, 3]);
observable
  .observeOn(Schedulers.async) // Выполняется асинхронно (в отдельном потоке)
  .subscribe(print);
```

**Важные Schedulers:**

- `Schedulers.immediate` — выполнение в текущем потоке.
- `Schedulers.async` — выполнение в фоновом потоке.
- `Schedulers.microtask` — выполнение через microtask.

## 4. Основные операции Rx

### 1. map

Преобразует каждый элемент потока.

```dart
final observable = Observable.fromIterable([1, 2, 3]);
observable.map((x) => x * 2).listen(print); // Выведет: 2, 4, 6
```

### 2. filter

Фильтрует элементы по условию.

```dart
final observable = Observable.fromIterable([1, 2, 3, 4, 5]);
observable.filter((x) => x % 2 == 0).listen(print); // Выведет: 2, 4
```

### 3. merge

Объединяет несколько потоков в один.

```dart
final stream1 = Observable.fromIterable([1, 2]);
final stream2 = Observable.fromIterable([3, 4]);
Observable.merge([stream1, stream2]).listen(print); // Выведет: 1, 2, 3, 4
```

### 4. zip

Соединяет элементы из разных потоков по позициям.

```dart
final stream1 = Observable.fromIterable([1, 2]);
final stream2 = Observable.fromIterable(['a', 'b']);
Observable.zip2(stream1, stream2, (x, y) => '$x-$y').listen(print); // Выведет: "1-a", "2-b"
```

### 5. subscribe

Подписка на поток.

```dart
final observable = Observable.fromIterable([1, 2, 3]);
observable.subscribe(
  (data) => print('Data: $data'),
  onError: (error) => print('Error: $error'),
  onDone: () => print('Completed'),
);
```

### 6. flatMap

Преобразует каждый элемент в Observable и "сглаживает" результат.

```dart
final observable = Observable.fromIterable([1, 2]);
observable.flatMap((x) => Observable.fromIterable([x, x * 2]))
    .listen(print); // Выведет: 1, 2, 2, 4
```

### 7. scan

Аналог `reduce`, но возвращает промежуточные результаты.

```dart
final observable = Observable.fromIterable([1, 2, 3]);
observable.scan((acc, x) => acc + x, 0).listen(print); // Выведет: 1, 3, 6
```

### 8. distinct

Отфильтровывает повторяющиеся значения.

```dart
final observable = Observable.fromIterable([1, 2, 2, 3]);
observable.distinct().listen(print); // Выведет: 1, 2, 3
```

## 5. Практическое применение в Flutter

Пример: загрузка данных из API с обработкой ошибок и отображением прогресса.

```dart
class ApiService {
  static Future<String> fetchUser() async {
    await Future.delayed(Duration(seconds: 1));
    return 'John Doe';
  }
}

final userStream = Observable.fromFuture(ApiService.fetchUser())
    .map((name) => 'Hello, $name!')
    .onErrorReturn('Failed to load user')
    .startWith('Loading...');

userStream.listen(print);
```
