# Лекция: Flutter. Isolates

## Введение

В мире мобильной разработки, особенно при использовании Flutter, важно понимать, как работает архитектура приложения и как управлять потоками выполнения. В этой лекции мы рассмотрим **Isolates** — механизм изолированного выполнения кода в Dart-приложениях. Это ключевой элемент для создания высокопроизводительных и стабильных приложений, особенно при работе с тяжелыми задачами.

---

## 1. Что такое Isolates?

### Определение

**Isolate (изолят)** — это независимый поток выполнения в Dart-приложении. Каждый изолят имеет собственную память, стек и даже собственный диспетчер задач. Это означает, что изоляты **не могут напрямую общаться** между собой — они полностью изолированы друг от друга.

### Основные особенности:

- Каждый изолят имеет собственную память (heap), не разделяемую с другими изолятами.
- Изоляты выполняются **независимо**, то есть не могут блокировать другие изоляты или основной поток UI.
- В каждом изолате **не существует совместного доступа к данным** — все данные передаются по значению, либо через межизолятные сообщения.
- Изоляты **не могут использовать `static` переменные** между собой.
- Изоляты могут быть использованы для выполнения тяжелых задач, чтобы не блокировать основной UI-поток.

---

## 2. Отличия Isolates от потоков (Threads)

### Потоки (Threads) в других языках:

В Java или C#, потоки (threads) имеют общую память и могут напрямую взаимодействовать друг с другом. Это дает возможность совместного использования данных, но также ведет к проблемам с синхронизацией, блокировками и гонками.

### Isolates в Dart:

- **Изоляция данных**: каждый изолят имеет свою память.
- **Отсутствие совместного доступа к данным**: нет прямого доступа к переменным другого изолата.
- **Безопасность и стабильность**: если один изолят падает, другие продолжают работать.
- **Синхронизация не требуется**: так как нет общих ресурсов, нет необходимости в `lock`, `mutex` и т.д.

> 💡 Пример: Если вы запускаете тяжелую задачу (например, обработку изображения) в основном потоке, интерфейс блокируется. Если же вы выполните эту задачу в отдельном изолате, UI будет продолжать работать.

## 3. Запуск изолятов

В Dart есть несколько способов запустить изолят:

### 3.1 `Isolate.run()`

Метод `Isolate.run()` позволяет запустить функцию в новом изолате и сразу получить результат.

#### Пример:
```dart
import 'dart:isolate';

void main() {
  Isolate.run(() async {
    // Выполняется в отдельном изолате
    print("Запуск в изолате");
    return "Результат из изолата";
  }).then((result) {
    print(result); // Выведет: Результат из изолата
  });
}
```

> ⚠️ `Isolate.run()` не поддерживает передачу параметров, только возвращаемое значение.

---

### 3.2 `Isolate.spawn()`

Этот метод позволяет запустить **функцию-обработчик** в новом изолате и передать ей параметры.

#### Пример:
```dart
import 'dart:isolate';

void isolateMain(SendPort sendPort) {
  // Обработчик, который будет выполняться в отдельном изолате
  int sum = 0;
  for (int i = 1; i <= 1000000; i++) {
    sum += i;
  }

  // Отправляем результат через SendPort
  sendPort.send(sum);
}

void main() async {
  ReceivePort receivePort = ReceivePort();

  await Isolate.spawn(isolateMain, receivePort.sendPort);

  receivePort.listen((data) {
    print('Результат: $data'); // Выведет: Результат: 500000500000
  });
}
```

> ✅ `Isolate.spawn()` — более гибкий способ запуска изолятов, особенно при необходимости передавать данные.

---

### 3.3 `compute()`

`compute()` — это удобная обертка над `Isolate.spawn()`, используемая в Flutter для выполнения тяжелых задач в фоне, например, в `async/await`.

#### Пример:
```dart
import 'package:flutter/foundation.dart';

int heavyCalculation(int input) {
  int result = 0;
  for (int i = 1; i <= input * 1000000; i++) {
    result += i;
  }
  return result;
}

void main() async {
  final result = await compute(heavyCalculation, 5);
  print("Результат: $result");
}
```

> 💡 `compute()` — идеальный выбор для фоновой обработки данных в Flutter. Он автоматически управляет изолатом, передает данные и возвращает результат.

## 4. Обмен сообщениями между изолятами

### 4.1 Использование `SendPort` и `ReceivePort`

Для общения между изолятами используются `SendPort` и `ReceivePort`.

#### Пример: передача данных и ответа

```dart
import 'dart:isolate';

void worker(SendPort sendPort) {
  // Получаем сообщение через ReceivePort (в данном случае, просто вручную)
  // В реальном приложении обработчик будет получать данные через SendPort
  int result = 10 * 10;
  sendPort.send(result);
}

void main() async {
  ReceivePort receivePort = ReceivePort();
  await Isolate.spawn(worker, receivePort.sendPort);

  // Подписываемся на получение данных из изолата
  receivePort.listen((data) {
    print("Результат из изолата: $data");
  });
}
```

### 4.2 Передача сложных данных

Так как изоляты не могут напрямую обмениваться ссылками, данные передаются по значению.

#### Пример с Map:
```dart
void workerWithMap(SendPort sendPort) {
  Map<String, dynamic> data = {
    'name': 'John',
    'age': 30,
  };

  sendPort.send(data);
}

void main() async {
  ReceivePort receivePort = ReceivePort();
  await Isolate.spawn(workerWithMap, receivePort.sendPort);

  receivePort.listen((data) {
    print("Данные из изолата: $data");
  });
}
```

> ⚠️ Важно: если вы передаёте объекты, они копируются (включая вложенные структуры). Если данные большие — это может быть медленно.

## 5. Когда использовать Isolates?

### Используйте изоляты, когда:

- Вы хотите выполнить тяжелую задачу (например, обработка фото, вычисления) без блокировки UI.
- Нужно параллельно выполнять несколько задач.
- Хотите улучшить производительность и стабильность приложения.

### Не используйте изоляты, когда:

- Вы хотите просто обновлять состояние в UI — для этого нужен `setState()` или `Bloc`.
- Нужно часто передавать данные между потоками — это может быть медленным и неэффективным.

## 6. Пример реального использования: вычисления в фоне

### Задача: обработка массива чисел в фоне

```dart
import 'package:flutter/foundation.dart';

List<int> processNumbers(List<int> numbers) {
  return numbers.map((n) => n * 2).toList();
}

class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Isolates Example')),
      body: Center(
        child: ElevatedButton(
          onPressed: () async {
            List<int> numbers = List.generate(100000, (i) => i);

            // Выполняем в изолате
            final result = await compute(processNumbers, numbers);
            print("Обработано ${result.length} элементов");
          },
          child: Text('Запустить обработку'),
        ),
      ),
    );
  }
}
```
